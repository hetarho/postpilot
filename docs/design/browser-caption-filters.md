# Browser caption filters and glitch

T596 draws blur-in, ambient, neon, iridescent and glitch through cached local ink and bounded Canvas/Pixi effects. `BrowserLocalComponents` keeps the existing layout and transform scene, and derives every effect state from the frozen output frame/time. No text SVG or PNG is generated per output frame and no server raster request is required. The component version is `native-cds-r33-pop-exposure-v2-ground-v1-filters-v1`; the asset identity hashes the exact native painter sources, browser effect/Canvas/Pixi sources and locked Pixi implementation.

Blur-in preserves the native cubic entrance and pivot scale. PixiJS 8.22.0 core BlurFilter uses kernel15/quality4; strength is solved from its tap variance and fractional bilinear sampling variance rather than treating strength as native Gaussian sigma. Ambient composes its two radial ellipses before Gaussian26. Neon renders changing wide and tight glows to cropped owned targets, reuses the wide target for the intentional double merge, then adds the core. Iridescent caches its group SourceAlpha halo and stroke, while moving gradient stops update an authored shader. Glitch keeps deterministic RGB offsets and all six bands; RGB copies precede the bands across all lines, matching the native painter.

Both engines passed 810 transparent-reference cases and 450 controlled bright/dark backdrop cases: all three ratios, steady/rapid paces, rare Hangul substitution, Latin kerning, punctuation, explicit two-line text, entrance/settled/exit boundaries, blur/glow extrema and neon flicker. Layout agrees within 0.001px. The current host renderer regenerated all 1,260 frames, and every retained case input and reference PNG is byte-identical. Controlled backdrop cases use product scrim/geometry drawing but explicitly state `syntheticOnly:true` and `sampledOriginals:false`; T598 independently proves original-only sampling authority.

The maximum intrinsic premultiplied relevant-pixel residuals for Pixi are 1.691% blur-in, 0.271% ambient, 0.419% neon, 0.247% iridescent and 0.966% glitch. Canvas maxima are 1.569%, 0.253%, 0.376%, 0.255% and 0.856%, respectively. Over the controlled backdrops, the largest caption RGB region error is 0.528% Pixi and 0.481% Canvas. These are measured native resvg0.48.1/browser resvg-wasm2.6.2 antialiasing/filter residuals, not a human appearance or final-output qualification. The machine-readable companion identifies each worst frame and preserves raw report hashes.

Final stress runs paint 268 forward/reverse frames per style and evict 72 distinct masks per style. Ten repeated seeks per style have identical frame hashes. Warm movement/effect updates do not rerasterize text. Cancellation releases leases; real WebGL1 refuses by style name; `WEBGL_lose_context` refuses by style name and releases owned scene/cache resources. Shared Pixi filter pools remain renderer-owned and are never cleared by a caption. The isolated diagnostic tags their texture sources to measure scratch allocation; unobserved product scratch is unspecified rather than an invented zero.

Pixi stress peak managed texture lower bounds are 30.64MiB blur-in, 79.00MiB ambient, 81.55MiB neon, 33.35MiB iridescent and 33.22MiB glitch; shared filter scratch peaks are 4.5, 6, 6, 0 and 0.1875MiB. These figures exclude driver/MSAA overhead, JS/font/WASM heaps and process memory. Cold/warm timings in the companion are observations during competing work. The Pixi diagnostic waits with `gl.finish`; Canvas draws may finish asynchronously, so these values do not establish a faster engine or product throughput.
