### 0.2 디자인 원칙 (P1~P7) — 각 원칙이 광고주 채택에 기여하는 방식

| # | 원칙 | 광고주 채택 기여 | 근거 |
|---|---|---|---|
| **P1** | **정보 우선(Information first)**: 모든 클립은 상호·위치·가격·메뉴 중 최소 2개를 화면 텍스트로 노출한다. | 광고주가 원하는 "검색되고 구매로 이어지는 후기"의 최소 조건. 정보 태그·인증 마크와 맞물려 신뢰도 상승. | F2, F3 |
| **P2** | **UI 무침범(Zero overlap)**: 자막·카드·배지는 §1 안전영역 밖으로 1px도 나가지 않는다. | 제품명·문구가 버튼에 가리는 것은 브랜드 콘텐츠에서 치명적 실수로 간주됨. | F7 |
| **P3** | **무음 가독성(Silent-first)**: 모든 텍스트는 48px 이상, 대비 4.5:1 이상, 글자수 대비 최소 노출 시간을 지킨다. | 홈피드·무음 시청에서도 메시지가 전달되어야 완주율·정보 전달력이 확보됨. | F2, F8, F10 |
| **P4** | **절제된 모션(Restraint)**: 페이드·8px 슬라이드 이외의 모션 금지. 글자 단위 팝, 회전, 바운스 금지. | "AI 템플릿 티"와 밈형 톤을 제거해 브랜드 세이프티 인상을 준다. 절제된 톤은 카테고리 간 일관성도 보장. | F4 |
| **P5** | **투명한 표기(Disclosure by default)**: 광고·협찬 표기 배지를 첫 컷·마지막 컷에 의무, 전 구간 상시를 기본값으로. | 표기 누락은 광고주의 법적 리스크. "표기를 알아서 챗기는 크리에이터"가 채택된다. | F4, F5 |
| **P6** | **현장감 보존(Authenticity)**: 원본 오디오 유지, 장식 그래픽·스티커·이모지 금지, 문장은 1인칭·경험형. | 직접 경험이 드러나는 채널이 오래 가고 브랜드가 선호한다. | F4 |
| **P7** | **결정 가능성(Deterministic)**: 모든 배치·스타일 선택은 규칙표(§5)로 결정되고, 같은 입력은 같은 출력을 낸다. | 광고주는 "이 크리에이터의 다음 영상도 이 품질일 것"이라는 예측 가능성을 산다. | 제품 제약, F3 |

### 0.3 광고주가 싫어하는 것 — 피해야 할 디자인 패턴 (Anti-patterns)

| 금지 패턴 | 이유 | 근거 |
|---|---|---|
| 자막을 캔버스 하단 0~420px에 배치 | 제목·설명·태그·음악 UI에 가려 문구가 사라짐 | F7 |
| 우측 160px 안에 텍스트·로고 | 좋아요·댓글·공유 버튼과 겹침 | F7 |
| 광고 표기가 없거나 40px 미만, 배경과 유사한 색 | 공정위 지침 위반 → 광고주 법적 리스크 | F5 |
| 타 플랫폼 워터마크, 앱 로고, "Made with ○○" | 노출 제한 및 "재업로드/AI 티" 신호 | F6, F4 |
| 글자 단위 팝업·바운스·회전, 화려한 트랜지션(와이프·줌 블러) | 밈형·AI 템플릿 인상, 브랜드 톤과 충돌 | F4 |
| 이모지·스티커·과한 강조색 남용 | 정보형 후기의 신뢰감 저하 | F3, F4 |
| 자동 배경음악 삽입 | 저작권 리스크(광고주가 가장 민감), 현장음 손실 | F6, P6 |
| 3줄 이상 자막, 한 화면 40자 초과 | 무음 시청에서 읽히지 않음 | F10, P3 |
| 정보 없는 감상형 카피만 있는 영상("너무 맛있어요!") | 검색·전환에 기여하지 않음 | F2, F3 |
| 잘못된 상호·가격 (오탈자·환각) | 광고주 신뢰 즉시 상실. AI 생성 카피는 사용자 입력값 외의 숫자·고유명사를 만들지 않는다. | F4, P7 |

## 1. 안전 영역 (비율 3종)

### 1.1 네이버 클립 9:16 UI 오버레이 geometry (추정)

공식 가이드가 없으므로(F6) 아래는 **2026-09 기준 네이버 앱 클립 탭 세로 피드 스크린샷 관찰 + 타 플랫폼 공개 수치(F7) + 클립 고유 요소(정보 태그 칩, F2)** 를 합쳐 추정한 값이다. 1080×1920 캔버스로 정규화했다. 신뢰도는 각 행에 표기.

| UI 요소 | 추정 영역 (x, y, w, h) | 근거·추정 방법 | 신뢰도 |
|---|---|---|---|
| 상태바 + 상단 탭(추천·인기·스팟·구독) + 검색 아이콘 | (0, 0, 1080, **230**) | 릴스 108~250·틱톡 130 사이. 클립은 탭이 4개로 한 줄 텍스트 탭 + 상태바. 노치 기기 상태바 ~130 + 탭 ~100. | 중 |

### 1.4 16:9 · 1:1 안전영역

네이버 클립에서 16:9·1:1이 어떻게 보이는지는 공개 자료가 없어 **추정(신뢰도 하~중)** 이다.
- 16:9: F1에 따라 클립은 가로 롱폼을 PC 업로드로 받는다. 세로 피드에 노출될 때는 **검은 배경 위 레터박스(가로폭 맞춤, 세로 중앙)** 로 표시된다고 추정(타 플랫폼 관행·네이버TV 이관 콘텐츠의 성격상). 이때 영상 자체 높이는 1080×(1080/1920)=**607px 상당**이며, 하단 UI 블록과 겹치지 않는다. 즉 16:9는 **자기 캔버스 안에서만** 안전영역을 지키면 된다.
- 1:1: 공식 지원 언급 없음. 업로드되면 세로 피드에서 **상하 레터박스(검정 또는 블러)** 로 중앙 표시된다고 추정. 정방형은 하단 UI(y≥1440 상당)에 걸리지 않는다.

| 비율 | 캔버스 | 안전영역 (x, y, w, h) | 근거 |
|---|---|---|---|
| 9:16 | 1080×1920 | (64, 250, 856, 1170) | §1.2 SA-C |
| 16:9 | 1920×1080 | (**96, 72, 1728, 936**) | 좌우 5%·상하 6.7%의 방송형 타이틀 세이프(액션세이프 10%/타이틀세이프 5% 관행 절충). UI 겹침 없음(추정). 블로그·PC 플레이어 컨트롤바(하단 ~72px) 고려. |
| 1:1 | 1080×1080 | (**64, 72, 952, 936**) | 좌우 64(릴스 관행), 상하 72(피드 카드 모서리 라운드·크롭 대비). |

## 3. 자막(카피) 스타일 카탈로그

### 3.1 결정: 3종 → **4종** (2종 수정 유지, 1종 교체, 1종 추가)

| 현재 | 결정 | 최종 이름(사용자 노출) | 이유 |
|---|---|---|---|
| 깔끔하게 (박스 54/600) | **수정 유지** | **깔끔하게** | 가장 안전한 기본형. 크기 56/700으로 상향(P3), 패딩·라운드 토큰화 |
| 기록처럼 (크림 라벨 44/600) | **수정 유지** | **메모** | 정보(가격·시간·위치) 전달용으로 역할을 명확화. 좌측 정렬 허용 |
| 강조형 (흰 글자+8px 외곽선 76/800) | **교체** | **크게 강조** | 8px 외곽선은 밈형·"AI 템플릿" 인상(F4). 6px 스트로크+그림자+선택적 스크림으로 절제. 72px |
| — | **추가** | **형광펜** | 광고주가 원하는 "숫자·핵심어 하나만 튀는" 정보형 강조(P1). 전체 플레이트 없이 키워드만 강조하므로 화면 점유 최소 |

**왜 4종인가**: 사용자는 디자이너가 아니므로 선택지는 "역할"로 구분되어야 헷갈리지 않는다. 4종은 각각 *기본(깔끔) / 정보(메모) / 감정 강조(크게) / 숫자 강조(형광펜)* 로 역할이 겹치지 않는다. 5종 이상이면 역할 중복이 생기고, 3종이면 정보형 강조가 빠진다(P1·P7).

### 3.2 공통 규칙

- 폰트: Pretendard Variable (스타일 3 '크게 강조'는 Paperlogy 허용 — §3.5)
- 최대 **2줄**, 어절 단위 자동 줄바꿈. 2줄을 넘으면 AI가 문장을 줄인다(§5.3).
- 등장 모션 **[A]**: opacity 0→1 **180ms** + Y +12px→0, 이징 `cubic-bezier(0.22, 1, 0.36, 1)`. ffmpeg 구현: 플레이트 PNG(알파)에 `fade=t=in:st={T0}:d=0.18:alpha=1`, overlay y식 `y='{Y0}+12*pow(1-min(1,(t-{T0})/0.18),3)'`.
- 퇴장 모션 **[A]**: opacity 1→0 **120ms**, 이동 없음. `fade=t=out:st={T1-0.12}:d=0.12:alpha=1`.
- 위 두 모션 외 모션 금지(P4). 글자 단위 등장·타이프라이터·카운트업 **[B]** 는 채택하지 않음(근거: F4 — 브랜드 톤 안정성이 채택률에 더 기여).
- 강조색: 프로젝트 1개 고정(현행). 스타일별 적용 방식은 아래.

## 5. AI 배치·선택 규칙

모든 규칙은 **결정론적**(P7). 입력: 컷 메타데이터(장면 유형, 피사체 바운딩박스, 밝기 맵), 자막 문장, 사용자 입력(상호·위치·가격·메뉴·카테고리·체험단 유형·강조색).

### 5.1 위치 선택 규칙

앵커 후보: `TOP`, `UPPER_MID`, `LOWER_MID`, `BOTTOM` × 가로 `CENTER`, `LEFT`, `RIGHT`. 9분할을 **채택하지 않고** 위 4×3 = 12 조합 중 스타일별 허용 조합만 사용한다(9분할은 미묘한 위치 차이로 일관성이 깨짐, P7).

**입력**: 컷의 주 피사체 bbox `S=(sx, sy, sw, sh)` (없으면 null). 피사체 = 음식·제품·간판·메뉴판·얼굴 순 우선순위로 검출된 1개.

**결정 절차(순서대로 첫 성립 조건 채택)**:
1. 스타일이 `메모`이면 후보 = {TOP/LEFT, BOTTOM/LEFT}. 그 외 후보 = 스타일 기본 앵커 → 대체 앵커 순(§3 각 표).
2. 각 후보의 플레이트 예상 영역 `R`을 계산(텍스트 폭 측정 + 패딩). `R ⊄ SA-C`이면 후보 제거.
3. 이미 배치된 다른 컴포넌트(정보 칩, 광고 배지, 훅/엔딩 카드)와 `R`이 겹치면 후보 제거. 단 광고 배지와 겹치면 **자막이 양보**(배지는 고정).
4. `S`가 있으면 `IoU(R, S)`를 계산해 **겹침 면적이 S 면적의 15% 이하**인 후보 중 우선순위가 가장 높은 것 채택. 전부 15%를 넘으면 겹침이 가장 작은 후보 채택.
5. `S`가 null이면 스타일 기본 앵커.
6. **간판·메뉴판 컷**(OCR로 텍스트가 검출된 컷)은 자막을 `UPPER_MID/LOWER_MID`에 두지 않고 TOP 또는 BOTTOM 중 `S`와 먼 쪽만 허용(원본 텍스트와 조판 텍스트가 나란히 놓여 "합성 티"가 나는 것을 막음, F4).
7. 한 영상 안에서 연속 컷의 자막 앵커는 **최대 1단계**만 이동(BOTTOM→LOWER_MID 허용, BOTTOM→TOP 직접 점프 금지). 시선 점프를 줄여 정갈함 유지(P4). 예외: 규칙 6.

### 5.2 스타일 선택 규칙 (장면 유형 × 문장 유형 → 스타일)

문장 유형 판정(우선순위 순):
- `NUM`: 아라비아 숫자 + 단위(원, 분, 인, %, 개, 시, 배) 1개 이상
- `HOOK`: 문장 끝 `?`/`!`, 또는 훅 어휘("이유", "비밀", "진짜", "솔직히", "결론", "이거") 포함, 11자 이하
- `FACT`: 위치·시간·메뉴명 등 명사 위주 15자 이하
- `DESC`: 그 외 서술형

| 장면 유형 \ 문장 | NUM (1개) | HOOK | FACT | DESC |
|---|---|---|---|---|
| 음식 클로즈업 | 형광펜 | 크게 강조 | 메모 | 깔끔하게 |
| 매장 외관·간판 | 메모 | 크게 강조 | 메모 | 깔끔하게 |
| 매장 내부·분위기 | 형광펜 | 크게 강조 | 메모 | 깔끔하게 |
| 메뉴판·가격표 | 메모(TOP/BOTTOM만) | 깔끔하게 | 메모 | 깔끔하게 |
| 사람·얼굴 | 깔끔하게 | 크게 강조 | 깔끔하게 | 깔끔하게 |
| 제품 언박싱·디테일 | 형광펜 | 크게 강조 | 메모 | 깔끔하게 |
| 풍경·이동 | 깔끔하게 | 크게 강조 | 메모 | 깔끔하게 |

추가 제약:
- `크게 강조`는 영상당 **최대 2회**, 첫 사용은 컷 1~2에서만(훅 역할). 초과 시 `깔끔하게`로 폴백.
- `형광펜`은 숫자·키워드가 **정확히 1개**일 때만. 2개 이상이면 `메모`.
- `NUM` 문장의 숫자는 **사용자 입력값(가격·인원·시간)에 있는 숫자만** 사용 가능. AI가 새 숫자를 만들면 생성 실패로 처리하고 문장을 재생성.
- 연속 컷에서 같은 스타일 3회 초과 시 4번째는 `깔끔하게`↔`메모` 사이에서만 교대(톤 유지).

### 5.3 자막 길이·노출 시간 규칙

- 최소 노출 `D_min(ms) = 900 + 90 × (한글 글자수, 공백·기호 제외)`. 예: 12자 → 1,980ms, 20자 → 2,700ms. (표준 자막 관행 "1초 이상 + 글자수 비례", F10)
- 최대 노출 = 컷 길이 − 240ms(in/out 여백). `D_min`이 이를 넘으면 (a) 문장을 줄여 재생성 → (b) 컷을 `D_min+240ms`까지 연장(원본 여유 있을 때) → (c) 자막 생략, 순서로 처리.
- 컷 길이 대비 자막 점유율: 1개 자막은 컷의 **60~100%** 구간을 점유(짧게 깜빡이지 않음).
- 글자수 상한: 스타일 표(§3) 준수. AI 생성 프롬프트에 상한을 하드 제약으로 전달하고, 초과 시 재생성 최대 2회 후 `깔끔하게` 2줄로 축약.
- 문장 톤: 1인칭 경험형, 이모지·"ㅋㅋ"·"ㄹㅇ" 금지, 과장 최상급("최고", "역대급") 금지(광고 심의·과장광고 리스크), 사용자 입력에 없는 고유명사·숫자 금지(P6, F4).

### 5.4 컷당 자막 개수

- 기본 **1개**(현행 유지).
- 컷 길이 **≥ 4.0s**이고 문장 유형이 `DESC`+`NUM` 조합으로 자연스럽게 분리될 때만 **2개 순차**(첫 자막 종료 후 120ms 간격 → 두 번째 등장). 동시 표시는 불가(정보 칩·배지는 자막으로 세지 않음).
- 근거: 시청자가 한 화면에서 읽을 수 있는 텍스트 양(P3), 그리고 정보 밀도(P1)를 컷을 늘리지 않고 확보.

### 5.5 색상 대비 자동 판단

- 필요한가: **플레이트 없는 스타일(크게 강조·형광펜)과 스크림 결정에만 필요.** 플레이트 스타일은 α0.72 이상 배경으로 최악 케이스 대비가 보장되어 불필요(§2.1).
- 방법 **[A]**: 자막 노출 구간의 첫·중간·마지막 프레임 3장을 추출(`ffmpeg -ss … -frames:v 1`), 플레이트 예상 영역 `R`을 크롭해 **평균 상대휘도 L**(0~1, Rec.709)과 **표준편차 σ**를 계산(`signalstats` 또는 PIL). 3프레임 평균 사용.
- 규칙: `L ≥ 0.6` → 스크림 추가. `σ ≥ 0.25`(복잡한 배경) → 스크림 추가. 둘 다 아니면 스트로크+그림자만.
- 강조색 글자(크게 강조 키워드)는 스크림 유무와 무관하게 `L ≥ 0.6`이면 **흰색으로 대체**(lime·amber가 밝은 배경에서 3:1 미달).
- 모든 최종 조합은 §9.1 대비 계산기로 4.5:1 미만 시 자동으로 `깔끔하게`로 폴백.

### 5.6 컴포넌트 배치 순서(우선순위)

1. 광고 배지(고정, 양보 없음) → 2. 훅/엔딩 카드(해당 구간) → 3. 정보 칩(TOP/LEFT, 최대 2) → 4. 자막(§5.1) → 5. 스크림(자막에 종속).
- 훅 카드 노출 중(0~1.5s)에는 자막·정보 칩 표시 안 함. 엔딩 카드 노출 중에는 자막 표시 안 함(칩은 카드에 통합).
