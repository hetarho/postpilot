- B1 [?] P1 `backend/internal/billing/subscription.go:146` `lapseCancelled`: bug: the expiry/cancellation branch upserts the complete `DueSubscriptions` snapshot without re-reading the current subscription, checking its `UpdatedAt`/term/status or checking a pending renewal. ## Auth concerns — read-only source analysis for root assessment

- `auth/service.go:271,448` ResetPassword consumes a one-use link, replaces password and deletes sessions as independent store statements. Failures can burn the link or change the credential while leaving sessions live. `Login:501–526` verifies a read password snapshot and creates its session without a current-credential predicate; a verification started before reset can issue a new old-password-derived session after reset completed. Review as an auth concurrency/recovery defect under AUTH-4/ARCH-10.

Root to assess source references and operator-account reachability. No further auth execution planned.
