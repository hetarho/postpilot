# 자막 스타일 15종 — 실제 렌더 결과

프로덕션 이미지(`postpilot:gate-runtime`)에서 꺼낸 resvg 0.48.1과 ffmpeg 9.0.1로 렌더했다.
웹 미리보기가 아니라 실제 출력 프레임이므로, 여기 보이는 조합은 지금 파이프라인으로 만들 수 있다.

- `caption-styles.mp4` — 15종을 3.2초씩 이어 붙인 48.0초 세로 영상 (1080x1920, 30fps)
- `stills/` — 각 스타일의 대표 프레임
- `fonts/` — 폰트 4종 조판 예문
- `src/` — 재현용 스크립트 (`lib/styles.py` 가 스타일 정의)

## 재현

바이너리를 먼저 꺼낸다.

    cid=$(docker create postpilot:gate-runtime)
    docker cp $cid:/usr/local/bin/resvg  bin/resvg
    docker cp $cid:/usr/local/bin/ffmpeg bin/ffmpeg
    docker rm $cid

폰트는 `fonts/`에 Pretendard·Paperlogy(저장소 번들)와 Google Fonts OFL 2종을 놓는다.
그 뒤 `python3 animate.py --workers 14` 로 프레임을 그리고 인코딩한다.
정지 컷만 필요하면 `python3 render.py --t 0.55`.

## 확인된 제약

- `feDisplacementMap` 은 resvg 0.48.1에서 결과가 엉뚱한 자리로 밀린다. 쓰지 않는다.
- SVG 필터로 글로우를 크게 퍼뜨리면(stdDeviation 50 이상) 알파가 죽어 화면에서 사라진다.
  넓은 광원은 필터 대신 `radialGradient` 타원을 직접 깔아야 한다.
- ffmpeg 빌드에 `blend` `geq` `colorkey` `alphamerge` `drawtext` `zoompan` 이 없다.
  `--disable-everything` 뒤에 필요한 필터만 이름으로 켜기 때문이고, `drawtext`를 빼면
  대부분 `--enable-filter=` 에 이름만 더하면 살아난다. `drawtext`는 libfreetype·libharfbuzz가 더 필요하다.
- SVG 필터는 `color-interpolation-filters="sRGB"` 를 붙이지 않으면 linearRGB로 계산돼 색이 달라진다.
- Paperlogy 는 `font-family="Paperlogy"` 로만 잡힌다. `Paperlogy 8 ExtraBold` 는 거부된다.
- 배경을 매 프레임 SVG로 다시 그리면 프레임당 9초가 든다. 한 번만 그려 두고
  `<defs><g id="bgsrc">` 로 참조하면 1초 아래로 떨어지고, 리퀴드 글래스가 이 참조를 블러해서 쓴다.
