# Jua Regular

Unmodified official font from Google Fonts:
[`ofl/jua/Jua-Regular.ttf`](https://github.com/google/fonts/tree/main/ofl/jua).

- SHA-256: `769677aef240bfc3b9965f2b50748075bff885e6c6992fc591a3fb268279f898`.
- Size: 2,119,352 bytes.
- Family name inside the file: `Jua` (subfamily `Regular`), weight 400, 2,519 glyphs.
- License: SIL Open Font License 1.1; the official notice is in `LICENSE`.
- Runtime: `/usr/share/postpilot-fonts/jua/Jua-Regular.ttf`, loaded explicitly as
  one `--use-font-file` with system-font discovery disabled.

Only the one weight exists: Jua ships a single face, and every caption style set
in it asks for weight 400.

Jua carries 2,367 of the 11,172 Hangul syllables — roughly the KS X 1001 set —
and lacks `·`, `—`, `…` and the fullwidth punctuation the other three faces
carry. A caption whose style names Jua and whose text needs a syllable this file
has no glyph for falls back to the default caption style with a CLIP-108 notice
(CDS-84); no glyph is ever substituted from another family.
