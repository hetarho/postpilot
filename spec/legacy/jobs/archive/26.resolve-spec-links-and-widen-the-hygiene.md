## Implementation Checklist

- [x] T001 Establish the baseline before changing anything: run a one-off sweep (the script in R001's evidence works)
      and save its output. Every later count is compared against it, and A1 is only true against a number that was
      measured first.
- [x] T002 Rewrite the upward links in the **24** files under `spec/jobs/archive/` and the **8** under
      `spec/changes/archive/`. These documents live one level deeper than the link text assumes, so `../x` must

      not resolve today.

      `spec/jobs/archive/22.post-purpose-presets.md:41` and `:129`. They need a sibling reference, not a
      depth change.

      drop the anchor fragment, skip `{{placeholder}}`.
- [x] T007 Two exclusions the widened resolver **must** implement, or it reports three false positives on its first
      run and gets switched off (A3): (a) ignore link-shaped text inside **code spans and fenced code blocks** —
      `spec/code-review/01.*.md` quotes a broken link as evidence inside backticks, and it must stay quotable;

      exclusions become an untested hole in the middle of the guard.
- [x] T010 `.github/workflows/ci.yml` — add `- run: pnpm lint:style:probe` and `- run: pnpm lint:spec:probe` to the
      `frontend` job, each immediately before its non-probe counterpart (currently lines 27–28). Order matters for

- [x] T011 Verify the whole gate from a clean state: `pnpm lint:spec`, `pnpm lint:spec:probe`, `pnpm lint:style`,
