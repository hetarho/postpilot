# IDEATION voice-chat-examples
> st:converted@261116 | An owner knows what to write in the learning chat and says it easily, so the chat collects the voice the owner's reviews are written in.

## vision
- problem: each chat turn hands over an imagined scene and a length (1~3문장) but never an answer's shape, so owners stall on what to write and must invent content before typing; most scenes are everyday (rain, bus, gifts) rather than the reviews the voice will write
- target: an owner making a personal voice through 대화하기
- core value: talking is easy because the content comes from the owner's memory and the shape from real reviewers' examples, while the register stays the owner's

## explored
- [o] ask about one experience of the owner's own by template kind, in that kind's review order ← recalling is easier than imagining, and replies come out in review voice
- [o] three examples per question in different registers, collapsed, labelled and never insertable ← one visible register gets copied into the learned voice
- [o] examples keep the frame of published Korean reviews and change the content; frames came from Tistory and 뽈레 reviews because Naver blog refuses the research crawler (measured 261116) ← examples should sound like real reviewers, not product copy
- [o] review moments before other everyday scenes among imagined situations ← the posts are reviews
- [x] examples alone with the scenes unchanged ← leaves the burden of inventing each scene's content
- [x] a review skeleton around a product-given place with a filling progress strip ← still imagined, and the experience thread already follows the review order
- [x] rewriting a given short review in one's own words ← the source drags sentence count, length and words into the fingerprint, and it reads as homework
- [x] the example as ghost text in the composer ← it disappears once typing starts and shows one register at a time
- [x] one always-visible gray example line per question ← one register per turn invites copying
- [x] Deferred to ideation/voice-fidelity ← whether examples pull replies toward their registers is measured with the other voice-fidelity measurements

## shape
- flow: pick kind (+ optional name) → five thread questions with collapsed examples → second experience → ten replies → explicit analysis | 생각나는 게 없어요 → imagined situations
- v1: experience threads for six kinds, examples on every chat question, review-first situation order / not: photo questions in threads, a review-skeleton progress strip, rewriting tasks
