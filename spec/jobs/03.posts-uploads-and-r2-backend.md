## Acceptance Criteria (from plan/02.post-drafting-and-list)

<!-- Plan 02 criteria owned by this job (plan AC numbers in parentheses). AC 1, 2, 4, 11 and the browser halves of 3, 5, 6 belong to jobs 04/05. -->

- [ ] A1 (plan AC3, server half) `ConfirmUpload` creates the `images` row only after a HEAD finds the object; the row records `filename`, `r2_key = posts/{slug}/{image_id}.jpg`, client-supplied `width`/`height` and the HEAD `bytes`.
- [ ] A2 (plan AC5, server half) No RPC accepts image bytes; `CreateUpload` returns a presigned PUT URL on the R2 host, so the API never relays a photo.
- [ ] A3 (plan AC6) Deleting a photo removes the `images` row and the R2 object (a subsequent HEAD returns not-found).
- [ ] A4 (plan AC7) An `uploads` row whose `ConfirmUpload` never arrives is removed, with its object, by the sweep after expiry.
- [ ] A5 (plan AC8) A photo's URL is a presigned GET minted per `GetPost`; the same object requested without a signature is denied (bucket private).
- [ ] A6 (plan AC9) `ListPosts` shows only the acting user's posts; `GetPost` on another user's slug → 403 (`PermissionDenied`); unknown slug → 404 (`NotFound`).
- [ ] A7 (plan AC10) Two posts created the same day with the same title get slugs `…-title` and `…-title-2`; retitling does not change the slug.
- [ ] A8 (derived) `CreateUpload` refuses a filename already attached to the post (`AlreadyExists`); filenames are unique per post.
- [ ] A9 (derived) `SavePostDraft` with an empty slug creates the post and returns the minted slug; repeated saves with the slug are idempotent updates of `title`/`memo` and bump `updated_at`.
- [ ] A10 (derived) The api refuses to boot when any `R2_*` variable is missing, with a message naming it.

- [ ] T007 `backend/internal/post/ports.go`: consumer-owned `ObjectStore { PresignPut, PresignGet, Head, Delete, List }` with `ErrObjectNotFound`; `backend/internal/storage/r2.go`: the adapter over the S3 client (constructed from config in `cmd/api`), mapping the SDK not-found error to `ErrObjectNotFound`.

- [ ] T010 `backend/internal/post/store/store.go`: row ↔ domain mapping.

- [ ] T012 `backend/internal/post/rpc/handler.go`: proto ↔ domain mapping; error mapping (`PermissionDenied`, `NotFound`, `AlreadyExists`, `FailedPrecondition`); registrar for rpcserver.
- [ ] T013 `backend/cmd/api/main.go`: build the R2 adapter, post service, handler; start the sweep goroutine after the server starts and stop it on shutdown.
