## Cost note (requested review — added tokens and fees per model)

Measured on the landed 697-rune constant (440 Hangul syllables plus punctuation/quotes): across the registry's modern
tokenizers Korean prose runs ≈1.0–1.7 tokens/char, so the section adds **≈700–1,200 input tokens,
call it ~1,000**, to the write and revise system prompts only (observe and analyze prompts are untouched; an A/B
experiment pays it twice, once per candidate). Output tokens are unaffected. At list prices from
`backend/config/providers.yaml` (2026-08-30), +1,000 input tokens per call costs:

| Write-capable model | Input $/M | Added $/call | ≈ KRW/call |
| --- | --- | --- | --- |
| DeepSeek V4 Flash | 0.045 | $0.000045 | 0.06원 |
| GLM 5.3 Flash | 0.075 | $0.000075 | 0.1원 |
| Qwen3.8 Flash | 0.15 | $0.00015 | 0.2원 |
| GPT-5.6 Luna | 0.20 | $0.0002 | 0.3원 |
| DeepSeek V4 Pro | 0.66 | $0.00066 | 0.9원 |
| GLM 5.3 | 1.40 | $0.0014 | 2.0원 |
| Claude Sonnet 5 (recommended writer) · GPT-5.6 Sol · Grok 4.6 | 2.00 | $0.002 | 2.8원 |
| Claude Opus 5 | 5.00 | $0.005 | 7.0원 |

Monthly bound for this 2-user product at a generous 120 write-stage calls/month (generations + revisions + A/B):
Sonnet 5 ≈ **$0.24/월 (약 340원)**; absolute worst case (every call on Opus 5) ≈ $0.60/월; flash-tier models under
$0.02/월. The section lives in the byte-stable prefix, so providers with implicit prompt caching bill most repeats
at their cached-input rate (typically 0.1–0.25×), pushing the real figure well below the bound. Conclusion:
**cost is negligible; no budget gate or config is warranted** — the 700-char size cap in T001 exists to keep the
prompt's instruction budget focused, not to save money.
