# Job 13: Platform Export (new)

> Implementation work doc. Source spec: [plan/08.platform-export](../plan/08.platform-export.md).

> SSOT (plan/policy/tech) and set status: done. Write it in English.
>
> Whole of plan 08 in one frontend-only job: four pure converters (`features/export-*`, one function each per PRD F-7),
> shared block/clipboard helpers, the export panel widget, and the editor composition. Requires job 11 (content types
> and the reading view). No backend change.

## Acceptance Criteria (from plan/08.platform-export)

- [x] A1 All four tabs render output derived from the same `PostContent`; switching tabs triggers no network request and is visually instant.
- [x] A2 Naver output is plain text (no `<` `>` markup) and every IMAGE block appears at its position exactly as `[사진 <file> — <caption>]` (or `[사진 <file>]` without a caption).
- [x] A3 Tistory output is a valid HTML fragment (parses without error when wrapped in a `<div>`), every `<img>` has an adjacent replacement comment naming the file, and it contains no `<html>`/`<body>` wrapper.
- [x] A4 Site output is a single standalone HTML document; two different posts produce byte-identical `<style>` content (the template is fixed, not generated).
- [x] A5 Markdown output starts with valid YAML front matter containing `title`, `date`, `summary`, `tags`; headings, quotes, lists and images use the mapping in plan 08.
- [x] A6 The copy button places the exact rendered string on the clipboard; in an environment where the Clipboard API is unavailable, the output area is auto-selected and the manual-copy hint appears.
- [x] A7 Each converter has a snapshot test over a fixture that includes every `BlockType`, an image without caption, a heading of level 3, and Korean text with characters that need HTML escaping.
- [x] A8 Each tab shows its PRD guidance line; the Naver tab additionally offers the title for separate copying.
- [x] A9 No converter emits a presigned URL or any `api.postpilot.*` / R2 host string.
- [x] A10 The export panel is absent while a post has no generated content.
