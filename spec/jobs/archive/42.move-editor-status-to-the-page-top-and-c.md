**This is a frontend-only job.** No proto, no generated client, no migration, no Go. `proto/**`,
`frontend/src/shared/api/gen/**`, `backend/**` must be absent from `git diff --stat`.

**Token vs config.** `SAVE_STATUS_SETTLED_MS` is behavior and belongs in `frontend/src/shared/config`.
The progress bar's height, the focus-ring gutter and the listbox panel's stacking level are *design
tokens*: they are registered in `frontend/src/app/styles/index.css` and used as Tailwind utilities
(design-language §1.2), never as arbitrary values at a call site and never in `shared/config`.

## Build notes — decisions and deviations

Recorded because the checklist above is ticked and a reader has to be able to tell what was built
from what was written.

- **T004/T010 — the status region is TWO exports of one module**, `EditorProgressBar` and
  `EditorStatusLine` in `pages/editor/ui/EditorStatus.tsx`. The bar has to be `sticky` to hold the
  page's top edge through a long draft, and a sticky box must be in the page's normal flow, so it
  is the first child of the editor's `main`; the line belongs on the row that already holds 목록
  and 삭제. One module owns both, and both read the same job, save state and post status.
- **T009 — `SaveStatus.tsx` was deleted rather than reshaped.** With T010's single status line
  there is no second mount point for it: the line is the live region, so a component whose whole
  job was to be that region has no surface left (§1.1 — no unused inventory). Its replacement is
  `features/save-draft/model/useSaveStatus.ts`, which owns the settle and the localized label and
  is consumed by `EditorStatusLine`. `draft-queue.ts`'s `stateOf` is untouched, as the job requires.
- **T003 — `Popover`'s own panel scroller needed no change.** It was audited: the panel carries
  `p-4` (16px), which already exceeds the focus ring's 4px on every side, so its ring is inside the
  scrollport and is not clipped. The gutter token is applied where the clipping is real —
  `Sheet`'s body, which has no padding of its own — and `Popover`'s panel carries a comment saying
  why nothing was reserved there. `SegmentedControl` (`p-1` = 4px), `TabLinks` (`p-1`), `PhotoStrip`
  and `ContactSheet` (`px-4`/`pb-*`) and `AboutPage`'s table scroller (`px-4`) were audited the
  same way and are all already clear.
- **T010 precedence — a failing save outranks the running job's stage.** The source spec ordered
