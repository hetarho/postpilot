## Acceptance Criteria (from plan/02.post-drafting-and-list)

<!-- Plan 02 criteria owned by this job (plan AC numbers in parentheses). -->

- [ ] A1 (plan AC1) Typing a memo, force-killing the browser within a few seconds, and reopening the post shows the typed text (autosave fires ≤ ~2 s after the last keystroke).
- [ ] A2 (plan AC11, title/memo half) Opening a post from the list restores title and memo (photos: job 05).
- [ ] A3 (derived) "새 글" opens `/posts/new`; the first autosave creates the post and the URL becomes `/posts/<slug>` without a reload; later edits save against that slug.
- [ ] A4 (derived) The list shows only the acting user's posts newest-first with the title (or "제목 없음"), `updated_at`, and a status badge (`draft` / `review`).
- [ ] A5 (derived) Opening another user's slug shows a 403 message; an unknown slug shows 404; neither crashes the app.
- [ ] A6 (derived) A save-status indicator shows saving / saved / not-saved states; a failed save retries and the text is never lost while the tab lives.
- [ ] A7 (derived) `/` redirects to `/posts`; the scaffold `pages/home` (ping page) is removed; login's default redirect is `/posts`.
