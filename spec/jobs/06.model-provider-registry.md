# Job 06: Model Provider Registry (new)

> Implementation work doc. Source spec: [plan/04.model-provider-registry](../plan/04.model-provider-registry.md).
> /implement-job 06 builds it via the two checklists below. When done, reflect the result into the
> SSOT (plan/policy/tech) and set status: done. Write it in English.
>
> Whole of plan 04 in one full-stack job: the `internal/llm` port + registry + first adapter (`openai_compatible`),
> `providers.yaml`, `provider.proto`, per-user selection memory, and the frontend model catalog + per-stage dropdown
> component (mounted on pages by jobs 09 and 11). Requires job 01. Runs before the job queue (job 07) per the build
> order; independent of jobs 03–05.

## Acceptance Criteria (from plan/04.model-provider-registry)

- [ ] A1 Adding a provider or model by editing `providers.yaml` and restarting makes it appear in the dropdowns with no code change; an invalid yaml stops the api from starting with a clear error.
- [ ] A2 A provider whose `api_key_env` is unset shows all its models greyed with reason "API key not configured"; they cannot be selected.
- [ ] A3 The `observe` dropdown lists only `vision: true` models; `write` and `analyze` list all.
- [ ] A4 A selection made on one device is restored on another device for the same account and stage.
- [ ] A5 When a saved model is removed from the yaml, the dropdown shows it greyed with the "vanished" reason and the saved selection is cleared; the user must choose again.
- [ ] A6 The frontend never receives an API key or a provider SDK payload — only ids, labels, and flags (asserted by the proto shape; keys exist only in server env).
- [ ] A7 (refined — the generation/analysis actions arrive in jobs 09/11/12) A fresh account has no row in `model_selections` and `StageModelSelect` renders the empty state "모델을 선택하세요" for every stage, exposing `selected = null` so callers block their action; the app writes no default ([I3]).
- [ ] A8 A provider 429 surfaces as `ErrRateLimited` with the provider's message intact, so the job error the user sees names the cause (PRD §7: 무료 모델 한도 초과).
- [ ] A9 Requesting an image part or a JSON schema on a model that lacks the capability fails fast with `ErrUnsupported` before any network call.
- [ ] A10 No package above `internal/llm` imports an adapter or SDK package (enforced by a `go list -deps` test in the job).

- [ ] T003 `backend/config/providers.yaml`: the initial registry — an `openrouter` provider (`adapter: openai_compatible`, `base_url: https://openrouter.ai/api/v1`, `api_key_env: OPENROUTER_API_KEY`) with a router entry (`openrouter/free`, `vision: true`, `structured_output: false`) plus a couple of paid vision + structured-output models; field comments. `backend/Dockerfile`: `COPY config /config` and `ENV PROVIDERS_CONFIG=/config/providers.yaml` (baked; a stack may mount an override). - [ ] T004 (migrate) `backend/internal/platform/db/migrations/0003_model_selections.sql` — `model_selections(user_id, stage, provider_id, model_id, updated_at, PRIMARY KEY(user_id, stage))`. (Plan 04's illustrative `0004` is superseded by build order.)
