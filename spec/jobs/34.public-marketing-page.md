## Acceptance Criteria (from plan/15.public-marketing-page)

<!-- The source spec's acceptance criteria. After building, verify each is true in the running code. -->

- [ ] A1 An unauthenticated direct visit or refresh at `/about` renders successfully through the static SPA fallback.
- [ ] A2 Mounting `/about` performs no session/API/provider request and does not enqueue or mutate anything.
- [ ] A3 `/about` is structurally outside the authenticated route guard; protected application routes remain protected.
- [ ] A4 `/login` exposes the localized `Postpilot이란? / What is Postpilot?` link without changing login submission, generic failures, or safe redirect behavior.
- [ ] A5 The About header contains locale and theme controls plus Login as the page's only product CTA; there is no signup, contact, waitlist, or purchase action.
- [ ] A6 Locale initially follows plan 13, changes immediately between complete Korean and English copy, persists by its existing rules, and never changes `/about`.
- [ ] A7 Theme initially follows and persists by plan 14, and the page remains correct and AA-compliant in Day and Night.
- [ ] A8 Both locales accurately cover the defined hero, workflow, differentiators, output formats, access limitation, and control/privacy facts.
- [ ] A9 Marketing copy makes no unsupported capability, privacy, availability, or performance claim and does not present planning or unverified behavior as shipped.
- [ ] A10 Localized title, description, Open Graph text/locale, canonical URL, and `og:url` update on route/locale changes and do not leak after navigation away.
- [ ] A11 The page contains no screenshot, generated marketing image, analytics/tracking code, form submission, remote font, embedded media, or new third-party request.
- [ ] A12 The page has one H1, logical heading order, semantic ordered steps, labelled controls, visible focus, keyboard support, and no colour-only state.
- [ ] A13 At 320 px there is no horizontal page scroll; 360/390/430 px, safe areas, 200% zoom, both themes, and Korean/English header widths remain usable.
- [ ] A14 A signed-in visitor may follow Login and be redirected by the existing login guard; About itself does not special-case session state.
- [ ] A15 Existing authentication, authenticated navigation, locale, theme, export, and publishing tests remain unchanged in meaning.
- [ ] A16 Route, locale, metadata, zero-network, accessibility/responsive, frontend test, lint, FSD/style, and build checks pass.
