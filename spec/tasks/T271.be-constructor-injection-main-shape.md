# T271 required collaborators enter through constructors; main is four steps
> st:todo | ssot:ARCH-40 ARCH-6 ARCH-24 | base:ARCH@5 | dep:T270

## goal
Replace the `Set*`/`With*` injection of required collaborators with constructor arguments across the backend services and reshape `cmd/api/main.go` into `loadPlatform → buildContexts → registerJobs → serve`.

## acceptance
- [ ] every service whose `Set*`/`With*` target is required for a code path to work takes it in `New(...)`: `post.Service` (8 setters → ctor), `generation.Service` (6), `auth.Service` (5), `clip.Service.SetGeneration/SetSources/SetFinalizer`, `GenerationService.WithFinisher/WithCredits/WithAdmission`, `usage.SetAnchors`; a setter survives only where the absent mode is legal and has a test that exercises the absence
- [ ] a constructor with a nil required collaborator panics at boot (or returns an error) with the collaborator's name; a `cmd/api` test constructs the full graph once and asserts no panic
- [ ] `cmd/api/main.go`'s `main()` is ≤60 lines calling `loadPlatform`, `buildContexts`, `registerJobs`, `serve`, each in its own file; no rule body, no adapter type over 30 lines remains in package main
- [ ] behaviour unchanged: ARCH-26 passes, the `cmd/api` end-to-end gate passes

## impl notes
- from review/arch-260919 F18 F13 (main shape)
- ARCH-40: required = constructor, optional = setter with a tested absent mode
- order matters for cycles: where two services need each other (post ↔ generation), pass a narrow port interface for the late-bound one and construct it second; do not keep a setter to hide a cycle — split the port
