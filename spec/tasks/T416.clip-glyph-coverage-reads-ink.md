# T416 A caption face's coverage is the set of characters it actually draws
> st:blocked@260927 | ssot:CDS-84 CDS-25 | base:CDS@28 | dep:-

## goal
A caption whose face maps a syllable to an empty glyph falls back to the default style with a CLIP-108 notice instead of rendering blank.

## acceptance
- [ ] `media/font_family.go` faceCoverage counts a character as covered only when its glyph has ink (non-empty outline), not merely a non-zero cmap index; Paperlogy's 8,392 empty syllables are uncovered
- [ ] a failing-first test renders a Paperlogy-faced caption containing an empty-glyph syllable (e.g. 갂) and asserts the default-style fallback and the notice
- [ ] the cost stays bounded: coverage is computed once per face and cached
- [ ] verify BE: `cd backend && test -z "$(gofmt -l .)" && go vet ./... && go build ./... && go test -timeout 30m ./...`

## result
- blocked: CDS-84 sends a caption whose face lacks a character to the default style, but the default 크게 강조 is Paperlogy 800 itself (CDS-25), and Paperlogy maps all 11,172 syllables while drawing only 2,780 (measured: 갂 쎯 empty; 똠 햏 뷁 drawn; Jua, NanumMyeongjo and Wanted Sans draw everything they map). With an ink test a Paperlogy caption (bold, iridescent, glitch, ember, stack, outline) holding such a syllable has no style to fall back to: the layout would refuse it as `copy_limit` and fail the render, where today it renders blank. CDS-84's premise "the primary face covers every syllable" holds for the cmap, not the ink. update-ssot CDS: pick what such a caption does — refuse with its own notice so the owner rewrites it, fall back to a fixed Wanted Sans style, move 크게 강조 to a face that draws every syllable, or allow glyph substitution for those syllables
