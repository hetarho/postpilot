# T222 The server hands the preview the caption SVG it will render
> st:todo | ssot:CDS-83 CLIP-143 | base:CDS@21 CLIP@32 | dep:T219 T221

## goal
Serve each caption's rendered SVG fragment from the one place the style set lives, so the preview and the render cannot drift.

## acceptance
- [ ] one RPC returns, for a project's current plan, each caption's SVG fragment built by the same style registry the renderer uses, together with its canvas box and the ratio's safe area
- [ ] the fragment carries no absolute position: the caller places it with one transform, so moving a caption needs no round trip
- [ ] a sequence style returns the fragment of one representative frame, labelled as such
- [ ] changing a caption's style or text returns a new fragment; changing only its position or size does not
- [ ] a contract test renders the returned fragment through resvg and compares it with the renderer's own output for that caption, byte-identical
- [ ] ARCH-26 and ARCH-28 pass

## impl notes
- the fragment is a `<g>` with the caption drawn at the origin plus the `<defs>` its filters need, id-prefixed per caption ← two captions on screen would otherwise collide on filter ids
- the response carries the safe area so the editor clamps without mirroring CDS-9/CDS-13 constants a second time
- fonts reach the browser as the same bundled files served statically; the fragment names the family and the viewer loads it with `@font-face` ← a system font would shape differently from resvg and break CDS-83
