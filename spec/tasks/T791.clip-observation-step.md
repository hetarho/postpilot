## goal
`관찰하기` analyzes a clip's sources from ①, ② lets the owner correct the observed descriptive text, and `다시 관찰하기` re-analyzes chosen sources.

## acceptance
- [ ] ①'s 확인 big action reads `관찰하기` while a selected source lacks an observation: it shows the analysis-only quote and ceiling, runs browser preparation on the browser route, starts the analysis job in the focused job view with cancellation (THEME-40) and lands on ② when done; otherwise it reads `다음`.
- [ ] ②'s heading row carries `다시 관찰하기`: the owner chooses sources, a source edited by hand first confirms that its edits will be lost, then the quote is approved and the analysis job runs for those sources.
- [ ] In ②, each observed range's event, action, subjects (one per line), subject and audible speech edit in place and autosave; an edited range and source show the owner's correction; clearing observed speech shows the field error; editing is read-only while a job runs and on a finalized project; CLIP-49's usage stays visible.
- [ ] `스토리라인 먼저` and `바로 만들기` on ② quote no analysis for sources already observed or pinned.
- [ ] Tests: `features/generate-clip/ui/ClipGenerationActions.test.tsx` and the `useGenerateClip` tests (analysis mode, browser preparation, quote changed), `features/inspect-clip-observations/ui/*.test.tsx` (edit, owner mark, speech refusal, read-only states), `widgets/clip-workspace/model` tests (focused job includes `analyze_clip`, landing on ②), `pages/clip/ui/ClipObservations.test.tsx`; `pnpm lint`, `pnpm lint:fsd`, `pnpm lint:style` and `pnpm build:web` pass.
