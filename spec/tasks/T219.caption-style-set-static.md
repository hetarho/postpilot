# T219 The approved caption style set, its faces and its glyph fallback
> st:doing@260917.cap | ssot:CDS-80 CDS-17 CDS-18 CDS-25 CDS-66 CDS-84 | base:CDS@21 CLIP@32 | dep:-

## goal
Introduce the caption style registry — each style fixing its face, type role, colour treatment and motion — with the static styles rendering and a face that cannot set a syllable falling back with a notice.

## acceptance
- [ ] a style registry in `internal/clip/design` names every approved style with its face, type role, colour treatment, motion and whether it is static or sequence-rendered, and `크게 강조` is the default
- [ ] Jua and NanumMyeongjo ship beside Pretendard and Paperlogy, each pinned by exact size and SHA-256 at construction as the existing two are, with the licence notices in the image
- [ ] the renderer passes every bundled face to resvg with system fonts off and sets a caption in the face its style names
- [ ] a caption whose style's face lacks one of its syllables renders in the default style instead and records a CLIP-108 notice naming that caption; no glyph is ever substituted from another family
- [ ] a style id outside the project's allowed set is refused before rendering as an authoring error
- [ ] the static styles render in a golden test per style and per ratio, and the glyph-coverage check has a test using a syllable Jua lacks
- [ ] the ffmpeg/resvg name check (ARCH-39) still passes and the media image stage builds and runs locally (ARCH-37)
- [ ] ARCH-26 passes

## impl notes
- the registry is Go code, not JSON in `design.json` ← a style carries filter graphs and generated geometry that a constants file cannot express, while `design.json` keeps the numbers both sides mirror
- glyph coverage is read once per face at construction from its cmap and cached, so the per-caption check is a set lookup
- every filter in a style declares `color-interpolation-filters="sRGB"` ← resvg computes filters in linearRGB by default and the colour then differs from what a browser draws (→CDS-83)
- `feDisplacementMap` is not admitted to any style ← resvg 0.48.1 places its result at the wrong offset, so a style using it cannot satisfy CDS-83
