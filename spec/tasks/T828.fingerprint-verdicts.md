## impl notes
- contract (voice.proto): add `enum FingerprintVerdict { FINGERPRINT_VERDICT_UNSPECIFIED = 0; FINGERPRINT_VERDICT_SIMILAR = 1; FINGERPRINT_VERDICT_DIFFERENT = 2; }` (UNSPECIFIED = no verdict) and `FingerprintVerdict verdict = 6;` on `FingerprintItemComparison`; keep field 4 `headline` with its comment rewritten to "the key of the facet the item leads with: the voice's dominant value"; keep `distance` (still computed, used for nothing user-facing). Rewrite `GetPostFingerprintResponse`'s ordering comment. Additive only — old clients keep working
- Go: `ItemComparison` gains `Verdict Verdict` (`VerdictNone`, `VerdictSimilar`, `VerdictDifferent`); `headline()` is replaced by a per-item lead choice: endings → the voice's largest class key; marks → the voice's largest mark key; emoji → the voice facet with the largest rate, `emoji` when all are 0; shape → `average`; openings → `openings` (or `closings` when the voice has no opening); adverbs → the voice's first word; person → `dominant`; headings → `emoji`
- `Compare` drops an item that `voice.Unknown(item)`; an item `text.Unknown(item)` stays with `Unknown: true` and no verdict
- add `CompareMinExpected = 2` to `backend/internal/voice/limits.go` as VOICE_COMPARE_MIN_EXPECTED (occurrences); expected = voiceRatePerHundred × textSentences / 100
- tolerances (code-owned, unexported consts in `fingerprint.go`, all inclusive):
  - endings: 비슷함 when the text's largest class equals the voice's and their shares differ by ≤ 0.15
  - marks: 비슷함 when `halfL1` over the six mark shares ≤ 0.20
  - emoji: per facet, 비슷함 when |v − t| ≤ max(3, 0.5 × v) per 100 sentences; the item is 다름 if any facet is not
  - shape: 비슷함 when |v − t| / max(v, 1) ≤ 0.25 for average chars and line-break shares differ by ≤ 0.25
  - openings: judged only when the voice has a recurring opening or closing line; 비슷함 when `sharesLine` holds for openings or for closings
  - adverbs: judge only voice words whose expected count ≥ `CompareMinExpected`; no such word → no verdict; 비슷함 when the text uses at least half of them
  - person: voice dominant "" → 비슷함 when the text's dominant is "" too, else 다름; voice dominant X → no verdict when its expected count < `CompareMinExpected`, else 비슷함 iff the text's dominant is X
  - headings: 비슷함 when emoji shares and question shares each differ by ≤ 0.30
- mapping: `backend/internal/voice/rpc/fingerprint.go` `ToProtoComparisons` maps `Verdict`; the experiment context's copy is T829's
