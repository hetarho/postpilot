## goal
Cut frames and transition windows are computed by one Go timeline that both the ffmpeg composition graph and the ground sampler read, and the browser draws CDS-36's fades with the same curve the server's ffmpeg draws, pinned by a fixture Go writes — so a browser export and a server export of one plan show, and sample, the same frames (CLIP-192).

- [ ] `fadeBlackMean` reads its window from that timeline and keeps mirroring ffmpeg's xfade fade-through-black curve
