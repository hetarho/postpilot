# T216 ① arranges the sources and hints the writer
> st:todo | ssot:CLIP-136 CLIP-123 CLIP-121 CLIP-47 CLIP-55 | base:CLIP@31 ARCH@3 | dep:-

## goal
Let the owner order the sources in ①, carry that order to the writer, turn the source→item binding into an optional hint, and tell the owner what the instruction now directs.

## acceptance
- [ ] migration 0058 adds `clip_source_leases.position INTEGER NOT NULL DEFAULT 0`; `GetClipSources` and `SourceBatch.Sources` load in position order, then confirmation order; a new batch starts in confirmation order
- [ ] new RPC `ReorderClipSources(project_id, batch_id, repeated string source_ids)` persists positions for the whole batch and refuses a list that is incomplete, duplicated or names a foreign source
- [ ] the flow request's `source_order` (T211) follows that order; a batch never reordered plans exactly as today
- [ ] `ClipSourceStrip` supports drag reorder with a touch path and a keyboard alternative (move earlier/later on the focused tile with a live announcement), autosaving through `ReorderClipSources`
- [ ] the per-tile item Listbox stays, labelled as a hint (ko "이 원본은 어느 메뉴인가요? (선택)", en equivalent) with help text that nothing depends on it; the instruction textarea's help text says it directs footage order, rhythm and what the captions say
- [ ] tests: BE — reorder persistence, refusals, ordered load; FE — keyboard reorder and the autosave call; verify FE (ARCH-25), BE (ARCH-26), generated code (ARCH-28)

## impl notes
- leases are per batch (migration 0036 `clip_source_leases`); positions are per batch too, so a discarded batch takes its order with it
- CLIP-55 requires touch and keyboard alternatives for every drag; a small pointer-event implementation on the existing snapping strip is preferred over a new dependency, and if a library is chosen ARCH-33 applies (read the current docs first, install through pnpm, confirm the lockfile)
- T189's `useClipSourceBinding` keeps its shape; only the wording and help text change here — its semantics changed in T210/T211 (a hint the writer receives)
