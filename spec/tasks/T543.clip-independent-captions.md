## goal
Allow direct caption selection/placement and independent wording updates without changing speech.

## acceptance
- [ ] Select a caption in the main preview and move it within safe bounds; selected contextual controls edit text/style/size/interval, including the first caption in an empty plan.
- [ ] Display-only edits leave spoken text, speech fingerprint/readiness and provider call count unchanged and support undo/redo.
- [ ] Explicit script-to-caption refresh updates only eligible derived wording, preserves owner-edited wording and all existing timing, and reports newly unplaceable text for correction.
- [ ] Tests cover edited wording/timing independently, removed or split origins, captions across cuts, region exclusions, new text overflow and direct pointer/keyboard placement; existing style/glyph tests stay green.

## impl notes
- Under DUB-27, implement and automatically verify this task with deterministic fixtures before live supplier qualification; do not promote production readiness from fixtures.
- Reuse ClipCaptionStage drawing/safe-area transforms in the primary composed preview and share selection through widget composition. Do not render a second independently editable caption copy in the phone sheet.
- Expose a credit-free caption refresh action labelled 대본에서 자막 업데이트. Track text_edited/timing_edited through the persisted model from T540. For missing/deleted origins, preserve owner-authored captions; offer explicit additions/removals instead of inferring overwrite permission.
- Refresh means wording only: keep interval, position, size and chosen style. A new segment with no valid free caption interval remains a pending addition offered to the owner. A caption whose protected interval cannot hold the new wording surfaces overflow rather than shortening it silently.
- Keep sentence/rapid exposure, region no-caption intervals and style/glyph handling in their current CDS rules. Shortening generated starting caption text must never shorten the spoken script or audio.
