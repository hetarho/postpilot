# T462 Sample every unplated text's ground from the originals through one shared sampler
> st:todo | ssot:CLIP-192 CLIP-157 CDS-44 CDS-32 CDS-85 CDS-7 ARCH-45 ARCH-48 | base:CLIP@52 CDS@31 ARCH@13 | dep:- | touches:backend/internal/clip/media/

## goal
Measure the CDS-44 ground of every unplated declared text from the retained originals through one sampler both render kinds can call, and make the server render use it.

## acceptance
- [ ] A sampler takes a laid-out portable plan, the output frames CDS-44 names for each unplated caption, info, hook and ending visual (today's `declaredSampleWindow` + `sampleOffsets` and `sampledBounds`) and the originals, and builds each output frame's footage exactly as the composition does: the covering cut's source time at its fixed rate, that cut's own crop, cover, focal point and canvas scale, the xfade of the transition's kind (`fade`, `fadeblack`) at the same frame progress inside an overlap, and the incoming cut's own frame at a hard-cut boundary as `concat` gives.
- [ ] The server render's declared path samples through it instead of `composition-footage.mp4`; `applyDeclaredGround`, the region and caption scrims, accent white and `composition_contrast` notices follow from its grounds with no other change. The legacy non-portable `copyLayer` path is unchanged.
- [ ] Its result is a bounded, serializable ground per visual, keyed by instance id and phrase index and holding what `measureFrames` measures; applying a round-tripped result gives the same scrim, accent and contrast decisions as applying the in-memory one.
- [ ] Tests: output-to-footage frame mapping on a cut's middle at a non-1× rate, inside a `fade`, inside a `fadeblack` and at a hard-cut boundary, each compared with the same frame cut from a composition the renderer actually builds (L and σ within a stated tolerance, identical scrim and accent decisions); the round-trip test; the existing ground tests (`luminance_test`, `regions_test` `TestRegionBlocksTakeTheirOwnScrim`, `information_frame_test`) pass; `pnpm smoke:media` passes with a declared bright-ground case whose centred outro takes `scrim.radial`.
- [ ] ARCH-31's local gates pass.

## impl notes
- Frame arithmetic follows `compositionGraph` (`media/render.go`): each cut contributes its output frames, a transition of `transitionFrames(ms)` overlaps the previous cut's tail from `elapsed-overlap`, and a zero transition is a join. Output to source time is `cut.StartMS + (outputMS − cutOutputStartMS) × PlaybackRatePermille / 1000`.
- Build each footage frame with ffmpeg on the original (seek plus the per-cut video chain the composition uses for its bare cut footage, one PNG frame) and blend overlaps in Go on the decoded frames with xfade's `fade` and `fadeblack` formulas, so no ffmpeg filter is added to the image's minimal build.
- Group the requested frames by source so a worker holds one original at a time (`localmedia.Loader`); the frame count stays three per sampled visual.
- Why one sampler over the originals: CLIP-157 and CLIP-192 need both kinds to reach the same decision, one function is parity by construction, and building the composed footage for a browser render would spend most of a server render. The original and the lossless intermediate give the same pixels up to scaling noise, which the tolerance test pins.
- Sampling stays media-worker work under ARCH-45; nothing here runs in the API.
