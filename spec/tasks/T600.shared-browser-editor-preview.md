## goal
Drive playback, scrubbing and caption/preset previews with the same frozen composition/time rules used by export.

## acceptance
- [ ] The existing React editor preserves timeline/properties, direct edits, autosave, undo/redo, keyboard/touch controls and owner text; frame evaluation stays outside React rendering.
- [ ] Footage, captions, regions, transitions and audio use one output clock; pause/seek/replay/edit invalidation cannot display or play older decode/speech callbacks.
- [ ] Main preview uses the same component/frame evaluator as export at its declared reduced resolution/cadence, with real-time frame dropping limited to preview only.
- [ ] Caption style samples, region preset diagrams and flow simulation use the local component catalog; ordinary editing needs no owner-specific server raster/frame-sheet request.
- [ ] Unsupported preview effects/audio and final loudness limits are stated accurately; missing/stale speech is not silently represented as current output.
- [ ] Tests cover every style, source-only/narration-only/mixed playback, rapid phrases, preset text/blank slots, controls, seek races and preview/export parity; real-browser checks and required local CI pass.

## impl notes
- Compose existing entities/clip-preview and workspace ports; do not add another editor framework, duplicate plan store or arbitrary animation language.
- Use output-time audio scheduling and user-gesture playback rules. Share schedules/selected-range DSP with T593 while keeping final loudness proof in exported-output verification.
- A new draft invalidates compatible resources only where content changed; immutable ink can survive position-only edits and incompatible versioned cache entries cannot.
- Render one representative sample per visible style/preset with bounded caching; do not animate every gallery item continuously.
- Flow simulation remains explicitly still/silent under CLIP-173/176 even though it shares component appearance.
- Keep finalized steps read-only and the private saved result separate from editable draft and T599's provisional local artifact.
