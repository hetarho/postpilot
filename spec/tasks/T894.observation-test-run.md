## goal
An admitted observation test freezes the owner's test photos, has every observe-stage contestant observe them independently with checkpointed batches, returns observations without any writer call, and prices only those observation calls.

## acceptance
- [ ] Deterministic, unit (`generation`, fake LLM): freezing an observation test binds output, photo keys/dimensions and prompt/schema versions into the hash and freezes no writer, profile, template or guideline; each candidate runs only its own observe batches with its own model, never calls a writer, checkpoints after each batch, resumes without repeating completed batches after an interruption, and a failed batch is retried only through the failed-only path.
- [ ] Deterministic, unit: the initial plan and `PlanWritingTestRetry` list only observe calls for observation output (so the estimate prices observation only); post-output plans are unchanged.
- [ ] Deterministic, unit (`experiment/app`): `ResolveWritingTestSource` for observation output turns the owner's ready test photos into frozen images and refuses unknown/foreign photos; `RunTestCandidate` stores the observations as the candidate's T893 observation output.
- [ ] Deterministic, unit: affected `cd backend && go vet ./internal/generation/... ./internal/experiment/... && go test ./internal/generation/... ./internal/experiment/...` plus the ARCH-24 task lint pass. Hand off `go test ./cmd/api/...`, the full BE suite and media smoke to the batch gate.
