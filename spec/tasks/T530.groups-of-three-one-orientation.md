# T530 photo groups of three, one orientation, always captioned
> st:todo | ssot:GEN-77 GEN-78 GEN-14 GEN-40 POST-105 TMPL-38 | base:GEN@23 POST@31 TMPL@21 | dep:- | touches:backend/internal/generation backend/internal/post backend/internal/template backend/cmd/api backend/internal/platform/config frontend/src/entities/post frontend/src/entities/template frontend/src/features/edit-post-content

## goal
A photo group holds at most three photos of one orientation and every group the writer produces carries a caption; the prompts tell the writer each photo's orientation, the filter repairs a violating group, and the template count follows the cap.

## acceptance
- [ ] `post.PhotoGroupMax` and FE `PHOTO_GROUP_MAX` are 3; the save refuses a fourth photo; the editor's add picker stops at three
- [ ] the write (direct and along-storyline) and revise prompts carry one per-post line naming every attached photo's orientation (세로/가로, portrait/landscape) after the filenames; the static GALLERY rule states 2~3 photos, one orientation and a non-empty caption
- [ ] FilterAttachments splits a group by orientation (first photo's orientation first, order kept) into the fewest even parts of ≤3 (4 → 2+2, 5 → 3+2, 7 → 3+2+2); a one-photo part becomes an IMAGE; the first part keeps the caption, later parts take the alt (or the caption without an alt); an empty written caption takes the alt; revision applies the same with the fresh attachment snapshot
- [ ] the collage renders as one row (two columns for 2, three for 3)
- [ ] a template count above the cap renders as `{{사진 자리 · 3장 묶음}}`; `TEMPLATE_PHOTO_ROW_MAX` defaults to 3 on both sides and in `.env.example` / `.env.production.example`
- [ ] Go tests: filter cases above, prompt orientation lines (ko/en, write/revise), bound pinned to `post.PhotoGroupMax`, template clamp pinned to the post cap; prompt goldens updated; vitest for PhotoGroup columns and the editor cap
- [ ] ARCH-25 and ARCH-26 pass

## impl notes
- orientation: `generation.Image` gains `Width`, `Height` (from `post.Image` in `cmd/api/adapters_generation.go`); a helper `photoOrientations(images) map[string]bool` (true = portrait, `Height > Width`; square and unknown dims are landscape). T531 adds the rotation turn to this one helper, so keep it the only place orientation is computed.
- `FilterAttachments(content, photos, videos, portrait map[string]bool)`; nil map = everything landscape. Callers: `write.go` (`post.Images`) and `revise_handler.go` (fresh snapshot — extend the fresh read to carry dims). Balanced chunking: k = ceil(n/3) parts, sizes differ by at most one, larger first.
- prompts: `koreanGalleryRule` → `GALLERY 블록은 같은 방향(사진 방향이 모두 세로이거나 모두 가로)인 첨부 사진 2~3장을 한 자리에 묶어 설명 하나로 보여 줍니다. files에 파일명을 보여 줄 순서대로 적고, layout은 나란히 보여 주는 COLLAGE나 한 장씩 넘겨 보는 SLIDE 중 하나로 쓰고, alt는 묶음 전체에 하나, caption은 묶음 전체에 하나를 비워 두지 말고 쓰고, file은 비워 두세요. 다른 블록에서는 files를 빈 배열로, layout을 빈 문자열로 두세요.`; English mirrors it (`2 to 3 attached photos of one orientation — all portrait or all landscape`, `a caption that is never empty`). The bound test now reads `2~3` / `2 to 3`.
- per-post line in `attachmentMaterial` (both the photo-only and the with-video branch, and its English twin) right after the filename line: `사진 방향: a.jpg 세로, b.jpg 가로` / `Photo orientation: a.jpg portrait, b.jpg landscape`, in post order; absent for a post with no photos. The revise user half gets the same line after `[첨부 파일명]`'s list. `WritePromptInput` gains `Orientations map[string]bool` (or the helper's result) — nil renders no line, so a caller that passes none keeps its bytes.
- template clamp: `template.PhotoPlace` renders `min(count, photoGroupCap)` with `photoGroupCap = 3` declared in the template package (it may not import post); a `cmd/api` test pins `template` cap == `post.PhotoGroupMax`. Config default `templatePhotoRow` 4 → 3 in `internal/platform/config`, the FE `TEMPLATE_PHOTO_ROW_MAX` fallback 4 → 3, and both example env files.
- FE: `PHOTO_GROUP_MAX = 3`; PhotoGroup collage `total === 2 ? 'grid-cols-2' : 'grid-cols-3'`; update tests that used four photos in a collage.
- the 기본 지침 text stays (it names no number).
- prod note for the result: a hand-edited VPS `.env` or a Cloudflare build var still at 4 keeps the builder offering 4, which now renders as a group of three.
