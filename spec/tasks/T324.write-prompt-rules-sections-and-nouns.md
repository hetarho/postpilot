## impl notes
- This task is the one owner of `prompts.go`'s fixed text and of the write goldens; T330 adds only the per-post phrase section on top of it.
- New constants beside the grounding constants in `backend/internal/generation/prompts.go`: `koreanTitleProhibitions` / `englishTitleProhibitions` (one line holding both GEN-49 prohibitions: no title whose long text varies only by a single piece of information; no keyword repeated twice or more inside one title).
- `koreanTitleFormProhibitions` / `englishTitleFormProhibitions`: the same two prohibitions, stated as outranked by the template's title form and binding only what the model writes inside the form's `<write>` (TMPL-52).
- `koreanTagRule` / `englishTagRule` (GEN-50): choose tags among labels already true of the post rather than the first one reached for.
- Each constant carries a doc comment naming its primary source, the way `koreanAltitude`'s names its decision. The prohibitions cite Google Search Central (boilerplate titles: long text varying by one piece of information) and Naver 서치어드바이저 (a keyword repeated twice or more in a title risks a penalty), per `spec/ideation/post-quality-and-related-links.md` and QUAL-6. Every other title claim has no primary source and stays out.
- The tag rule's comment cites GEN-50 and states that no search-demand data is read anywhere (QUAL-34); nothing in this task reads one.
- `WritePrompt` and `englishWritePrompt` insert `"\n" + <plain prohibitions> + "\n" + <tag rule>` directly after the naming line. The exported constants hold the plain variant, so `TestNaturalnessBaselineIsSharedByWriteAndRevise`'s literal prefix and `TestMemoNamingAuthorityIsInWritePromptsOnly`'s line order hold unchanged.
- The variant: a helper `writeStaticRules(language Language, titleForm bool) string` returns `WritePrompt`/`englishWritePrompt`, or the same text with the plain prohibitions line swapped for the form line via `strings.Replace(…, 1)`. `BuildWritePromptForLanguage` passes `template != nil && template.TitleArea != ""`.
- Neither variant may contain the other as a substring, so the exactly-once counts can tell them apart.
- Accepted consequence: a title-area post's static prefix differs from a title-less one at that line. That gives two stable prefixes and never per-post drift. `TestWritePromptAppendsOneTemplateSectionAfterTheCompleteVoiceProfile` keeps passing because `testBrief()` has no title area.
- `templatePrecedence` rewrite (GUIDE-35/36): the template decides 구성·순서·포함할 내용; 문체·종결어미 follow the profile above; a concrete substitution the template states (the source says A, write B) beats the profile; an abstract instruction about better words carries no such authority. It keeps the doc comment's property: no `지침` (TMPL-13).
- `guidelinePrecedence` rewrite (GUIDE-35/36/37): keep its first sentence and `지침이 템플릿의 요구와 충돌하면 지침을 우선하고`. Then 문체·종결어미 follow the profile; a concrete substitution ranks 지침 > 템플릿 > 말투 프로필; an abstract vocabulary instruction carries none; when two 지침 lines conflict the earlier one wins. T342 injects the preset last, so an owner's line beats it.
- Both sentences stay Korean for every target language (GUIDE-15, TMPL-13). The revise goldens do not move, because neither carries a template or guideline section.
- `nouns` (GEN-55, R28): the shape line in both constants gains `,"nouns":[]` after `"blocks":[]`. New constants `koreanNounsRule` / `englishNounsRule` go on their own line after the block-fields line: nouns lists the distinct nouns the title and the body use, in the output language, bare without particles, at most 40.
- The bare-form clause is load-bearing: QUAL-7's containment matches an 어절 that starts with the noun. The number 40 appears literally in both lines, and a test asserts it equals `WriteNounsMax`.
- `config.go`: `WriteNounsMax = 40`.
- New `schemas/write_answer.schema.json`: `post_content.schema.json` plus `"nouns": {"type": "array", "maxItems": 40, "items": {"type": "string"}}`, with `nouns` added to the top-level `required`, keeping the strict-mode shape (every property required, `additionalProperties: false`). It has no enum: a numeric enum breaks Gemini's whole object.
