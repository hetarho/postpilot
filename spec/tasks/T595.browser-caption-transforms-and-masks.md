## goal
Reproduce transform-, word- and mask-based caption styles using reusable local ink.

## acceptance
- [ ] Word-pop, pop, stack, sticker, bubble, serif and outline use deterministic frame progress with exact current easing, pivots, word ordering, masks and entry/exit boundaries.
- [ ] Static-style movement/fades and rapid phrases retain their declared behavior; rapid mode does not silently change drawing, face or plate.
- [ ] Per-word/per-line masks and ink are reused while position, opacity, rotation, scale and reveal geometry change; steady text is not rerasterized every frame.
- [ ] First/last visible frames, seek/replay and export at different processing speeds yield the same time state without unseeded randomness or missing frames.
- [ ] Generation workload copy distinguishes reusable ink and frame-dependent work without a device-independent longest-duration promise.
- [ ] All-style/ratio/pace frame tests for this group, long-text/glyph cases, cache/resource tests and real-browser comparisons pass with required local checks.

## impl notes
- Port drawWordPop, drawPop, drawStack, drawSticker, drawBubble, drawSerif and drawOutline from the current caption painter as the mathematical reference.
- Represent words/lines and plates as stable scene nodes/textures; prefer bounded rectangular/scissor reveals where they reproduce the current clip paths.
- Do not animate React components per exported frame or recreate Pixi filters/graphics containers when only parameters change.
- Update the existing pre-generation rendering-work presentation under CLIP-145/CDS-81; no new AI calls, caption-count cap or per-glyph animation feature is added.
- Add the styles to T588's fixture adapter and record appearance deviations for the final qualified review rather than changing the selected style to hide them.
