## acceptance
- [v] Word-pop, pop, stack, sticker, bubble, serif and outline use deterministic frame progress with exact current easing, pivots, word ordering, masks and entry/exit boundaries.

- [v] First/last visible frames, seek/replay and export at different processing speeds yield the same time state without unseeded randomness or missing frames.
- [v] Generation workload copy distinguishes reusable ink and frame-dependent work without a device-independent longest-duration promise.
- [v] All-style/ratio/pace frame tests for this group, long-text/glyph cases, cache/resource tests and real-browser comparisons pass with required local checks.
