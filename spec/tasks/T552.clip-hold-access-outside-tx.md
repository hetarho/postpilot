## goal
A clip reservation never fetches OpenRouter's endpoint document while it holds the SQLite writer: the live free-path qualification runs first, outside the transaction, and the in-transaction hold skips it.

## acceptance
- [ ] `clipapp.Guard` takes a required access checker (constructor argument, ARCH-40) and `Guard.Reserve` calls it before `WriteTx` opens; a refusal returns before any transaction
- [ ] `usage.Start` gains `AccessChecked bool`; `usage.Service.Hold` skips `CheckModelAccess` only when it is set, and every other caller (generation, voice, template, experiment holds) still runs the check before its own `InWriteTx`
- [ ] `cmd/api` wires the checker from the non-transaction ledger (`jobAdmission` resolves the acting plan and calls `ledger.CheckModelAccess` with the same planned calls `hold` builds), and `clipAdmission.Hold` passes `AccessChecked: true` into the in-transaction hold
- [ ] clip/app test: a fake writer records when a transaction is open; the access checker runs while none is, and the in-transaction admission receives the checked flag; a checker refusal leaves no admission and no transaction
- [ ] usage test: a fake qualifier counts `QualifyFree` calls — Hold with `AccessChecked` makes none, Hold without it makes one per free call
- [ ] behaviour unchanged otherwise: ARCH-26 green
