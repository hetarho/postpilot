## goal
Measure a real whole-frame PixiJS 8 WebGL compositor against the optimized Canvas 2D control on identical fixtures, replacing the Canvas-hybrid Pixi arm as comparison evidence.

## acceptance
- [ ] A third diagnostic arm `pixi-webgl-compositor` in scripts/browser-render-comparison (the `Arm` union in contract.ts, worker.ts, entry.ts and runner.mjs) composes footage frames, region blocks and captions in one PixiJS 8 WebGL stage on the worker's OffscreenCanvas, and feeds the same frozen plan, decoder, audio processor, packet sink, OPFS MP4 and verdict as `canvas2d-shared`.
- [ ] `node scripts/browser-render-comparison/static-check.mjs` covers the new arm (arm listed, same fixture/plan/source binding) and passes; `pnpm run lint` and `pnpm run format:check` pass.
- [ ] The runner's single case and then the four-case matrix run in this host's Playwright Chromium. Each arm records cold/warm named phases, logical peaks, sampled-pixel residuals against `canvas2d-shared`, output verdicts and cleanup, together with the actual WebGL renderer string; a software rasterizer (SwiftShader, llvmpipe) is labelled as software and is not hardware evidence. The run is added to docs/design/browser-render-comparison-current.json with earlier runs kept, and summarized in docs/qa/browser-render-pixi-compositor.md.
- [ ] The production composition in frontend/src/entities/clip-preview/lib/video.worker.ts is unchanged; the doc states whether the Pixi arm was faster and within the measured residuals, as input for a later default decision that needs human output review.
- [ ] exit: when the timebox runs out, record which arm/case runs completed or failed with their errors and what remains, and finish; an arm that did not run is recorded as unexecuted, never as slower or faster.

## impl notes
- Split from T604 (inbox 261111 decided T604). Diagnostic only: no file under frontend/src changes behavior. Reuse the caption and region builders the comparison already imports from entities/clip-preview (ink-caption-pixi.ts, ink-caption-filter-pixi.ts, ink-caption-ember-pixi.ts) without forking them.
- Footage: wrap each decoded `VideoFrame` as a Pixi texture source for that frame only and close the frame once it is drawn. Keep the ARCH-63 bounds of the other arms: bounded in-flight frames, textures destroyed per frame and no growing texture cache.
- Output: `new VideoFrame(offscreenCanvas, { timestamp })` with the same explicit timestamps as the other arms, plus the same diagnostic readback the other arms already pay so timings stay comparable.
- A browser without WebGL2 records the arm as unexecuted with its reason; the arm never falls back to Canvas 2D on its own.
- Run with other expensive checks stopped, as scripts/browser-render-comparison/README.md requires, and bind a clean exact commit with `--expected-head`.
- The Windows Chrome/Edge measurement of all arms is T750; integrated-GPU and lower-resource devices remain T604.
