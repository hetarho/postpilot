# T366 The draft queue's assignments are one record per channel
> st:todo | ssot:- | base:ARCH@9 | dep:-

## goal
`draft-queue.ts` keeps its four assignments as one typed `Assignment<T>` record per channel, walked by a single channel list, so a new channel is one table row rather than about 12 hand-kept sites. `SendDraft` takes one named request. The 분야 baseline can no longer be omitted.

## impl notes
- from review/published-quality-260924 F24
- Do not move this queue into `shared/lib/autosave`. T266 (arch-260919 F8) tried that and recorded why it was not done: a serial channel with per-assignment waiters, baselines and take-backs, plus the mid-flight re-key, would put post rules into `shared/lib`. Keep the file's header comment (:1-17) and the shared `SaveState` / `AUTOSAVE_*` imports. This task only folds the four copies inside it.
- **Which channels share the shape: all four.** Voice, 템플릿, 분야 and target language each have the same five parts:
  - a wanted value and a server-held baseline;
  - dirty = `slug && wanted !== saved`;
  - toSend: dirty-only on an existing post, a create-time rule otherwise;
  - waiters settled by "landed / superseded / still waiting";
  - a take-back on refusal.

  Only three things differ. They become data in one table:

  | channel key | error noun | create sends | baseline before the post exists |
  |---|---|---|---|
  | `voiceId` | `voice` | always (`v => v`) | `''` |
  | `templateId` | `template` | only when chosen (`v => v \|\| undefined`) | `''` |
  | `fieldId` | `field` | only when chosen | `''` |
  | `targetLanguage` | `target language` | always | `undefined` |

  The take-back `wanted = saved ?? wanted` is today's rule for all four. For the voice, 템플릿 and 분야, `saved` is always set once `slug` is, so `?? wanted` only matters for the language (:559, :575).
- **New types in `draft-queue.ts`** (export the three the tests and `useAutosave` need):
  - `export interface Assignments { voiceId: string; templateId: string; fieldId: string; targetLanguage: ContentLanguage }`. The keys are the request's and the options' member names, so a request is `{ slug, draft, ...carried }` and the init reads `options[channel]`. Leave `fieldId: string`: T373 retypes it to `BlogFieldChoice`.
  - `export type AssignmentChannel = keyof Assignments`
  - `export interface DraftRequest extends Partial<Assignments> { slug: string; draft: Draft }`. Carry SendDraft's doc comment (:49-63, :70-71) over onto the members. An undefined member leaves the post's value alone, and `''` clears a 템플릿 or a 분야.
  - `interface AssignmentWaiter<T> extends FlushWaiter { value: T }`. It replaces the four `*Waiter` interfaces (:120-134).
  - `interface Assignment<T> { wanted: T; saved: T | undefined; waiters: AssignmentWaiter<T>[] }`. `saved` is "what the server is known to hold". Keep the voice/template/field field comments (:148-163) on the table rows.
  - `type AssignmentRecords = { [K in AssignmentChannel]: Assignment<Assignments[K]> }`
  - `const RULES: { [K in AssignmentChannel]: { noun: string; onCreate: (wanted: Assignments[K]) => Assignments[K] | undefined; unsaved: Assignments[K] | undefined } }`, filled from the table above.
  - `const CHANNELS = ['voiceId', 'templateId', 'fieldId', 'targetLanguage'] as const satisfies readonly AssignmentChannel[]`, plus a `satisfies` check that it covers every key (a `Record<AssignmentChannel, true>` built from it, or a test).
  - `export interface DraftQueueOptions extends Assignments { slug; saved; send: SendDraft; retry?; onState; onMinted }`. This is `attachDraftQueue`'s parameter, so `fieldId` is required by construction.
- **Generic helpers** replace :264-311 and :338-411:
  - `dirty(queue, channel)`
  - `toSend(queue, channel)`

  - `carried(queue): Partial<Assignments>` (only the members this save carries)
