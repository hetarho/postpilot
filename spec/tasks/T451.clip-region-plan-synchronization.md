## goal
Make project region edits update the same content used by correction, preview and both render kinds without rebuilding footage or captions.

## acceptance
- [ ] Enabling a region with final text creates its plan elements even for an empty template composition; disabling removes its visible text and decoration while retaining draft content. Initial intro/outro intervals are first 2.5 s/last 3 s over existing output and add no footage or duration.
- [ ] Final-text edits and preset changes update only affected region content/layout, preserving footage, captions, audio and existing valid owner-edited region intervals. Instruction-only edits do not rewrite the plan; existing out-of-range timing remains an identified authored error rather than silently retimed content.
- [ ] Correction edits to region text update the matching project slots in the same save; direct edits become owner-fixed. Reloading or switching surfaces never restores a second, stale copy of region words.
- [ ] Blank slots retain their ordinal identity and omit only the corresponding text/gap/decoration; disabled/all-empty blocks draw nothing. Surplus drafts produce the existing unused-content notice, remain editable and return on capacity growth. Owner-fixed overflow identifies its slot and is never shortened or removed.
- [ ] A changed visible composition advances the saved plan revision atomically and makes a prior render stale; semantic no-op saves do not. Concurrent settings/correction saves cannot overwrite a newer plan or slot edit; conflicts preserve the caller's draft. Instruction-only changes invalidate future generation inputs without falsely changing rendered appearance.
- [ ] Go regression tests cover no-template insertion, template-backed deduplication, blank middle slots, disable/re-enable, capacity changes, inverse correction updates, revision conflicts and rollback on invalid authored text. Media/manifest tests cover exact region text, absence and geometry in all three ratios.
- [ ] Pass ARCH-31's local gates and run the matching CPU media image smoke under ARCH-37; this task does not activate a GPU profile.

## impl notes
- Centralize region-to-plan projection and correction-to-slot reconciliation in the clip domain; use `composition_state.go`, `correction_composition.go`, `region_lines.go` and the portable plan's existing snapshot/inputs. Stable slot-to-element identity must not depend on the count of nonblank lines. Never render seeded template entries a second time beside project slots.
- Wire project updates and `store/correction.go` through the same transaction boundary, validating before persistence. Extend the existing expected-revision mechanism to any region write that changes an existing plan, and return the resulting canonical project. Reuse existing conflict/busy/finalized errors; do not add a silent last-writer-wins path.
- Preserve region intervals/identities when compatible elements already exist; use retained timing when restoring a region and defaults only when no prior timing exists. Keep unused slot drafts separate from drawable elements. Generation's text-fitting/removal policy must not run over an owner's edit.
- Audit region resolution in `backend/internal/clip/media`, draft overlay generation, browser render manifests and server preflight: enablement and slot content must come from the canonical project/plan, never preset fallback or a fresh template lookup. Keep raster drawing and timing ownership on the current shared path.
- Expose structured slot validation/notice data through existing error and notice transport. Invalid edits remain an unsaved caller draft; don't partially persist enablement, text or a plan. T453 binds these errors to fields and serializes the UI save queues.
