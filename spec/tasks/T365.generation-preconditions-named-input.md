# T365 Generation preconditions take one named input
> st:todo | ssot:- | base:ARCH@9 | dep:-

## goal
The ordinary and comparison generation gates each take one object whose members are all required. A caller that omits a blocker's input no longer compiles, instead of silently passing the gate. `/ai-models/compare` passes `published` and `videos`.
