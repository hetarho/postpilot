# T731 Make the source cadence measurement deterministic
> st:todo | ssot:CLIP-204 ARCH-31 ARCH-37 | base:CLIP@71 ARCH@21 | dep:- | touches:backend/internal/clip/media/probe.go backend/internal/clip/media/chunks.go | lane:- | explore:2h

## goal
The same original measures the same `CadenceVerified` on every run, so `Verify media`'s worker parity gate cannot flip on an unchanged tree.

## acceptance
- [ ] The cause is identified from captured ffmpeg logs (a repeated preparation run on a linux/amd64 runner-like host, or the decode command alone over the smoke fixture), and recorded in result.
- [ ] `constantCadenceReport`/`decodeMeasurement` read the vfrdet report so a nondeterministic log shape cannot change the verdict for an unchanged source, without accepting a source whose decoded timestamps vary.
- [ ] `probe_test.go` (or the existing media unit tests) pins the log shapes found: the report split from its prefix by a concurrent `-progress pipe:2` write, an extra early-closed graph report, and a genuinely varying report.
- [ ] `TestWorkerExecutionParity/preparation` passes repeatedly in the worker smoke image (`docker run … /media.test -test.run=^TestWorkerExecutionParity$/^preparation$ -test.count=N`).
- [ ] exit: when the 2h timebox ends without a reproduction, record the runs and log captures tried, keep the measurement unchanged, and leave the gate as a recorded runner flake.

## impl notes
- Evidence: Verify media run 41469072328 (commit 70811b8c, T730 — only a browser-composition constant changed), job `Media worker`, step `Run CPU worker parity, isolation and health`: `worker_smoke_test.go:178: original measurement changed`. Worker and embedded measurements of the same fixture match in every field except `CadenceVerified` (worker true, embedded false); DecodedFrames 1200 and all durations equal. The same subtest passed on GitHub at 05c8d739 and earlier, locally on 70811b8c, and 12 more local repeats under amd64 emulation.
- Both measurements run `-vf vfrdet` with `-progress pipe:2` (probe.go `Probe`, chunks.go:148) and parse stderr; `constantCadenceReport` requires exactly one `[Parsed_vfrdet_…] VFR:x (v/c)` match with c>0. Two nondeterministic shapes fit a false verdict with intact frame counts: the av_log prefix and message written in separate writes with a progress block between them (no match), or the negotiation graph closing after it already saw frames (two matches).
- Preferred fixes, in order: send progress to its own descriptor so the log cannot interleave with it; otherwise parse the `VFR:x (v/c)` message independently of its prefix and accept one or more graphs with c>0 as long as every report has v=0. Keep the (0/0) negotiation report ignored.
- A measurement change moves no media identity unless its output changes; if `MediaRendererVersion`/asset identities would move, follow reference-clip-data-migration-traps (Dockerfile labels follow the Go constants).
