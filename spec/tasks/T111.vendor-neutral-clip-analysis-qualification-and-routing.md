## goal
Replace the Google-family clip gate with one server-owned qualification contract that can safely admit any registered observe model whose current OpenRouter route accepts the bounded inline clip request and exposes an enforceable complete price ceiling.

## acceptance
- [ ] a clip-owned qualifier evaluates every registered observe model without a provider slug or model-family admission allowlist: no `video_input` yields `CLIP_MODEL_VIDEO_INPUT_ABSENT`, while a video-capable model is evaluated against its current OpenRouter endpoint document, the exact request shape and the price policy used by generation
- [ ] endpoint qualification chooses one deterministic compatible provider leaf and distinguishes the other three stable failures: no valid bounded-inline route → `CLIP_MODEL_INLINE_ENDPOINT_UNAVAILABLE`, no leaf supporting every parameter the actual request sends → `CLIP_MODEL_REQUIRED_PARAMETERS_UNSUPPORTED`, and no enforceable complete ceiling for applicable billing units → `CLIP_MODEL_PRICE_CEILING_UNAVAILABLE`; precedence and malformed/ambiguous-document behavior are pinned by table tests
- [ ] required parameters are derived from the request rather than a universal list: `max_tokens` is required, `response_format`/`structured_outputs` are required only when the model capability causes a JSON-schema request, and `reasoning` is required only when that request sends reasoning; a model without structured output remains eligible through the existing caller-owned parser fallback
- [ ] a qualified call freezes the chosen provider leaf, endpoint/profile fingerprint, required parameters and exact decimal price limits; the adapter sends one `provider.only`/`provider.order`, `allow_fallbacks=false` and `require_parameters=true`, then rechecks the same qualification before completion and refuses drift without retry, supplier fallback, relaxed limits or another model
- [ ] the prepared MP4 remains one bounded inline part and one pass; `processing: static` is sent only by a positively documented endpoint profile that supports it, every other route omits provider-specific processing controls, and no route sends adaptive exploration; this optional control never determines whether an otherwise compatible provider/model is admitted
- [ ] pricing requires prompt and completion rates and conservatively covers every applicable media, reasoning, request, cache and conditional unit published by the chosen endpoint without overlap; an omitted optional media SKU is accepted only where the current OpenRouter contract makes it inapplicable/included rather than an unknown charge, while malformed, unknown-applicable or unenforceable pricing fails closed
- [ ] authenticated `ClipService` exposes one read-only eligibility RPC returning model ref plus exactly one of eligible/the four stable statuses for every registered observe model in registry order; it makes no model call or DB write, discloses no provider payload/price/key, bounds endpoint lookups, deduplicates concurrent reads and caches only successful endpoint documents for the existing catalog TTL
- [ ] `QuoteClipGeneration`, `StartClipGeneration`, post-preparation admission and metered completion consume the same qualifier and frozen policy; any incompatibility is refused before approval/reservation or, on recheck drift, before a model call with zero new credit debit and no automatic substitution, while signed-URL post generation and write experiments retain their independent `MODEL_VIDEO_UNSUPPORTED` contract
- [ ] the four new reasons are registered with the display-safe `{model}` parameter contract and are used consistently by synchronous details and durable clip failures; absent, duplicate, malformed or unmapped details still become `UNKNOWN_FAILURE`, and logs/errors contain no endpoint body, prompt, media, data URL, signed URL or credential
- [ ] adapter, registry, clip service and RPC tests use sanitized endpoint fixtures for an explicit-media-price Google route, prompt/completion-only Qwen route, conditional-price ByteDance route and parser-fallback Amazon route, plus missing modality/endpoint/actual parameter/price, ambiguous leaf, fingerprint drift, cache expiry/concurrency and one-request/no-fallback cases; no paid provider call is made
- [ ] ARCH-26, ARCH-28 and the relevant ARCH-31 local gates pass; generated Go, agent and TypeScript protobuf code is committed with appended fields only

## impl notes
- place the eligibility use-case, status enum and consumer-owned endpoint-qualification port under `internal/clip`; let `internal/llm/openaicompat` own OpenRouter document parsing, routing keys and price semantics, and compose them only in `cmd/api` so neither clip domain nor public proto learns a provider SDK type
- add the RPC to `ClipService`, not `ProviderService`: `video_input` remains raw catalog capability and signed-URL readiness remains a different workflow contract. Keep protobuf fields 17/18 wire-compatible; `inline_static_video` is no longer authoritative for CLIP and must not be broadened to conflate static processing with generic inline eligibility
- append a wire enum with `UNSPECIFIED`, `ELIGIBLE`, `VIDEO_INPUT_ABSENT`, `INLINE_ENDPOINT_UNAVAILABLE`, `REQUIRED_PARAMETERS_UNSUPPORTED` and `PRICE_CEILING_UNAVAILABLE`; the domain enum must reject `UNSPECIFIED` rather than treating it as eligible. Return refs/statuses only and let T112 merge display metadata from the existing observe list
- evaluate the same model-dependent analysis request the service will issue. Freeze structured-output presence as part of `CallPolicy`/`ExecutionPolicy` matching so a quote made with the parser fallback cannot execute later with an unpriced or unsupported schema parameter
- retain exact rational arithmetic and T083's conservative conditional-price handling. Treat optional OpenRouter price keys as separate units only when the request can incur them; never infer that a missing required price is zero, and never charge the quote envelope as measured final use
- endpoint-document fetch failure has no successful current proof and therefore cannot produce an eligible item; an unexpired successful cache may be reused, but an expired/stale document may not. Use a small code-owned concurrency bound and the existing 5-minute catalog TTL/15-second fetch timeout rather than a new environment variable or dependency
- record the official OpenRouter video-input, endpoint, provider-routing and pricing references used for the parser/profile in code comments or sanitized fixtures under ARCH-33. The named fixture families prove distinct metadata shapes; their ids are not an allowlist and live network availability is not a deterministic test assertion
- preserve the 8 MiB raw-copy, 12 MiB encoded-request, 60-second and preparation/resource bounds from T083/T084; this task changes qualification, request shaping and policy freezing, not media preparation, rendering or the registered-model set
