## goal
A draft holding a storyline and no content reads 스토리라인 작성 완료 in the post list and in aggregate 내 글, as a clip does.

## acceptance
- [ ] The post list summary carries whether the post holds a storyline; a draft with a storyline and no content shows `스토리라인 작성 완료` (en `Storyline ready`) as a mid-way badge; a running job, a failure and a pending experiment keep outranking it in their existing order.
- [ ] The status filter is unchanged and keeps such a post under 초안; review, finalized and published posts never show the storyline badge.
- [ ] Aggregate 내 글 shows the same label for such a post as the post list does, with the same precedence.
- [ ] Tests: `pages/posts/ui/PostsPage.test.tsx` (badge and precedence truth table, filter unchanged), `pages/my-work/ui/MyWorkPage.test.tsx` (aggregate label), the post list store/handler test for the new summary field; `pnpm gen:proto` and `pnpm gen:sql` leave no diff after commit; gofmt, `go vet ./...`, `go build ./...`, `pnpm lint` and `pnpm build:web` pass.
