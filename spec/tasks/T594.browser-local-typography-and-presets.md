## goal
Create local qualified layout/ink resources for static captions, disclosure and every existing region preset.

## acceptance
- [ ] Browser layout/typesetting uses the fixed bundled faces, exact weight/tracking/line-fit rules and Wanted Sans glyph substitution; no system font or implicit missing-glyph replacement is used.
- [ ] Bold, keynote and film captions, disclosure and all intro/outro presets reproduce current text, slot order, geometry, role floors, blank-slot behavior and supported ratios.
- [ ] Compatible resvg-wasm or approved equivalent resources draw reusable ink/masks locally without a server PNG/frame-sheet request.
- [ ] Cache keys include all text/font/size/style/ratio/paint/layout inputs; movement-only changes reuse ink, bounded eviction destroys GPU/bitmap resources and original footage is never persisted.
- [ ] Long Korean lines, rare syllables, numbers/units, mixed text, region wrapping, glyph gaps and effect bleed are compared with native reference frames.
- [ ] Layout/cache/unsupported-font tests, real-browser font/WASM fixtures and required local checks pass; applicable source and OFL notices are included in the inventory.
