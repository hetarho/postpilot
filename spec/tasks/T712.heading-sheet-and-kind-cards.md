## goal
The headings step offers 제목 제안 받기 through a style-request sheet with example chips and uses the ordinary 다음; the section step offers its three content kinds as cards drawing 글 쓸 때 / 완성된 글.

## acceptance
- [ ] headings step: the top 내 말로 쓰기 button and the voice-style help line are gone; the frame's next slot holds 다음
- [ ] 제목 제안 받기 opens a `Sheet` asking 원하는 스타일을 말씀해주세요 with a textarea counted to `HEADING_STYLE_REQUEST_MAX_CHARS`, example chips that fill it, the estimate and 제안 받기; sending calls `operation.start(model, request)` and closes the sheet; model/too-many/pending/failure states still show on the step
- [ ] section step: three radio cards (AI가 쓰는 글 · 직접 입력 · 고정 문구), each with 글 쓸 때 and 완성된 글 panels drawn from this section's heading/question/literal; arrow keys move between them; question/literal fields stay below
- [ ] tests: `HeadingSuggestions.test.tsx` (sheet opens, chip fills, send passes request, closes); new `ContentKindCards.test.tsx` (choosing 직접 입력 emits `ask`, panels show the question)

## impl notes
- examples are code in the feature i18n (`wizard.headings.sheet.examples`, four entries, ko/en), the first being 이모지를 포함해서 20대 여성을 타겟팅할 수 있는 소제목으로 만들어줘; tapping replaces the field text
- the commit action sits in flow after the chips, not a pinned footer (keyboard viewport, VOICE-53 precedent)
- cards: `fieldset` + native radios (`sr-only`) inside `label` cards so the browser provides arrow keys; selected card `ring-2 ring-stroke-accent`, focus-visible ring via `has-[:focus-visible]`
- panels: write → 글 쓸 때 "따로 채울 칸 없음" + memo/photo glyphs, 완성된 글 heading + line bars; ask → 글 쓸 때 a mock field titled by the question, 완성된 글 heading + the answer chip "적은 내용 그대로"; literal → 글 쓸 때 "따로 채울 칸 없음", 완성된 글 heading + the literal text (placeholder when empty)
- reuse stand-ins exported by T711 (`PreviewStandIns`)
