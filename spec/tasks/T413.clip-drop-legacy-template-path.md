# T413 The legacy clip template path, category presets, chips, hook, CTA and fact minimum are gone
> st:todo | ssot:CLIP-14 CLIP-59 CLIP-68 CLIP-111 CDS-37 CDS-51 CDS-60 | base:CLIP@46 CDS@27 | dep:-

## goal
Every clip template is an outline template and every project renders from the shared defaults plus its own design selection: nothing in the backend or proto can create, read, generate or render a legacy category-preset template, and no chip, hook card, closing CTA or fact minimum exists anywhere.

## acceptance
- [ ] CreateVideoTemplate/UpdateVideoTemplate accept only a composition body; the `preset` fields, `SeedPresetFields` RPC and every legacy recipe field are gone from `clip_template.proto`/`clip.proto` with their numbers and names reserved; a request without a body is refused `InvalidArgument`
- [ ] `design.json` holds no `presets`, `cta` or `facts.minimum`; `ValidPreset`, `ValidCTA`, `DefaultCTA`, `MissingFactsError`, `CLIP_FACTS_REQUIRED`'s switch arms, `ChipPriority`, `ChipLabels`, `Cut.Chips`, `EditPlan.Hook`/`CTA` and `FreezeLegacyPlan` are deleted; `CutBounds` takes the shared 1.2–6.0 s range with CDS-37's observed-scene exceptions only
- [ ] no legacy read-compat remains: `CompositionLegacy`, `legacyCompositionRoot`, recipe→outline conversion, `RetiredCopyStyles` and CDS-60's old-plan caption-pace fallback are removed; a forward migration drops or rewrites any legacy template/project columns (pre-alpha data is disposable)
- [ ] tests: the preset/chip/CTA/fact tests are deleted; new tests pin that a body-less create is refused and that CutBounds ignores any preset; `TestCategoryPresetsKeepTheirValues` is removed
- [ ] verify BE: `cd backend && test -z "$(gofmt -l .)" && go vet ./... && go build ./... && go test -timeout 30m ./...`
- [ ] verify gen: `pnpm gen:proto && git diff --exit-code -- backend/internal/gen frontend/src/shared/api/gen` · `pnpm gen:sql && git diff --exit-code -- backend`
- [ ] `pnpm --filter ./frontend test` and `pnpm build:web` still pass after regen
