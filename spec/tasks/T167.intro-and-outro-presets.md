## goal
A clip opens and closes with the card-free preset its template selected, white only, filled with nothing but slot text.

## acceptance
- [ ] `role="hook"` renders the intro preset named by the document's `intro` attribute and `role="ending"` the outro preset named by `outro`, reading geometry from `design.Region`: slot baselines and rule y positions exactly as `regions` states them on 9:16, scaled by canvas height / 1920 on 16:9 and 1:1 with every font size kept except `t.hook` from `ratios.*.hook_size`
- [ ] every slot and rule is `text_white` or `text_muted` at its declared alpha; no region part reads the project accent, and outro E's bar is the white `rule.bar`
- [ ] slots come from the element's rows in declared order; a row beyond the preset's slot count, a row containing a newline, or a row longer than its type's `chars` fails with `copy_limit` naming the element (CDS-77's authored half)
- [ ] a slot whose text resolves empty is omitted and the remaining slots keep their fixed y; a block whose every slot is empty emits no parts at all, rules included
- [ ] hairlines and bars are `plate` rect parts of the manifest so V10 passes unchanged; V20 checks that a rendered block's slot count, y positions, sizes and fills match the selected preset and is listed in the verifier's check list
- [ ] `media/cards.go`, `cardLayout`, `measureCard`, `cardPlate`, `CardElements`, `hookLines`, `layers.cardInput`, `overlay.CardView`, the `card` overlay preset and its `bindings.json` entries, and `ratios.*.hook_card` / `end_card` in `design.json` (both copies) are removed
- [ ] automatic caption placement uses the CENTER column only; LEFT and RIGHT remain reachable only from an explicitly authored element (CDS-74)
- [ ] `docs/design/clip-output-design-spec-v1.md` describes the four presets in place of the hook and ending card sections, and `clip_sample_tmp/` is deleted
- [ ] test: all four presets in all three ratios stay inside the safe area and meet the V2 floors, and V20 rejects a block whose slot y or fill differs from its preset
- [ ] test: an empty middle slot leaves the others at their declared y; an all-empty block emits no parts
- [ ] test: a third intro row, a two-line row and a 10-character `t.hook` row are refused before rendering with the element named
- [ ] `cd backend && test -z "$(gofmt -l .)" && go vet ./... && go build ./... && go test ./...`

## impl notes
- `layoutDeclaredCard` in `media/composition_roles.go` becomes `layoutDeclaredRegion`: it resolves the preset, walks rows against slots, and measures each slot as a single centred line — no card region, no padding, no plate
- the grammar keeps the role names `hook` and `ending` — only what they draw changes — and the preset comes from `Document.Design` (T169); until T169 lands, read the attributes through `composition.ReadStored` defaults b/bold/e so the two tasks can run in parallel
- a legacy plan's two-line hook (`EditPlan.Hook`) now fails `copy_limit` on rerender instead of reflowing: CDS-64 identifies and preserves, it does not reflow, and the owner shortens it in step ②
- brightness sampling for the blocks is T168's; expose `regionBounds(visual)` — the union of the block's slot bounds — so T168 samples it without re-measuring
- resvg draws Paperlogy only when `faces.paperlogy` is the typographic family (T166 fixes it, T170 guards it); the test fixtures in the Docker `media-smoke` image are the only place the real face renders
