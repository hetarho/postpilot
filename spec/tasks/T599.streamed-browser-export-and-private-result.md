## goal
Encode/mux bounded browser output without server drawing and separate local readiness from durable completion.

## acceptance
- [ ] The qualified browser path composes/encodes the frozen full-quality 30-fps output locally with exact requested audio and no native sampling/raster/render stage.
- [ ] Encoded packets flow directly into one MP4 mux session with finite backpressure; no full video-chunk array plus second whole-file BufferTarget copy is required.
- [ ] Position-aware file writes use a supported seekable writer, bounded private temporary output or bounded Blob fallback; size/resource exhaustion fails explicitly without corrupt/truncated MP4.
- [ ] Producing-side verification checks the existing resolution/codec/fps/video-duration/audio/speech contract before local playback/download becomes available.
- [ ] UI distinguishes verified local output, pending private upload and durable success; finalization stays closed until existing revision/verdict/upload promotion succeeds.
- [ ] Upload retry reuses valid local bytes; cancellation/logout/leave/context failure reclaims workers and temporary output, and stale/deleted/finalized promotion cannot replace the prior result.
- [ ] Lifecycle, mux-position, output bounds, ordinary/narrated parity and race tests plus real-browser export/storage checks and required local checks pass.

## impl notes
- Evolve the current render-video/run-render/mux-mp4/store-result collaborators to streamed packet sinks and small track measurements rather than transporting all chunks to the window.
- Keep standard seekable MP4 output; initially disable fastStart if necessary to avoid buffering the whole payload, and verify normal seek/playback after finalization. Fragmented output is not silently substituted for the delivery contract.
- Set a named initial temporary/Blob output ceiling of 128 MiB for the existing at-most-60-second profile; enforce it while writing, not only after allocation.
- OPFS spools contain only output MP4 and minimal owner/run identity, never source/proxy bytes, decoded speech or signed links. Clear on logout and reclaim abandoned spools before exposing any new-session artifact.
- Retain the current result-store admission, measured-verdict and exact speech fingerprint fences. A locally playable result is provisional and never becomes the canonical ClipProject.result before storage acceptance.
- Keep browser and native final-render activation independent from browser analysis preparation and existing real voice qualification.
