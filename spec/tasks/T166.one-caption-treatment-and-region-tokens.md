# T166 Collapse the style system to one caption treatment and add the region tokens
> st:todo | ssot:CDS-22 CDS-25 CDS-39 CDS-40 CDS-17 CDS-21 CDS-66 | base:CDS@15 ARCH@2 | dep:-

## goal
The design configuration describes one caption treatment and the two region blocks, and the style-selection machinery that chose between five styles is gone.

## acceptance
- [ ] `backend/internal/clip/design/design.json` keeps exactly one entry under `styles`, keyed `caption`, carrying the CDS-25 rule (no plate, `stroke.text` 6, `shadow.text`, `t.title`, 2 × 11, CENTER); `clean`, `memo`, `bold`, `mark` and `simple` are removed
- [ ] `faces.paperlogy` is `"Paperlogy"`; `type.hook` size is 132 and `type.badge` is 32/800; `pad.chip` is 4/8; `type.mark`, `type.body` and `type.simple` are removed with the styles that used them
- [ ] new tokens land beside them: `rule` (hair_w 520, hair_h 2, hair_alpha 0.55, accent_w 160, accent_h 6) and `region_y` (intro [846, 960, 1010, 1090], outro [860, 980, 1030, 1110])
- [ ] `frontend/src/shared/config/clip-design.json` is byte-identical and the Go test that compares them still passes
- [ ] `design.SelectStyle`, `design.Classify`, `design.StyleHistory`, `design.SceneStyles`, `Classes` and `Guards.RunAlternate`/`BoldMax`/`BoldFirstCut` are deleted along with their tests; callers stop passing a style history
- [ ] `composition.styleNames` is empty of the retired names and `ValidRoleStyle` accepts only `auto`
- [ ] test: the single treatment's rule round-trips from JSON with the CDS-25 numbers
- [ ] test: the FE mirror comparison fails when only one side changes
- [ ] `cd backend && test -z "$(gofmt -l .)" && go vet ./... && go build ./... && go test ./...` and `pnpm --filter ./frontend test`

## impl notes
- the single entry is keyed `caption`, not `bold`: CDS-66 says no element names a style, so the key is internal and should read as the region it serves
- `SelectStyle` currently short-circuits with `if slices.Contains(allowed, "simple") { return "simple" }`, which already made the CDS-40 table dead whenever simple was approved — deleting the table removes a rule that had stopped applying
- `design.json` is embedded by Go and imported by the FE; both copies must change in the same commit or the mirror test fails
- callers to fix: `media/composition_layout.go` (history, candidate styles), `clip/pace.go` (`composeRapid` selects a style), `clip/render.go` (`design.Styles` lookups)
