## goal
An observation call to a model that reasons gets four times the batch budget (8,192 tokens for the default batch of four photos), in ordinary observation, its quote and hold, and observation tests, so reasoning observers stop truncating.

## acceptance
- [ ] Deterministic, unit (config): `Observation(false)` is the batch budget; `Observation(true)` is the batch budget times `observeReasoningHeadroomFactor`, bounded by `Ceiling`; `WriteFloor` and write budgets are unchanged.
- [ ] Deterministic, unit (generation): a photo and a video observation request to a model whose `ModelInfo.Reasons` is true carries the raised `MaxTokens`, and a non-reasoning model keeps the batch budget; an observation test freezes the raised budget for a reasoning contestant and the batch budget for another, and its observe call plan prices that frozen budget.
- [ ] Deterministic, unit: quote/hold pricing of an observe call (`cmd/api` `providerCredits.ForCalls` and the generation estimate) uses the same reasoning-aware budget.
- [ ] Deterministic, unit: affected `cd backend && go vet ./... && go test ./internal/platform/config/... ./internal/llm/... ./internal/modelcatalog/... ./internal/generation/... ./internal/experiment/... ./cmd/api/...` pass with gofmt clean, plus the ARCH-24 task lint.
