## goal
`useClipLocalCaptionPreview` stops re-serializing the whole composition input on every render (15 Hz during playback); the key text and the preview behavior stay identical.

## acceptance
- [x] The key (useLocalSamples.ts:52-60) is computed in a `useMemo` whose dependencies are `enabled`, `selectedId`, `retry` and every field of the input the key includes (owner, project, plan, ratio, sources, layout observations, versions, authoritative fingerprint, and the design via a small `JSON.stringify(input?.design ?? null)` scalar because callers pass a fresh design literal); the revisions stay out because the key already drops them; a type-level exhaustiveness check over `keyof BrowserProjectCompositionInput` makes a future input field fail to compile until it is classified.

- [x] Behavior unchanged: same key text for the same inputs, same effect timing, renderer reuse and requests; existing `entities/clip-preview/ui` and `features/correct-clip/ui/ClipCorrectionWorkspace.test.tsx` tests pass; task check passes (related vitest, ESLint and Prettier on changed files, `tsc -b`, `pnpm lint:fsd`, `pnpm lint:style`).
