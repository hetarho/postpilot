# T260 split entities/clip-project into four nouns
> st:todo | ssot:ARCH-13 ARCH-14 ARCH-15 | base:ARCH@5 | dep:-

## goal
Split the 5.5k-line `entities/clip-project` into `clip-project` (lifecycle + api), `clip-plan` (plan editing + timeline), `clip-preview` (frames, assets, video worker, `PreviewVideo`) and `clip-observation`, and move preview fetching out of entity UI.

## acceptance
- [ ] four entity slices exist, each with one `index.ts`; `entities/clip-project/index.ts` exports ≤40 symbols and no other new barrel exceeds 60
- [ ] `clip-plan` owns `model/edit-plan.ts`, `model/timeline.ts`, `model/caption-pace.ts`, `model/revision.ts`, `api/edit-plan.ts`; `clip-preview` owns `ui/ClipDraftPreview.tsx` (renamed `PreviewVideo`, presentational), `model/draft-preview.ts`, `model/preview-assets.ts`, `video.worker.ts`, `browser-*.ts`; `clip-observation` owns `model/observations.ts`, `api/attempt-inspection.ts`; the rest stays
- [ ] cross-entity references go through `@x` only (`entities/clip-plan/@x/clip-preview.ts`, …) and the `@x` graph among the four has no cycle (steiger passes)
- [ ] `ClipDraftPreview` no longer calls `useTransport` or `clipPreviewRequest`: fetching + `PreviewPreparation` move to `features/preview-clip-draft/model/useClipDraftPreview.ts`, and the entity component renders from props so `ClipDraftPreview.test.tsx` renders it from a fixture with no transport
- [ ] every consumer (15 slices) imports from the new barrels; `pnpm lint:fsd`, `pnpm lint` and `tsc` pass
- [ ] behaviour unchanged: the existing clip tests pass unmodified except for import paths; the new feature hook has a unit test with a fake service covering ready / failed / cancelled preview
- [ ] ARCH-25 passes
