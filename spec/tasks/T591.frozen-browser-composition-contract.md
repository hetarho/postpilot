## goal
Derive an immutable versioned browser snapshot from the saved edit plan and evaluate composition from one output clock.

## acceptance
- [v] A browser run freezes project/plan revision, source fingerprints/transforms, components/fonts/assets, exact text and geometry, timing, source-audio state and immutable speech/volume provenance.
- [v] One pure output-frame evaluator covers cuts, transitions, crop, fixed rates, region/caption intervals and deterministic style progress; preview/export callers use its published surface.
- [v] No AI-authored executable HTML/CSS/shader/JavaScript, runtime signed URL or decoded media is stored in the plan/snapshot.
- [v] Existing saved plans/results remain readable; unknown or incompatible component versions refuse explicitly, and superseded seek/render callbacks cannot publish into a newer snapshot.
- [v] Server admission/publication retains ownership, retention, finalization and revision guards without requiring server frame sampling or component rasterization on the new qualified path.
- [ ] Unit and contract tests cover timeline fixtures, malformed versions, forged ownership/provenance, same-source cuts, transitions, first/last frames and cancellation/supersession; required local checks pass.

## impl notes
- Extend the existing ClipEditPlan/browser-worker types additively; reuse frameTimeline, frameLayers and existing speech fingerprints instead of introducing another editable timeline.
- Keep clip-specific evaluation and drawing ports in entities/clip-preview, design data in clip-design and generic resources in shared/lib/media. Use @x boundaries and no React in model modules.
- Use a runtime resolver for owner-bound media URLs; fingerprint/version fields identify artifacts, not host filesystem paths or arbitrary fetch targets.
- Component definitions are product-bundled code selected by known IDs. A structured saved plan never evaluates arbitrary model/user code.
- Add proto or persistence fields only for enduring identity/version data actually needed by admission; preserve wire numbers and regenerate through pnpm gen:*.
- Keep the new path gated until later component/output qualification; no task treats version negotiation as output-quality approval.
