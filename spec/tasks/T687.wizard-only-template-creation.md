## goal
Every place that creates a post template — 새 템플릿, first-use setup and 이 글 형식으로 템플릿 만들기 — runs the wizard, while saved templates keep block editing, AI refinement and an advanced 원문.

## acceptance
- [ ] `/templates/new` offers no AI/direct method chooser; an existing unsaved creation session (`?session=`) still resumes in the studio until it is saved or discarded (EDIT-15).
- [ ] `?from=<slug>` opens the wizard and, after the target step, adds the post's HEADING texts in post order as checked custom sections; a post with no heading adds none; nothing else is read from the post and no AI starts.
- [ ] First-use setup's post-template step hosts the wizard in place of the studio and the manual fallback.
- [ ] The saved-template editor shows blocks by default and moves `원문` with its 형식 안내 behind a `고급` entry; switching stays lossless.
- [ ] The authoring studio no longer offers new post-template creation; refining a saved template and unified-test candidate preparation are unchanged.
- [ ] Tests: `pages/template/ui/TemplatePage.test.tsx` `opens the wizard for a new template`, `resumes an unsaved creation session`; `pages/template/ui/TemplateRequest.test.tsx` rewritten to `seeds the wizard with the post's headings`; `widgets/creation-setup/ui/CreationSetup.test.tsx` post-template cases run through the wizard; `features/edit-template/ui/TemplateDirectEditor.test.tsx` `keeps 원문 behind 고급`; `GrammarStaysInternal.test.tsx` still passes.
