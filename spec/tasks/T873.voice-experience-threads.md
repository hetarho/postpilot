## goal
The catalog holds a code-owned question thread for each of 맛집 · 카페 · 뷰티 · 숙소 · 체험·여가 · 제품, with examples, and lists unanswered situations with review moments first; ListVoicePrompts exposes both.

## acceptance
- [ ] `ExperienceKind` (`food` · `cafe` · `beauty` · `stay` · `leisure` · `product`) with Korean label (맛집 · 카페 · 뷰티 · 숙소 · 체험·여가 · 제품) and plain word (그곳 for all but 제품, which reads 그 제품); `Prompt.Kind` is empty for situations and set for thread questions.
- [ ] Each kind has at least 2 opening, 5 description and 2 closing questions (`thread_<kind>_<part>_<n>` keys), following the kind's TMPL-72 role order (계기 → 첫인상/분위기 → 핵심 → 좋았던 점 → 아쉬운 점 → 가격·양 → 추천 대상 → 다시 갈지/쓸지); no thread question needs a photo; each carries three T871-style examples (same frame table, test and rules).
- [ ] A question's text names the experience only through the `{experience}` token, placed at a sentence start before a comma or at a sentence end, never followed by a particle; a catalog test asserts every thread text has exactly one token and the character after it is `,` `?` `.` or end of text.
- [ ] Catalog order puts review-moment situation families (food, drink, shopping, recommendations, neighborhood, gift, photos) before the other everyday families; existing keys and texts are unchanged; a test asserts every pre-existing key still resolves through `PromptByKey`.
- [ ] `VoicePrompt` gains `VoiceExperienceKind experience_kind`; `ListVoicePromptsResponse` gains `repeated VoiceExperienceKindInfo kinds` (kind, label, plain) in display order; a handler test asserts six kinds and one thread prompt's kind; generated code refreshed with `pnpm gen:proto`.

## impl notes
- Thread questions keep VOICE-60's voice: casual, framed for neighbours (`이웃에게 소개하듯`), one to three sentences asked. Sample opening: `{experience}, 어쩌다 가게 됐어요? 이웃에게 소개하듯 첫마디를 꺼내 주세요.`; product opening: `{experience}, 어쩌다 쓰게 됐어요?`.
- Examples for thread questions are about the kind in general (the owner's own place is unknown), so a 맛집 example about 칼국수 answers "others' 대표 메뉴" honestly; reuse `exampleFrames` from `prompt_examples.go` (T871) and its test helpers.
- Proto enum `VoiceExperienceKind { VOICE_EXPERIENCE_KIND_UNSPECIFIED = 0; …_FOOD = 1; …_CAFE = 2; …_BEAUTY = 3; …_STAY = 4; …_LEISURE = 5; …_PRODUCT = 6; }` (TS: `VoiceExperienceKind.FOOD`).
- `VOICE_INITIAL_QUESTION_COUNT` and readiness stay as they are here; answers per experience come in T874.
- Medical/cosmetic treatment reviews are not a target (TMPL-72): 뷰티 questions stay on hair, nails and skin care visits.
