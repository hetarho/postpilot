# T408 Generation stops freezing 분야 phrases and posts stop carrying replacement candidates
> st:todo | ssot:GEN-14 GEN-18 GEN-55 POST-83 | base:GEN@13 POST@16 | dep:T407

## goal
The write prompt carries no `[분야 상위 글 문구]` section and the write answer no `replacements`. The post keeps only its nouns, so the `posts.replacement_candidates` column and the post proto's candidate fields are gone. Every stored payload, snapshot and candidate output that still holds the old keys decodes as if they were absent.

- [ ] a generate payload, a write snapshot and a stored experiment candidate output containing `"field_phrases"` / `"replacements"` decode equal to the same document without them. New tests: payload and snapshot legacy-decode cases, plus `TestALegacyCandidateOutputDecodesAsNone` extended with a `"replacements"` key.
