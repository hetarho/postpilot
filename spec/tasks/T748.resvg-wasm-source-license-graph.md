## goal

## acceptance

## impl notes
- Split from T604 (inbox 261111 decided T604). The original npm WASM stays the shipped binary; the independently rebuilt candidate mentioned in docs/qa/browser-static-release.md stays unapplied.
- Fetch sources with git only, into a session temp directory outside the checkout: `git clone --filter=blob:none https://github.com/thx/resvg-js <tmp>/resvg-js`, then `git -C <tmp>/resvg-js checkout 9ca058462ac529120c8cc84ddcd6fef644cc5406`. Do not use curl/wget and do not install cargo.
- The graph is the dependency closure of the WASM package crate (find it from the workspace members' Cargo.toml, the `wasm` build target) resolved through Cargo.lock; napi/node-only crates, build-only tools and dev-dependencies are excluded, and each exclusion is stated in the manifest.
- Embedded strings: scan the WASM bytes for Rust registry path fragments of the form `<crate>-<semver>/src/` (panic locations). They are a lower bound that checks the graph, never the graph itself.
- Per-crate notices come from the crate's own repository at its exact version tag (`git clone --depth 1 --branch <tag>`), or at the commit in the crate's `.cargo_vcs_info.json` when no tag matches; record the repository URL and ref as provenance in the shape of the existing entries. A crate whose exact text cannot be obtained within the timebox stays `unresolved`.
- Keep the existing notice file naming (`<name><version>-LICENSE`) and generate the manifests through scripts/browser-media-licenses.mjs; the generator and its test own the new `rustGraph` shape.
- The license files are not part of the canonical ink identity (`clip-design-assets-v1-ink-*`); if a touched file turns out to be, refresh that identity as the 261111 haeram update did.
