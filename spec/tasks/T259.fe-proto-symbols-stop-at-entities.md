# T259 proto symbols and connect-query reach no further than entity api
> st:todo | ssot:ARCH-17 ARCH-14 ARCH-13 | base:ARCH@5 | dep:-

## goal
Make `entities/*/api` the only place outside `shared/api` that names a proto service, message schema or `@connectrpc/connect-query`, for every domain except clip, and enforce it with ESLint.

## acceptance
- [ ] an ESLint block over `src/pages/**`, `src/widgets/**`, `src/features/**` forbids `@connectrpc/connect-query` imports and any `ImportSpecifier` from `@/shared/api` whose name matches `/(Service|Schema)$|^Proto[A-Z]/` (`no-restricted-imports` + `no-restricted-syntax`); `pnpm lint` fails on a violation
- [ ] the rule carries a temporary allowlist for the clip slices only (`pages/clip`, `pages/clips`, `features/*clip*`, `widgets/clip-*`), with a comment naming T262 as the task that removes it
- [ ] every other page/feature/widget consumes hooks and domain types from an entity: `entities/session/api` (auth), `entities/voice/api`, `entities/post/api`, `entities/template/api`, `entities/guideline/api`, `entities/model-catalog/api`, `entities/model-experiment/api`, `entities/plan`/`subscription/api`, `entities/publish-job`/`publishing-agent/api` gain the query/mutation hooks the features used to build inline
- [ ] `shared/api/index.ts` still re-exports the `*_pb` modules (entities need them) but its non-proto surface is transport, `AppFailure`, language and auth events only; a test pins that no page/feature/widget file names `Service`/`Schema` symbols (a `grep`-style vitest over the source tree)
- [ ] behaviour unchanged: existing tests pass, including `test/*` fakes, and the ESLint warning count does not grow
- [ ] ARCH-25 passes

## impl notes
- from review/arch-260919 F5 (non-clip half; clip is T262 after the entity split)
- hook shape: an entity exports `use<Noun>Query(args)`, `use<Verb><Noun>()` (mutation with `onSuccess` invalidation of its own keys) and `<noun>QueryKey(args)`; features pass callbacks/options, never descriptors
- the verb line (ARCH-14): a mutation hook no feature renders around is entity `api`; a feature keeps only ui + the model that is about the interaction (confirm dialogs, optimistic state)
- mappers proto↔domain stay in `entities/*/api` (ARCH-15), so `ProtoPlan`-style names disappear from features: the entity returns domain types
- `eslint-plugin-boundaries` already types elements in `frontend/eslint.config.*`; add element types `shared-api` and `entity-api` there so the connect-query ban is a `boundaries/external` rule, and use `no-restricted-syntax` for the symbol-name half
- do not touch clip slices beyond the allowlist: T260/T261 reshuffle them and T262 finishes the migration
