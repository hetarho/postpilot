# T187 The writer reads the instruction and lets it outrank guidance
> st:todo | ssot:CLIP-121 CLIP-11 CLIP-31 | base:CLIP@27 ARCH@2 | dep:T186

## goal
Carry the project instruction into the composition request and state that, on content, it outranks the template's authored guidance while the declared structure stays the template's.

## acceptance
- [ ] the instruction travels in the composition request beside `composition_source`, the answers and the observations, and nothing else about the request changes (→CLIP-31)
- [ ] the prompt states the precedence explicitly: where the instruction and the template's authored `guide` text disagree on what a caption says, how many captions a section gives or which subjects they cover, the instruction wins
- [ ] the prompt states the other half just as explicitly: section order, element presence, role, position, timing and every declared maximum stay the template's, and the instruction cannot add a section or an element (→CLIP-116 →CLIP-65)
- [ ] a project with no instruction produces a request byte-identical to today's, asserted directly (→GUIDE-18's discipline)
- [ ] the instruction is data, never an instruction to the tool: it cannot request footage, tools, another model or a schema change, and the existing untrusted-data sentence covers it
- [ ] the instruction counts toward the frozen input allowance, and a project that overflows is refused before paid work with its measured size (→CLIP-90)
- [ ] tests: the request carries it, the byte-identical baseline without one, and the overflow refusal
- [ ] verify BE (ARCH-26) passes

## impl notes
- `ai/composition_prompt.go` owns both halves: `compositionPlanPrompt` for the precedence sentences and `buildCompositionPlanPrompt`'s payload map for the value
- today's second line reads `Frozen XML is the content authority`; it becomes the structure authority, with the instruction named as the content authority above the template's `guide` text — one sentence, not a section, so the contract stays one screen
- the prompt already ends with the closed response contract; the instruction changes no schema and adds no field to the response
