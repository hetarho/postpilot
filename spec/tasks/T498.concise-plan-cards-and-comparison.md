The page retains THEME promotional primitives, reduced-motion behavior, keyboard access, and a single vertical scroller with no horizontal overflow at 320 px.
- [ ] `/about` still displays the complete static offer required by MKT-5 without a session request, estimator or checkout action. FE tests cover the new comparison, clip inputs and unavailable/free cases, card content, `/about` regression and localized text; run ARCH-25 verification.
