## goal
Every catalog question (starter, legacy and every situation family) carries three example replies in three different registers, each built on a published review's frame, and ListVoicePrompts returns them.

## acceptance
- [ ] `voice.Prompt` gains `Examples []PromptExample`; every prompt in `Prompts()` has exactly `VOICE_PROMPT_EXAMPLES` (3) examples with three distinct registers, each 1–3 prose sentences by `ProseSentences`, Hangul, and naming a frame from `exampleFrames` whose register equals the example's; a catalog test in `prompt_examples_test.go` asserts all of this for every prompt and fails if one is missing.
- [ ] No example contains a source's content words listed with its frame (place, product or dish names in `exampleFrames[].avoid`); the same test asserts it.
- [ ] Within one question family (everyday_* keys that share a `Text`), the examples fit every scene of the family — checked by reading each family's eight scenes; the result line records that the read was done.
- [ ] `VoicePrompt.examples` (repeated `VoicePromptExample { VoiceRegister register; string text }`) is returned by ListVoicePrompts; a handler test asserts one prompt's three examples round-trip; generated code is refreshed with `pnpm gen:proto` and committed.
- [ ] Task check passes: `cd backend && gofmt -l ./internal/voice && go vet ./internal/voice/... && go test -count=1 ./internal/voice/...`; FE type check `pnpm --filter ./frontend exec tsc -b` still passes on the regenerated TS. The full batch (ARCH-31) is the integration owner's.

## impl notes
- Data model: `type Register string` (`haeyo` · `da` · `eumseum` · `hamnida`), `type PromptExample struct { Register Register; Frame string; Text string }`. `Frame` stays in Go for traceability and tests; the proto carries only register and text. Proto enum `VoiceRegister { VOICE_REGISTER_UNSPECIFIED = 0; VOICE_REGISTER_HAEYO = 1; VOICE_REGISTER_DA = 2; VOICE_REGISTER_EUMSEUM = 3; VOICE_REGISTER_HAMNIDA = 4; }`; protobuf-es drops the prefix in TS (`VoiceRegister.HAEYO`). Add `VOICE_PROMPT_EXAMPLES = 3` beside the other constants in `prompts.go`.
- Attach examples by family in `prompt_examples.go`: a map keyed by the prompt key for single prompts (starter_*, legacy keys) and by the family prefix (`everyday_food`, …) for the 24 families of eight; `Prompts()` fills `Examples` from it. 54 distinct question texts → 162 examples.
- Frame library: put this table in `prompt_examples.go` as `exampleFrames` (id, register, source, skeleton, avoid). Every example keeps one frame's sentence shape, ending and mark habits and replaces its content. Frames may serve any part where the shape fits (a review frame can carry a weather or commute scene). Use at least two different frames per question.
