# T460 One closed-row guideline list with a 기본 지침 sheet

## goal
`/guidelines` and `/video-guidelines` show ONE list of one-line rows (기본 지침 in use, then the owner's) that open in place, with 기본 지침 added from a dock sheet and taken out by `적용 안함`.

## acceptance
- [ ] one list in injection order: the 기본 지침 in use (product order) then the owner guidelines (server order); no separate `기본 지침` / `저장된 지침` sections; a switched-off 기본 지침 is not in the list; the order line above it names the 기본 지침 first (`기본 지침, 전역 지침, 템플릿 지침, 분야 지침 순서로 적용돼요`; clip: `기본 지침, 전역 지침, 영상 템플릿 지침 …`)
- [ ] a closed row is one line at the pointer floor: a `button` with `aria-expanded` holding the name (기본 지침) or the title — or, with no title, the text — `truncate`d to one line, then one badge — `추천` for a 기본 지침; `전역` / `템플릿` / `분야` / `적용 대상 없음` for a 지침; `전역` / `영상 템플릿` / `적용 대상 없음` for a 영상 지침 — and a chevron; every row starts closed and rows open independently
- [ ] an open 기본 지침 shows its text, its target note (`한국어 글에만 적용돼요` / `기억 사용을 켠 글에만 적용돼요`) and `적용 안함`, which saves at once with no dialog (SetDefaultGuidelineEnabled false) and the row leaves the list; a refusal puts it back and its catalogue message renders in one live region above the list
- [ ] an open owner guideline shows its text (`whitespace-pre-wrap`), its full scope (template-name or 분야 chips; `전역` / `적용 대상 없음` as a badge) and two icon buttons `수정` (pencil) and `삭제` (trash), each `aria-label`led with the guideline; `삭제` keeps today's confirmation saying enqueued work keeps its frozen text
- [ ] `수정` turns the open row into one form — `GuidelineTitleField`, the text textarea with its live remaining count, the scope control — then 저장 · 취소; 저장 sends ONE UpdateGuideline carrying only the parts that differ (title, text, whole scope), nothing changed exits without a call, a refused save keeps the form open with every typed value and the catalogue message under it
- [ ] the dock holds `기본 지침` (secondary) beside `새 지침` / `새 영상 지침`; `기본 지침` opens the shared `Sheet` titled `기본 지침` listing every 기본 지침 of the kind in product order with name, text and target note; one out of use carries `추가` (saves at once, the sheet stays open, the row then reads `적용 중`), one in use reads `적용 중` with no control; a refused 추가 says why under that row
- [ ] the empty state (`page.empty` + example) shows only when the list holds nothing — no 기본 지침 in use and no owner guideline
- [ ] the candidate disclosure below the list is unchanged
- [ ] checked in the dev app at 360 and 1280 px, both themes, for both pages: twelve closed 기본 지침 rows fit in about one phone screen
- [ ] tests: `GuidelinesPage.test.tsx` / `VideoGuidelinesPage.test.tsx` cover the one list and its order, closed rows (name / title / text fallback, badges), open/close independence, `적용 안함` (request, row leaves, refusal restores + message), the sheet (all listed, 추가 keeps it open and flips to 적용 중, refusal message), the one-form edit (one request with changed parts only, no-op, refusal keeps the draft), delete confirmation, and the empty state rule; `DefaultGuidelineRow.test.tsx` updated or replaced
- [ ] `pnpm --filter ./frontend test`, `pnpm build:web`, `pnpm lint`, `pnpm lint:fsd`, `pnpm lint:style` pass

## impl notes
- the closed/open row: extend `shared/ui/disclosure` with a row size (e.g. `size?: 'title' | 'row'`, `row` = `label` typography, `min-h-11`, `aside` carrying the badge) rather than a second disclosure primitive; each row is its own uncontrolled `Disclosure`, `headingLevel={3}` inside the list; the closed region is not rendered (existing behaviour)
- `entities/guideline/ui`: replace `DefaultGuidelineRow` (switch row) with the open-row body of a 기본 지침 (text + target note + an action slot) and add a `GuidelineScopeBadge` (closed-row badge from scope + templates count + kind); keep the target-note copy keys (`defaults.koreanOnly`, `defaults.memoriesOnly`) and `defaults.badge`; delete `defaults.use` (the switch label) once unused
- new `features/toggle-default-guideline`: `DefaultGuidelineSheet` (dock trigger + Sheet) and `StopDefaultGuidelineButton` (`적용 안함`), both over `useSetDefaultGuidelineEnabled` (entity hook; it is already optimistic and re-reads the list); the sheet reads `defaults` from `useGuidelines` so in-use state follows the cache; one mutation instance per sheet row so a refusal lands under its row
- `features/edit-guideline`: replace `EditableGuidelineText` + `EditableGuidelineScope` with one `GuidelineEditForm` over T459's `useUpdateGuidelineCall().save({ title?, text?, scope? })`; scope compared as kind + sorted id/분야 sets; delete the two old components and `saveText`/`saveScope` once nothing calls them
- `DeleteGuidelineButton` becomes an icon button (`ghost`, `size="icon"`, lucide `Trash2`) keeping its `Dialog`
- `widgets/guideline-directory`: `GuidelineDirectory` composes `defaults.filter(enabled)` then `guidelines` into one `ul`; drop the `page.defaults` / `page.saved` headings and `clipPage.defaults` / `clipPage.saved` keys; the `ActionBar dock="list"` holds `DefaultGuidelineSheet` then `CreateGuidelineSheet`
- copy (guidelines namespace): `defaults.stop` "적용 안함" / "Don't apply", `defaults.add` "추가" / "Add", `defaults.inUse` "적용 중" / "In use", `defaults.sheetTitle` + dock label "기본 지침" / "Default guidelines", `scope.templatesShort` "템플릿" / "Templates", `scope.fieldsShort` "분야" / "Categories", `scope.videoTemplatesShort` "영상 템플릿" / "Video templates" (reuse existing keys where they already say this)
