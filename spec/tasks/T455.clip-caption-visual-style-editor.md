# T455 Select and style individual captions in the draft preview

## goal
Let the owner select any caption and preview a named visual style, position or size change before rendering.

## acceptance
- [ ] Selecting a caption in the caption track seeks to its output interval and opens its sheet with a representative frame, current appearance and named visual samples for all approved styles. Selection uses caption identity, including zero/multiple captions per cut and captions crossing cuts.
- [ ] Choosing a style changes only that selected caption, preserves its exact text and output/phrase timing, and leaves the AI style set unchanged. Position and size remain directly editable; face, background/plate, outline and animation follow the chosen style without separate controls.
- [ ] A valid style change retains compatible explicit size/position, autosaves and appears in video preview and flow simulation. It never silently clears size to avoid a role-floor error; invalid drafts stay selected/editable with the affected caption's error and cannot be rendered until corrected.
- [ ] Style, position and size edits participate in existing undo/redo, including recovery from an invalid style draft. A prior delivered render retains its own revision label and becomes stale only after a valid visible change is saved; render/finalize flush the same draft queue.
- [ ] Sample and overlay responses for an earlier selection/style cannot replace the current caption or preview. Busy/loading/error states remain usable, preserve typing/selection and reuse existing bounded sample retry behavior without triggering AI.
- [ ] Extend `ClipCaptionStage.test.tsx`, correction reducer/history tests, draft preview and flow-simulation tests to cover outside-AI-set selection, distinct captions on one cut, cross-cut timing, size preservation/errors, undo/redo, stale sample responses and both static/sequence styles. Verify readonly, keyboard and narrow-screen behavior; pass ARCH-31's local gates.

## impl notes
- Replace the AI-set-filtered Listbox in `features/correct-clip/ui/ClipTextControls.tsx` with the existing product-approved sample catalog/picker pattern. Its style change currently clears `ownerSizePx`; remove that reset and submit the retained appearance to T454's validation.
- Build on `ClipCaptionStage.tsx`, `ClipCorrectionWorkspace.tsx`, `entities/clip-plan/model/edit-plan.ts` and `timeline.ts`; reuse existing representative-frame, selection, patch and undo state. Do not add a one-caption-per-cut model or another transport client inside UI code.
- Fetch visual samples through entity APIs and keep reusable sample presentation below features under FSD. A sample illustrates the style; the actual selected text and appearance must also redraw over the representative frame. Preserve the preview's declared per-frame animation limits.
- Keep unsaved invalid patches locally instead of reverting the picker or dropping the caption. Associate structured server errors with stable caption identity, merge only responses for the current request and clear an error only when its cause is resolved.
- Keep new copy in owning ko/en dictionaries and use existing sheets/tokens/status patterns. No new libraries or independent typography/animation settings are required.
