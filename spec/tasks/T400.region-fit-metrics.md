# T400 Font advance metrics and the region slot width fit
> st:todo | ssot:CDS-86 CDS-19 CDS-77 CDS-84 | base:CDS@26 | dep:-

## goal
A pure, shared width measure (a generated per-face advance table) and the CDS-86 fit — shrink to the floor, then two balanced lines — that every later region task decides with.

## acceptance
- [ ] `backend/internal/clip/design/metrics.json` exists, is embedded by the design package and is byte-identical to `frontend/src/entities/clip-design/config/clip-metrics.json` (a design test enforces it the way `TestFrontendMirrorIsByteIdentical` does for design.json)
- [ ] the table carries, per face and weight used by region text (`paperlogy:800`, `wantedsans:600`, `wantedsans:700`, `nanummyeongjo:800`, `jua:400`): advances at font-size 100 for every covered character, a single `hangul` advance where all 11,172 syllables share one, the Hangul ink top and bottom as em ratios, and the face's widest advance as the fallback
- [ ] an env-gated generator (`CLIP_METRICS_UPDATE=1`, media package test, host resvg + bundled fonts) rewrites both files; an env-gated check (`CLIP_MEDIA_SMOKE=1`) compares the table with resvg `--query-all` on sample strings and fails beyond 0.5 % for text without kerned Latin pairs
- [ ] `design.TextWidth(face, weight, tracking, size, text)` returns the advance sum scaled to `size` plus tracking between characters, never below resvg for the same string; characters absent from a face's table use the fallback width
- [ ] `design.Covers(face, weight, text)` is false exactly when a character is absent from a face that does not cover it (Jua: any character outside its table; the other faces: Hangul always covered)
- [ ] `design.FitRegionSlot(spec, text, width)` implements CDS-86: keep the size when it fits; otherwise shrink to `size × width / textWidth`, not below the floor; a display, headline, hook or title spec below its floor splits at the 어절 boundary minimising the wider line and fits again (2 lines); a spec marked one-line never wraps; the result reports lines, size and `Over` (still wider at the floor, or `Covers` false)
- [ ] `design.RegionSlotBudget(spec, width)` returns the Hangul syllables that fit at the floor across the lines the spec allows, for prompts and answer limits
- [ ] design tests pin the fit on the mock-up cases: headline 96 on 856 px — `해미 한우` stays 96, `연남동 숯불 한우 오마카세` ≈ 85 one line, `연남동 골목에서 30년째 숯불 한우만 굽는 집` two lines at ≈ 90; display 132 `연남동 골목 30년 해미 한우` two lines; label 36 overflows only past its 34 floor; Jua text with an uncovered syllable is `Over`
- [ ] BE gate (ARCH-26) and FE gate (ARCH-25) green

## impl notes
- measured 260926 with resvg 0.48.1: Paperlogy 800 Hangul advance 88 (uniform), Wanted Sans 600 and 700 86.43 (uniform), NanumMyeongjo 800 95.02 (uniform), Jua 400 varies per syllable (≈75–78, 2,367 covered) → store Jua syllables individually and the others as one `hangul` value; ASCII 0x20–0x7E plus the punctuation the templates use (`· ‧ – — … ‘ ’ “ ” ₩ % ℃ ㎡ ~ ×`) per face
- the table deliberately ignores kerning: resvg shapes `AV` 6–10 % narrower than A+V, so the table over-measures kerned Latin and a fitted line always stays inside its width; admission, the AI repair, the renderer and the browser all decide with this one table so they cannot disagree
- JSON shape (sorted keys, 2-space indent, trailing newline so the byte-mirror stays stable): `{"units":100,"faces":{"paperlogy:800":{"hangul":88,"fallback":…,"ink":{"top":…,"bottom":…},"glyphs":{"A":…}}}}`
- width = size/100 × (Σ advance + tracking×100×(n−1)) — the trailing letter-spacing resvg reports after the last glyph is not part of the ink width
- `SlotSpec` = {role, size, floor, face, weight, tracking, lines (1|2)} — T401 builds it from the preset schema; `FitRegionSlot` is pure and takes the width, so the preset decides the measure
- balance rule for two lines: try every 어절 boundary, keep the split whose wider line is narrowest; one 어절 that alone is wider than the width at the floor is `Over`
- the generator lives beside the other media measurement code (it needs `r.measure` or the same resvg call) and is not part of `go test ./...` without the env flag
