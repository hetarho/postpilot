## goal
The owner's corrections to an observed scene's descriptive text are saved, reach every writing call, and pin that source's observations against a later model change until 다시 관찰하기.

## acceptance
- [ ] `SaveClipObservationEdits` replaces, per observation id (`<sourceId>/<index>`), only `event`, `action`, `subjects`, `subject` and `speech`; time range, scene, motion, quality, certainty, usability, readable-text and caption-safe regions are not in the message and never change; clearing `speech` on a segment that observed speech is refused with a field error so audibility stays as observed.
- [ ] It refuses an unknown id, a finalized project and a project with a running job, and changes no plan, render, confirmation or storyline.
- [ ] The edited segment records its owner-changed fields and its source is marked edited by hand; `ClipObservedSegment` and `ClipSourceObservation` project `owner_edited`.
- [ ] Storyline, flow, narration and revision calls receive the corrected text (CLIP-31), and storyline paragraphs keep their observation ids.
- [ ] A source edited by hand counts as analyzed while its id and fingerprint match, even after the observe model, contract or language changes: quotes count no chunks for it and runs use its stored analysis; only `reanalyze_source_ids` (T788) replaces it and drops its edits.
- [ ] Tests: `backend/internal/clip/store/observation_edits_test.go` (save, refused fields, speech clear refusal, refusals by state, owner flag), quote/run tests that a pinned source survives a model change and is replaced by reanalysis, a writing-input test showing corrected text reaches the storyline and flow requests, `backend/internal/clip/rpc/observations_test.go` (projection), and the cmd/api clip contract tests that read observations.
- [ ] `pnpm gen:proto` and `pnpm gen:sql` leave no diff after commit; gofmt, `go vet ./...`, `go build ./...` and the selected `go test` packages pass.
