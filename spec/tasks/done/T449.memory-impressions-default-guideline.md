# T449 The 기억을 통한 감상 추가 기본 지침
> st:done@260928 | ssot:GEN-73 GEN-16 GUIDE-41 MEM-5 | base:GEN@18 GUIDE@10 MEM@4 | dep:-

## goal
Add the post-kind 기본 지침 기억을 통한 감상 추가: on by default, injected only into a prompt that carries `[기억]`, it lets a `preference` memory supply the impression of a fact the material states.

## acceptance
- [v] `guideline.Defaults(KindPost)` lists `memory_impressions` directly after `impressions`, with both copies (ko 기억을 통한 감상 추가) and `MemoriesOnly` set on it alone
- [v] `ForPrompt` returns its text only when the caller says the run carries memories, in the product's order, and never while the account has it switched off
- [v] a generate, a write comparison and a storyline job freeze it exactly when their frozen memories are non-empty; a revision and every clip call never do
- [v] a `preference` memory's line in `[기억]` reads `취향: <text>`; the other kinds render as before and the stored text is unchanged
- [v] `ListDefaultGuidelines` carries `memories_only`, and the /guidelines row of such a default says 기억 사용을 켠 글에만 적용돼요 (en: Applies only to posts that use memories)
- [v] tests: the registry order and flags, ForPrompt with and without memories and switched off, the freeze sites' flag (generate, comparison, storyline, revise), the real wiring in `cmd/api` freezing the text only with a matching memory, the `취향:` label, the RPC field and the row note
- [v] ARCH-26, ARCH-25, ARCH-28 (proto regenerated and committed), ARCH-30 and the spec lint pass

## impl notes
- registry: `DefaultGuideline` gains `MemoriesOnly bool` beside `KoreanTargetOnly`; the entry is key `memory_impressions`, inserted after `impressions`, since GUIDE-41's order is the injection order (GUIDE-14)
- ko text: "기억에서 '취향:'으로 적힌 것은 글쓴이가 직접 준 감상으로 봅니다. 재료에 적힌 사실에 글쓴이가 감상을 적지 않았다면, 그 취향이 뜻하는 감상을 덧붙여도 됩니다. 예를 들어 매운 음식을 좋아한다는 취향이 있고 메모에 '매웠다'가 있으면 '매워서 좋았다'처럼 쓰세요. 감상을 붙일 사실은 재료에 적힌 것이어야 하고, 취향만으로 사실을 만들지 마세요. 글쓴이가 이 글에 적은 감상이 있으면 그 감상을 따르세요. 이 지침은 '감상은 내가 쓴 것만'의 예외입니다."
- en name "Impressions from memories", en text: "A memory marked '취향:' is a taste the author gave. Where the material states a fact and the author gave no impression of it, you may add the impression that taste implies: with a taste for spicy food and a memo saying it was spicy, write that it was spicy and good. The fact must come from the material; never make one up from a taste alone. Where the author wrote an impression for this post, follow theirs. This is the exception to 'Impressions only as I gave them'."
- the text names itself the exception to 감상은 내가 쓴 것만 ← `guidelinePrecedence` lets the earlier of two conflicting 기본 지침 win, and an explicit exception is not a conflict
- `guideline.Service.ForPrompt` gains a trailing `withMemories bool`, and a `MemoriesOnly` default is skipped without it; generation's `GuidelinesForPrompt` port gains the same argument, and `cmd/api`'s `generationGuidelines` passes it through while `ForClip` passes false
- generation: `freezeWriteMaterial` and `freezeStorylineMaterial` freeze memories BEFORE guidelines and pass `len(memories) > 0`; the revision passes false (MEM-22) ← the flag has to be what the run will actually render, and a retrieval that matched nothing renders no `[기억]` (MEM-21)
- the `취향:` label is prefixed in `memory.TextsForPost` for `KindPreference`, a fixed Korean label for every target like every other prompt framing; generation still receives texts only and never learns a kind (MEM-5's prompt grouping rests on the enum) ← the 기본 지침 has to name which memories are tastes, and retrieval does not know the switch; with the switch off the label licenses nothing, since 감상은 내가 쓴 것만 names its own sources
- proto: `DefaultGuideline.memories_only = 6`, mapped in `guideline/rpc` beside `korean_target_only`; FE `entities/guideline` model, queries mapping, `DefaultGuidelineRow` note under the text exactly like `defaults.koreanOnly`, i18n key `defaults.memoriesOnly`, and the `test/guidelines.ts` fixture field
- no migration: the switch is stored by key only when switched off (GUIDE-43), so every account starts with the new key on; queued payloads keep the texts they froze (GUIDE-17)
- fixed counts move: the RPC test's 11 post defaults become 12, and the registry test reads 자연스러운 한국어 문체 by key rather than by index
