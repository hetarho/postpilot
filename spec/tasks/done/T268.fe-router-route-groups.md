# T268 the route tree is assembled from route groups
> st:done@260920 | ssot:ARCH-16 ARCH-24 | base:ARCH@5 | dep:-

## goal
Split the 621-line `app/routes/router.tsx` into one file per route group and let pages export their own search schemas, so a new screen edits its group file and its page only.

## acceptance
- [v] `app/routes/` holds `router.tsx` (root route, tree assembly, ≤120 lines) plus group files (`auth.ts`, `posts.ts`, `voices.ts`, `clips.ts`, `templates.ts`, `models.ts`, `billing.ts`, `publishing.ts`, `account.ts`, `admin.ts`, `marketing.ts`) each exporting its `createRoute` list
- [v] every `validateSearch` schema that belongs to a page is exported from that page's `index.ts` (`searchSchema`) and imported by the group; `beforeLoad` guards that are shared (session required) live once in `app/routes/guards.ts`
- [v] the legacy voice-tab redirect (`:459-505`) lives in `voices.ts` with a unit test for each legacy path
- [v] a route-tree test pins the full set of paths before and after (snapshot of `routeTree` paths), so the split changes no URL
- [v] behaviour unchanged: page tests pass; ARCH-25 passes

## impl notes
- from review/arch-260919 F11
- TanStack Router's `createRoute` objects compose freely; `routeTree = rootRoute.addChildren([...auth, ...posts, ...])` keeps typing intact
- a page exporting its search schema is `model` content of the page (ARCH-15) and keeps `app/` from knowing page internals

## result
- `app/routes/router.tsx` is 70 lines: the tree assembly, `createRouter` and the module augmentation. The shell it hangs off — `RouterContext`, `rootRoute`, the authenticated/writing/video layout routes, the `/` redirect and the shared `masterOnly` guard — is `app/routes/tree.ts` (80 lines), which is what lets a group file name its parent without importing the assembly
- eleven group files: `auth` `marketing` `posts` `voices` `templates` `clips` `models` `billing` `publishing` `account` `admin`, each exporting its `createRoute` list in the order the tree adds them (a static path always before the param that would swallow it). `guidelines` rides with `templates` — both are writing material, and one route does not earn a file
- twelve `validateSearch` schemas moved to the page that reads them (`pages/<screen>/model/search.ts`, exported as `<screen>SearchSchema` from the page's `index.ts`), with the rationale comments travelling with the schema
- the legacy `/voice` redirect lives in `voices.ts` and `app/routes/voices.test.ts` unit-tests every legacy path — the five tabs, an unknown tab, an account with no voices, and a voice-load outage — without mounting the app
- `app/routes/tree.test.ts` pins all 45 addresses the tree resolves to, so a group that forgets a route or hangs it off the wrong parent fails a test rather than changing a URL
- verify: ARCH-25 green (2214 tests / 283 files, eslint 0, steiger clean, style + build ok)
