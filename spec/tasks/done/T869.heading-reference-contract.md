## goal
StartTemplateHeadingSuggestions accepts up to `HEADING_REFERENCES_MAX` saved heading lines that are frozen into the job and steer wording below the style request and above the 기본 voice.

## acceptance
- [v] proto `StartTemplateHeadingSuggestionsRequest.reference_headings` (field 6, `repeated string`) exists and generated Go/TS are regenerated through `pnpm gen:proto` (deterministic, task stage)
- [v] references are trimmed and frozen in the job payload and reach the model as one quoted data part; none sends no such part and keeps the existing modes (deterministic: `heading_suggestion_test.go`, task stage)
- [v] more than `HeadingReferencesMax` lines, or a blank line, a line holding a line break or one over `AskLabelMaxChars` Unicode characters, is refused as invalid input before admission (deterministic: `heading_suggestion_test.go`, task stage)
- [v] the fixed contract orders style_request, then reference_headings, then voice_style; says the references are wording data only, never facts, never copied unchanged, and never lift the one-line/length rules (deterministic: `heading_suggestion_test.go`, task stage)
- [v] the prompt inventory lists the referenced mode and its pinned counts are updated (deterministic: `go test -count=1 ./cmd/api/ -run 'PromptInventory|PromptEvaluation'`, task stage)
- [v] FE `HEADING_REFERENCES_MAX` mirrors the limit; `useWizardHeadingSuggestions().start(model, styleRequest, referenceHeadings)` sends the lines (deterministic: vitest in `entities/template`, task stage)
