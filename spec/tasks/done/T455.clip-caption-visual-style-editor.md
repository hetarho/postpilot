## goal
Let the owner select any caption and preview a named visual style, position or size change before rendering.

## acceptance
- [v] Selecting a caption in the caption track seeks to its output interval and opens its sheet with a representative frame, current appearance and named visual samples for all approved styles. Selection uses caption identity, including zero/multiple captions per cut and captions crossing cuts.
- [v] Choosing a style changes only that selected caption, preserves its exact text and output/phrase timing, and leaves the AI style set unchanged. Position and size remain directly editable; face, background/plate, outline and animation follow the chosen style without separate controls.
- [v] A valid style change retains compatible explicit size/position, autosaves and appears in video preview and flow simulation. It never silently clears size to avoid a role-floor error; invalid drafts stay selected/editable with the affected caption's error and cannot be rendered until corrected.
- [v] Style, position and size edits participate in existing undo/redo, including recovery from an invalid style draft. A prior delivered render retains its own revision label and becomes stale only after a valid visible change is saved; render/finalize flush the same draft queue.
- [v] Sample and overlay responses for an earlier selection/style cannot replace the current caption or preview. Busy/loading/error states remain usable, preserve typing/selection and reuse existing bounded sample retry behavior without triggering AI.
- [v] Extend `ClipCaptionStage.test.tsx`, correction reducer/history tests, draft preview and flow-simulation tests to cover outside-AI-set selection, distinct captions on one cut, cross-cut timing, size preservation/errors, undo/redo, stale sample responses and both static/sequence styles. Verify readonly, keyboard and narrow-screen behavior; pass ARCH-31's local gates.

- Keep new copy in owning ko/en dictionaries and use existing sheets/tokens/status patterns. No new libraries or independent typography/animation settings are required.

## result
- outcome: A caption's sheet now offers every approved style, whether or not the AI set includes it, as a radiogroup of tiles. The first tile is the caption's own style, then each style follows with the renderer's sample drawing and its name; animated styles are marked "움직이는 스타일". Choosing one patches only that caption's `ownerStyle` and keeps its size and place. The size range shown and validated is the role of the style the caption is drawn in, by the rule the server uses. A kept size outside it is marked on the size field and makes the draft unsaveable, so autosave and render wait until an undo or a corrected size clears it. The field follows undo and redo. A save refused on this caption is also shown on its sheet. Captions are still selected by their own identity; several on one cut and one crossing cuts were checked, and a caption is placed over the cut its interval starts in (now `captionStartCut`). The style samples come from the existing bounded-retry query and fall back to names when they fail. Caption and overlay answers are keyed by what the captions draw, so a late answer for an earlier style never replaces the current one. The read-only view names the style.
