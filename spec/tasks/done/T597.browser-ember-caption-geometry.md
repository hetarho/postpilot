## goal
Reproduce the most demanding ember style with cached text and deterministic animated flame geometry.

## acceptance
- [v] Ember text/stroke/glow, back/front flame layers, gradients and indexed sparks reproduce the native style at every declared output time.
- [v] Static text/glow resources are cached while bounded flame/particle geometry updates; no full text SVG/PNG is created for each frame.
- [v] Cold/warm stress reports include effect-area/texture/geometry bounds and phase timings; growing caption count does not retain every inactive GPU resource.
- [v] Long text, rare syllables, three ratios, rapid/sentence paces, transitions and effect extrema are compared with native reference frames without clipping or plain-style substitution.
- [v] Randomness, elapsed rendering time, pause/seek and repeated export do not change the animation's state at a given frame.
- [v] Real-browser geometry/resource/frame tests and required local checks pass; absent representative hardware remains an explicit final qualification limit.

## impl notes
- Parallel group execution uses isolated worktrees; exact final cross-slice edits remain uncertain (touches:-). Coordinate shared public exports and adapter seams explicitly; review and integration are serial and resolve overlap without shared-checkout writes.
- Port drawEmber's indexed sine/cosine motion, cubic curves, gradient stops, layer ordering and 16-spark lifecycle as the reference; avoid a visually unrelated generic particle preset.
- Use stable scene resources and bounded mesh/vector updates or a matching authored shader. Precompute immutable ink and blur layers and update only the dynamic parameters.
- Keep colour/alpha and shadow bleed consistent with the existing sRGB painter. Reduced effect resolution is allowed only if CDS-104's appearance review qualifies it.
- Add entrance, settled, maximal flame/glow and exit samples to the common harness; compile success or one still frame does not certify motion.
- No new arbitrary particle/decorative feature is exposed to owners or AI; this is the existing approved ember component.
