## goal

## acceptance
- [v] The post list summary carries whether the post holds a storyline; a draft with a storyline and no content shows `스토리라인 작성 완료` (en `Storyline ready`) as a mid-way badge; a running job, a failure and a pending experiment keep outranking it in their existing order.

- [v] Aggregate 내 글 shows the same label for such a post as the post list does, with the same precedence.
