## impl notes
- `design.json` is the one file the renderer and the verifier both read; the frontend mirror is asserted byte-identical in `backend/internal/clip/design/design_test.go`, so the change is copy-forward, not a second edit
- `copy_max_width` 856 stays: CDS-9 keeps the reading measure as a typographic choice and CDS-20's characters-per-line are stated on it, so widening the safe area must not widen the line
- regenerate goldens with `UPDATE_CLIP_GOLDENS=1`; the x coordinates move by 48 px on 9:16 and stay put on the other two ratios
- rerendering an existing project moves its text 48 px right; finalized projects keep their stored result untouched, so CLIP-101's no-silent-change rule is not breached
- the centring test reads `Region.X + Region.Width/2` from the manifest parts rather than parsing SVG, so it covers caption, information, intro and outro in one assertion
- `anchor.right` 984 now equals the header's right margin (CDS-57), which is intended — both are the symmetric 96 px inset
