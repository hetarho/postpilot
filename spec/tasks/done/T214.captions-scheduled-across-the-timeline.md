## goal
Lay out, verify and render narration captions as absolute-interval elements: disjoint on the timeline, floor-checked, rapid-split inside their own interval, anchored across the cuts they cover, with V11 and V18 checked timeline-wide.

## acceptance
- [v] `scheduleDeclaredCaptions` no longer groups by cut: narration captions sort by start; an overlap omits the later one with `caption_overlap`; the CDS-41 floor is met by the text, the short alternative, then extension into free room, else `caption_floor`; the per-cut `sentence_count` rule applies only to legacy cut-bound captions
- [v] `layoutDeclaredRapid` splits a narration caption inside `Resolved.StartMS..EndMS` and treats its stored phrases as absolute (no cut offset)
- [v] anchor selection for a caption spanning cuts evaluates the subject box and readable-text flag of every cut it covers and picks one anchor; the one-step rule applies between consecutive captions
- [v] `composition_verify.go`: V18 disjoint windows across every caption on the output timeline; V11 a collected fact behind every number, any item; V16 every interval inside the output
- [v] the information-pair layer renders only for frozen legacy plans; new plans never carry one
- [v] `PrepareClipPreview` shows narration captions at their absolute times across cut boundaries
- [v] tests: scheduling ladder; absolute rapid phrases; spanning-cut anchor; verifier V18/V11; the identity smoke (`docker buildx build --target identity-smoke -f backend/Dockerfile .`) and the media smoke stage built and run locally (ARCH-37), with the new baseline digest pinned because the delivered clip changes on purpose (CLIP-125)
- [v] verify BE (ARCH-26)

- `scheduleDeclaredCaptions` now takes the plan and splits in two: `scheduleNarration` orders the narration by start on the OUTPUT timeline (overlap → `caption_overlap`, floor → shorter text → free room → `caption_floor`, an owner-edited window untouched), `scheduleCutCaptions` keeps the per-cut sequencing a frozen legacy plan was written under
