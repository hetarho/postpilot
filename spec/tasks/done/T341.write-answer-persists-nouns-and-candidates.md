# T341 Write results store nouns and replacement candidates beside the content
> st:done@260924 | ssot:GEN-48 GEN-53 GEN-55 POST-79 ARCH-3 ARCH-7 ARCH-24 | base:GEN@10 POST@11 ARCH@9 | dep:T337 T330

## goal
- A generation and an applied write winner replace the post's stored nouns and replacement candidates, a revision and a manual save keep them, the post exposes the candidates on the wire, and an A/B candidate's output carries both.

## acceptance
- [v] A completed generation stores the write answer's nouns in `posts.content_nouns` and its candidates in `posts.replacement_candidates`, both outside `content` and `machine_baseline`; a write with no nouns or no candidates stores NULL, so stale ones from an earlier generation are cleared.
- [v] A completed revision keeps the stored nouns and candidates byte for byte (GEN-55, R16, R29).
- [v] SavePostContent (a manual edit or a taken phrase, POST-80) leaves both untouched; stale spans are the FE's to drop (GEN-53).
- [v] Applying a write-experiment winner replaces both with that candidate's; a candidate output recorded before this change applies as none and clears them (GEN-4).
- [v] A retried identical write (same content, language, nouns and candidates) is still a no-op that leaves both stored and advances no revision; an identical-content write with different nouns or candidates is a new machine write that stores them.
- [v] `Post.replacement_candidates` (field 30) carries each stored candidate as `{surface, index, source, phrases}`, in stored order; nouns never reach the wire.
- [v] The model lab's candidate output JSON carries `nouns` and `replacements` when present; one without them decodes as none.
- [v] Learning snapshots, exports and the machine baseline carry no nouns or candidates.
- [v] Tests: new `internal/post/write_annotations_test.go` (`TestAGeneratedWriteStoresNounsAndCandidates`, `TestARevisionKeepsNounsAndCandidates`, `TestAManualSaveKeepsNounsAndCandidates`, `TestAnIdenticalRetriedWriteKeepsThemStored`, `TestAnInvalidCandidateIsRefused`); `internal/post/store/store_test.go` `TestWriteAnnotationsRoundTripOutsideTheContent`; new `internal/post/rpc/replacements_test.go` `TestReplacementSurfaceWalksTheGeneratedEnum` plus the toProtoPost projection; new `internal/generation/write_annotations_test.go` (`TestGenerateHandsTheWriteAnswerToThePost`, `TestAPhraselessWriteClearsCandidates`, `TestReviseKeepsTheStoredAnnotations`, `TestRunWriteCandidateReturnsTheAnswer`, `TestApplyWriteWinnerForwardsTheWinnersAnnotations`); new `cmd/api/write_annotations_test.go` (`TestCandidateOutputCarriesNounsAndReplacements`, `TestALegacyCandidateOutputDecodesAsNone`, `TestGenerationPostsMapsTheAnnotations` on the real stores).
- [v] Verify: `cd backend && test -z "$(gofmt -l .)" && go vet ./... && go build ./... && go test -timeout 30m ./...`
- [v] Verify: `pnpm gen:sql && git diff --exit-code -- backend`

## impl notes
- T322 left `ReplacementSurface { _UNSPECIFIED = 0; _TITLE = 1; _TAG = 2; _BODY = 3 }`, `ReplacementCandidate { surface = 1; int32 index = 2; source = 3; repeated phrases = 4 }` and `Post.replacement_candidates = 30`. T323 left `content_nouns` and `replacement_candidates` (`json_valid` CHECKs). T329 left `Post.ContentNouns` and its decoder in `store/content.go`. T334 left UpdateGeneratedContent's `status <> 'published'`.
- T324 left `generation.WriteAnswer{Content PostContent; Nouns []string}`; `writeCandidate` returns `(WriteAnswer, llm.Usage, error)`, and `write` returns `(WriteAnswer, error)`. T330 added `WriteAnswer.Replacements []Replacement` with `Replacement{Surface ReplacementSurface; Index int; Source string; Phrases []string}` and `ReplacementTitle/Tag/Body = "title"/"tag"/"body"`.
- `RunWriteCandidate` and `Generate` were deliberately left for this task. No proto or migration changes here.
- Post domain (`types.go`): `type ReplacementSurface string` with `ReplacementSurfaceTitle = "title"`, `ReplacementSurfaceTag = "tag"` and `ReplacementSurfaceBody = "body"`, and `Valid()`.
- Post domain: `ReplacementCandidate{Surface ReplacementSurface; Index int; Source string; Phrases []string}`. Index is the tag index for tag, the block index for body and 0 for title (GEN-53).
- Post domain: `WriteAnnotations{Nouns []string; Candidates []ReplacementCandidate}`, and `Post.ReplacementCandidates []ReplacementCandidate` (nil = none).
- Candidates live outside `PostContent` (R29) because PostContent is copied into `machine_baseline`, exports and the learning snapshot.
- `Service.SetGeneratedContent(ctx, userID, slug string, content PostContent, language Language, annotations *WriteAnnotations) error`: nil keeps both stored values, and non-nil replaces both, where empty clears.
- The presence is the pointer, never slice nil-ness: T324's parse returns nil nouns for a missing member, and that must still clear on a write.
- SetGeneratedContent resolves `next` to `WriteAnnotations{found.ContentNouns, found.ReplacementCandidates}`, or `*annotations` when non-nil. It then validates each candidate: `Surface.Valid()` and `Index >= 0`, otherwise `&InvalidContentError{Reason: "replacement candidate"}`.
- Bounds (≤ 40 nouns, ≤ 20 spans, ≤ 3 phrases) are generation's (T324, T330) and are not re-checked.
- The idempotence check, and the zero-row re-read after T334's published check, both add `slices.Equal(found.ContentNouns, next.Nouns)` and `slices.EqualFunc(found.ReplacementCandidates, next.Candidates, equalCandidate)`, with `slices.Equal` on the phrases. nil and empty compare equal.
- `DraftWriter.UpdateGeneratedContent(ctx, slug, userID string, content PostContent, language Language, annotations WriteAnnotations, updatedAt time.Time) (bool, error)` always receives the resolved values, the way SaveGenerationOptions receives the full next tag count.
- "nil keeps" is resolved in the service, not with COALESCE. Revise and generate are serialized per post by the job guard, and manual saves never touch these columns, so the read-then-write cannot lose an update. An explicit NULL is then the one canonical "none", so the SQL change test below agrees with the service's.
- `posts.sql` UpdateGeneratedContent (ASCII) sets `content_nouns = sqlc.narg(content_nouns)` and `replacement_candidates = sqlc.narg(replacement_candidates)`.
- Its idempotence group gains `OR content_nouns IS NOT sqlc.narg(content_nouns) OR replacement_candidates IS NOT sqlc.narg(replacement_candidates)`, and T334's `status <> 'published'` stays ANDed outside the group.
- `store/content.go`: `marshalNouns([]string) sql.NullString` and `marshalCandidates([]post.ReplacementCandidate) sql.NullString`, with empty → NULL. Candidates go through a store-owned `replacementCandidateJSON{Surface string \`json:"surface"\`; Index int \`json:"index"\`; Source string \`json:"source"\`; Phrases []string \`json:"phrases"\`}`, so the domain carries no JSON tags (ARCH-7).
- The encoding is deterministic, so identical values compare equal in SQL. `toPost` decodes `replacement_candidates` beside T329's nouns: NULL or `[]` is nil, and invalid JSON is an error naming the slug.
- SavePostContent, SaveGenerationOptions, Finalize, the learning snapshot and ListPostsByUser never read or write either column.
- Callers of the store method that must change: `service.go`, `cmd/seed/main.go:191` (passes `post.WriteAnnotations{}`, which T348 then fills) and the 15 calls in `store/store_test.go`. The `fake_test.go` UpdateGeneratedContent stores both and mirrors the new idempotence.
- Callers of the service method: `lifecycle_test.go` (6), `service_test.go` (3), `template_answer_test.go`, `template_seed_test.go`, `template_test.go` (1 each), `voice_test.go` (3), `cmd/api/bootstrap_test.go` (1), and those T329/T334/T337 added. Pass nil where a test does not care.
- `post/rpc/replacements.go`: `replacementSurfaceToProto(post.ReplacementSurface) (postpilotv1.ReplacementSurface, bool)`, a switch over the three with no `default`; anything else falls through to `(REPLACEMENT_SURFACE_UNSPECIFIED, false)`.
- `toProtoPost` sets `ReplacementCandidates` from `p.ReplacementCandidates`: `{Surface, Index: int32(Index), Source, Phrases}`, dropping a `false` (unreachable, since the service validated the surface).
- Nothing inbound carries candidates, so there is no from-proto half. The walk test asserts every non-zero `postpilotv1.ReplacementSurface_name` value is the image of exactly one domain surface, and that each domain surface maps to a non-zero value (ARCH-3).
- `internal/generation/types.go`: `WriteAnnotations{Nouns []string; Replacements []Replacement}` and `func (a WriteAnswer) Annotations() *WriteAnnotations`, which always returns non-nil.
- `ports.go` `Posts.SetGeneratedContent(ctx, userID, slug string, content PostContent, language Language, annotations *WriteAnnotations) error`.
- `generate_handler.go`: `answer, err := s.write(...)`, then `SetGeneratedContent(..., answer.Content, job.TargetLanguage, answer.Annotations())`. `recordVersionSample` keeps receiving `answer.Content`. A phrase-less write has nil Replacements, so the non-nil annotations clear stale candidates (GEN-48).
- `revise_handler.go` passes `nil`, which keeps both (GEN-55, GEN-57: a revision has no phrase list and no nouns answer).
- `experiment_surface.go` `RunWriteCandidate(ctx, raw, model) (WriteAnswer, CandidateUsage, error)` returns writeCandidate's whole answer.
- `ApplyWriteWinner(ctx, userID, postSlug string, answer WriteAnswer, raw ...[]byte) error` keeps T334's published refusal and voice/language checks, then calls `SetGeneratedContent(..., answer.Content, frozenLanguage, answer.Annotations())` and `recordVersionSample(..., answer.Content)`.
- `cmd/api/adapters_generation.go` `generationPosts.SetGeneratedContent`: nil stays nil. Otherwise nouns are copied, and each Replacement maps through a closed switch `generation.ReplacementTitle/Tag/Body` → `post.ReplacementSurfaceTitle/Tag/Body`; an unmatched surface returns an error instead of guessing. Index, source and phrases are copied.
- `cmd/api/adapters_experiment.go` `outputPost` gains `Nouns []string \`json:"nouns,omitempty"\`` and `Replacements []outputReplacement \`json:"replacements,omitempty"\``, with `outputReplacement{Surface string \`json:"surface"\`; Index int \`json:"index"\`; Source string \`json:"source"\`; Phrases []string \`json:"phrases"\`}`.

- `RunCandidate` encodes `toOutputPost(answer)`, and `ApplyWinner` passes `fromOutputPost(value)`.
- A legacy output has neither member, so it decodes to nil slices, and applying it clears through the non-nil `Annotations()`.
- `omitempty` keeps a phrase-less, noun-less candidate's bytes as today.
- `internal/experiment/rpc/handler.go` `setOutput` decodes its own `outputPost` shape and ignores unknown members, so the lab wire still shows only PostContent. The experiment input hash covers the snapshot, not the output, so no hash moves.
- `generation_test.go` `fakePosts.SetGeneratedContent` records `annotations []*WriteAnnotations` beside `contents`. Existing assertions on `contents` stay as they are.

## result
- Changed (backend): `internal/post/types.go` (`ReplacementSurface` and `Valid`, `ReplacementCandidate`, `WriteAnnotations`, `Post.ReplacementCandidates`), `service.go` (`SetGeneratedContent` takes `*WriteAnnotations`: nil keeps, non-nil replaces; each candidate validated; `generatedAlready` and `equalCandidate` for both idempotence checks), `ports.go`; `store/queries/posts.sql` (UpdateGeneratedContent writes both columns and compares them in its idempotence group) and the regenerated `store/sqlc/posts.sql.go`; `store/content.go` (`marshalNouns`, the store-owned `replacementCandidateJSON`, `marshalCandidates` / `unmarshalCandidates`); `store/store.go` (writes both, `toPost` decodes the candidates); `rpc/replacements.go` (new) and `rpc/handler.go` (field 30); `internal/generation/types.go` (`WriteAnnotations`, `WriteAnswer.Annotations`), `ports.go`, `generate_handler.go`, `revise_handler.go` (nil), `experiment_surface.go` (`RunWriteCandidate` returns the whole `WriteAnswer`, `ApplyWriteWinner` takes one); `cmd/api/adapters_generation.go` (`postAnnotations`, a closed surface switch), `cmd/api/adapters_experiment.go` (`outputPost` gains `nouns` / `replacements` with `omitempty`; `toOutputPost(answer)`, `fromOutputPost` → `WriteAnswer`); `cmd/seed/main.go` (`post.WriteAnnotations{}`).
- Tests: the five named files, each with the named cases, plus `TestToProtoPostCarriesTheReplacementCandidates`. The 40 existing call sites pass nil or `post.WriteAnnotations{}`. The post fake stores both annotations and calls the service's own `generatedAlready`, so its idempotence cannot drift from the service's; the SQL predicate is pinned separately by the store test. The generation fake records `annotations` beside `contents`. The full BE gate passes (67 packages), and `gen:sql` regenerates byte-identically (checksums).
- `marshalNouns` and `marshalCandidates` return `(sql.NullString, error)` like the file's other codecs, rather than the bare `sql.NullString` the notes sketched. A candidate with no phrases is stored as `"phrases":[]`, so equal values encode equally, and it reads back as an empty slice, which the service compares equal to nil.
- Mutation check: 22 mutations over the service's resolve, validate and compare, both SQL clauses, the codecs, the wire, the three generation paths and both adapters. All are caught. A phrases-only change first survived, and the retry test now has that case too.
- No SSOT deviation.
