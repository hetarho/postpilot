# T337 A post saves its 분야 through the draft save and its quality ticks as a generation option
> st:done@260924 | ssot:POST-13 POST-81 POST-82 QUAL-23 ARCH-3 ARCH-6 ARCH-40 ARCH-24 | base:POST@11 QUAL@3 ARCH@9 | dep:T334

## goal
- The two per-post run inputs are stored and exposed: 분야 rides SavePostDraft with presence semantics including on create, quality ticks ride SavePostGenerationOptions, and neither changes status, revision, baseline or learning eligibility.

## acceptance
- [v] SavePostDraft with `field` absent keeps the post's 분야, `BLOG_FIELD_UNSPECIFIED` clears it to 없음, and any of the nine values assigns it; `Post.field` answers the stored value (UNSPECIFIED for 없음).
- [v] A create from `/posts/new` (empty slug) carrying a 분야 mints the post with it in the same insert.
- [v] A 분야 the directory does not know, or an out-of-range enum number, is NotFound `POST_FIELD_NOT_FOUND`: nothing is minted on a create, and on an update neither title, memo, voice, template, answers nor 분야 change.
- [v] SavePostGenerationOptions with `quality_rules` absent keeps the ticks, present replaces them, and present-and-empty clears them; duplicates collapse; the stored and answered order is M1 → M4 whatever the request order; `Post.quality_rules` answers them.
- [v] A `QUALITY_METRIC_UNSPECIFIED` element or an out-of-range number is InvalidArgument `POST_QUALITY_RULE_INVALID` and no option in the request is applied.
- [v] Neither save changes status, content revision, machine baseline, finalization or learning eligibility; both work on draft, review and finalized posts and answer `POST_PUBLISHED_LOCKED` on a published one with nothing changed.
- [v] A 분야 save equal to the stored one writes nothing; a tick save equal to the stored set together with unchanged other options is the existing no-op.
- [v] `generation.PostInput` carries the post's 분야 and tick ids from the generationPosts adapter, and every payload golden and experiment snapshot hash is byte-identical.
- [v] Tests: new `internal/post/field_test.go` in `template_test.go`'s shape (`TestSaveDraftAssignsClearsOrKeepsTheField`, `TestACreateCarriesItsField`, `TestAnUnknownFieldIsRefusedAndNothingLands` for create and update, `TestAFieldSaveIsAnOptionSave` on a finalized post, `TestAFieldSaveOnAPublishedPostIsLocked`, `TestNewServiceRequiresAFieldDirectory`); new `internal/post/quality_ticks_test.go` (`TestNormalizeQualityRules`, `TestTicksSaveKeepClearAndCollapse`, `TestAnUnknownTickIsRefusedAndNothingLands`, `TestTicksAreAnOptionSave`, `TestATickSaveOnAPublishedPostIsLocked`); `internal/post/store/store_test.go` (`TestFieldAndTicksRoundTrip`, `TestAssignPostFieldWritesOnlyAChange`); new `internal/post/rpc/quality_rules_test.go` (`TestQualityMetricWalksTheGeneratedEnum`, `TestSavePostDraftFieldPresence`, `TestSavePostGenerationOptionsTicksPresence`); `cmd/api/bootstrap_test.go` `TestGenerationAdapterCarriesTheFieldAndTheTicks`.
- [v] Verify: `cd backend && test -z "$(gofmt -l .)" && go vet ./... && go build ./... && go test -timeout 30m ./...`
- [v] Verify: `pnpm gen:sql && git diff --exit-code -- backend`
