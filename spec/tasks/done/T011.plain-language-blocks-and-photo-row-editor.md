# T011 Plain-language block names, fixed text instead of place/link, and the photo row stepper
> st:done@260906 | ssot:TEMPLATE-18 TEMPLATE-20 TEMPLATE-26 TEMPLATE-36 TEMPLATE-37 TEMPLATE-38 | base:TEMPLATE@3 ARCH@1 | dep:T010

## goal
Rename the composition toolbar and row badges to what the reader gets, show each block's help on the button, retire the place/link buttons by reading stored ones as fixed text, and let a photo position carry a side-by-side count edited with a stepper.

## acceptance
- [v] the TypeScript parser reads `count` on photo slots with the same rules and reasons as Go (`invalid_count`, `malformed_tag` on non-photo slots), the shared fixture `cases.json` passes on both sides including the cases T010 added, and the differential corpus still matches
- [v] the add toolbar offers exactly five buttons in this order: `AI가 쓰는 글` · `고정 문구` · `사진` · `사진마다 반복` · `AI에게만 하는 말` (en: `AI writes here` · `Fixed text` · `Photo` · `Repeat per photos` · `Note to AI`); each button shows its name and its one-line help as visible text, not a `title` or tooltip; `사진마다 반복` is still hidden when the aim is inside a repeat
- [v] a collapsed row's badge uses the same name as the button that creates it; no palette or row copy contains 작성, 삽입 or bare 반복
- [v] a stored body with a `place` or `link` slot opens as a `고정 문구` row whose text is the slot's label, falling back to 지도 / 링크 (en: Map / Link) when the label is empty; the draft is not dirty until the user edits; the next 저장 writes that row as literal text and the body no longer contains the slot; the composition is not shown as unreadable
- [v] a 사진 row expanded shows a stepper labelled 가로로 놓을 사진 수 (en: Photos side by side) with − and + buttons, the current value, min 1 and max `TEMPLATE_PHOTO_ROW_MAX`; the buttons disable at the bounds; the collapsed summary reads `사진 1장` for 1 and `사진 n장 가로로` for n > 1 (en: `1 photo` / `n photos side by side`)
- [v] a photo row inside a repeat shows the repeat's help stating how many photos one iteration takes: `한 번 되풀이할 때 사진 n장을 씁니다` where n is the sum of the counts inside it (en: `Each repetition uses n photos`)
- [v] `toBody` emits `<slot kind="photo"/>` for count 1 and `<slot kind="photo" count="n"/>` for n > 1; builder → body → builder is byte-identical for every builder output including counts; `blocks.test.ts` pins both
- [v] `shared/ui/stepper` is a new primitive (group with an accessible label, − / + buttons, `aria-valuenow`/`min`/`max` on the value, keyboard arrow support) with its own test, built from tokens only and used by the composition editor
- [v] `frontend/src/shared/config` exports `TEMPLATE_PHOTO_ROW_MAX` from `VITE_TEMPLATE_PHOTO_ROW_MAX` falling back to 4; `.env.example` documents the mirror beside the backend var
- [v] `GrammarStaysInternal.test.tsx` still proves no grammar syntax reaches the page, extended with `count="` in its syntax list and a body carrying `count="3"`
- [v] every existing test that clicked or read 작성 / 메모 / 반복 / 지도·장소 / 링크 is updated to the new names; the i18n `builder.reasons` gains `invalid_count` (ko: `가로 사진 수가 1~{{max}} 사이가 아니에요`, en: `Photos per row must be between 1 and {{max}}`)
- [v] `pnpm --filter ./frontend test` · `pnpm lint` · `pnpm lint:fsd` · `pnpm lint:style:probe && pnpm lint:style` · `pnpm build:web` pass on Node 24.18.0

## result
The composition now speaks the reader's language, the retired positions read as fixed text, a photo position carries a side-by-side count edited with a stepper — and the TypeScript parser is back in step with the Go one, so the shared fixture and the differential corpus are green on both sides again.

- `entities/template/lib/grammar.ts`: `TemplateNode.count`, `'invalid_count'`, `ParseOptions{photoRowMax}` threaded through `parse`/`parseNodes`/`parseTag`, and `slotCount` with the Go parser's rule verbatim — absent = 1 on a photo position and 0 elsewhere, a count on a retired kind is `malformed_tag`, and the value must be ASCII digits after trimming the shared blank set (`+2` and `2.0` refused rather than coerced, because `Number()` and `strconv.Atoi` disagree about exactly those)
