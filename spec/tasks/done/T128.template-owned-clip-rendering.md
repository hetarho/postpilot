## goal
Render explicit composition elements at their declared times while preserving the existing footage and typography quality.

## acceptance
- [v] No template element means no badge/card/chip/CTA or reserved header space; authored labels and disclosure phrases render exactly without a campaign mapping.
- [v] Whole-output and start/end-relative text persists correctly across cuts and fades; cut-relative text follows its cut after reorder, and invalid explicit windows return element-specific errors without silent clamping or deletion.
- [v] Explicit styles/positions/literals bypass automatic caption repair; automatic generated copy uses only approved alternatives and records any drop, while overlap remains advisory.
- [v] All three output ratios retain bundled fonts, safe/header bounds, contrast, motion, H.264 High 30 fps and the existing audio/loudness profile; hook ducking follows only an actually declared hook interval.
- [v] Frame tests verify absence/presence at exact boundaries, cross-cut fixed text without double opacity, arbitrary authored disclosure, different item prices, no hidden furniture, migrated outputs and invalid literal preservation.
- [v] Existing production media and resource gates pass for maximum cuts/rapid cues using bounded memory/disk and one final lossy encode.
- [v] Run the applicable local ARCH-25 through ARCH-29 checks, deterministic proto/SQL regeneration when changed, and spec lint; use a before/after generation snapshot when unrelated generated changes already exist.

## impl notes
- Use the version-5 resolved element timeline as the only composition source. Replace WithFacts/preset-generated furniture and live-template lookups with the retained project snapshot and explicit element records. Preserve old-plan support via the T126 converter.
- Share interval resolution, role layout, glyph measurement and crop transforms between rendering and the later preview API. Return a structured manifest with element ID, effective style, bbox, timing, source cut, authority and validation/fallback reason.
- Compose output-relative overlays after the source-cut transition composition so a whole-output caption is not duplicated or faded twice at cut joins. Cut-relative elements use the resolved output interval and their declared motion. Preserve the existing bounded merge tree; process bounded overlay batches with lossless intermediates and the single final CRF encode.
- Reuse overlay catalog SVG templates, resvg and the pinned fonts; adapt card and chip views to authored row/label/value lists. Keep the existing detailed CDS sizes, colours, safe areas and ratio-specific geometry. A role is a reusable visual recipe, not a content generator.
- Gate authored invalid text/style/timing with allowlisted element failures while preserving the prior result and correction draft. Repair only automatic generated-copy choices. No forced clean style, emphasis frequency, fixed fact count, whole-clip badge or first/last card window may reappear as a verifier prerequisite.
- Activate the composition workflow capability only after both new planner and renderer are wired. Retire preset seeding from normal generation paths and retain legacy conversion as explicit data, not runtime hidden defaults.
