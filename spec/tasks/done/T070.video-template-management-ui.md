## goal
Let an account create, inspect, edit and delete the reusable video templates that clip generation requires.

## acceptance
- [v] `entities/clip-template` owns the generated-contract mappers, cache keys, query/mutation hooks and types for information fields, copy styles and accents; no slice imports generated code directly
- [v] authenticated lazy routes `/video-templates`, `/video-templates/new` and `/video-templates/$templateId` render text loading/empty/failure states and preserve unknown/foreign not-found behavior
- [v] the directory lists name, information-field count, allowed styles and updated time, links the whole row, and docks one `새 영상 템플릿` action at every width
- [v] the editor has fields for name and cut guidance, an ordered information-field builder with add/reorder/delete plus label and prompt, three approved copy-style choices with at least one selected, and one optional accent from the code-owned palette
- [v] live validation mirrors every T069 bound and the server remains authoritative; save sends the whole recipe once and keeps the unsaved draft after a refusal
- [v] the three style choices show deterministic static previews using the same ids, palette and visual measurements T074 consumes; previews contain exact sample text and never call an image model
- [v] delete uses `Dialog`, names the detached-project count returned by the server, invalidates template and clip-project caches, and routes away only after success
- [v] all controls come from `shared/ui`, fields and sortable rows meet pointer floors at 320 px, and the page follows the existing template directory/editor rather than introducing a second design language
- [v] ko/en `clips` resources have identical topology and no concatenated sentences; tests cover create/edit/delete, field reordering, the non-empty style gate, server failure retention and both not-found states
- [v] ARCH-25 passes

## impl notes
- use one `entities/clip-template` slice rather than extending `entities/template`: the grammar-backed post template and the structured video recipe share a label only, not a contract
- represent `copyStyles` and `accent` by stable ids from `clip.proto`; CSS preview recipes may live in `entities/clip-template/ui` because T074's rendered pixels are backend output, not a shared runtime dependency
- keep the routes out of primary navigation in this task; T080 groups them under 영상 once both video destinations exist
- copy the page composition and mutation/cache patterns from `pages/templates` and `pages/template`, but do not copy the post-template grammar/source-mode controls
