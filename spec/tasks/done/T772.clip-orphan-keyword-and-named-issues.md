## goal
A generated caption whose copy fell back to a grounded shorter sentence no longer keeps an accent keyword that sentence lacks, plans already stored that way open, save and confirm, and ② names each caption problem and opens the caption it belongs to.

## acceptance
- [v] every shorter-copy fallback (narration reading floor in `media/composition_cues.go`, rapid parent, role and caption layout alternatives in `media/composition_layout.go`) keeps the keyword only when the new text contains it (CDS-25: one word of the caption may take the accent; CDS-41, CDS-55)
- [v] a stored portable plan (versions 5–7) whose element keyword is missing from its own text decodes with that keyword empty, so ApplyCorrection, ConfirmationRefusal and the editing projection accept it; a keyword its text holds is untouched (CLIP-75)
- [v] ② lists, beside the existing cut issues, one entry per caption or region text with a problem, naming the text and the reason (accent word missing, too long, too short on screen, timing, size, place, phrases, overlap, intro/outro overlap, evidence review); choosing an entry opens that text's sheet (CDS-213 "identify the exact … element")
- [v] the caption sheet states the specific reasons instead of only the generic `timeline.textInvalid`
- [v] tests: `backend/internal/clip` decode test for the orphan keyword (dropped, kept when present, confirmation refusal empty for the production-shaped narration caption), `backend/internal/clip/media` test that a shorter narration fallback clears a keyword it lacks and keeps one it holds; `frontend/src/features/correct-clip` test that a draft with an orphan keyword shows the named entry and that choosing it opens the caption sheet; `go test ./internal/clip/ ./internal/clip/media/ ./internal/clip/store/ ./internal/clip/rpc/ ./cmd/api/`, `pnpm --filter ./frontend exec vitest run src/features/correct-clip src/entities/clip-plan src/widgets/clip-workspace`, tsc, eslint, prettier, steiger, gofmt and vet pass

- Shared rule: `clip.KeywordWithin(text, keyword string) string` beside the portable text types; the media fallbacks and the decode heal both call it.
