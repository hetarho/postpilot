# T527 block editor edits photo groups
> st:done@261004 | ssot:POST-106 POST-13 POST-14 | base:POST@30 | dep:T526 | touches:frontend/src/features/edit-post-content frontend/src/test/posts.ts

## goal
The owner can make, change and undo a photo group in the block editor, and the editor refuses what the server refuses.

## acceptance
- [v] the type picker offers 사진 묶음 only when the post has two or more photos
- [v] 사진 → 사진 묶음 keeps the photo first and adds the next attached photo not already used by it, layout 콜라주; 사진 묶음 → 사진 keeps the first photo with its alt and caption; any other type → 사진 묶음 starts from the first two attached photos
- [v] the group card edits the layout (콜라주 · 슬라이드), the photos as an ordered list (move and remove; remove disabled at two), an add picker offering attached photos the group does not hold (disabled at `PHOTO_GROUP_MAX` or when none remain), the alt and the caption
- [v] the editor's content validity refuses a group with fewer than 2 or more than `PHOTO_GROUP_MAX` photos, a repeated photo, an unattached photo or no layout
- [v] the missing-photo count before finalize counts every unattached photo of an IMAGE or a GALLERY (editor and the MSW handler in `test/posts.ts`)
- [v] vitest pins each case above in `BlockEditor.test.tsx`
- [v] ARCH-25 passes
