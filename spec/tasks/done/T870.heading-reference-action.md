## goal
The post template wizard's 제목 제안 받기 sheet shows a secondary `내 템플릿 소제목 참고해서 제안 받기` beside 제안 받기 when the owner's saved templates hold heading lines, and it sends the typed request together with those lines.

## acceptance
- [v] `savedHeadingLines(templates)` returns the 고정 문구 lines of saved bodies (repeat children included, title area never read), trimmed, nonempty, ≤ `TEMPLATE_ASK_LABEL_MAX_CHARS`, in directory order, deduplicated, at most `HEADING_REFERENCES_MAX`; an unparsable body is skipped (deterministic: `heading-references.test.ts`, task stage)
- [v] with saved heading lines the sheet shows the action beside 제안 받기; tapping it starts one request carrying the typed style request and the lines, and closes the sheet once admitted (deterministic: `features/create-template-wizard/ui/HeadingSuggestions.test.tsx`, task stage)
- [v] with no saved template, or none holding a heading line, the action is absent; the 새 영상 템플릿 wizard never shows it (deterministic: same test file plus the existing clip wizard tests, task stage)
- [v] 제안 받기 still sends no references (deterministic: same test file, task stage)

- `WizardHeadingSuggestions` gets an optional `referenceHeadings?: readonly string[]` prop passed to `StyleRequestSheet`; when nonempty the action row holds a `variant="secondary"` button left of the `cta` 제안 받기, both sharing one sending state, the pressed one showing `pending`, both disabled while either is sending or the request is over its limit; the reference button calls `operation.start(writeModel, request, referenceHeadings)`; no help line or ⓘ beside it
- i18n: `headings.sheet.sendWithReferences: '내 템플릿 소제목 참고해서 제안 받기'` in `entities/template/config/target-i18n.ts` next to `headings.sheet.send`
- post wizard only: `features/create-template-wizard/ui/HeadingSuggestions.tsx` takes `ownerId`, reads `useTemplates(ownerId)` and passes `useMemo(() => savedHeadingLines(templates), [templates])`; `HeadingsStep` and `TemplateWizard` pass `ownerId` down.
