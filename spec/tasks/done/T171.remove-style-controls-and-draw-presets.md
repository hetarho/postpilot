## impl notes
- `clip-design.json` is byte-identical across FE and BE and a Go test asserts it, so this task consumes T166's file rather than editing it
- the step ② draft preview composites backend-rendered PNG assets (`PreparePreview`), so its parity with T167 comes from the backend; the FE-drawn preview is the template editor's `CompositionPreview`, which is where the presets have to be drawn by hand from the tokens
- the preview is the owner's only proof before paying for a render (CDS-65), so a preset drawn only on the backend is a parity failure, not a cosmetic gap
- keep the accent picker: one project accent survives (CLIP-14) and colours the caption's accent word alone (CDS-15); nothing in a region block reads it
- the correction workspace still edits text, position and timing — only the style affordance goes; the design step and the skeleton forms are T172's, so this task leaves the builder's hook/ending controls as they are apart from the style select
