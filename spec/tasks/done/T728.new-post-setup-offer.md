## goal
`/posts/new` on an account with no made writing voice or no post template opens a sheet offering to make what is missing, with `이대로 쓰기` and `다시 묻지 않기`, and the shared offer slice exists for T729's clip offer.

## acceptance
- [v] `/posts/new` opens the sheet only after the voice and template reads both succeed, and before the editor takes input; while either read is pending the existing loading placeholder shows; a failed template read renders the editor with no sheet
- [v] its title names what is missing (말투 · 템플릿 · both) and it shows one action per missing kind: `새 말투 만들기` opens `CreateVoiceSheet`; with a voice still being made, `말투 이어서 만들기` opens `/voices/$voiceId` for the newest such voice by `createdAt`; `새 템플릿 만들기` opens `/templates/new?post=new`
- [v] `이대로 쓰기`, Escape and the scrim close it for this creation; `다시 묻지 않기` closes it and no later `/posts/new` of that account on this browser opens it; another account still sees it
- [v] `/posts/new?template=<id>` (back from the wizard) and `/posts/new?from=setup` never open it; `/posts/$slug` never opens it; a made voice plus at least one template never opens it
- [v] first-use setup's finish to `/posts/new` or `/clips/new` navigates with `from=setup`; `/` carries no search
- [v] tests: `features/offer-creation-setup/model/offer.test.ts` (missing sets, newest unmade voice), `model/dismissal.test.ts` (per owner and kind, throwing storage falls back to memory), `ui/CreationOfferSheet.test.tsx` (titles, actions, Escape), `pages/editor/ui/EditorPage.offer.test.tsx` (every row above), `widgets/creation-setup/ui/CreationSetup.test.tsx` (finish carries `from=setup`)
- [v] the existing editor, creation-setup and mobile-audit tests pass unchanged in what they assert

## impl notes
- new slice `features/offer-creation-setup` (public `index.ts`), shared with T729:
  - `model/offer.ts`: `type CreationOfferKind = 'post' | 'clip'`; `type VoiceOffer = { action: 'create' } | { action: 'continue'; voiceId: string }`; `interface CreationOfferMissing { voice?: VoiceOffer; template: boolean }`; `postOfferMissing(active: readonly Voice[], templateCount: number): CreationOfferMissing | undefined` (voice missing = no `made` active voice; `continue` = the newest unmade active voice by `createdAt`); `clipOfferMissing(templateCount): CreationOfferMissing | undefined` (template only, never voice ← CLIP-223)
  - `model/dismissal.ts`: `readOfferDismissed(ownerId, kind, storage?)` / `writeOfferDismissed(ownerId, kind, storage?)`, key `CREATION_OFFER_DISMISSAL_PREFIX + kind + ':' + encodeURIComponent(ownerId)` from `config/index.ts` (`'postpilot:creation-offer:v1:'`), value `'1'`; every storage call in try/catch with an in-memory `Map` fallback, the pattern of `features/complete-setup/model/setup-progress.ts`
  - `model/useCreationOffer.ts`: `useCreationOffer({ ownerId, kind, suppressed })` → `{ settled, open, missing, close, dismiss }`. Post reads `useVoices(ownerId)` and `useTemplates(ownerId)`; clip reads `useClipTemplates(ownerId)`; the other kind's hooks get `''` (disabled reads, the `useSetupAvailability` pattern). `settled` = every read of its kind finished (success or error). The open decision is latched ONCE when it settles (suppressed, any read error, dismissed or nothing missing ⇒ closed) so a directory refetch never reopens or retitles it
  - `ui/CreationOfferSheet.tsx`: presentational over the shared `Sheet` (THEME-29): `header` = the title (`Typography variant="title"`, `labelledBy`), body = one line, `footer` = the create actions stacked first (the first `cta`), then `다시 묻지 않기` and the close action (`이대로 쓰기`; clip: `이대로 만들기`) as ghost buttons in one row. Props: `kind`, `open`, `missing`, `onCreateVoice`, `onContinueVoice(voiceId)`, `onCreateTemplate`, `onClose`, `onDismiss`. It renders no sibling feature (ARCH-13): the page opens `CreateVoiceSheet`
  - `config/i18n.ts` namespace `creationOffer`, registered in `app/providers/i18n/resources/index.ts` (ARCH-16). ko: titles `말투와 템플릿이 아직 없어요` · `말투가 아직 없어요` · `템플릿이 아직 없어요` · `영상 템플릿이 아직 없어요`; body `먼저 만들어 두면 글마다 골라 쓸 수 있어요.` / clip `먼저 만들어 두면 영상마다 골라 쓸 수 있어요.`; actions `새 말투 만들기` · `말투 이어서 만들기` · `새 템플릿 만들기` · `새 영상 템플릿 만들기` · `이대로 쓰기` · `이대로 만들기` · `다시 묻지 않기`; en equivalents.
