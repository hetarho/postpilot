## goal
A pure, deterministic finder returns every phrase in a post's prose that shows one of its voice's counted habits, located the way origin spans are located.

## acceptance

## impl notes
- `voice.Block` (in `fingerprint.go`) gains `Index int`; `fingerprintBlocks` in `backend/cmd/api/adapters_voice.go` sets it to the block's position in `found.Content.Blocks` before skipping media
- new `backend/internal/voice/habits.go`:
  - `type HabitKind string` = `ending` | `adverb` | `opening` | `closing` | `signature`
  - `type HabitPhrase struct { BlockIndex int; ItemIndex int /* -1 for TEXT/QUOTE */; Start, End int /* runes, half-open */; Quote string; Kind HabitKind; Term string; VoicePerHundred float64 /* 0 when not a rate */; TextCount int; Example string; ExampleFictional bool }`
  - `func FindHabitPhrases(analysis Analysis, blocks []Block, present map[string]bool) []HabitPhrase` — searched fields: TEXT/QUOTE `Content` and LIST `Items` only
- matching:
  - ending (①): for each sentence (`SegmentSentences`) whose `stripTail` text ends with one of `Counted.Endings.Suffixes` (longest first), span the suffix just before the stripped tail; rate = `Suffix.Count × 100 / Counted.Sentences`
  - adverb (⑥): whitespace tokens where `lexiconWord(stripToken(token))` equals one of `Counted.Adverbs.Words`; span the word inside the token; rate = `WordRate.PerHundred`
  - opening/closing (⑤): the post's first / last prose line (blocks order) whose `firstSyllables` equals a voice opening / closing line's; span that line's first / last sentence
  - signature: exact substring occurrences of each `AI.SignaturePhrases` entry (whitespace-collapsed comparison not needed); rate 0
  - `TextCount` = occurrences of that term across all searched fields
- example: the first sentence containing the term among `Counted.*.Example` and `AI.Examples` whose `MaterialID` is in `present` (VOICE-21 withdrawal; the caller passes `samplePresence` of the voice's current samples); synthetic analysis → the first `SyntheticSample` sentence containing the term, `ExampleFictional: true`; no match → empty
- uses the T827 ⑤ (callers pass the analysis as the store decorator returns it)
