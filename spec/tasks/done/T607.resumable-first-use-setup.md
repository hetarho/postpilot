## goal
Guide missing personal setup through a guarded resumable creation funnel.

## acceptance
- [v] Only successfully loaded missing configuration offers automatic setup on home; configured or explicitly completed/deferred accounts see the launch and protected deep links remain uninterrupted.
- [v] A pure event machine guards welcome/model/voice/post-template/clip-template/ready states, saving/running/failure transitions, back/skip, duplicate and obsolete events and confirmed completion.
- [v] The funnel creates or resumes one unfinished voice with existing owner-writing collection, explicit model choice/analysis, durable job polling and preserved errors; made voices skip learning.
- [v] Post/video templates are authored and explicitly saved with existing shared builders, validation and previews. Saved fields remain account records, with no automatic templates, inference or hidden model selection.
- [v] Versioned owner-scoped browser progress stores only acknowledgements/resume step/safe intent, handles invalid or throwing storage and logout/account switching, and offers explicit restart in settings.
- [v] Integration tests cover fresh/partial/configured/deferred users, load and mutation failures, resume/reload, safe destinations, duplicate submission, job recovery and no unsolicited AI; all frontend verification and a browser check pass.

## impl notes
- Place the pure reducer, validated browser progress adapter and useSetup controller in features/complete-setup; pages only compose widgets. Use account id as ownership and React remount key.
- Compose widgets/creation-setup from lower-layer model controls, voice material/analysis actions and entity template builders/mutations. Keep content in memory and existing account records, never browser preference payloads.
- On home mount check voices, post templates and clip templates concurrently; model choices are inspected only for setup. A failed directory read renders retry and an explicit continue action, never treated as empty.
- For voice setup resume the first active unfinished voice, create only on explicit submit, use existing readiness and analysis job hooks and invalidate profile/directory on terminal work. Make progress only after published profile.made.
- Build a small one-question form per step with existing TemplateComposition/TemplatePreview and CompositionBuilder/CompositionPreview. Validate and guard mutation submits; advance from returned saved ids and retain input on failure.
- Persist browser acknowledgement per account using an exception-safe versioned preference. Route entry does not write an entity; an explicit finish/defer follows only `/`, `/posts/new` or `/clips/new`. Existing actual saved data skips steps on another browser.
- Test pure transitions exhaustively plus real route/UI behavior and browser reflow/focus in day/night. No backend migration or new package.
