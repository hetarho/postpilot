# T206 The bundled ffmpeg carries what the render code names
> st:done@260916 | ssot:ARCH-39 | base:ARCH@3 | dep:T205

## goal
Fail the build when the `--disable-everything` ffmpeg is missing a filter, decoder, encoder or muxer the render code emits.

## acceptance
- [v] the media package names, in one place, the filters, decoders, encoders and muxers the render path emits
- [v] a check inside the image compares that list against what the bundled binaries report and fails naming each missing entry
- [v] the check gates the pushed image, so a missing entry stops the image rather than being reported beside it — unlike the smokes (→ARCH-38)
- [v] every filter name appearing in the golden `.filter` fixtures is present in that list, checked on the host so a forgotten list update fails ARCH-26 without Docker
- [v] the check compiles nothing new, running the test binary the builder already produces
- [v] tests: the host-side golden cross-check above, plus a unit test that a name absent from the binaries is reported as missing

## impl notes
- two halves, split by where each can run: the golden-to-list cross-check reads files only, so it stays ungated and rides ARCH-26; the list-to-binary check needs the real binaries, so it is env-gated like the other image checks (→ARCH-36) and runs in its own stage.
- the stage runs `/media.test -test.run=^<name>$` — the binary the builder already produces for the media smoke — so no new compilation enters the build and the stage costs seconds, not minutes.
- the list lives beside the render code in `backend/internal/clip/media`. Compare against `ffmpeg -filters`, `-decoders`, `-encoders`, `-muxers`; `ffprobe` needs no separate list since it comes from the same build.
- keep the check out of `media-tools.sh`: that script is the thing being verified, and comparing its own `--enable-*` flags against itself proves nothing.
- the failure this exists for is on record: `4a028a5` shipped an ffmpeg without `atempo`, so every non-unit playback rate with retained source audio was broken in production while the emitted graph was correct.

## result
- changed: `backend/internal/clip/media/tooling.go` (new, the four lists), `backend/internal/clip/media/tooling_test.go` (new, both checks plus the parsers), `backend/Dockerfile` (`media-tooling` stage, `deployable` stage the deploy now pushes, `production` rebased onto it), `.github/workflows/deploy-backend.yml` (`target: deployable`).
- the lists: 24 filters read out of the 31 graph fixtures plus `anull` and `vfrdet`, which only the code names (`loudness.go` returns "anull" as a no-op chain, `probe.go`/`chunks.go` pass `-vf vfrdet`). Encoders and muxers are every `-c:v`/`-c:a`/`-f` literal in non-test files; `copy` is excluded as stream copying.
- decoders are scoped to what this package writes and reads back (h264, aac, png, pcm_s16le). A source's own codec is deliberately absent: the render code never names it, so ARCH-39's "the render code names" does not reach it, and an hevc decoder dropped from the build would still slip through. Worth a follow-up if source intake ever declares its accepted codecs.
- `-protocol_whitelist file,pipe` is the same class of risk and is NOT covered: ARCH-39 names filters, decoders, encoders and muxers only. A later revision could add protocols to the same mechanism cheaply.
- cost measured in the image: the check itself runs in 0.01 s and the whole stage in under a second, reusing `/media.test` from the builder, so nothing new compiles.
- verified negatively: adding `definitelynotafilter` to `requiredFilters` made `docker buildx build --target deployable` exit 1 naming that entry, so the gate really does stop the image.
- parser trap worth knowing: some fixtures carry a header line (`delivered inputs=4`) above the graph. Splitting the file on `;` alone swallowed the graph beneath it and invented "delivered inputs" as a filter, so the parser splits per line and keeps only `[a-z][a-z0-9_]*` names. Expression arguments carry their own commas (`crop=...x='max(0,min(...))'`), which is why splitting ignores separators inside single quotes.
- no SSOT divergence.
