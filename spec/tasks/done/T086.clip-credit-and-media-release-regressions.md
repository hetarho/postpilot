## goal
Pin the complete approval-to-settlement and preview-to-cleanup workflow with repeatable integration, resource and compatibility regressions before release.

## acceptance
- [v] a local integration harness runs authenticated quote/start/poll through real SQLite admission, real media preparation/rendering and a counted fake provider, proving every proxy exists and passes limits before reservation and the first AI request
- [v] the success case sends the exact actual chunk count plus one text-only plan request, retains an original-derived result, caps debit by both approval and hold, refunds unused credits once and cleans originals/proxies/request scratch
- [v] fault cases cover malformed last source, oversized last proxy, low disk, quote change/expiry, ceiling excess, unknown prices, permission denial without usage, paid partial failure, reasoning truncation, result-save failure and malformed/oversized provider output with the expected call count and settlement
- [v] concurrent starts/reservations, duplicate acceptance, aborted client connections, failed terminal/settlement writes and restart at prepare/hold/partial-usage/save boundaries preserve nonnegative lots, one executable attempt, idempotent recovery and no automatic provider replay
- [v] a fake provider reporting cost above both limits never creates an additional user debit or debt; no-usage failed work including the base costs zero; raw unknown usage remains unknown and a settled attempt is not charged again
- [v] old clients without quote fields and old queued clip payloads cannot initiate paid work; photo-only posts, signed-URL-compatible post fixtures, incompatible post/experiment refusals, ordinary/master accounts and free rerender regressions pass
- [v] browser tests prove previews survive accepted/queued/running work and end exactly at the matching terminal state or page exit, while maximum/held/settling/final/refund states remain legible and explicit retry never fires itself
- [v] the production media image completes nonroot tests under a 1 GiB memory and two-CPU runtime limit without OOM; measure peak container memory, elapsed preparation/render time and disk high-water marks for 60-second high-motion/audio input and a 20-source/30-minute stress case
- [v] stress instrumentation proves at most one media job/original/encoder at once, at most 49 proxies before analysis, each proxy at most 8 MiB, encoded requests at most 12 MiB, and workspace usage below the configured bounds; inspect final output and speech/timing fixtures, not just process exit codes
- [v] ARCH-25 through ARCH-28 and ARCH-31 local gates, targeted Go race suites, spec lint and whitespace checks pass; reproducible commands and measured results are recorded before this task becomes done
- [v] no production database, provider credential, user media, historical credit adjustment, live model completion, Naver publish, remote push or deployment is required or performed by the regression harness

## impl notes
- this task adds cross-layer fixtures and executable regression coverage; it does not substitute for T081 through T085's own acceptance tests, and a discovered defect must be fixed and reverified before reporting the series ready
- use local fake storage plus an HTTP completion stub with exact request/body counters and deterministic usage/error responses, real temporary SQLite databases and the existing nonroot Docker media-smoke mechanism; verify payload/log redaction with canary strings
- build synthetic rotation/VFR/no-audio/noisy-motion fixtures locally and use a repository-approved or newly recorded nonprivate speech fixture for audio continuity; never fetch or upload the owner's media merely to validate quality
- run the resource limit on the runtime image, not on the Go compiler; record container-wide memory including subprocesses, disk peaks and timings, and isolate test workspaces/databases from any active development or production stack
- use the existing race-enabled job/usage/clip store suites and extend fault seams around queue activation, durable terminal state and settlement transactions; a running job interrupted by restart fails rather than resuming model calls
- exercise an actual ordinary account for debit/refund assertions and a separate master fixture for exemption; do not infer user-credit safety from an OpenRouter dashboard, a zero stored token count or a master-only smoke
- include representative nonzero Gemini media/cache/reasoning metadata, conditional price tiers, frozen endpoint drift and known-zero versus absent rates. Verify quote/hold parity, no overlapping token double-count, optional-feature exclusion and unavailable estimates when aggregate usage cannot price the actual modalities/cache; old token-only pricing versions must not execute
- include read-only compatibility checks for generated contracts/migrations, preserving existing post/voice/experiment behavior outside the explicit VIDEO-11 URL gate; do not alter T008 or any archived task
- keep test artifacts sanitized and finite, document invocation beside the existing media/AI test guidance, and report remaining provider-contract uncertainty honestly; successful local stubs are not a claim of a successful paid live model run
