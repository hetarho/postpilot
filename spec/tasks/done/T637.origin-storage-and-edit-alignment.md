## acceptance

- [v] Machine generation/revision and compatible source application atomically publish matching content/plan/origins under existing ownership/CAS/idempotency/lifecycle fences; malformed origins do not discard valid content or finalize implicitly.

- [v] Owner read/save responses return the authoritative current revision and aligned review state, never another result or owner. Published read-only rules and original finalize/export readiness stay unchanged.
- [v] Real SQLite store/API regressions cover legacy upgrade, revision races, unchanged/no-op edits, punctuation/new content, duplicate/reordered blocks, attachment deletion, machine baseline equality, lost receipt and purge; memory extraction still stores only explicit approved facts.
