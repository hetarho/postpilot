## impl notes
- FSD forbids a feature importing another feature, so `ModelCatalogManager` takes an optional `recommendations?: ReactNode` slot and `AdminModelsPage` passes `<RecommendationSetManager />`; the tab state is `ModelPurpose | 'recommendations'` and the catalog reads keep the last purpose while the sixth tab is open, so returning to a purpose tab does not refetch
- tab copy `catalog.purposeTab.recommendations` (추천 조합 / Recommended sets) in the manage-model-catalog fragment; `RecommendationSetManager` keeps its own heading and description as the tab panel's content
- entity: `CatalogDocumentPlan.recommendations?: { added: string[]; removed: string[]; changed: string[]; unchanged: string[]; reordered: boolean }`, undefined when `present` is false; the mapper reads the new proto field
- the preview renders the set diff as one more group after the purposes, removals called out as the purposes' deregistrations are; `isKnownCause` and `document.issueCause.*` gain `set_label_invalid` `duplicate_set` `set_limit` `stage_before_set` `duplicate_stage` `missing_stage` `slot_unregistered` `slot_unclassified` `slot_duplicate`
- remove `AdminRecommendationsPage`, `adminRecommendationsRoute`, the `recommendations` entry of `ADMIN_TABS` and `admin.tab(Short).recommendations`
