- [v] `pages/guidelines`: the defaults render first in registry order, then the owner's rows exactly as today; the owner list's empty state still appears when the owner has none (the defaults are not the owner's rows)
- [v] no other surface shows or switches a 기본 지침 (GUIDE-19)

## impl notes
- Switch primitive: use the `shared/ui` switch. If the 데이터 받기 switch in `entities/template/ui/TemplateComposition.tsx` (662-726) is hand-rolled, promote it to `shared/ui/switch` first and use it in both places (ARCH-20).
- Copy (namespace `guidelines`): badge `추천` / `Recommended`; Korean-only note `한국어 글에만 적용돼요` / `Applies to Korean posts only`; switch label `{{name}} 사용` / `Use {{name}}`.
