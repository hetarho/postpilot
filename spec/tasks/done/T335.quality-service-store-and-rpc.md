## goal
- The quality context comes alive: GetPostMeasurement returns this revision's M2/M3/M4, GetAccountQuality returns the four-state aggregate over 발행됨 posts with rule texts in the post's target language, RulesFor and PhrasesFor are ready for T344's enqueue freeze, and the phrase-list store is ready for T338's batch.

## acceptance
- [v] GetPostMeasurement(slug) answers the post's current content revision and M2, M3 and M4 with verdicts; M3/M4 are read from `post_measurements` when its row matches the revision and `quality.MeasureVersion`, otherwise recomputed and upserted; M2 is computed at read against the post's 20 most recent published others (QUAL-4).
- [v] While fewer than 3 published posts other than this one exist, the post's M2 is BELOW_MINIMUM carrying minimum 3 and that count (QUAL-36); a post with no content answers every metric ABSENT and reads or writes no measurement row.
- [v] GetAccountQuality(slug) answers one entry per metric in M1–M4 order — verdict, values, band, minimum and published count — derived at read from `published` posts only, newest `published_at` first (QUAL-2, QUAL-39); only an OVER_BAND entry carries its rule text, rendered in that post's target language (R22).
- [v] An absent value is unset on the wire, never 0 (QUAL-40); an empty, unknown or foreign slug answers NotFound `POST_NOT_FOUND` on both rpcs; both require a session and no request carries an account id.
- [v] `RulesFor(ctx, userID, slug, ticked, lang)` returns the rendered texts of the ticked metrics that are OVER_BAND now, in M1–M4 order; with nothing ticked it reads nothing and returns none; an unknown or repeated id is dropped.
- [v] `PhrasesFor(ctx, field)` returns the stored list in rank order, and an empty list for a blank field, a field with no row, or an empty row (QUAL-41).
- [v] The phrase store reads one field's row and replaces a field's whole row (phrases, corpus size, `refreshed_at` — SQL NULL when nil — and `next_refresh_at`), inserting it when the field has none; these two are all T338's batch needs.
- [v] Deleting a post removes its measurement row through the FK cascade, and the next aggregate no longer counts it (POST-85).
- [v] QualityService is registered in `serve.go`; `wiring_test.go` expects 22 handlers; `contexts.quality` is non-nil after `buildContexts`.
- [v] Nothing in `internal/quality`, `internal/quality/store` or `internal/quality/rpc` depends on llm, provider, usage or job (QUAL-16).

## impl notes
- `backend/sqlc.yaml`: append an entry after billing's — engine `sqlite`, schema `internal/platform/db/migrations`, queries `internal/quality/store/queries`, out `internal/quality/store/sqlc`, package `sqlc`, `omit_unused_structs: true`; run `pnpm gen:sql` and commit the generated package.
- Tables come from T323's migration (`post_measurements` per R15, `field_phrase_lists` per R24); this task adds no migration.
- `store/queries/measurements.sql` (ASCII only — one Korean character breaks codegen for the whole file): `GetPostMeasurement :one` selects every R15 column but the key `WHERE post_slug = ? AND user_id = ?`.
- `store/queries/measurements.sql`: `UpsertPostMeasurement :exec` is `INSERT … ON CONFLICT(post_slug) DO UPDATE SET` every non-key column `= excluded.…` `WHERE post_measurements.user_id = excluded.user_id` (the `clip/store/queries/clips.sql` answers-upsert precedent).
- `store/queries/phrases.sql` (ASCII only): `GetFieldPhraseList :one` (`WHERE field = ?`); `ReplaceFieldPhraseList :exec` (INSERT all five columns, `ON CONFLICT(field) DO UPDATE SET` phrases, corpus_size, refreshed_at, next_refresh_at).
- No due listing and no reschedule query: T338 reads each of the nine fields' rows by field (a never-refreshed field has no row) and, on a failed page, rewrites the row it read with only `next_refresh_at` moved, through `ReplaceFieldPhraseList`. Only the batch writes this table, so the read-then-replace has no competing writer.
- `store/store.go`: `Store{writer *sql.DB; write, read *sqlc.Queries}` with `New(writer, reader *sql.DB) *Store` (memory/store precedent); writes go through `write`, reads through `read`; timestamps use memory/store's fixed-width UTC `writeLayout` `2006-01-02T15:04:05.000000000Z07:00`.
- Store methods: `Measurement(ctx, userID, slug) (quality.StoredMeasurement, bool, error)` (sql.ErrNoRows → false); `SaveMeasurement(ctx, quality.StoredMeasurement) error`.
- Store methods: `PhraseList(ctx, field) (quality.PhraseList, bool, error)`; `ReplacePhraseList(ctx, quality.PhraseList) error`, with phrases JSON-encoded and an empty list stored as `[]`, never `null`.
- `ReplacePhraseList` writes SQL NULL for a nil `RefreshedAt` (a field whose first fetch failed) and `PhraseList` reads NULL back as nil.
- Row mapping: `repetition_share`, `title_relevance` and `avg_sentence_length` NULL ↔ nil; `top_noun` NULL ↔ ""; the three counts are NOT NULL ints; nothing JSON-tagged reaches the domain (ARCH-7).
- Domain (types.go / ports.go): `var ErrPostNotFound = errors.New("quality: post not found")`; `StoredMeasurement{PostSlug, UserID string; Revision int64; MeasureVersion int; Self Self; ComputedAt time.Time}`; `PhraseList{Field string; Phrases []string; CorpusSize int; RefreshedAt *time.Time; NextRefreshAt time.Time}`.
- ports.go: `Measurements{ Measurement; SaveMeasurement }` and `PhraseLists{ PhraseList; ReplacePhraseList }`, both implemented by `store.Store`; the service reads through `PhraseList` only, and T338's batch consumes `PhraseLists` as declared here.
- ports.go (R14): `PostSource{ Post(ctx, userID, slug string) (PostSnapshot, error); Published(ctx, userID string, limit int) ([]PublishedPost, error) }`; `Post` returns `ErrPostNotFound` for an unknown or foreign slug; `Published` is `published_at` DESC.
- `PostSnapshot{Slug string; Revision int64; Content *Document; ContentLanguage *Language; TargetLanguage Language; Nouns []string}`: Content nil means no content yet.
- `PublishedPost{Slug string; Revision int64; Content Document; ContentLanguage *Language; Nouns []string; PublishedAt time.Time}`.
- R14 lists `status` on `Post`; nothing in this context reads it (published-ness arrives only through `Published`), so the port omits it (ARCH-6: a port names what its use-case needs).
- service.go (ARCH-40): `Deps{Measurements Measurements; Phrases PhraseLists; Posts PostSource; Now func() time.Time}`; `NewService(deps Deps) *Service` panics `"quality: <name> collaborator is required"` for each missing one.
- Test `deps.Now == nil` directly rather than through post.NewService's `map[string]any` loop, because a nil func stored in `any` does not compare equal to nil.
- `PostMeasurement(ctx, userID, slug) (PostReading{Revision int64; Measurement PostMeasurement}, error)`: a trimmed-empty slug → ErrPostNotFound; `Posts.Post`; Content nil → `{snapshot.Revision, AbsentPost()}` with no store call.
- `PostMeasurement` otherwise: sample = `Sample{Slug, *Content, LanguageOf(ContentLanguage), Nouns}`; self = the lazy row; published = `Posts.Published(ctx, userID, PostWindow+1)`; answer `JudgePost(sample, self, OthersOf(samples, slug))`; PostWindow+1 is enough for 20 others when the post is itself published.
- Lazy row: `Measurement(userID, slug)`; when found with `Revision == snapshot revision` and `MeasureVersion == quality.MeasureVersion`, use its Self; otherwise `MeasureSelf(sample)`, `SaveMeasurement` with `ComputedAt: now().UTC()`, and use it; an upsert error fails the read.
- Concurrent reads race benignly: both compute the same Self, and a row left at an older revision by a late write is recomputed on the next read, because the row is keyed by revision and version (R15).
- Nouns change only with a write that also advances `content_revision` (T341's SetGeneratedContent), so revision + version is a complete key for M3.
- `AccountQuality(ctx, userID, slug) (AccountReading{Account Account; RuleTexts map[Metric]string}, error)`: `Posts.Post` (ownership and TargetLanguage); `Posts.Published(ctx, userID, TitleWindow)`; lazy rows for the first min(PostWindow, n) posts; `Aggregate`.
- `AccountQuality`: for each OVER_BAND metric, `RuleText(m, snapshot.TargetLanguage, account.Named(m))` fills `RuleTexts[m]` when it renders; nothing else is rendered (R22).
- `RulesFor(ctx, userID, slug string, ticked []string, lang Language) ([]string, error)` (R23): parse with `ParseMetric`, drop unknown and repeated ids; none left → `nil, nil` before any read, so ticking nothing adds no quality-rule bytes and costs no query.
- `RulesFor` otherwise: `Posts.Post(slug)` proves ownership (the reason R23's slug is a parameter); the same aggregate as `AccountQuality`; for m in `Metrics()` order, append `RuleText(m, lang, Named(m))` when m is ticked, OVER_BAND and renders.
- `PhrasesFor(ctx, field string) ([]string, error)`: a trimmed-empty field → nil without a read; no row → nil; otherwise a copy of the stored phrases in stored (rank) order; T344 takes the first 30.
- rpc/handler.go: `Handler{service *quality.Service}`, `NewHandler`, `var _ postpilotv1connect.QualityServiceHandler = (*Handler)(nil)`, `actingUser` copied from memory/rpc (`auth.UserFromContext` → Unauthenticated `AUTH_REQUIRED`).
- rpc `toConnectError`: `quality.ErrPostNotFound` → `CodeNotFound` "post not found" `FailureReason_POST_NOT_FOUND` (foreign and unknown are indistinguishable, like memory's); anything else → `slog.Error` plus `CodeInternal` `UNKNOWN_FAILURE`.
- rpc mapping: `toProtoMetric` and `toProtoVerdict` have one case per domain value and no `default:`; the trailing UNSPECIFIED return is reachable by no domain value, which the walk tests prove (every generated non-UNSPECIFIED value reached exactly once, `len(QualityMetric_name) == len(quality.Metrics())+1`, same for verdicts) (ARCH-3).
- rpc messages: quality.proto is T322's and binding; every domain member maps onto the wire member T322 declared for it; a nil value leaves its `optional` field unset; bands come from limits.go's constants, minimums from `quality.Minimum`, and entries follow `quality.Metrics()` order.
- A per-post M2 carries `Others` as the published count it was judged against; account M4 values are medians and may be x.5; account M3 carries both bands (0.08 and 0.50).
- If T322's shape cannot carry a value exactly (an integer member for a median, one band for M3's two), amend `proto/postpilot/v1/quality.proto` only — no concurrent task touches it — regenerate with `pnpm gen:proto`, run ARCH-25 for the regenerated FE file, and say so in the result.
