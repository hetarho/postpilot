## goal
The section step lets the owner type the optional 고정 문구 of a 질문을 바탕으로 작성 part (the 별점 part's rating criteria among them), and the card's 완성된 글 drawing and the live preview show it above the written lines.

## acceptance
- [v] the 질문을 바탕으로 작성 inputs show the question, 필수 and an optional `고정 문구 (선택)` textarea bound to the section's fixed text; leaving it empty is never a problem (deterministic: `SectionStep`/`ContentKindCard` test, task stage)
- [v] the 완성된 글 drawing and the wizard preview show the fixed text above the written lines when it has text, and nothing extra when it is empty (deterministic: `ContentKindCard.test.tsx`, `WizardPreview.test.tsx`, task stage)
- [v] a wizard run through a leaf reaches the 별점 step, types criteria into the 고정 문구, saves, and the created body ends with heading, criteria and the field on consecutive lines (deterministic: an existing wizard flow test extended, task stage)
