# T361 A write comparison freezes the same write material as Start
> st:done@260925 | ssot:MEM-19 MODEL-30 GEN-18 GUIDE-40 QUAL-41 ARCH-7 | base:MEM@3 MODEL@17 GEN@12 GUIDE@6 QUAL@4 ARCH@11 | dep:T354 T359

## goal
One helper resolves a write's frozen material: brief, 지침, 기억, ticked rules and 분야 phrases.
- Start and the A/B snapshot both call it, so a comparison of a post with 기억 사용 on carries its memories.
- The preset line rides only with frozen phrases.
- The snapshot gets its own tagged wire struct, so no domain type's field names or tags are hashed any more.

## acceptance
- [v] `freezeWriteMaterial(ctx, post)` is the only place a write resolves its material. `Start` and `SnapshotWriteInput` call it and nothing else on the write path calls the five `freeze*` helpers. `StartRevision` keeps `freezeTemplate` plus the guideline owner texts only.
- [v] MEM-19/GEN-18/MODEL-30:
  - the snapshot of a `UseMemory` post carries the memories retrieved at snapshot time;
  - both candidates' per-post halves carry one `[기억]` section with them, byte-identical between the two;
  - a memory edited after the snapshot reaches neither candidate, and the port is called once;
  - the same post with a retrieval that finds nothing snapshots `"Memories":null`, as every snapshot does today;
  - with memories present, the snapshot bytes, and so the input hash, differ.
- [v] GUIDE-40/QUAL-41, for Start's payload and for the snapshot:
  - a post whose 분야 froze no phrases gets no preset line, while its owner guidelines, 분야-scoped ones included, still freeze;
  - with frozen phrases, the preset line is appended last;
  - a revision never carries it, even when the guideline port returns one.
- [v] `guideline.Service.ForPrompt` returns the owner texts and the preset line apart (`PromptTexts`). The generation port `GuidelinesForPrompt` returns `GuidelineTexts`. The cmd/api adapter and every fake are updated.
- [v] Snapshot wire (F14, ARCH-7):
  - `internal/generation/types.go` has no struct tags (`grep -n 'json:"' backend/internal/generation/types.go` is empty);
  - the write and observe snapshots encode through `snapshot*` wire structs with explicit tags in `internal/generation/experiment_snapshot.go`.
- [v] Byte identity:
  - a write snapshot without memories encodes byte-identically to today's, both unprepared and after `PrepareWriteInput`, pinned by goldens captured at HEAD before any edit;
  - an observe snapshot likewise;
  - stored snapshots decode and re-encode to the same bytes.
  - One exception is intended: a post with the preset on and an empty phrase list now freezes one line fewer (GUIDE-40).
- [v] Behavior otherwise unchanged: existing tests still pass, with the updates in impl notes.
- [v] Tests (named in impl notes):
  - `experiment_snapshot_test.go`: `TestWriteSnapshotEncodingIsPinned`, `TestEveryWriteSnapshotMemberRoundTrips`, `TestObserveSnapshotEncodingIsPinned`.
  - `memory_test.go`: `TestWriteSnapshotFreezesMemoriesForBothCandidates`.
  - `guideline_test.go`: `TestThePresetLineRidesOnlyWithFrozenPhrases` and `TestAComparisonFreezesTheWriteMaterialStartFreezes`.
  - `internal/guideline/service_test.go`: `TestForPromptReturnsThePresetLineApart`.
- [v] BE gate passes: `cd backend && test -z "$(gofmt -l .)" && go vet ./... && go build ./... && go test -timeout 30m ./...`
