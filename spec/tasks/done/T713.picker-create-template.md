## goal
①'s template picker ends with 새 템플릿 만들기, which opens the wizard and, on 저장, returns to the post (or a new draft) with that template assigned.

## acceptance
- [v] `PostTemplateSelect` lists 없음, templates, then 새 템플릿 만들기; choosing it calls `onCreateTemplate` and assigns nothing
- [v] the editor navigates to `/templates/new?post=<slug|new>`; the wizard's 저장 then replaces to `/posts/$slug?template=<id>` or `/posts/new?template=<id>`; without `post` it keeps opening the saved template
- [v] the editor applies a `template` search once through the ordinary assignment (`autosave.assignTemplate` for a saved post, the draft's `setTemplateId` for a new one) and strips it from the URL; an id equal to the current assignment changes nothing
- [v] tests: `PostTemplateSelect.test.tsx` create option; search-schema tests for both routes; an editor test that a `template` search assigns once

## impl notes
- `CREATE_TEMPLATE_VALUE = '__create_template__'` mirrors the voice picker's create option
- search: `newTemplateSearchSchema` gains `post?: string`; `pages/editor` exports `editorSearchSchema` (`template?: string`) used by `newDraftRoute` and `postEditorRoute`
- the apply effect lives in `pages/editor` beside `DraftEditor` and runs after the post (or the new draft's assignments) is ready; leaving the wizard unsaved returns through the browser and assigns nothing
