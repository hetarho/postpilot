## goal
Connect compact horizontal source browsing to retained AI observations and saved-plan cut usage throughout the clip workspace.

## acceptance
- [v] Source selection and terminal filename summaries scroll horizontally, each selected local source has one larger playable preview, and upload errors and page progress remain visible outside the strip.
- [v] Owner-scoped project detail exposes structured retained source metadata and observation segments without media bytes, storage keys, URLs, raw JSON or new AI calls; project list remains free of observations.
- [v] Every existing-project step exposes latest-successful observations, a recorded summary and expandable ranges with events, subjects, speech and quality; missing or unreadable observations and empty source ranges have explicit states.
- [v] Each range maps to the intersecting ranges and 1-based cut numbers of the saved plan by source ID and fingerprint; saved deletion, trimming and reordering update usage; revision mismatch is labelled as saved-plan usage, not rendered output.
- [v] Previous observations remain identified during queued/running/failed regeneration; local playback is offered only for a matching fingerprint, and releasing local media preserves readable observations.
- [v] Korean and English copy, keyboard selection/disclosure, mobile overflow and both themes follow existing primitives and tokens.
- [v] RPC tests cover ownership, structured projection, absent/invalid analysis and list exclusion; frontend interaction tests cover source selection, observation disclosure, missing media, usage mapping, revision labels and step integration.
- [v] ARCH frontend/backend/agent checks, formatter, deterministic proto/SQL regeneration and spec lint pass locally.

## impl notes
- One cohesive full-stack task; no schema migration, new dependency, provider call or generation pipeline change.
- Add an additive detail-only ClipProject observations message containing status (available/empty/unavailable) and source records with existing retained metadata and timecoded event/subjects/speech/quality fields; regenerate through pnpm gen:proto, never edit generated code.
- Parse existing Analysis JSON through clip's existing strict decoder; reuse the parser for retained sources, allowing absent analysis to produce an empty source list. Malformed retained analysis is an unavailable projection and disables its unusable correction projection on detail reads while keeping the existing result accessible.
- Keep RPC mapping under clip/rpc, frontend mapping and usage projection under entities/clip-project, reusable source-strip presentation in that entity and observation interaction under features/inspect-clip-observations; compose it in pages/clip without same-layer feature imports.
- Horizontal source selectors use existing shared Button/Typography primitives with labelled pressed state, thumbnail metadata only and a current/total indicator; one selected preview uses controls and no autoplay. Terminal summaries contain text rather than retained source pixels.
- Observations appear after a successful generation using existing detail polling. They are an optional section available on all three steps. Current uploads and retained successful sources remain clearly identified as separate data when a new attempt is in progress.
- Match local previews by fingerprint, retained cut use by source ID plus fingerprint, and report overlap boundaries as max(start)/min(end), excluding touching endpoints. Usage reads project.editing.plan, never the unsaved correction draft; compare editPlanRevision with renderedPlanRevision and result presence for its label.
- Render plain recorded text, never generated explanations or confidence scores. Summaries reuse a nonempty recorded event/speech/subject, with details collapsed initially; no extra AI summary.
- Preserve other sessions' existing work. No commit, push, production change or paid/live rendering is needed for this read-only presentation and contract change.
- Verify generated determinism against a hash snapshot of the newly generated output, since intended uncommitted generated changes necessarily differ from HEAD; SQL generation must leave backend changes identical to its before-run snapshot.
