## goal
Create durable eight-suggestion and conversational configuration drafts.

## acceptance
- [v] Five fixed kinds use private owner-scoped durable sessions, eight suggestions, selected artifact, captured target metadata, bounded chat and monotonically increasing revisions.
- [v] Explicit recommend and refine each admit one frozen bounded write call, with request-key replay, account/kind authorization, version guards, active-account exclusion and dispatch/restart protection.
- [v] Exactly eight distinct domain-valid artifacts are returned together; refine updates only the selected draft and a friendly reply. Invalid/cancelled work preserves prior suggestions, draft and request text without hidden correction.
- [v] Reads recover completed/failed jobs without issuing new model work; foreign IDs, stale versions and owner changes cannot disclose or replace another draft.
- [v] Core persistence/RPC tests cover duplicate admission, concurrent selection/send, interrupted publication preparation, bounded history, cancellation/restart and zero-call operations.
