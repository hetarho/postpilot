# T185 The writer's cut budget follows the sections the answers admit
> st:done@260916 | ssot:CLIP-103 | base:CLIP@28 ARCH@2 | dep:T183

## goal
Derive the assembly writer's cut budget from the sections a project's own answers actually admit, not from the template's authored prose.

## acceptance
- [v] the budget counts a section only when the project's answers admit it: a repeated group contributes its admitted item count, and an optional section whose binding is blank contributes nothing (→CLIP-60)
- [v] a template whose prose describes a section the answers leave empty produces a budget that the selected footage can fill
- [v] the budget stays a bound on the plan, never an instruction to reach it — a shorter plan remains valid (→CLIP-99)
- [v] tests: the same template with and without the optional answers, asserting the different budgets, and a repeated group at its minimum and above it
- [v] verify BE (ARCH-26) passes

## impl notes
- the admitted-section count is the same derivation T183 puts beside `Document.Maxima`; read it rather than re-walking the document
- the budget feeds the writer's prompt bounds, so changing it changes the stated contract, not a post-hoc check

## result
- derivation: `composition/resolve.go` gained `AdmittedSections`, which reads a project's own answers — one instance per item a repeated group holds, none for a group the answers left empty, one for a section bound to no group, and the grammar's cut ceiling for `scenes` repetition, which is bound to no item
- writer contract: `ai/composition_prompt.go` states `admitted_sections` as an input fact and the prompt says a section absent from it has no footage to describe whatever the guides say, that no section exceeds its stated instances, and that the list bounds the plan and is never a quota
