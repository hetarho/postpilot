Delete the two old components and their now-unused i18n keys (`edit.facets` if nothing else reads it) ← FORMAT principle 7, no dead paths
- `entities/memory/api/memory-mutations.ts`: `useUpdateMemoryCall` gains `save({ text?, kind?, tags? })` building one `UpdateMemoryRequest` with presence (proto already has `optional text`, `optional kind`, `MemoryTagsPatch tags`); drop `saveText` / `saveFacets` once nothing calls them ← the server applies all present parts in one update, so one form cannot half-save
- the diff is computed against the memory as loaded when 수정 was pressed; tags compare as the parsed, trimmed list (`parseMemoryTags`) in order
