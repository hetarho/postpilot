# T271 required collaborators enter through constructors; main is four steps
> st:done@260919 | ssot:ARCH-40 ARCH-6 ARCH-24 | base:ARCH@5 | dep:T270

## goal
Replace the `Set*`/`With*` injection of required collaborators with constructor arguments across the backend services and reshape `cmd/api/main.go` into `loadPlatform → buildContexts → registerJobs → serve`.

## acceptance
- [v] every service whose `Set*`/`With*` target is required for a code path to work takes it in `New(...)`: `post.Service` (8 setters → ctor), `generation.Service` (6), `auth.Service` (5), `clip.Service.SetGeneration/SetSources/SetFinalizer`, `GenerationService.WithFinisher/WithCredits/WithAdmission`, `usage.SetAnchors`; a setter survives only where the absent mode is legal and has a test that exercises the absence — done as `post.NewService(store, blobs, Limits, Deps)` (7 setters gone; `SetTemplateDirectory` stays, documented optional, pinned by `TestWithoutATemplateDirectoryPostsStillWorkAndAssignmentIsRefused`), `generation.NewService(…, Deps)` (all 6 gone), `auth.NewService(store, ttl, Deps)` (all 5 gone; Google/TopUp/Bootstraps are documented legal-absent fields of Deps, not setters), `clip.NewService(store, limits, sources, finalizer)` + `NewGenerationService(…, GenerationDeps)` binding `projects.generation` itself (all 6 gone), `usage.NewService(…, anchors)` (gone). Left outside this task's list and logged for follow-up: `voice.SetExperimentGuard`, `experiment.SetVoiceDirectory`, `guideline.SetTemplateDirectory`, `modelcatalog.SetUpstream/SetReasoningSpend`, `billingstore.SetCreditsForTx/SetPlansForTx`
- [v] a constructor with a nil required collaborator panics at boot (or returns an error) with the collaborator's name; a `cmd/api` test constructs the full graph once and asserts no panic — every new constructor panics naming the missing collaborator (`TestConstructionRefusesALedgerWithoutAnchors`, `TestConstructionRefusesAServiceWithoutAMailer`, the post voice-directory check), and `cmd/api/wiring_test.go:TestBuildContextsWiresEveryRequiredCollaborator` runs `buildContexts` + `registerJobs` + `handlers` over `config.Load()` defaults on a migrated temp DB and asserts every context is non-nil (only `payments` may be nil while billing is disabled)
- [v] `cmd/api/main.go`'s `main()` is ≤60 lines calling `loadPlatform`, `buildContexts`, `registerJobs`, `serve`, each in its own file; no rule body, no adapter type over 30 lines remains in package main — `main()` is 23 lines over `platform.go`, `contexts.go`, `jobs.go`, `serve.go` (+ `commands.go` for the operator subcommands); adapters are split into `adapters_{voice,post,generation,experiment,catalog}.go` and `credits.go`. Two adapter methods exceed 30 lines and stay: `generationPosts.AttachedImages` (69, a post→generation input mapper, no rule) and `jobAdmission.Hold` (30, the credit gate joining plan + registry + ledger) — the latter and `meteredRegistry` are the remaining rule bodies in package main and belong to the job/usage seam T272 reshapes (logged)
- [v] behaviour unchanged: ARCH-26 passes, the `cmd/api` end-to-end gate passes — `gofmt`/`go vet`/`go build` clean and `go test ./...` green (58 packages) after the change; `cmd/api` (incl. the SQLite race harnesses and the new wiring test) passes in 37s; the Docker release smoke was not re-run: this task changes construction only, and that gate is red at HEAD for an unrelated reason (T270 result)
