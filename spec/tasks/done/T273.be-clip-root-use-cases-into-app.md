## result
- Changed: 29 root files lost their service declarations and `internal/clip/app` gained 23 files (31 production files now, 4.6k lines) plus 7 test files that moved with the code they test (`eligibility`, `quotes`, `recovery`, `generation_failure`, `instruction_reuse`, `language`, `attempt_diagnostics`, `attempt_identity` tests, in part). Moved: `Service`, `SourceService`, `GenerationService`, `GenerationDeps`, `NewService`, `NewSourceService`, `NewGenerationService`, every method on the three, and 30-odd unexported helpers only they use (`chargedApproval`, `planRecoveryDigest`, `renderPayload`, `revisionJobPayload`, `sourceWriter`, `admissionRefusal`, `logAttemptDiagnostic`, …)
- Seven helpers both halves use were exported rather than duplicated: `BoundedText` (was `bounded`), `StrictJSON`, `EditingStateOf` (was `editingState`; `EditingState` already named the method), `RequiredQuoteAnswers`, `SupportedGenerationPayload`, `GenerationPayload` + `GenerationPayloadVersion`, and `GenerationPayload.Design()`
- 32 files outside the root (`clip/rpc`, `clip/store` tests, `cmd/api`, the root's external tests) now import `clipapp "…/internal/clip/app"` for the services; `cliprpc.NewHandler(*clipapp.Service)`
- Method: a go/types-driven mover (scratchpad tool, not committed) classified every root declaration — seeds, then a fixpoint moving the unexported helpers referenced only by moved code (tests follow the code), then byte-range extraction with `clip.` inserted before every identifier that resolves to a staying root object; `goimports` supplied the imports. `go vet` then caught the unkeyed literals the new package boundary exposed (six production sites, keyed)
- Scope adjustment for T274: the "move the worker orchestration" half is done here (it could not be separated from the services), so T274 is only `Run` decomposition + the remaining bare clocks in `attempt.go`/`generation.go`/`rerender.go`
- Gates: ARCH-26 full pass; release smoke 19/28 with the identical pre-existing failure set (T270 result); spec lint clean apart from pre-existing warnings
- Nothing diverged from ARCH-5/6/7; no update-ssot owed
