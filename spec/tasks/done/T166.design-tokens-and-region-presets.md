## impl notes
- preset ids are the owner's letters — `intro` a|b, `outro` b|e, `caption` bold — so the template attribute (T169), the token key and the UI label (T172) all say the same thing; `regions` is a new key because `presets` still holds the retired category presets, which this batch leaves alone
- the caption treatment moves from `styles.bold` to `regions.caption.bold`: CDS-66 says no element names a style, so the renderer reaches it through `design.Caption()`, never by looking a name up
- `SelectStyle` short-circuits with `if slices.Contains(allowed, "simple") { return "simple" }` and already made the CDS-40 table dead; deleting the table removes a rule that had stopped applying
- keep `ratios.*.hook_size` (72 on 16:9, 76 on 1:1): CDS-46 still scales `t.hook` alone, and T167 reads it for intro B and outro B slot 1; leave `ratios.*.hook_card`, `end_card`, `chip` and `info_frames` for T167 and T168, whose consumers still compile against them
- `design.json` is embedded by Go and imported by the FE; both copies must change in the same commit or the mirror test fails; the FE only needs to keep compiling here — T171 removes the style controls themselves
- reference values were read from `clip_sample_tmp/explore/gen.py` (intro A y 940/1020, intro B 846/960/1010/1090, outro B 900/950/1040) with the CDS-72 adjustments for outro E (label 836, score +0.04em, bar white)
