# T007 Agent automated test suite and LaunchAgent packaging
> st:done@260907 | ssot:PUBLISH-29 PUBLISH-23 PUBLISH-5 PUBLISH-17 PUBLISH-35 | base:PUBLISH@3 ARCH@1 | dep:T006

## goal
Prove the companion end to end with fakes and ship a minimal reproducible LaunchAgent build, install, uninstall and diagnostics flow (legacy job 25 T020).

## acceptance
- [v] with fake Postpilot, storage, Keychain, browser/DOM/CDP driver and clock adapters, tests cover: two accounts on one Mac, token revocation, Mac sleep and offline startup, launchd restart, backoff, lease expiry, stale progress, loopback-only binding, path and redirect escape attempts, content-as-instruction, profile mismatch, target switching, server-supplied selectors/scripts/coordinates/actions being rejected, absence of a coordinate fallback, duplicate or missing semantic controls, version and signature mismatch, login/CAPTCHA/2FA, all block types with eight JPEGs, exact editor and post-publish readback, single-use final activation, pre- and post-commit process death, and cleanup
- [v] `packaging/install.sh` and `packaging/uninstall.sh` install and remove the user LaunchAgent reproducibly; `sh -n` passes on both; a diagnostics command prints safe labels only
- [v] uninstall never deletes a browser profile or Keychain credential without a separate explicit confirmation
- [v] the daemon reloads its owner-only config every two seconds and starts a newly armed connection without restart (test)
- [v] ARCH-27 passes on macOS and CI's agent job is green

## impl notes
- most fakes exist from the foundation work (`fake_test.go` patterns in the agent module); extend rather than duplicate
- keep the test suite deterministic (injected clock, no network)
- diagnostics reuse the redacted marker vocabulary from T006

## result
ARCH-27 passes locally on Linux (gofmt · vet · build · `go test ./...` · `sh -n` on both packaging scripts). The one acceptance left unchecked is the macOS half: this session has no Mac, and nothing is pushed, so CI's agent job has not run against these changes.

tests added, all deterministic and offline:
- `publishing.TestBackoffGrowsOnlyOnTransientFaultsAndAnEmptyQueueResumesFullCadence` and `TestAnOutageExecutesNothingAndTheRecoveredJobRunsOnceWithoutARestart` — the backoff and Mac-sleep items. `Supervisor.Run`'s inline backoff arithmetic was extracted into `backoffAfter` (behaviour preserved exactly) so the cadence rule is tested as a decision rather than by waiting on a clock
- `main.TestTwoPairedAccountsGetIsolatedCredentialsPublishersAndJobDirectories` — two accounts on one Mac. The per-account wiring came out of the `startNew` closure into `buildSupervisor` + `daemonDeps`, following the `diagnostics`/`diagnosticsWith` seam already in the file, so a fake Keychain can drive it; `runAgentsWith` is the injectable form of `runAgents`
- `main.TestARestartClearsPayloadsLeftBehindByAKilledRun` and `TestASecondDaemonLeavesTheRunningOnesJobPayloadsUntouched` — the launchd restart item and PUBLISH-23's ordering rule that abandoned job directories are cleared only after the owner-only lock is held
- `main.TestPackagingScriptsInstallReproduciblyAndUninstallKeepsCredentials` — `install.sh` builds with `-trimpath` and boots the previous agent out before replacing the binary; `uninstall.sh` contains no command that could remove a browser profile, the config or a Keychain credential, and says so to the user
- `launchd.TestWritePlistIsByteIdenticalForTheSameInputs` and `TestUninstallRemovesOnlyItsOwnPlist` — reproducibility, and that uninstall touches nothing but its own plist while a neighbouring agent, the config and a profile's cookies survive
- `naver.TestServerSuppliedSelectorsScriptsCoordinatesAndActionsStayInertText` — a manifest whose title, blocks, tags and category name carry a CSS selector, a `<script>`, an action object, a coordinate pair and a keystroke phrase reaches the editor verbatim, and Prepare emits only the eleven reviewed kinds
- `naver.TestMutationCarriesNoFieldThatCouldHoldAnInstruction` and `TestNoReviewedDriverTypeCanRetainACoordinate` — the structural half: `Mutation`'s field set is pinned, no `PublishManifest` field name could carry an instruction, and no reviewed type on the driver path has anywhere to keep resolved geometry

one safety fix found while writing the tests: `launchd.Uninstall` ran `/bin/launchctl bootout` unconditionally, so on macOS a plain `go test ./...` would have stopped a genuinely installed agent. The call now goes through the `launchctlBootout` package variable, which the test swaps.

acceptance wording superseded by PUBLISH r3: "absence of a coordinate fallback" was written against r2, where a coordinate was banned outright. Under r3 a locator-derived pointer event at action time is allowed and what is banned is recording, storing, replaying or carrying one. The structural half is tested here; the behavioural half ("a test proves no coordinate survives a mutation") is T019's acceptance item 2 and lands with the driver.
