# T210 The plan carries a narration
> st:done@260916 | ssot:CLIP-134 CLIP-66 CLIP-67 CLIP-137 CLIP-138 CLIP-17 CLIP-97 CLIP-123 CLIP-62 | base:CLIP@31 CDS@20 ARCH@3 | dep:T207

## goal
Let a portable plan hold narration captions with absolute output intervals beside the template's fixed regions, edit them in a correction, ground them on facts and the instruction alone, and record notices only for what the server changed.

## acceptance
- [v] a narration caption is a `PortableText` with `Scope="narration"`, `Resolved.CutID=""`, `Resolved.Element{ID:"narration-N", Kind:"ai", Role:"caption", Basis:"output-start"}` and absolute `Resolved.StartMS/EndMS`; `validatePortablePlan` admits it without a document declaration and requires 0 ≤ start < end ≤ DurationMS and pairwise-disjoint narration intervals
- [v] `ClipEditableText` gains `bool narration = 28`; the rpc mapper sets it; a narration caption's phrases are absolute output times, the rule `CompositionPlacement` already states for an element without a cut
- [v] `applyNativeCorrection` accepts adding a narration caption (request-only `creation{kind:"add"}` on `CorrectionText`, instance id minted by the server), removing one, and editing text, interval and phrases; an owner-written or owner-edited caption is `OwnerEdited` and skips grounding; an overlap or an interval outside the output is refused naming the instance and is never retimed (CLIP-67)
- [v] cut creation, split, trim, reorder and rate changes leave every narration interval unchanged; `ResolvePortableIntervals` resolves a narration caption like an output-start element
- [v] `GroundNarration(text string, facts []composition.Fact, instructed bool) string` grounds a caption: every measured claim and price basis matches some collected global or item fact, experiential markers need `instructed`, and there is no cross-item or context-item check; `GroundScopedText`, `BindCutItem` and `ScopedFact` remain only for frozen legacy plans
- [v] `composition.Cut` with empty `SectionID/GroupID/ItemID` is valid for a snapshot that declares no sections, and `ResolveSelectedComposition` resolves only the fixed regions for such a plan
- [v] notices: new plans never record `copy_not_generated`, `item_unassigned`, `item_uncertain`, `item_binding_conflict`, `cross_item_identity` or `context_item_claim`; the reasons `caption_overlap`, `caption_outside_output` and `caption_floor` exist for server removals
- [v] `EncodeEditPlan`/`DecodeEditPlan` round-trip narration captions inside the version-6 envelope; every existing fixture still decodes
- [v] tests: round trip; validation refusals; correction add/remove/edit and refusal; `GroundNarration` table (a number against another item's fact passes, an unmatched number fails, experiential with and without an instruction); verify BE (ARCH-26), generated code (ARCH-28)
