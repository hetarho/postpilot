## goal
Offer lightweight commercially licensed typography and an independent rapid phrase pace, with automatic composition, exact manual editing and a real-footage review video.

## acceptance
- [v] Existing recipes/plans retain sentence-mode behavior; optional template pace persists and round-trips through API/storage, and unknown modes fail validation.
- [v] The fifth simple style uses licensed bundled Pretendard, restrained white outlined text and matching frontend previews; the original four styles remain available.
- [v] Rapid generation splits grounded text without an extra provider call; 300/500/500 ms phrases, touching boundaries, fallback on insufficient room and explicit manual timing validate consistently across backend/frontend.
- [v] Template and correction screens offer independent pace selection, split/merge and individual phrase editing/add/remove with immediate timing feedback; save/reload/rerender retain every phrase.
- [v] Rapid render output replaces phrases without fades, bounds simultaneous overlay memory and checks typography/contrast; original-footage MP4 and boundary frames are retained for owner review at ≤$0.10 external model spend.
- [v] Meaningful domain/storage/RPC/UI/render tests, local ARCH checks, production media/release gates and the real-footage comparison pass.

## impl notes
- Add Recipe.CaptionPace and optional patch, an additive SQLite template column defaulting to empty/steady, and additive protobuf fields for template pace and each ClipCaption pace. Empty pace is sentence mode for legacy clients and stored plans; persist new plan version 4 while reading versions 1–3.
- Caption.Pace owns timing/motion independently of Style. Shared rapid tokens define 300–1000 ms exposure, 24 per cut and 14 characters per line. A cut with rapid captions does not use the steady two-copy/DESC→NUM rule; manual cues remain chronological and non-overlapping.
- Keep clean as the fallback in approved style sets. Selecting simple makes it the primary drawing choice; the pinned Pretendard Variable face is already bundled under SIL OFL 1.1, verified against https://github.com/orioncactus/pretendard/blob/main/LICENSE. The frontend self-hosts the same original face and license for its simple preview. No external font download, system fallback or image-generation call is required.
- Use a deterministic word/grapheme splitter with identical Go/TS fixtures. Automatic composition tries the grounded short alternative if rapid phrases cannot fit; it can fall back to existing sentence composition. No transcript alignment is claimed.
- Crop rapid overlay PNG inputs to their bounded drawing region plus shadow padding, then place them at the original measured coordinates, so many phrases do not keep full-frame decoders alive. Fast cues have zero entrance/exit motion. Simple outlined text uses conservative token contrast without per-phrase video sampling.
- Add the simple file binding while preserving existing operator catalogs through a fallback to their copy.clean binding. Keep the optional shorts example as an example, and use all eight local originals for a comparison without model calls.
