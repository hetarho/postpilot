# T528 exports map photo groups
> st:done@261004 | ssot:EXPORT-5 EXPORT-12 EXPORT-26 | base:EXPORT@9 | dep:T526 | touches:frontend/src/features/export-naver frontend/src/features/export-tistory frontend/src/features/export-site frontend/src/features/export-markdown frontend/src/widgets/export-panel

## goal
All four exports carry a photo group as one place with one caption, and the Naver tab numbers photos one by one and copies a group's photos and caption.

## acceptance
- [v] Naver text: photos numbered 1… in photo order across single photos and groups; a group is `콜라주_3_4_5_<folded caption>_콜라주` / `슬라이드_…_슬라이드` (`collage_…_collage` / `slide_…_slide` for English content), the bare form without a caption, UNSPECIFIED as collage; `naverPhotoOrder` returns one entry per photo number
- [v] Naver tab: a group renders through `PhotoGroup` with every photo its own copy control named by its photo number, one caption copy control under the group, and a missing photo keeping its cell; the guidance says to upload a group's photos together and choose the same layout
- [v] Tistory: `<figure data-layout="collage|slide">` with one empty-`src` `<img>` + `data-file` + replacement comment per photo and one `<figcaption>`
- [v] site: `<figure class="gallery gallery-collage|gallery-slide">` with the photos and one `<figcaption>`; the fixed stylesheet gains the two gallery rules and stays content-independent
- [v] Markdown: the group's image lines in order, then the one italic caption
- [v] Naver, Tistory and Markdown outputs for the existing fixture without a group are unchanged; snapshot tests cover a collage with a caption and a slide without one in all four converters
- [v] ExportPanel tests pin group copy controls, numbering and the caption control
- [v] ARCH-25 passes

## impl notes
- `export-naver/model/convert.ts`: walk once with a running photo counter; IMAGE → `photoMarker(n)`; GALLERY → `groupMarker(word, numbers, caption)` reusing `foldCaption`; `naverPhotoOrder` = `walkBlocks(...).flatMap(blockPhotos)` so position n-1 is photo n.
- `widgets/export-panel/ui/ExportPanel.tsx`: replace `markerIndexByBlock` with photo indices per block (`Map<blockIndex, number[]>`, 0-based, from the same walk); IMAGE keeps its single index as `marker`; split the caption-copy part out of `PreviewPhoto` into a component so a GALLERY's `renderBlock` returns `PhotoGroup` with `renderPhoto` → the photo copy button (target `photo:${photoIndex}:${file}`) and `renderCaption` → one caption control (target `caption:${firstPhotoIndex}`, unique per caption); a missing photo cell uses the same filename placeholder as `renderMissingImage`.
- `export-tistory`: per photo `<img src="" alt="${alt}" data-file="${file}"><!-- ${file} 업로드 후 src 교체 -->` (English instruction per provenance), escaping as the IMAGE case does.
- `export-site`: figure classes above; stylesheet rules — `.gallery-collage{display:grid;grid-template-columns:repeat(auto-fit,minmax(10rem,1fr));gap:.5rem}` and `.gallery-slide{display:flex;gap:.5rem;overflow-x:auto;scroll-snap-type:x mandatory}.gallery-slide img{flex:0 0 100%;scroll-snap-align:center}` (adjust to the sheet's existing conventions); the site snapshot changes for every post because the sheet is shared (EXPORT-26).
- `export-markdown`: `![alt](file)` per photo with the group's alt, then `*caption*`.
- guidance copy (`widgets/export-panel/config/i18n.ts` `naverPhotos`, ko/en): append one sentence — ko `콜라주_…_콜라주·슬라이드_…_슬라이드 자리는 그 번호의 사진을 한 번에 올린 뒤 같은 배치를 고르세요.`
