## goal
`/clips/new` on an account with no video template opens T728's offer sheet with `새 영상 템플릿 만들기`, whose wizard 저장 returns to a new clip in that channel with the template selected.

## acceptance
- [v] `/clips/new` waits for the video-template read (loading text) and opens the clip offer when the directory is empty; a failed read renders the form with no sheet; one or more templates never open it; it never offers 말투
- [v] `이대로 만들기`, Escape and the scrim close it for this creation; `다시 묻지 않기` stops the clip offer for this account on this browser while the post offer still opens
- [v] `/clips/new?template=<id>` and `/clips/new?from=setup` never open it; an existing clip never opens it
- [v] `새 영상 템플릿 만들기` opens `/video-templates/new?channel=<channel>&clip=new`; with `clip=new`, every create save in `VideoTemplatePage` replaces to `/clips/new?channel=<channel>&template=<id>`; without it the saves still open `/video-templates/$templateId`; with `clip=new` the wizard keeps its structural back link (영상 템플릿 목록), as the post wizard does with `post=new`
- [v] `/clips/new?template=<id>` selects that template once the directory has it, taking its design selection as choosing it does (CLIP-168); an id not in the directory leaves 없음
- [v] tests: `pages/clip/ui/ClipPage.offer.test.tsx` (every row above for the clip page), `pages/video-template/ui/VideoTemplatePage.test.tsx` (clip=new returns, default unchanged, back link), `pages/clip/model/search.test.ts` (template and from parsing), a `ClipProjectForm` case for the handed template
- [v] the existing clip page, clip form and video-template tests pass unchanged in what they assert

## impl notes
- reuse T728's slice: `useCreationOffer({ ownerId, kind: 'clip', suppressed })` and `CreationOfferSheet kind="clip"` (`clipOfferMissing`); no new model
- `pages/clip/model/search.ts`: `clipCreationSearchSchema` adds `template?: string` (trimmed, non-empty); `from` is already there from T728
- `ClipPage`/`NewClip`: `suppressed = !!template || from === 'setup'`; wait on `offer.settled` with the page's loading text before mounting the form; key `NewClip` by owner, channel and handed template; the create action navigates `/video-templates/new` with `search: { channel, clip: 'new' }`
- `ClipProjectForm`: new optional prop `initialTemplateId` used only while creating (`!stored`): when the directory contains it, apply it once (ref-guarded) through the same path as choosing it (`change('videoTemplateId', id)`), so `designOf` fills the presets and caption styles
- `pages/video-template/model/search.ts`: `videoTemplateSearchSchema` adds `clip?: 'new'`; `VideoTemplatePage`'s two create `onSaved` navigations branch on it; the back link mirrors how `pages/template/ui/TemplatePage.tsx` treats `post=new` (contextual return, THEME-58)
