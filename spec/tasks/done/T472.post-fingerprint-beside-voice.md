# T472 ② shows the post's fingerprint beside its voice's

## goal
After each generation and AI 수정, ② shows beside the post's measurements how its fingerprint compares with its voice's, counted from the post's blocks with no model call, through one shared comparison widget that 검증 (T473) and 말투 반영 비교 (T474) reuse.

## acceptance
- [v] `GetPostFingerprint(post_slug)` (VoiceService) returns, for the caller's post, the content revision it measured and `VOICE-62`'s comparison of `MeasureBlocks(post content)` against the post's voice's current analysis; a post with 말투 없음, with no content, or whose voice is deleted or not made answers `applicable = false` with no items; another account's post is `PermissionDenied`, an unknown one `NotFound`; no provider is called
- [v] the voice context reads the post through a consumer-declared port (`PostContents`) adapted in `cmd/api`, and never reads post tables
- [v] a shared `FingerprintComparison` widget renders each item as its label, the headline facet as `내 말투 {voice} · {text label} {text}`, all facets on demand, and `알 수 없음` for an unknown item, in the order the server gives
- [v] ② renders the comparison under `PostMeasurementRow` with the text label `이 글` when the answer is applicable, refetches when the content revision changes (a generation, an AI 수정 or a hand edit), says nothing about the template, and renders nothing for a 말투 없음 post
- [v] tests: voice rpc and service tests (made voice, 말투 없음, not made, deleted, foreign, unknown), the port adapter, FE `FingerprintComparison` (order, headline, facets, unknown) and `EditorPage.refine` (shown for a made voice, absent for 말투 없음, refetched on a new revision)
- [v] verify: ARCH-25, ARCH-26 and ARCH-28 pass

## impl notes
- Proto: `GetPostFingerprintRequest { post_slug }`, `GetPostFingerprintResponse { applicable, revision, items }`; `FingerprintItemComparison { item (enum of the eight), unknown, distance, headline (facet key), facets [{ key, unit, voice, text }] }` where `unit` is `share` | `per_hundred` | `chars` | `sentences` | `text`, `voice` / `text` carrying a number or a string (`oneof`); the same message serves T473 and T474
- Port: `voice.PostContents { PostForFingerprint(ctx, userID, slug) (voiceID string, revision int64, blocks []Block, err) }`, adapted over `post.Service` (ownership errors map to the voice context's forbidden and not-found sentinels) in `cmd/api/adapters_voice.go`; blocks map TEXT, HEADING, LIST (items) and QUOTE and skip IMAGE and VIDEO
- The comparison is computed per request (cheap, deterministic) and never stored
- FE: `entities/voice` gets `usePostFingerprint(slug, revision)` keyed `['voice-post-fingerprint', transport, owner, slug, revision]`; `widgets/voice-fingerprint/ui/FingerprintComparison.tsx` takes `items` and `textLabel`; item labels ko `문장 끝` · `문장 끝 부호` · `이모지와 자모` · `문장과 문단` · `여는 줄과 닫는 줄` · `자주 쓰는 말` · `1인칭` · `소제목과 목록` (en: `Endings` · `Sentence marks` · `Emoji and jamo` · `Sentences and paragraphs` · `Opening and closing lines` · `Frequent words` · `First person` · `Headings and lists`), facet labels and units in the widget's `config/i18n.ts`; shares as whole percent, per-hundred as counts, chars with `자`
- ②: `EditorRefinePanel.tsx` `beforeArticle` renders `PostMeasurementRow` then a `PostFingerprintRow` (section title `말투 지문`) when `post.voice?.made` and content exist; its query key carries `post.contentRevision`, so a job's completion and each content save refetch it
- Do not run concurrently with another task in this tree that regenerates proto

## result
- outcome: `GetPostFingerprint(post_slug)` answers the revision it counted and `Compare(voice's current analysis, MeasureBlocks(post blocks))` per request with no model call; each facet now carries its unit (`share` · `per_hundred` · `chars` · `sentences` · `text`) and a number or its terms on the wire. It is not applicable for 말투 없음, no content, or a deleted or unmade voice. A foreign post is `PermissionDenied (POST_FORBIDDEN)` and an unknown one `NotFound (POST_NOT_FOUND)`. The voice context reads the post through `voice.PostContents`, adapted in `cmd/api/adapters_voice.go` over `post.CurrentContent`, whose snapshot now carries the post's `VoiceID`. The shared `widgets/voice-fingerprint` `FingerprintComparison` shows each item's name, its headline facet as `내 말투 … · {label} …`, every facet in a row disclosure and `알 수 없음` for an unknown item; ② mounts its `PostFingerprintRow` (말투 지문) under the measurements for a made voice and refetches on each content revision.
