## goal
Give the owner one default-off `원본 소리 유지` toggle per video in steps ① and ②, with revision-safe persistence and preview feedback.

## acceptance
- [v] Each current source card in editable steps ① and ② has a sibling semantic switch labelled `원본 소리 유지`, defaults off for new sources and independently selects neither the card nor playback when toggled.
- [v] Reopened and canonically reselected sources display the persisted setting; latest-attempt/read-only observations, running work, finalized projects and foreign/unavailable sources cannot mutate it.
- [v] A pre-plan switch calls the owner mutation with revision zero, and a post-plan switch joins the correction save queue with the current revision; optimistic state rolls back on failure while keeping a clear retry status.
- [v] A real post-plan toggle makes the previous result visibly stale and offers credit-free rerender without changing observations, cuts, captions or model-reuse messaging; an idempotent toggle changes no revision.
- [v] Step ② toggle changes participate in undo/redo by sending the inverse semantic mutation at a new optimistic revision, and concurrent plan autosave or revision conflict preserves both the local plan and intended sound state for explicit retry.
- [v] Preview sound is the intersection of source permission, per-cut volume, transition gain and the preview master-audio control; volume zero, master mute and absent audio never rewrite the source setting.
- [v] Source-strip, upload-session, retained-source, correction, page and i18n tests cover default/reopen/inherit, owner/read-only states, failure rollback, conflict, undo/redo, result staleness and independent accessible card/switch interaction.
- [v] Browser checks cover keyboard and touch operation, 44 px targets, ko/en labels, light/dark themes and 320/360/390/430 px source strips without nested interactive controls or horizontal-page overflow.
- [v] Run applicable ARCH-25, ARCH-28 and ARCH-29 checks with deterministic protobuf output and dirty-workspace snapshot protection.

## impl notes
- Restructure each source `<li>` into a selection button and sibling shared switch; never nest a switch inside the existing whole-tile button. Use `role=switch`, `aria-checked` and a filename-associated accessible name.
- Keep the setting in source/project entity state and call T143's dedicated mutation from both steps. Serialize it with debounced plan saves through one revision queue so two successful writes cannot claim the same expected revision.
- Treat the setting as server-owned. Template controls, model payloads and generated plan fields never expose an authoring path for it.
- Preserve the preview master-mute control as ephemeral browser state and keep per-cut volume in the edit plan; neither substitutes for the durable source toggle.
