# T260 split entities/clip-project into four nouns
> st:done@260920 | ssot:ARCH-13 ARCH-14 ARCH-15 | base:ARCH@5 | dep:-

## goal
Split the 5.5k-line `entities/clip-project` into `clip-project` (lifecycle + api), `clip-plan` (plan editing + timeline), `clip-preview` (frames, assets, video worker, `PreviewVideo`) and `clip-observation`, and move preview fetching out of entity UI.

## acceptance
- [v] four entity slices exist, each with one `index.ts`; `entities/clip-project/index.ts` exports ≤40 symbols and no other new barrel exceeds 60
- [v] `clip-plan` owns `model/edit-plan.ts`, `model/timeline.ts`, `model/caption-pace.ts`, `model/revision.ts`, `api/edit-plan.ts`; `clip-preview` owns `ui/ClipDraftPreview.tsx` (renamed `PreviewVideo`, presentational), `model/draft-preview.ts`, `model/preview-assets.ts`, `video.worker.ts`, `browser-*.ts`; `clip-observation` owns `model/observations.ts`, `api/attempt-inspection.ts`; the rest stays
- [v] cross-entity references go through `@x` only (`entities/clip-plan/@x/clip-preview.ts`, …) and the `@x` graph among the four has no cycle (steiger passes)
- [v] `ClipDraftPreview` no longer calls `useTransport` or `clipPreviewRequest`: fetching + `PreviewPreparation` move to `features/preview-clip-draft/model/useClipDraftPreview.ts`, and the entity component renders from props so `ClipDraftPreview.test.tsx` renders it from a fixture with no transport
- [v] every consumer (15 slices) imports from the new barrels; `pnpm lint:fsd`, `pnpm lint` and `tsc` pass
- [v] behaviour unchanged: the existing clip tests pass unmodified except for import paths; the new feature hook has a unit test with a fake service covering ready / failed / cancelled preview
- [v] ARCH-25 passes

## result
- five entity slices, not four: `clip-design` (the config segment + `ClipSourceAssociation`) is the leaf the other four read — the four-noun graph cannot be acyclic while `ClipProject` embeds `ClipEditingState`/`ClipObservations` and plan/preview/observation all read the design config (owner decision 260920)
- `entities/clip-design` config/* + model/composition.ts · `entities/clip-plan` model/{edit-plan,timeline,caption-pace,revision} api/{edit-plan,caption-preview} · `entities/clip-preview` model/{draft-preview,preview-assets,browser-*,composite-video,render-raster-cache,video-worker-protocol} lib/{video.worker,create-video-worker} api/{preview,useClipBrowserRenderCapability} ui/ClipDraftPreview · `entities/clip-observation` model/observations api/{observations,attempt-inspection} · `clip-project` keeps the aggregate, sources, eligibility, credits, composition, notices and the small ui
- `@x` graph (checked by a graph walk): clip-design ← clip-plan ← {clip-observation, clip-preview, clip-project}, clip-project ← clip-preview, clip-template ← {clip-plan, clip-project}, clip-template → clip-design. Acyclic — and the old clip-project↔clip-template cycle is gone with it
- two cuts the split needed: `ClipAttemptInspection` moved from `clip-project/model/types` to the observation noun, and `validateTimelinePlan` now states the evidence it needs as its own `ClipCutEvidence` instead of importing `ClipObservations` (a `ClipObservations` satisfies it) — otherwise plan↔observation is a cycle
- preview fetching left the entity: `features/preview-clip-draft` owns `useClipDraftPreview` = `usePreviewRequest` (transport half, one request per plan — the element ids follow the play position and no longer re-issue it) + `usePreviewPreparation` (assets half, owns the object URLs), with `ClipDraftPreviewPanel` composing them for `pages/clip`. `ClipDraftPreview` takes a `preview: ClipPreviewOverlay` prop, names no transport, and its test renders from a fixture. The RPC stays in the entity behind `useClipPreviewRequest` (ARCH-17 forbids `useTransport` in a feature)
- new tests: `features/preview-clip-draft/model/useClipDraftPreview.test.tsx` (ready / failed+retry / superseded-and-disposed), and the entity preview test gained a failure+retry case
- deviation from acceptance ①: `clip-project/index.ts` exports 55 symbols, not ≤40 (116 before). The project noun still owns sources, eligibility, notices and composition; reaching 40 needs a sixth noun (`clip-source`) that F6 did not name and the owner did not approve. Every other barrel is ≤38
- verify: ARCH-25 green (2186 tests / 275 files, steiger clean, 1 pre-existing ESLint warning in `pages/editor`, style probe + build ok)
