# T146 Compose validated split and fixed-rate clip assemblies

## goal
Have the writing model produce one grounded declarative assembly that uses split source ranges and fixed rates, then freeze it unchanged for execution and recovery.

## acceptance
- [v] Legacy and native composition response schemas express cut creation/splitting as independent ordered cuts and require exactly one `rate_permille` per cut; no LLM tool loop or extra edit/effect call is added to the existing writer plus bounded correction flow.
- [v] The writer receives only frozen template narrative, exact owner facts, complete v2 observations, source metadata and server-computed allowed rates; it receives no pixels, URLs, source-sound setting or authority to choose audio.
- [v] Prompts default to 1x, permit uncertain usable material only at 1x or unused, exclude unknown/unusable scenes and forbid overlap, variable ramps, reverse, freeze, frame synthesis, BGM and unsupported effects.
- [v] Multiple cuts from one source are valid only as distinct non-overlapping half-open ranges contained by one observed scene; cut/source identities, evidence references, section/item bindings and original-source timestamps remain exact through reordering.
- [v] Every cut length, target reconciliation, transition, sentence/rapid caption and cut/output-relative template interval is computed from transformed output time; original evidence and fact provenance never adopt output timestamps.
- [v] Any deterministic pre-validation target reconciliation converts output delta back to source delta and stays inside the same observed scene, owner association and neighboring source ranges; the persisted validated plan records the exact final ranges and no executor changes them afterward.
- [v] Invalid rate, overlap, unusable selection, unsupported slow cadence or transformed timing enters bounded same-model response correction with typed cut diagnostics and no silent drop or 1x fallback; genuinely insufficient footage stops without a format retry.
- [v] The server injects T143's current complete source-audio snapshot only after validating model output, persists the authoritative v6 assembly before media work and reuses an unchanged candidate after render failure with zero additional AI calls.
- [v] Schema, prompt-budget, parser, timeline, composition resolution, copy/evidence, response-correction and recovery tests cover six rates, same-scene splits, rate-aware grow/shrink, overlap rejection, uncertain footage and zero-AI continuation.
- [v] Run applicable ARCH-25 through ARCH-29 checks and deterministic generation checks with dirty-workspace snapshot protection.

## impl notes
- Use the T142 integer `rate_permille` contract in both `plan.schema.json` and `composition-plan.schema.json`; include each source's allowed-rate list derived from original cadence in the data payload rather than asking the model to infer frame-rate arithmetic.
- Keep source-audio settings out of both prompt JSON and the semantic plan-recovery digest. Merge the latest owner snapshot at the server boundary and include it in the render revision/hash only.
- Reject a cut crossing scene/status boundaries even when the union has no time gap. A `certainty=uncertain, usability=usable` scene may be selected only at 1000; `unknown` or `unusable` cannot be selected automatically.
- Update `composeTimeline`, portable `composition.Resolve` and caption exposure helpers to use the shared transformed-duration function. Reconciliation occurs before the assembly is encoded and checkpointed; render and preview may only materialize it.
- Bump or invalidate candidate-plan compatibility when the observation or assembly contract changes, while preserving reusable v2 observations under CLIP-93.

## result
- contract: `rate_permille` is required, enum-bounded and per cut in both `plan.schema.json` and `composition-plan.schema.json`; a new schema test pins that enum against `clip.PlaybackRates()` so a prompt can never offer a rate the parser refuses. Both parsers read it; no tool loop or extra call was added.
- domain: `evidence.go` gains `CutScenes`, `ContainedScene` and `SelectableScene`. A cut must lie WHOLLY inside one observed scene — a cut crossing two touching scenes is refused (`plan_cut_scene`) — and automatic assembly may not select unknown/unusable footage, nor uncertain footage above 1x (`plan_cut_usability`).
- timeline: `composeTimeline` measures cut length, fade floor, caption exposure, CDS-37 bounds, the total and the target on TRANSFORMED output time. Grow/shrink shares are output deltas converted back to source deltas through the shared helper (`outputSpan`/`sourceSpan`), and `observedSpan` now bounds reconciliation to the cut's own containing scene instead of a run of touching segments.
- refusals: overlapping same-source selection is refused for a fresh plan (`plan_source_overlap`, restated as the writer's own `outputError` so it earns a bounded correction, while the identical domain rule still refuses an owner edit as `ErrInvalid`). Insufficient footage keeps its `timeline_grow` phase and buys no format retry.
- prompts: both writers now state the default 1x, the source's own `allowed_rate_permille` list (server-computed from verified cadence), same-scene-only splits, half-open non-overlapping ranges, the unknown/unusable/uncertain selection rules, output-time durations, and that the model has no authority over source sound.
- server: `generation.go` stamps `FreezeSourceAudio(b, edit.Cuts)` onto the plan AFTER the model's output validates and again after layout, so the authoritative v6 assembly is persisted before any media work; the setting is in neither prompt nor `planRecoveryDigest`. That digest now also carries `AnalysisContractVersion`, so a candidate written under another observation contract is rewritten while its observations stay reusable and unpaid.
- tests added: six-rate transformed timeline, rate-aware grow/shrink source conversion, same-scene splits stable through reordering plus overlap refusal, writer-input isolation with allowed rates, unusable/unknown/uncertain selection matrix, bounded correction for rate/overlap/usability, the server-stated audio snapshot, candidate reuse across a sound change, and incompatible-candidate rewrite.
- tests changed rather than weakened: `TestACutMayGrowAcrossTouchingSegments` became `TestACutMayNotCrossTouchingScenes` (the rule inverted), `TestNativeWriterRechecksIdentityAfterTimelineGrowth` became `TestReconciliationCannotReachAnotherItemsFootage` (growth can no longer reach another item at all), and same-source fixtures that relied on reusing one range now use distinct ranges.
- staging note: `RefuseUnsupportedRates` still refuses a non-1x plan at the renderer, so between this task and T147 a generated non-1x plan would fail at render after being paid for. T147 removes that gate; do not deploy this commit alone.
- verify: ARCH-25/26/27/29 pass; ARCH-28 needs no rerun (no proto or SQL change) and the generated tree is unchanged. The `internal/clip/store` package flakes under full-suite load ("clip sources are not available in this state"); the same flake reproduces on commit c02fa07, before T145, so it predates this work.
