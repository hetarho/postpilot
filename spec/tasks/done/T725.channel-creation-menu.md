## goal
Every section list page carries the channel's creation menu — 새 글/영상 · 새 템플릿 · 새 말투 · 새 지침 — with the current section's creation alone nearest the button, replacing each page's own creation dock.

## acceptance
- [v] `ChannelActions({ channel?, section })` builds groups `[others in section order, [current]]`; closed label names the current creation (새 글 · 새 영상 · 새 템플릿 · 새 말투 · 새 지침); item labels 새 글쓰기 / 새 영상 만들기 · 새 템플릿 · 새 말투 · 새 지침
- [v] item targets: blog `/posts/new` `/templates/new` `/voices?new=1` `/guidelines?new=1`; clip channel X `/clips/new?channel=X` `/video-templates/new?channel=X` `/voices?new=1&channel=X` `/video-guidelines?new=1&channel=X`; 새 글/영상 records the channel creation entry as before
- [v] the menu renders on /naver-blog, /naver-clip, /insta-clip, /templates, /video-templates, /voices, /guidelines and /video-guidelines, and nowhere else (no menu on the editor or the clip workspace)
- [v] the pages' own creation docks are gone: TemplatesPage and VideoTemplatesPage `ActionBar`s; VoicesPage's dock (`?new=1` opens `CreateVoiceSheet` controlled, closing drops the parameter; the AI 말투 action and the legacy disclosure move into the page above the list); GuidelineDirectory's dock (`?new=1` opens the creation sheet; `기본 지침` and the direct-writing button move into the page above the list)
- [v] /video-guidelines honours `?new=1` like /guidelines, keeping its `channel` when the sheet closes
- [v] tests pass and cover the change: `widgets/channel-actions` test (order per section and channel, targets, creation entry), page tests for templates, video templates, voices, guidelines, video guidelines (menu present with its label, no old dock, `?new=1` opens the sheet), editor/clip workspace without the menu, updated posts/clips page tests

## impl notes
- `ChannelActions` keeps using T721's `FloatingActionMenu` and its `action-list-inset mt-auto` dock class. `section: 'work' | 'templates' | 'voices' | 'guidelines'` matches T724's `channelSections` keys; the widget owns its creation list (creation targets differ from section list hrefs). Icons: `PenLine` 글, `Clapperboard` 영상, `LayoutTemplate` 템플릿, `MessageSquareQuote` 말투, `ListChecks` 지침.
- GuidelineDirectory is a widget and cannot import another widget: give it a `dock?: ReactNode` prop rendered where its `ActionBar` was; GuidelinesPage and VideoGuidelinesPage pass `<ChannelActions … section="guidelines" />`. The FAB's `?new=1` opens the existing AuthoringSheet with the AI method; the direct-writing button in the page opens it with the direct method as the old dock button did.
- VoicesPage reads `new` and `channel` from its search (the route has no `validateSearch`; add one returning `{ new?: 1; channel?: ClipChannel }` if typed navigation needs it) and passes `channel` to `ChannelActions`.
- Secondary controls moved out of docks sit in one row above the list as `secondary`/`ghost` buttons, keeping their existing labels and handlers; no new copy beyond the menu labels.
- i18n stays in the `channel` namespace (`widgets/channel-actions/config/i18n.ts`), replacing the T722 destination keys with the creation keys above.
