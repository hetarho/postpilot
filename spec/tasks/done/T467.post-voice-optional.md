## goal
A post holds zero or one voice: 말투 없음 is a real answer on create and on reassignment, a named voice must be active and made, runs freeze the voice or its absence, a 말투 없음 prompt carries no voice bytes, and ①'s picker offers 말투 없음, the made voices and 새 말투 만들기.

## acceptance
- [v] a migration rebuilds `posts` with a nullable `voice_id`, without `machine_baseline_voice_id`, carrying every other current column, index and trigger; the insert trigger fires only for a non-null voice and the reassign trigger only when the new voice is non-null and differs (`NEW.voice_id IS NOT NULL AND NEW.voice_id IS NOT OLD.voice_id`); a migration test proves existing posts keep their voice and every child row (images, videos, uploads, generation jobs, template answers, memory links, quality rows) survives the rebuild, a NULL voice inserts, and a deleted voice is still refused on insert and on reassign
- [v] SavePostDraft creates a 말투 없음 post when no `voice_id` is sent; a named voice must be active, made and owned — unknown or foreign `NotFound`, deleted `FailedPrecondition` `VOICE_DELETED`, not made `FailedPrecondition` `VOICE_NOT_MADE` (a new reason); on update `""` clears to 말투 없음 and another value reassigns under POST-24's refusals, touching `voice_id` and `updated_at` alone
- [v] the voice directory port reports `made` per voice (a published analysis exists) and `VoiceRef` carries `made`; a post with 말투 없음 carries no `VoiceRef`
- [v] generation, revision, the storyline jobs and a post's write comparison accept a post with no voice and freeze the absence (`generation_jobs.voice_id` NULL); a result whose frozen voice or frozen absence no longer matches the post is refused `GENERATION_VOICE_MISMATCH`; a post whose voice is deleted or not made is refused before enqueue with the shared reason
- [v] a 말투 없음 write or revise prompt has no voice section and no voice clause: the output-language sentence, `templatePrecedence`, `guidelinePrecedence` and the revise literals use their no-voice variants, and the Korean target length stands on its own line; new goldens `write_prompt_no_voice.golden` and `revise_prompt_no_voice.golden` pin it while every golden of a post with a voice is byte-identical
- [v] a write-experiment snapshot of a 말투 없음 post freezes no voice and no profile (a snapshot golden pins it)
- [v] ①'s picker lists 말투 없음, then the made active voices, then each active voice not yet made disabled with `만드는 중`, then `새 말투 만들기`, which opens the create sheet; a post's own deleted voice stays listed disabled; `/posts/new` starts on the 기본 voice, or 말투 없음 when there is none, and no longer blocks without a default voice
- [v] the editor's voice warning covers a deleted voice (unchanged) and a voice not yet made (`아직 만들지 않은 말투예요. 말투를 만들거나 다른 말투로 바꿔 주세요.` with a link to that voice); the empty-profile warning is gone; a 말투 없음 post shows no voice on its `/posts` row
- [v] tests: post service and voice tests (create without a voice, clear, reassign, not-made refusal), store and migration tests, generation `voice_test.go`, `revision_test.go`, `language_contract_test.go` and the new goldens, experiment snapshot test, FE `PostVoiceSelect`, `EditorPage.assignments`, `preconditions`, `draft-queue`, `PostsPage`, `VoiceWarning`
- [v] verify: ARCH-25, ARCH-26 and ARCH-28 pass

## impl notes
- The posts rebuild follows `0022_post_templates.sql` (the last full rebuild) — the same table-swap order, trigger re-creation and FK comments; read the current column list from a migrated database (`sqlite_master`) rather than from 0022, since 0034, 0070, 0077, 0087 and 0096 added columns; keep the composite FK `(voice_id, user_id) REFERENCES voices(id, user_id)` — a NULL `voice_id` leaves it unchecked; drop the `machine_baseline_voice_id` FK with its column
- "made" means a published analysis exists; in today's storage that is `voice_profiles.current_version > 0`, read by the voice directory (`post.VoiceDirectory.Voices` returns it through `cmd/api/adapters_post.go:24-50`); T471 moves the definition to its analysis table without changing the port
- `VOICE_NOT_MADE`: next free `FailureReason` number; FE ko `아직 만들지 않은 말투예요. 말투를 만들거나 다른 말투로 바꿔 주세요.`, en `This voice isn't made yet. Make it or pick another voice.`; emitted by post create/reassign, generation start, revision start, storyline start and the lab write comparison start
- Post (`service.go` 152-286, 330-398): `activeVoice` returns `(ref, ok)` for an empty id instead of `ErrVoiceRequired`; `reassignVoice` handles `""`; `ReassignPostVoice` compares with SQLite's NULL-safe `voice_id IS NOT ?`, so clearing to 말투 없음 and setting from it both count as a change
- Generation: `activeVoice` (`service.go:573-583`) returns no voice for a post with none; `frozenVoice` (585-597) compares frozen and current values including absence — a frozen NULL with a post that now has a voice is a mismatch; the job adapters (`adapters_generation.go` 399, 418) pass the empty voice as no voice subject, so a post-linked job takes the post guard alone (the user-kind index applies only when `post_slug IS NULL`)
- Prompts (`prompts.go`): split `templatePrecedence` and `guidelinePrecedence` into voice and no-voice constants — the no-voice template sentence is `템플릿은 글의 구성·순서·포함할 내용을 정합니다. 템플릿이 "A 대신 B라고 쓰세요"처럼 바꿔 쓸 표현을 구체적으로 정하면 그 치환을 따르고, 더 나은 단어를 쓰라는 막연한 요구에는 그런 우선권이 없습니다.` and the no-voice guideline sentence drops `문체·종결어미는 위의 말투 프로필을 따르세요` and ranks `지침, 템플릿 순으로`; the output-language sentence (382 KO, 397 EN) drops its 말투 프로필 mention; `writeProfileSection` is skipped and a Korean target's length is written as `[길이]` like the other languages (470-479); `revise.go` 22-29 gets no-voice literals; the storyline prompts already carry no voice
- Experiment write snapshot (`experiment_snapshot.go` 57, 78-83, 140-152): `Voice` and `Profile` become optional and are omitted for 말투 없음
- FE picker (`PostVoiceSelect.tsx`): `Listbox` options are `{value, label, disabled}` only, so `새 말투 만들기` is an option with a reserved value (`__create_voice__`) that opens `CreateVoiceSheet` in a controlled mode (add an `open` / `onOpenChange` pair to the sheet) and leaves the selection unchanged; 말투 없음 is value `''`, following `entities/template`'s `NO_TEMPLATE_VALUE` pattern; the confirmation dialog for a reassignment is unchanged
- FE draft: `useDraftAssignments` seeds `defaultVoice?.id ?? - FE warnings: `EditorVoiceWarning.tsx` picks the deleted warning, the not-made warning (a new `widgets/voice-warning/ui/UnmadeVoiceWarning.tsx`), or nothing; `VoiceWarning.tsx` (empty profile) and `isEmptyProfile` go
