## goal
Preserve current rendered output while allowing trusted SVG preset files to change drawing independently of layout policy and video composition, and reconcile recent commit documentation.

## acceptance
- [v] Audit every commit since 2026-09-10 KST through b59a709, record its documentation coverage, correct missing descriptions of shipped behavior and distinguish remaining design-contract gaps from this refactor.
- [v] A filesystem catalog discovers versioned SVG presets and resolves configurable bindings; built-in assets are the default, with an optional startup directory snapshot and actionable startup errors for malformed assets.
- [v] All existing copy, information/disclosure and card drawing uses the same catalog; preset markup leaves Go source and dynamic text is escaped automatically. Existing layout, manifest, fonts, timing, credit and visibility policies remain unchanged.

- [v] Existing SVG goldens and real raster pixels remain equivalent; tests cover discovery, binding/contract errors, missing fields, XML escaping, bounded asset/output reads and immutable startup snapshots.

## impl notes
- This is the explicitly authorized technical foundation, not approval of the current overlay appearance or a new design proposal. Existing SSOT discrepancies that require a visual decision are recorded in the audit rather than silently changing output.
- Use Go standard-library template/XML/filesystem support, no added runtime dependency. The catalog owns file loading, bindings and rendering; the media adapter prepares typed view data from the existing measured layouts, and FFmpeg retains the bounded PNG reuse from T118.
- Default assets are embedded from the catalog's preset directory. `CLIP_OVERLAY_DIR` optionally supplies a complete trusted directory at boot; files are read once, not downloaded from frontend public URLs or read from a user-supplied RPC path. New folders are discovered without a Go preset switch.
- Use context-aware automatic text/attribute escaping, reject missing fields and malformed SVG, bound file counts and bytes, and preserve subprocess/privacy limits. No arbitrary raw text becomes markup.
- Preserve existing layout and verifier contracts; SVG drawing freedom does not silently register new product styles, fonts, layout rules or motion types.
- External model cost ceiling remains $0.10 total; deterministic local verification needs $0.
