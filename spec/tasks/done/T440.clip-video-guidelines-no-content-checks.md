## impl notes
- CLIP-63, CLIP-122, CLIP-137 and CDS-63 were deleted in CLIP r49 / CDS r29: their rules live on as the 입력한 사실만 and 감상은 내가 쓴 것만 기본 지침 (GUIDE-42), which the owner may switch off, so the server enforces none of them (CLIP-184). Generated region lines fall under the same rule, since CLIP-64 and CDS-1 give what copy states to the 영상 지침.
- `[영상 지침]` block, Korean for every language like the post section: heading `[영상 지침]`, labels `기본 지침:` / `사용자 지침:`, precedence `영상 지침은 이 영상의 흐름과 자막을 어떻게 만들지 정합니다. 사용자 지침이 기본 지침과 충돌하면 사용자 지침을 따르고, 같은 묶음 안에서 충돌하면 먼저 적힌 지침을 따르세요.` The instruction's existing authority sentences stay as they are (CLIP-121).
- The 기본 지침 texts are T431's clip set in the project's language (CLIP-104); a project with no template receives the global rows only.
- The storyline arrives in T445/T446; this task changes no storyline behaviour.
- A real-provider check is a paid call under CLIP-91's authorized cap: ask the owner before any.
