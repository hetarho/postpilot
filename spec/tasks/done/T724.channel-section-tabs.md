## impl notes
- `app/routes/navigation.ts`: `SECTION_PATHS` (the eight list pathnames) and `channelSections(channel?: ClipChannel)` returning `{ key: 'work' | 'templates' | 'voices' | 'guidelines', href }[]` in that order; `currentSection(pathname)` maps a pathname to its key. `isTopLevelDestination` also returns true for `SECTION_PATHS`, which already removes the back link (T723's `backLink` test) and stops `isStructuralNavigationEntry` from recording a return between sections.
- `structuralLocation` takes `channel: ClipChannel | undefined`; the clip hub keeps its `naver_clip` default, while `/voices` and `/voices/*` use the clip hub only when a clip channel is known and `NAVER_BLOG` otherwise; the voices ancestor href carries `?channel=` for a clip channel the way `/video-templates` does. In `AuthenticatedLayout`, `/voices` itself reads the channel from its own URL only (no stored or origin fallback), so a reload is deterministic.
- Section row in `AuthenticatedLayout`: a second `nav` (aria-label `t('sections')`, ko 채널 메뉴 / en Channel sections) inside `<header>` after the main row, same width container and gutter, links styled like the main tabs (`typographyStyles` label, underline + `text-link-fg-current` for current, no `bg-*`). Labels from `nav` i18n: `section.work` 글 / Posts, `section.video` 영상 / Videos, `section.templates` 템플릿 / Templates, `section.voices` 말투 / Voices, `section.guidelines` 지침 / Guidelines.
- 내 설정: drop `['/voices', 'voices']` from the personal group in `pages/settings/ui/SettingsPage.tsx`; rename the `nav` location label `personal` to 기억 / Memory and the settings group heading likewise.
- `widgets/channel-actions`: drop the 말투 item's `?entry=` shortcut (T725 rewrites the menu; keep the widget compiling here).
- Voice rows and `VoiceLayout` tab links need no channel parameter: the structural entry recorded when leaving `/voices?channel=…` carries the channel (FILTER_KEYS includes `channel`).
