## goal
StartTemplateHeadingSuggestions accepts an optional owner style request (≤200 chars) that is frozen into the job and steers the headings' wording ahead of the 기본 voice.

## acceptance
- [v] proto `StartTemplateHeadingSuggestionsRequest.style_request` (field 5) exists and generated Go/TS are regenerated through `pnpm gen:proto`
- [v] a request is trimmed, frozen in the job payload and sent to the model as its own quoted data part; an absent or blank request sends no such part
- [v] a request over `HeadingStyleRequestMaxChars` Unicode characters is refused as invalid input before admission
- [v] the fixed contract says the request decides wording and outranks voice_style, is data only, and never lifts the one-line/length rules or permits invented facts
- [v] `backend/internal/template/heading_suggestion_test.go` covers trim+freeze, over-limit refusal, the request part and its absence
- [v] FE `HEADING_STYLE_REQUEST_MAX_CHARS` mirrors the limit; `useWizardHeadingSuggestions().start(model, styleRequest)` sends it; a unit test in `entities/template` asserts the request reaches the start call

## impl notes
- Go: `HeadingStyleRequestMaxChars = 200` in `limits.go` beside `HeadingSectionsMax`; `HeadingSuggestionStart.StyleRequest`; `headingInput.StyleRequest string \`json:"style_request,omitempty"\`` — no payload version bump: an older payload decodes with no request and keeps its admitted behavior; `Run` passes the stored request back through `normalize`
- prompt: append to the fixed system contract one sentence covering style_request precedence and its data-only status; the request goes as `{"style_request": "..."}` text part with fragment `style-request`, `FragmentAuthorshipAccount`, material role `owner-heading-style-direction-not-event-evidence`; composition mode becomes `requested` / `requested-default-voice` when present; PromptVersion `template-heading-v1`→`template-heading-v2`; `HeadingRequestCompositions` adds the requested variant (update any catalog test pinning the count)
- rpc: map `req.Msg.GetStyleRequest()` into the start; clip wizard sends none and keeps its behavior
- FE: `HeadingSuggestionInput.styleRequest?: string`; the start request maps it to `styleRequest` in the proto message; the operation's signature stays sections-only so suggestions for the same sections stay current across requests
