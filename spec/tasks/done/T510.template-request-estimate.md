# T510 Quote one template request in credits

## goal
The editor can show 약 n 크레딧, or 무료, for one template request on the selected write model, priced as the catalog-based estimate of one call.

## acceptance
- [v] `plan.CallCreditsAt(p Pricer, rate RateSnapshot, prompt, completion int64) (int, bool)` is exported from `plan/post_figure.go`, built on `estimatorMilliAt` and `wholeCredits` with the same estimator allowance QUOTA-40 applies; `WritePostCreditsAt` and its tests are unchanged.
- [v] `TemplateService.EstimateTemplateRequest({ModelRef write_model})` returns `{bool free = 1; optional int32 credits = 2}`: a free-classified write registration → `free`; a priced paid one → `credits` for one call at the package constants `templateRequestEstimatePromptTokens = 6000` and `templateRequestEstimateCompletionTokens = 3000`; an unpriced, unknown or non-write ref → neither (unavailable). The response carries credits only — no cost, price or conversion for any caller (QUOTA-65).
- [v] The template package reads the figure through a `RequestEstimator` port; its `cmd/api` adapter uses `catalogPricer(info)` and `ledger.SelectRate` as `postFigures.estimate` (`cmd/api/post_figures.go`) does, and the same free test ListModels' post figure uses.
- [v] Tests: `CallCreditsAt` rounding and the missing-price case; the RPC for free, priced, unpriced and unknown refs; the existing non-master redaction tests still pass. ARCH-25 verification runs green.

## impl notes
- Why the template service and not a `ModelInfo` field: `provider.proto` and the provider service are being changed by T499–T506 in parallel, and the figure belongs to the template request (QUOTA-67 says no recent-usage figure exists for it), so it travels with the request's own RPCs.
- The 6000/3000 token assumptions are code-owned like `estimatorWritePromptTokens`: about the 형식 안내, a full draft and a few thousand characters of request in, a full body out. The hold (T508) still prices the worst case of four calls; this figure is never a quote.
