# T325 Quality text primitives: Korean and English containment, 8-어절 run hashing and sentence splitting
> st:done@260924 | ssot:QUAL-7 QUAL-8 QUAL-9 QUAL-10 QUAL-14 QUAL-26 ARCH-7 ARCH-33 ARCH-24 | base:QUAL@3 ARCH@9 | dep:-

## goal
- `backend/internal/quality` gains the pure, table-tested text core every metric reads — NFC 어절 tokens, noun containment by language, run matching with its covered-rune share and maximal runs, and sentence splitting with a decimal guard — with no tokenizer dependency.

## acceptance
- [v] `Tokens` NFC-normalizes, splits on Unicode whitespace and trims leading and trailing punctuation and symbols from each 어절: `“을지로`, `감자탕을!!`, `(성수동)` and `맛있었어요~^^` become `을지로`, `감자탕을`, `성수동` and `맛있었어요`; inner punctuation stays (`1,000원`, `3.5km`); a token that trims to nothing is dropped.
- [v] `Units` returns TEXT, HEADING and QUOTE content and each LIST item in block order; IMAGE and VIDEO give nothing; a TEXT block holding only an unfilled `{{slot:N}}` gives nothing, and a slot token inside prose is removed before tokenizing.
- [v] Korean containment: an 어절 contains a noun when it starts with it (`감자탕을` contains `감자탕`, `왕감자탕` does not); English: a word contains it only when equal case-insensitively (`Latte` contains `latte`, `lattes` does not); a nil content language measures as Korean; NFD input matches its NFC noun.
- [v] A multi-어절 noun (`제주 흑돼지`) is contained where its leading tokens equal consecutive 어절 and the next 어절 contains its last token under the language's rule (`제주 흑돼지를`).
- [v] `MatchRuns(post, others, 8)`: share = runes of the post's tokens inside any 8-token window that also appears in another document ÷ runes of all its tokens; each returned run is a maximal verbatim common run naming every other document it stands in; the result is absent (false) with no others or fewer than 8 post tokens.
- [v] A window never crosses a text-unit edge: two 4-token blocks equal to an 8-token paragraph elsewhere match nothing, while a window ending on a unit's last token or starting on the document's first token matches.
- [v] Overlapping matched windows merge into one maximal run, and a run shared with two other documents names both.
- [v] `Sentences` splits on `.` `!` `?` `…` and line breaks, keeps a decimal whole (`3.5km`, `1.5배`), treats `...`, `?!` and `……` as one boundary, and drops a piece with no letter or digit.
- [v] `golang.org/x/text` is a direct require in `backend/go.mod` (v0.42.0 and indirect at HEAD); no other module is added (no tokenizer).
- [v] Tests (all in `backend/internal/quality`): text_test.go `TestTokensNormalizeSplitAndTrimEdgePunctuation`, `TestUnitsFollowBlockOrderAndSkipUnfilledSlots`; containment_test.go `TestAKoreanEojeolContainsANounItStartsWith`, `TestAnEnglishWordContainsANounOnlyWhenEqualIgnoringCase`, `TestAMultiTokenNounIsContainedAcrossConsecutiveEojeol`, `TestAMissingContentLanguageMeasuresAsKorean`; runs_test.go `TestRunShareCountsRunesInsideMatchedWindows`, `TestAWindowNeverCrossesATextUnitEdge`, `TestOverlappingWindowsMergeIntoOneMaximalRun`, `TestARunNamesEveryOtherItStandsIn`, `TestRunsAreAbsentWithoutOthersOrEnoughTokens`; sentence_test.go `TestSentencesSplitOnTerminatorsAndLineBreaksButNotDecimals`.
- [v] Verify: `cd backend && test -z "$(gofmt -l .)" && go vet ./... && go build ./... && go test -timeout 30m ./...`

## impl notes
- Package `backend/internal/quality`, flat (ARCH-5, R13). Exactly one file carries the package doc comment recording that ARCH-5's context list is stale (clip and memory are missing): T322's `fields.go` if it has landed, otherwise `types.go`, which T322 then keeps instead of adding a second.
- types.go (ARCH-7: no struct tags, no proto, SQL or `internal/post` import): `type Language string` with `LanguageKorean Language = "ko"` and `LanguageEnglish Language = "en"`, and `LanguageOf(content *Language) Language` returning Korean for nil (QUAL-26: legacy content predates the field and was Korean).
- types.go: `type BlockType string` with `BlockText "TEXT"`, `BlockHeading "HEADING"`, `BlockImage "IMAGE"`, `BlockVideo "VIDEO"`, `BlockQuote "QUOTE"`, `BlockList "LIST"` — post's own spellings; T335's cmd/api adapter maps them with a closed switch.
- types.go: `Block{Type BlockType; Content string; File string; Items []string}` carries only what a metric reads (no Level, Alt or Caption: R18 and R20 count TEXT/HEADING/QUOTE/LIST text only); `Document{Title string; Blocks []Block}`, where Title is the content title (`PostContent.Title`), never `posts.title` (QUAL-7).
- text.go `Tokens(text string) []string`: `norm.NFC.String`, then `strings.Fields`, then `strings.TrimFunc(field, func(r rune) bool { return unicode.IsPunct(r) || unicode.IsSymbol(r) })`, dropping empty results; symbols are trimmed too so `~`, `^^`, `#` or an emoji at an edge never blocks a match.
- text.go `Unit{Type BlockType; Text string}` and `Units(doc Document) []Unit`: TEXT/HEADING/QUOTE → their Content, LIST → one Unit per item, IMAGE/VIDEO → none; every `{{slot:N}}` token (regexp `\{\{slot:[0-9]+\}\}`) is removed from TEXT content first, and a unit whose text is then blank is dropped.
- `post.Block` has no slot marker: the token in Content is how an unfilled slot is recognized (`generation/template_slots.go` `slotBlock`/`slotToken`).
- containment.go (R16): `Occurrences(tokens, noun []string, lang Language) int` counts positions i where tokens[i..i+k-2] equal the noun's first k-1 tokens and tokens[i+k-1] contains its last token; "contains" is `strings.HasPrefix` for Korean and `strings.EqualFold` for English, and the leading tokens compare with `==` (Korean) or `strings.EqualFold` (English); an empty noun has 0.
- containment.go: `Contains(tokens, noun []string, lang Language) bool` is `Occurrences > 0`; callers pass `Tokens(noun)`, so a noun gets the same NFC and edge trim as the text.
- Occurrences are counted over one Unit's tokens and callers sum per unit, so a noun never spans two blocks.
- Prefix containment is deliberately loose (`제주도에서` contains both `제주` and `제주도`): QUAL-7 defines it that way so a hand-edited title stays measurable without a morphological analyzer.
- runs.go (R18): `Run{Tokens []string; Start int; In []int}`, `Overlap{Share float64; Runs []Run}`, `MatchRuns(post Document, others []Document, length int) (Overlap, bool)`; the window length is a parameter because T331's `RunLength` (8) is its only production value and this task adds no limits file.
- A document's token sequence is its Units' Tokens concatenated; a position is an index into it; a window is `length` consecutive tokens within ONE Unit — never across a block or LIST-item edge, because a run straddling two blocks is not text that appears verbatim (QUAL-8).
- Each other document is indexed once: window key (the window's tokens joined by `"\x00"`) → positions; the Go map is the hash, and exact keys mean no collision handling exists.
- Share: a post token is covered when some window containing it has its key in another document's index; Share = Σ `utf8.RuneCountInString` over covered tokens ÷ the same over all tokens (runes of the NFC, trimmed tokens, so whitespace and edge punctuation never count).
- Runs: per other document d, a matched pair (post window j, d window k) whose predecessor (j-1, k-1) is not also a matched pair starts a chain; extending while (j+m, k+m) matches gives the verbatim common run of tokens [j, j+m+length).
- Runs are deduplicated by token sequence keeping the smallest Start; each run's In is every other document holding the whole sequence inside one of its Units (checked from that document's index of the run's first window), ascending; runs sort by Start, then more tokens first; no map iteration order reaches the output.
- `MatchRuns` returns false when others is empty or the post has fewer than `length` tokens (QUAL-40); a post with enough tokens and no match returns Share 0 with no runs, a real zero.
- sentence.go (R20): `Sentences(text string) []string` — NFC first; a boundary follows any run of `.` `!` `?` `…`, and every `\n` or `\r` is one; a `.` whose previous and next runes are both ASCII digits is not a boundary; each piece is trimmed and one with no `unicode.IsLetter`/`unicode.IsDigit` rune is dropped; abbreviations (`Mr.`) get no special case.
- Not here: sentence lengths, medians, bands and every metric (T331); phrase runs and stopwords (T338, which reuses `Tokens`); any noun extraction — nouns come from the write pass (QUAL-26).
- ARCH-33: read the `golang.org/x/text/unicode/norm` docs (context7 first) before coding, then `cd backend && go get golang.org/x/text@latest && go mod tidy`; confirm the require moved to the direct block and record the resolved version in the result.
