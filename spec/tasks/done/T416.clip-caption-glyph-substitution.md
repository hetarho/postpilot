# T416 A caption character its face does not draw is set in Wanted Sans Variable
> st:done@260928 | ssot:CDS-84 CDS-17 CDS-52 CDS-25 CDS-83 CDS-85 | base:CDS@30 ARCH@13 | dep:- | touches:backend/internal/clip/media/ backend/internal/clip/design/ backend/internal/clip/overlay/ backend/examples/overlays/ frontend/src/entities/clip-template/ frontend/src/entities/clip-design/

## goal
A caption whose style's face has no ink for a character (Paperlogy's 갂, a syllable Jua lacks) renders that character in Wanted Sans Variable inside the caption's own style instead of blank or restyled.

## acceptance
- [v] `media/font_family.go` coverage counts a character as drawn only when its glyph has an outline, a whitespace or format character (Zs, Cf) counting as drawn without one; the set is still computed once per face at construction, and the out-of-range lookup applies the same ink test
- [v] a caption's drawability is per character "its style's face draws it, or Wanted Sans Variable does": `composition_layout.go` keeps the caption's style when every character passes that and falls back to the default style (with the existing CLIP-108 glyph notice) only for a character Wanted Sans Variable lacks too; `layoutCopy` and `CaptionSize` use the caption check, while `checkCopy` for region slots, information and the badge stays face-only
- [v] measurement and drawing agree: the resvg measurement of a caption line, the static overlay (`copy.*` bindings) and every sequence painter (`design/caption_draw.go`) set each run of substituted characters in a `<tspan font-family="Wanted Sans Variable">` at the style's weight, while a caption with nothing to substitute emits byte-identical SVG to today
- [v] the overlay loader refuses a catalog whose `copy.*` template does not draw a substituted run (probe), and the example catalog under `backend/examples/overlays/` draws it
- [v] the video-template preview (`CompositionDesignFrame`) draws a caption character its face does not draw (per `clip-metrics.json`) in Wanted Sans Variable
- [v] failing-first tests: a Paperlogy (크게 강조) caption holding 갂 keeps style `bold`, records no glyph notice and its SVG carries 갂 inside a Wanted Sans Variable tspan; a Jua caption holding a syllable Jua lacks does the same; a sequence style (e.g. glitch) does the same; a Jua caption holding ㎏ falls back to the default style with the notice; a region slot holding 갂 still overflows as `unsupported_glyph`; the FE preview test pins the tspan

## impl notes
- from review/conformance-all-260927 F121; decided by update-ssot CDS r30
- measured 260928 (sfnt LoadGlyph segments): Paperlogy 800 maps 11,172 syllables and draws 2,780 (갂 쎯 empty; 똠 햏 뷁 drawn) and draws ㎏ ㎝ ℓ № and kana; Jua maps and draws 2,367 (뷁 yes, 갂 no) and lacks ㎏ … and CJK punctuation; Wanted Sans Variable and NanumMyeongjo draw all 11,172 syllables; Wanted Sans lacks ㎏ ㎝ ℓ №, Cyrillic, Greek and kana
- ink test: `font.LoadGlyph(&buf, id, fixed.I(100), nil)` returning no segments means empty; the face key for the substitute is `wantedsans` (one variable file, every weight), family `design.FontFamily("wantedsans")`
- one helper builds the markup for a caption string from a `substitute func(rune) bool` (nil or none missing → the plain escaped text, so ordinary captions stay byte-identical): runs of substituted runes wrap in `<tspan font-family="Wanted Sans Variable">`; the measurement SVG, the sequence painters (`CaptionFrame` carries the predicate; `f.text` and the per-word calls go through it) and the static view use the same run split
- static view: add `Runs []overlay.Run{Text, Family, Fill string}` to `overlay.Text`, set only when a line has a substitution (keyword runs carry the accent fill, so a coloured keyword keeps working); the caption template draws `{{if .Runs}}` runs as tspans with attributes only where set, else the current Prefix/Keyword/Suffix or Value branch; the view stays `copy-v1` (additive) and the boot probe keeps an old operator catalog from silently drawing blanks
- keyword and per-word measurement strings (`keywordValues`, `wordValues`) go through the same markup, since their offsets are measured
- the design metrics table and region fitting are untouched: `design.Covers` already reads ink for region slots (CDS-77)
- FE: `clipCovers`-style lookup per character (`faceOf(face, weight)`; a face absent from the table draws everything) splits a caption line into runs and wraps the undrawn ones in `<tspan fontFamily="Wanted Sans Variable">`; only caption lines, never regions, info or the badge
