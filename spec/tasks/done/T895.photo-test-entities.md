## goal
The writing-test entity can build an observation plan, read observation tests with their photos and blind observations, upload test photos through the same pipeline posts use, and its fixture refuses what the server refuses.

## acceptance
- [x] Deterministic, unit (`api/mappers.test.ts`): `planToProto` sends output OBSERVATION, the photo ids, stage OBSERVE and model entrants for an observation plan and refuses one with material text, attachments, a source post, setting fields, writer/observer models or no photo; a post plan sends output POST and no photo ids; `mapWritingTest` reads output (unspecified → post), photos and candidate observations, refuses observations on a post test and drops a candidate observation `model` before reveal.
