# T209 Caption pace and accent are project settings
> st:done@260916 | ssot:CLIP-139 CLIP-45 CLIP-14 CLIP-130 CLIP-1 CLIP-100 | base:CLIP@31 CDS@20 ARCH@3 | dep:-

## goal
Move caption pace and accent from the template to the project: chosen in ①, seeded from a legacy template's values, applied at render and preview, with a change marking the result stale and invalidating neither observations nor plan.

## acceptance
- [v] migration 0057 adds `clip_projects.caption_pace TEXT NOT NULL DEFAULT ''` and `clip_projects.accent TEXT NOT NULL DEFAULT ''`; sqlc gains `UpdateClipCaptionPace` and `UpdateClipAccent`; proto `ClipProject.caption_pace = 31` and `accent = 32`, and `optional string caption_pace` / `accent` on `CreateClipProjectRequest` and `UpdateClipProjectRequest`
- [v] `CreateProject` seeds both from the selected template's root attributes when the request leaves them empty; an empty pace reads as steady and an empty accent as none, everywhere
- [v] `UpdateProject` validates with `ValidCaptionPace` and `ValidAccent`; a change marks the rendered result stale the way a source-sound change does (CLIP-100) and leaves `planRecoveryDigest` and `QuoteInputDigest` unchanged
- [v] `EditPlan` gains render inputs `CaptionPace` and `Accent`, filled from the project where `Disclosure` and `Facts` are (render start, rerender, `PrepareClipPreview`) and applied to every caption and slot in place of `PortableText.Pace/Accent`; a project whose columns are empty falls back to the frozen document's values, so existing plans render as before
- [v] ① (`ClipProjectForm`) shows a pace SegmentedControl 문장형 | 빠른 구절형 and an accent row of the seven swatches plus none, both autosaved through the draft queue; ② `ClipTextControls` drops its per-text pace toggle and accent field (phrase editing stays)
- [v] tests: BE — seeding from a legacy template, stale-without-invalidation, render override and fallback; FE — controls render, save and reflect the project; verify FE (ARCH-25), BE (ARCH-26), generated code (ARCH-28)
