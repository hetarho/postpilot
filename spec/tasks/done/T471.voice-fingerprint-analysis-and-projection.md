## goal
말투 만들기 and 다시 분석 count the fingerprint (T470) and ask one call for the short AI part; the voice keeps its current and one previous analysis with `이전 분석으로 되돌리기`; 말투 분석 reads it back in two groups with the owner's own example sentences; the writer receives it as plain Korean with each item's meaning; and the ending-run rule becomes a 기본 지침 — while per-field overrides, version history, per-version generation snapshots, the six axes and the nine-section analysis leave the product.

## impl notes
- Schema: `voice_analyses(voice_id TEXT NOT NULL, user_id TEXT NOT NULL REFERENCES users(id) ON DELETE CASCADE, slot TEXT NOT NULL CHECK (slot IN ('current','previous')), snapshot TEXT NOT NULL, material_ids TEXT NOT NULL, analyze_model TEXT NOT NULL, created_at TEXT NOT NULL, PRIMARY KEY (voice_id, slot), FOREIGN KEY (voice_id, user_id) REFERENCES voices(id, user_id))`; `snapshot` = `{"version":1,"counted":{Fingerprint},"ai":{…},"material_count":N}`; `InsertVoice` stops creating a `voice_profiles` row; the directory's "made" becomes `EXISTS (current slot)`
- AI part schema (replaces `voice_analysis.schema.json`): `{ "impression": string, "tics": [{ "phrase": string, "when": string }], "signature_phrases": [string], "examples": [{ "field": "impression" | "tics" | "signature_phrases", "sentence": string }] }`, all required; the handler keeps the first two sentences of `impression`, at most 5 tics and 8 phrases, and fails a result missing any field (VOICE-24)
- AI prompt (Korean, code): `당신은 한 사람의 글버릇을 읽는 분석가입니다. 아래 학습 글은 모두 같은 사람이 직접 쓴 글이고, 제품이 이미 센 습관 수치가 함께 있습니다. 수치는 다시 세지 말고, 셀 수 없는 것만 쓰세요. impression: 이 사람의 글이 주는 전체 인상을 1~2문장으로. tics: 자주 나오는 말버릇과 그 말이 나오는 상황(최대 5개). signature_phrases: 이 사람만의 표현(최대 8개) — 음식·장소·상품 이름처럼 주제에 딸린 단어는 빼세요. examples: 위 셋을 보여 주는 문장을 학습 글에서 그대로 인용하고, 없는 문장은 만들지 마세요. 근거가 약하면 빈 목록으로 두세요.` followed by the counted summary and the corpus (`===== 학습 글 N: {label or prompt} =====`, prose lines only)
- Verbatim check: collapse whitespace on both sides and search every 학습 글's prose; an example not found is dropped
- The analyze job keeps its single planned analyze call; with T469 it no longer repeats; `Measure`, `MeasuredProfile`, `analysisGuideSections`, `analysisPrompt`, the structured analysis prompt, `mergeQualitativeProfile`, `validateAxes`, `profile.go` (overrides, versions, restore), `version_sample_test.go`, `override_base_test.go` and the axes code go
- Notice computation: current `material_ids` against the voice's 학습 글 — any id missing ⇒ `changed`; else the count of ids not in the set ⇒ `added`; `다시 분석` stays gated by 100% (T469)
- Projection (`PromptProfileForTopic(ctx, userID, voiceID, retrievalText, target, excludeMaterialID)`), Korean target:
  ```
  [말투]
  아래는 이 글쓴이가 직접 쓴 글에서 센 습관입니다. 이 습관대로 쓰고, 발췌한 문장의 표현이나 사실은 베끼지 마세요.
  - 문장 끝: '~다' 28%, '~해요' 31%, '~습니다' 7%, 그 밖의 끝맺음 34%. 이 비율을 따르세요. 자주 쓰는 끝맺음: ~더라구요, ~했어요.
  - 문장 끝 부호: 느낌표 32%, 물음표 5%, 물결표 10%, 말줄임표 3%, 마침표 40%, 부호 없음 10%. 같은 부호를 두 번 이상 겹쳐 쓰는 문장 8%.
  - 이모지와 자모: 100문장마다 이모지 12개, ㅎㅎ 4번, ㅋㅋ 0번, ㅠㅠ 2번.
  - 문장과 문단: 문장은 평균 24자, 문단마다 1~3문장(평균 2문장)이고 문장마다 줄을 바꿉니다.
  - 여는 줄: "안녕하세요!" / 닫는 줄: "오늘도 좋은 하루 보내세요~"
  - 자주 쓰는 말: 진짜(100문장마다 8번), 완전(5번), 근데(4번).
  - 1인칭: '저'(100문장마다 6번).
  - 소제목과 목록: 소제목의 70%가 이모지로 시작하고 40%가 질문형입니다. 목록은 '-'로 씁니다.
  - 인상: {impression}
  - 말버릇: '{phrase}' — {when}
  - 이 사람만의 표현: {phrases joined by ,}
  ```
