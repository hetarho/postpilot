# T371 The small mirrors are pinned
> st:done@260925 | ssot:ARCH-3 | base:ARCH@11 | dep:T362 T364 T369

## goal
Five values that live in two places are each tied to one source or one test: the Naver URL length, the slot token grammar, the phrase page size, the composition rule's count and the replacement instruction's two numbers. Editing one copy alone now fails a test.

## acceptance
- [v] `backend/internal/post/testdata/published_url/cases.json` carries `"maxChars": 2048`. Go `post.PublishedURLMaxChars` and FE `POST_PUBLISHED_URL_MAX_CHARS` are each asserted equal to it, and both harnesses build their at-limit and over-limit cases (and the FE astral case) from the fixture value.
- [v] One slot-token grammar: `template` owns it (`SlotToken` plus a new `ReplaceSlotTokens`). `quality/text.go`'s `slotToken` regexp and `generation/template_slots.go`'s `slotToken`/`itoa` are deleted, and both packages call `template`.
- [v] The phrase page size has one owner. `quality.BlogSearch.SearchBlog` takes `display`, the batch passes `PhrasePageSize`, and `naversearch` sends the `display` it is given (1…100, refused otherwise before any request) and keeps no page size of its own.
- [v] The composition rule's "세 가지 이상" / "at least three" is pinned against `DistinctBlockTypesBand+1` by a test.
- [v] `replacementsInstruction`'s "1~3개" and "최대 20개" are built from `ReplacementPhrasesMax` and `ReplacementSpansMax`, and its test asserts through the constants.
- [v] Tests:
  - [v] `post/publication_test.go` `TestParseNaverBlogURL` and FE `entities/post/model/published-url.test.ts` assert `maxChars`.
  - [v] `template/expand_test.go` new `TestReplaceSlotTokensMatchesExactlySlotTokens`.
  - [v] `naversearch/client_test.go` asserts `display` in the request and refuses 0 and 101.
  - [v] `quality/batch_test.go` asserts every call's display is `PhrasePageSize` at starts 1, 101 and 201.
  - [v] `cmd/api/phrase_batch_test.go` asserts the adapter passes display through.
  - [v] `quality/rules_test.go` new `TestCompositionRuleNamesTheBandCount`.
  - [v] `generation/field_phrases_test.go` asserts through the constants.
- [v] Behavior unchanged: every prompt and rule text is byte-identical (the write prompt goldens pass untouched), T364's `MeasureSelf` digest still matches, and the existing tests still pass.
- [v] Verify: BE `cd backend && test -z "$(gofmt -l .)" && go vet ./... && go build ./... && go test -timeout 30m ./...` · FE `pnpm --filter ./frontend test` · `pnpm lint` · `pnpm lint:fsd` · `pnpm lint:style:probe && pnpm lint:style` · `pnpm build:web`
