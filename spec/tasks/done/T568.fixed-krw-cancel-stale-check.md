# T568 Let a fixed-KRW subscriber cancel auto-renewal once time has passed
> st:done@261005 | ssot:BILL-7 | base:BILL@8 | dep:- | touches:backend/internal/billing/change.go backend/internal/billing/store/

## goal
Cancelling auto-renewal under fixed KRW billing succeeds whenever the stored subscription is the one the request read, instead of always failing `ErrStaleQuote` because the read copy's `UpdatedAt` was overwritten with `now` before the comparison (BILL-7).

## acceptance
- [v] `CancelSubscription` compares the in-transaction row's `UpdatedAt` with the `UpdatedAt` it read before changing anything, as `ResumeSubscription` and `CancelScheduledChange` do
- [v] real-store test (fixed KRW): a subscriber who subscribed an hour earlier cancels successfully — auto-renew off, scheduled change cleared, a `cancel_scheduled` event — and the next renewal pass at term end lapses the account without charging
- [v] real-store test: a subscription row written between the cancel's read and its transaction is refused `ErrStaleQuote` and left unchanged
- [v] behaviour unchanged otherwise: ARCH-26 green

## impl notes
