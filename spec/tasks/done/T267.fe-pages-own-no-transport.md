deviations
- `invalidatePostsDependingOn` takes the transport as its second argument: the keys it invalidates are transport-scoped (connect-query keys transports by object identity), so the signature in this task's acceptance could not be honoured literally. The hook form carries it for callers that have none
- `review-model-experiment` calls `invalidateWrittenPost` rather than the dependency entry: applying a winner writes THAT post's content, which is a post write, not a cross-noun staleness — collapsing them would invalidate every post detail on every experiment decision
- every dependency kind invalidates the same two entries and the parameter is currently documentation: the post cache is partitioned by slug, so which posts name a changed voice is not knowable from the client's keys. The entry is the place a narrower rule would land
- out of scope, still open from F9: `pages/template/ui/TemplatePage.tsx`'s inline Editor (265 lines, 9 useState) and `pages/ai-models`'s panels are page-owned state machines, not transport — and T259 had to delete `features/edit-template` (segment-less after its hook moved), so F9's `features/edit-template/model/useTemplateDraft` now means creating that slice
