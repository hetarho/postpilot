## goal
ExportPanel renders and TemplatePage composes; the copy-generation counters, copy queue, feedback timers and fallback reveal, and the template draft/baseline/save/create/adopt/leave-guard machine, live in model hooks a test can drive without rendering.

## acceptance
- [v] `widgets/export-panel`: the copy and feedback logic moves into `model` hooks of the widget (or the feature that owns copying, if one already does); `ExportPanel.tsx` keeps layout and wiring only and drops well below its current 583 lines
- [v] the template editor's state machine moves out of `pages/template` (ARCH-14: a page owns no state machine) into a feature `model` hook (`features/edit-template` or the existing feature that saves templates), which the page composes
- [v] each moved machine gets its own hook tests (renderHook) covering what the component tests covered for it; the existing component and page tests keep passing with unchanged expectations
- [v] user-visible behaviour unchanged: FE suite, `pnpm lint`, `pnpm lint:fsd`, `pnpm lint:style:probe && pnpm lint:style`, `pnpm build:web` green
