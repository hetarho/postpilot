# T408 Generation stops freezing 분야 phrases and posts stop carrying replacement candidates
> st:done@260926 | ssot:GEN-14 GEN-18 GEN-55 POST-83 | base:GEN@13 POST@16 | dep:T407

## goal
The write prompt carries no `[분야 상위 글 문구]` section and the write answer no `replacements`. The post keeps only its nouns, so the `posts.replacement_candidates` column and the post proto's candidate fields are gone. Every stored payload, snapshot and candidate output that still holds the old keys decodes as if they were absent.

## acceptance
- [v] a write prompt for a post with a 분야 is byte-identical to the same post without one: no phrase heading, no observation line, no replacements instruction, and the plain `WriteAnswerSchema`
- [v] the write answer carries `nouns` only (GEN-55 unchanged); `SavePostContent` takes no taken indices, and a generated write stores nouns and nothing else
- [v] a generate payload, a write snapshot and a stored experiment candidate output containing `"field_phrases"` / `"replacements"` decode equal to the same document without them. New tests: payload and snapshot legacy-decode cases, plus `TestALegacyCandidateOutputDecodesAsNone` extended with a `"replacements"` key.
- [v] new goose migration (the next free number, 0087 today) drops `posts.replacement_candidates`. Its Down re-adds the column with 0077's `json_valid` CHECK. A migration test in the `migration_0083_test.go` pattern goes UpTo(prev), then across, then DownTo(prev). `TestMigration0077IsIdempotent` no longer expects the column.
- [v] proto: `Post.replacement_candidates = 30` and `SavePostContentRequest.taken_candidates = 5` are removed with `reserved` numbers and names (repo convention, billing.proto:72–78); `enum ReplacementSurface` and `message ReplacementCandidate` are deleted; gen code regenerated
- [v] `rg -n "FieldPhrases|fieldPhrases|Replacement(s|Candidate|Surface)|replacement_candidates|taken_candidates|WriteAnswerReplacementsSchema" backend proto --glob '!**/migrations/**'` is empty, apart from the reserved lines and the legacy-decode tests
