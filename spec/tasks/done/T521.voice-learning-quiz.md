## goal
An unmade voice has one learning screen, while its prompt sheet advances through answers with visible readiness progress; made voices show the renamed tabs and simpler analysis.

## acceptance
- [v] An unmade voice shows no 말투 분석, 학습 데이터 or 검증 tab row; index and checks links reach `/materials`, and a successful first analysis reveals the three tabs.
- [v] The made voice tab and screen heading read `학습 데이터`; counted analysis rows remain but `숫자로 본 습관` title is absent.
- [v] 문항 풀기 opens the first unanswered prompt directly; saving advances to the next unanswered prompt on a blank form, with no `건너뛰기` or `문항 목록` control. Closing and reopening resumes at the first unanswered prompt; a refused save preserves the entry.
- [v] For an unmade voice the sheet shows the live readiness meter after each save, says `거의 다 왔어요` from 80% to below 100%, and offers `말투 만들기` at 100%; an already made voice may continue until every prompt has an answer.
- [v] After the final unanswered prompt, a voice below 100% cycles through prefilled answers for more sentences, preserving a photo on rewrite; at 100% (or for a made voice), it shows completion and a close control. The separate 검증 answer-one form remains single-answer and starts its check.
- [v] Tests cover routing, tab visibility, labels, quiz progression, readiness states and the check path; Korean and English keys stay paired; ARCH-25 frontend gates pass.

## impl notes
- The served prompt order is the quiz order. `samples` plus a local saved-key set prevent a just-saved prompt from appearing before the profile refetch completes. Once all prompts are answered short of 100%, the quiz uses the answer replacement API to cycle through them with their text and photo retained.
- Pass the profile readiness and made state into `AnswerPromptsSheet`; its parent already receives refreshed profile after `AnswerVoicePrompt` invalidates voice materials. Use the existing `VoiceReadinessMeter` and `MakeVoiceButton` so the percentage and provider gating are shared with the main screen.
- Hide the tab row using the directory voice's `made` state; redirect unmade index/checks routes to `/materials` so direct and legacy links cannot expose a non-learning screen. The materials route remains available after the voice is made.
- Keep `AnswerForm` reusable for 검증's one-answer path; remove quiz-only skip/list controls without changing that path. The prompt sheet's close action remains usable at any point.
