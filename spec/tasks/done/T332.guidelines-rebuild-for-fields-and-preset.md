- `toGuideline` accepts `'fields'` through `Scope.Valid()`.

- In `Preset`, `sql.ErrNoRows` from the row read becomes `Preset{}` with no error.

- `CountGuidelines` counts only `guidelines` rows, and the text UNIQUE constraint covers `guidelines` alone. GUIDE-39 therefore holds structurally, and the new test pins it.
- Injection order: interleave `created_at` across the three groups and expect global, then templates, then fields.
- Applicable texts: template P plus 분야 F, 분야 only, another 분야 excluded, and `field = ""`.
- Rescope: templates → fields and fields → templates, each leaving zero rows in the other link table.
- Delete: a fields guideline's links cascade and another guideline's links remain.
