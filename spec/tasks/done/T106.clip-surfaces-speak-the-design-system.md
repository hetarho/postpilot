## impl notes
- the FE reads `shared/config/clip-design.json` instead of mirroring numbers by hand because T102's equality test makes that file the same bytes the renderer embeds; a preview drawn from it cannot drift from the render
- the FE validator duplicates the BE rules for immediacy only; the server verifier remains the authority and every refusal it returns is shown beside a field (CDS constraint on manual choices), so a rule the FE misses still cannot ship
- two `Listbox`es for anchor and align rather than one 12-item list: the owner reasons about height and side separately, and the step rule (V13) concerns the vertical anchor alone
- `clean` is checked and disabled because T102's `ValidCopyStyles` requires it; a disabled control says why in its help text
- the seed dialog exists because adding reserved fields to a template already used by projects changes what those projects' step ① asks for; CLIP-25's answer preservation means nothing is lost, but the owner should know
- this task edits `features/edit-clip-template/ui/ClipTemplateEditor.tsx`, which T101 reshaped on 260911; start from T101's version (tasks/done/T101) and do not restore its pre-T101 chrome
