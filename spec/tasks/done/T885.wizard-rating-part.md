## goal
Every wizard leaf ends with a 별점 part asked through 질문을 바탕으로 작성, and that kind takes an optional 고정 문구 (such as rating criteria) that the body places directly above the field so it leaves with the heading when the answer is skipped.

- [v] every leaf of `TARGET_TREE` ends with the `rating` role (name 별점, help 직접 매긴 별점과 그 이유, default `ask`, no photo), and the catalog test still holds (deterministic: `target-catalog.test.ts`, task stage)
- [v] `toWizardBlocks` writes an ask section as heading, then its 고정 문구 (trimmed, blank lines closed up) when nonempty, then the field, all as consecutive lines; an empty 고정 문구 writes nothing; the 고정 문구 kind is unchanged (deterministic: `to-body.test.ts`, task stage)
- [v] the wizard's sections step lists 별점 last and checked for a leaf (deterministic: an existing wizard machine or flow test extended, task stage)

- `to-body.ts` `toWizardBlocks`: for `content === 'ask'` push the heading literal, then — when `section.literal.trim()` is nonempty — one literal block of it with blank lines closed up (`.split('\n').map(trimEnd).filter(nonblank).join('\n')`), then the ask block; check how `toBody` joins consecutive text blocks and assert in the test that no blank line ends up between heading, fixed text and the ask (TMPL-45's lead stops at a blank line)
- the step UI that edits the optional 고정 문구 is T886; until then the field can only come from the 고정 문구 kind's text
