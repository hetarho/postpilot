## impl notes
- schema (mirrors `model_selections`' stage/slot vocabulary so the slots map 1:1 onto an apply):
  - `recommendation_sets(id TEXT PK, label TEXT NOT NULL, position INTEGER NOT NULL, created_at TEXT NOT NULL, updated_at TEXT NOT NULL)`; list order `position, created_at, id`; a new set takes `max(position)+1`; no UNIQUE on position so a move is a plain two-row swap inside one transaction
  - `recommendation_set_slots(set_id TEXT NOT NULL REFERENCES recommendation_sets(id) ON DELETE CASCADE, stage TEXT NOT NULL CHECK(stage IN ('observe','analyze','write')), slot TEXT NOT NULL CHECK(slot IN ('active','candidate_a','candidate_b')), provider_id TEXT NOT NULL, model_id TEXT NOT NULL, PRIMARY KEY(set_id, stage, slot), CHECK(stage <> 'analyze' OR slot = 'active'))`
  - seed timestamps `2026-09-30T00:00:00.000000000Z`, position 1; the seed refs are the yaml's: observe active/A `google/gemini-3.7-flash`, B `qwen/qwen3.8-flash`; analyze `openai/gpt-5.6-luna`; write active/A `anthropic/claude-sonnet-5`, B `x-ai/grok-4.6`, all `provider_id` `openrouter`
  - query file `backend/internal/provider/store/queries/recommendation_sets.sql`, ASCII only (sqlc byte-offset bug)
- ownership: the provider context owns the rows (MODEL constraints placement). `provider.Store` gains `ListRecommendationSets` `CreateRecommendationSet(set, limit)` `ReplaceRecommendationSet` `DeleteRecommendationSet` `MoveRecommendationSet(id, earlier)`; create checks the count inside its write transaction and returns `ErrRecommendationLimit`; replace/delete/move return `ErrRecommendationNotFound` for an unknown id; replace deletes and re-inserts the set's slots and bumps `updated_at` in one transaction
- `provider.Catalog` drops `RecommendationSets()`; `llm` drops `RecommendationSet`, `RecommendationSelection`, `recommendationSetEntry`, `loadRecommendations` and the `recommendation_sets` yaml field, so the strict parser rejects a leftover key as an unknown field; the providers.yaml header comment names the rows instead
- service API: `RecommendationSets(ctx) ([]RecommendationSet, error)`, `SaveRecommendationSet(ctx, draft RecommendationSet) (RecommendationSet, error)`, `DeleteRecommendationSet(ctx, id)`, `MoveRecommendationSet(ctx, id, earlier)`; constants `MaxRecommendationSets = 10`, `MaxRecommendationLabelRunes = 60` in `provider/types.go`; ids are 16 random bytes hex like the other contexts' `newID`
- validation (MODEL-70) is a pure function over the draft plus `catalog.Lookup`: registration = `Suitable(stage, info)`, classification = `info.Levels[stage] != ""`, always checked (the operator is master; no plan or balance read). It returns `*SetDraftRefusal{Fields map[string]string}` with `Reason() = "MODEL_SET_INVALID"`, `Params()` = the field→cause map plus `fields` (sorted, comma-joined keys); field keys `label observe_active observe_candidate_a observe_candidate_b analyze_active write_active write_candidate_a write_candidate_b`; mapped to `CodeInvalidArgument`
- wire (ProviderService; ~10 rpcs, under ARCH-41's split point):
  - `SaveRecommendationSet(SaveRecommendationSetRequest{string id = 1; string label = 2; repeated RecommendationStageSelection selections = 3}) returns (SaveRecommendationSetResponse{RecommendationSet set = 1})`
  - `DeleteRecommendationSet({string id = 1}) returns ({})` · `MoveRecommendationSet({string id = 1; bool earlier = 2}) returns ({})`
  - the handler turns `selections` into the seven-slot draft; an unspecified/duplicate stage or candidates on analyze ⇒ `MODEL_STAGE_INVALID` InvalidArgument; a stage left out leaves its slots empty so validation reports them `required`
  - `FailureReason` adds `MODEL_SET_INVALID = 279`, `MODEL_SET_LIMIT = 280` (FailedPrecondition); FE `appFailureSpecs`: `MODEL_SET_INVALID` optional params = `fields` + the eight field keys, `MODEL_SET_LIMIT` required `limit`
- experiment: `Catalog.Recommended(stage, ref) bool` → `Recommended(ctx, stage) ([]ModelRef, error)`, read once per leaderboard build; the cmd/api adapter reads `provider.Service.RecommendationSets(ctx)`
- `cmd/api/providers_test.go`: drop the yaml set assertions and `TestShippedRecommendationRefsAreSeeded`; the migration test replaces it
