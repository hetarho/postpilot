# T515 Add /admin's 비용·환율 tab with the exchange rate in effect
> st:done@261001 | ssot:QUOTA-25 QUOTA-59 QUOTA-65 QUOTA-68 AUTH-18 | base:QUOTA@32 AUTH@11 | dep:T513 | touches:proto/postpilot/v1/plan.proto backend/internal/auth/rpc backend/cmd/api backend/internal/gen frontend/src/shared/api/gen frontend/src/app/routes frontend/src/pages/admin frontend/src/entities/plan

## goal
The operator reads the KRW/USD rate that paid AI work is priced at, its source, publication date, reference and applied values and whether it is a temporary fallback, on one /admin tab instead of on customer screens.

## acceptance
- [v] A master-only AdminService procedure returns the rate snapshot a new paid job would select now, or `unavailable` when no eligible rate exists (QUOTA-59). A non-master call is refused with permission_denied and MASTER_ONLY; the procedure is in `masterProcedures` in the same change. Backend tests cover a confirmed rate, a temporary fallback, an unavailable rate and the non-master refusal.
- [v] `/admin/costs` is the fifth admin tab (ko `비용·환율`, short `비용`; en `Costs & rate`, short `Costs`) after `편수 기준 조합`. Its first section shows source, publication date, reference and applied ₩/USD, and a text-labelled `임시 적용` state for a temporary fallback; an unavailable rate shows that paid AI work cannot start; a failed read shows a retryable error. Non-master visitors are redirected as for every /admin route.
- [v] FE tests cover the tab row, each state, keyboard reachability and both languages; route tree and navigation tests include `/admin/costs`. Run ARCH-25 verification, including proto generation idempotence.

## impl notes
- Proto (plan.proto, AdminService): `rpc GetExchangeRate(GetExchangeRateRequest) returns (GetExchangeRateResponse)` with `PlanFXRate rate = 1; bool unavailable = 2;`, reusing `PlanFXRate` kept by T513. Add `AdminServiceGetExchangeRateProcedure` to `masterProcedures` in `auth/rpc/interceptor.go`.
- Backend: the AdminService handler (`authrpc.NewAdminHandler`) takes a consumer-declared `RateReader` port with `CurrentRate(ctx) (plan.RateSnapshot, error)`; wire `estimatorCombos` from `cmd/api/adapters_catalog.go`, which already implements it, so the tab shows exactly the snapshot GetMyPlan prices estimates at. An error or `!Valid()` answers `unavailable: true`, not a failed RPC.
- Frontend: add `{ to: '/admin/costs', labelKey: 'costs', icon: Coins }` to `ADMIN_TABS`, the route beside `/admin/estimator`, `pages/admin/ui/AdminCostsPage.tsx` and an `entities/plan` query hook for the read. Lay the page out as titled sections, so T516 adds the comparison-cost section below the rate without restructuring. Format values with `formatNumber`, four decimals dropped as `PlansPage` did (`/ 10000`).
