## impl notes
- Split from T604 (inbox 261111 decided T604). Diagnostic only: no file under frontend/src changes behavior. Reuse the caption and region builders the comparison already imports from entities/clip-preview (ink-caption-pixi.ts, ink-caption-filter-pixi.ts, ink-caption-ember-pixi.ts) without forking them.
- Footage: wrap each decoded `VideoFrame` as a Pixi texture source for that frame only and close the frame once it is drawn. Keep the ARCH-63 bounds of the other arms: bounded in-flight frames, textures destroyed per frame and no growing texture cache.
- Output: `new VideoFrame(offscreenCanvas, { timestamp })` with the same explicit timestamps as the other arms, plus the same diagnostic readback the other arms already pay so timings stay comparable.
- A browser without WebGL2 records the arm as unexecuted with its reason; the arm never falls back to Canvas 2D on its own.
- Run with other expensive checks stopped, as scripts/browser-render-comparison/README.md requires, and bind a clean exact commit with `--expected-head`.
- The Windows Chrome/Edge measurement of all arms is T750; integrated-GPU and lower-resource devices remain T604.
