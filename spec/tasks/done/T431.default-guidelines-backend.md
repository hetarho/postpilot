## goal
Grounding, impressions, naming, altitude, the story rules, the title and tag rules and the naturalness baseline leave the static write prompt and become the product's 기본 지침 — code constants per kind with a per-account switch — rendered first in the `[작문 지침]` section of every write and revise run and frozen with it.

## impl notes
- Texts. Korean text for a Korean target, English for an English target; names are what the 지침 screen shows. Keep the meaning; small phrasing tunes are fine.
  - post
    1. `facts` 재료에 있는 사실만 / Facts from the material only — `메모, 사진 관찰, 템플릿 입력란, 기억, 스토리라인에 없는 구체적 사실은 쓰지 마세요. 사람과의 상호작용, 시설, 서비스, 대화, 가격처럼 확인되지 않은 내용을 지어내지 마세요. 확인할 수 없는 사실은 생략하거나 관찰된 범위 안에서만 쓰세요.` / `State no concrete fact the memo, the photo observations, the template's fields, the memories and the storyline do not carry. Do not invent interactions with people, facilities, services, conversations, or prices. Omit what you cannot confirm, or keep it within what was observed.`
    2. `impressions` 감상은 내가 쓴 것만 / Impressions only as I gave them — `감상, 맛, 평가는 글쓴이가 메모, 템플릿 입력란, 스토리라인에 직접 적은 것만 쓰고, 적혀 있지 않은 감상을 지어내지 마세요.` / `Write an impression, a taste or a verdict only as the author gave it in the memo, the template's fields or the storyline, and invent none.`
    3. `naming` 메모의 이름으로 / The memo's names — today's `koreanNaming` / `englishNaming` verbatim
    4. `order` 일어난 순서대로 / In the order it happened — `그날 일어난 순서대로 이야기하세요. 템플릿이 있으면 템플릿의 각 자리 안에서 그 순서를 지키세요.` / `Tell it in the order it happened; with a template, keep that order inside each of its places.`
    5. `opening` 첫머리에 이유와 기대 / Open with why — `메모에 간 이유나 기대가 있으면 글 첫머리에서 꺼내세요.` / `When the memo says why the author went or what they expected, open the post with it.`
    6. `photo_moments` 사진은 이야기의 한 장면 / A photo is a moment — `사진은 그 순간을 이야기하는 문장들 사이에 놓고, 사진을 설명하는 말로 문단을 시작하지 마세요. 각 문단은 앞 문단을 이어받아 넘어가세요.` / `Place a photo between the sentences about its moment, never open a paragraph by describing a photo, and let each paragraph pick up from the one before.`
    7. `closing` 끝에서 한 번 정리 / Close by drawing it together — `마지막에 그날을 짧게 정리하세요. 총평이나 재방문 의사는 글쓴이가 적은 것이 있을 때만 쓰세요.` / `Close by drawing the day together briefly; write a verdict or a will to return only if the author gave one.`
    8. `no_listing` 관찰을 나열하지 않기 / No listing of observations — today's `koreanAltitude` / `englishAltitude` verbatim
    9. `titles` 제목 규칙 / Title rules — `제목을 정보 하나만 바꿔 넣은 긴 상투 문구로 쓰지 말고, 한 제목 안에서 같은 키워드를 두 번 이상 쓰지 마세요. 템플릿에 제목 형식이 있으면 그 형식을 따르고, 이 규칙은 형식의 <write> 안에서 직접 쓰는 부분에만 적용하세요.` / `Do not write the title as long boilerplate in which only a single piece of information changes, and do not use any keyword twice or more within one title. When the template has a title form, follow it and apply this only to what you write inside its <write>.`
    10. `tags` 태그 규칙 / Tag rule — today's `koreanTagRule` / `englishTagRule` verbatim
    11. `natural_korean` 자연스러운 한국어 문체 / Natural Korean style (Korean target only) — the Korean text is today's `NaturalnessBaseline` body without its heading line, its closing line reworded to `말투 프로필, 활성 대조 규칙, 사용자 규칙과 충돌하면 그쪽을 따르세요.`; the English copy is for display only: `Caps stock contrasts, formulaic closers, uniform sentences, hype and piled metaphors in Korean prose; the voice profile outranks it.`
  - clip (rendered by T440)
    1. `clip_facts` 입력한 사실만 / Entered facts only — `이름, 숫자, 단위, 통화, 가격은 입력한 정보나 항목 정보에 적힌 그대로만 쓰고, 여러 답을 조합해 만들지 마세요. 어느 항목의 것인지 헷갈릴 수 있으면 그 항목의 이름을 함께 쓰세요. 지시, 입력한 정보, 관찰, 스토리라인에 없는 사실은 쓰지 마세요.` / `State a name, number, unit, currency or price only exactly as one entered fact or item fact states it, never assembled from several answers, and name the item it belongs to where it could be ambiguous. State no other fact the instruction, the entered facts, the observations and the storyline do not carry.`
    2. `clip_impressions` 감상은 내가 쓴 것만 / Impressions only as I gave them — `맛, 분위기, 만족 같은 감상은 지시나 스토리라인에 사용자가 적은 것만 쓰세요.` / `Write a taste, a mood or a satisfaction only as the owner gave it in the instruction or the storyline.`
    3. `clip_hook` 첫 자막에 무엇을 보여줄지 / Say what it is about first — `첫 자막은 이 영상이 무엇에 대한 것인지 한 줄로 말하세요 (예: 구리에서 찾은 숨은 오리집).` / `Let the first caption say in one line what the clip is about.`
    4. `clip_continuity` 자막은 이어지는 말 / Captions that carry on — `각 자막은 앞 자막을 이어받는 말로 쓰고, 화면에 보이는 것의 이름표처럼 쓰지 마세요. 자막은 컷을 넘어가도 됩니다.` / `Let each caption carry on from the one before rather than label what is on screen; a caption may run across cuts.`
    5. `clip_order` 일어난 순서대로 / In the order it happened — `컷과 자막은 그날 일어난 순서를 따르세요. 템플릿이 있으면 각 구성 단계 안에서 그 순서를 지키세요.` / `Let cuts and captions follow the order it happened; with a template, keep it inside each of its stages.`
    6. `clip_wrap_up` 끝에서 정보 정리 / Wrap up the facts — `마지막 자막들에서 가게 이름, 위치, 가격처럼 사용자가 입력한 정보를 모아 말하세요.` / `In the last captions, draw together what the owner entered, such as the name, the place and the price.`
    7. `clip_no_repeated_promotion` 같은 홍보 문구 되풀이하지 않기 / No repeated promotion — `같은 뜻의 홍보 문구를 두 번 쓰지 마세요.` / `Do not say the same promotional line twice.`
- Precedence sentence (Korean for every target, GUIDE-15 GUIDE-37): `지침은 이 글을 어떻게 쓸지 정합니다. 지침이 템플릿과 충돌하면 지침을 우선하고, 문체·종결어미는 위의 말투 프로필을 따르세요. 사용자 지침이 기본 지침과 충돌하면 사용자 지침을 따르고, 같은 묶음 안에서 충돌하면 먼저 적힌 지침을 따르세요. "A 대신 B라고 쓰세요"처럼 구체적으로 정한 치환은 지침, 템플릿, 말투 프로필 순으로 우선하고, 더 나은 단어를 쓰라는 막연한 요구에는 그런 우선권이 없습니다.` The revise sentence that follows the section: `이 지침은 수정 요청으로 새로 쓰거나 손대는 문장에만 적용하고, 요청 밖의 기존 문장은 사실 확인 없이 그대로 두세요.` The group labels `기본 지침:` and `사용자 지침:` stay Korean like the heading.
- Storage keeps only switched-off rows, so a new account starts with every 기본 지침 on and a key added later starts on for everyone (GUIDE-43).
- Kind: here every owner guideline is read as `post` whatever kind is asked; `ListGuidelines` with `CLIP` returns the clip defaults and no owner rows until T438 adds the column.
- Language: the guideline package owns a small `Language` (`ko`, `en`); the adapter maps `generation.Language`. Only a target language picks a prompt text; the UI language never reaches the server here (the answer carries both copies).
- The constants move out of `generation/prompts.go` into `guideline/defaults.go`; generation keeps no copy.
- The prompt is about as long as before (the same rules moved), so completion budgets are unchanged.
- Checking a real model is a paid provider call: ask the owner before making one.
