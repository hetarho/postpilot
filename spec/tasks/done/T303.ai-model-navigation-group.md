## goal
- Split AI model settings, comparison, history and leaderboard into four focused routed destinations with the existing group navigation.

## acceptance
- [v] Direct links to all four destinations show the matching content and one selected primary/group destination; phone/tablet menus and desktop rails expose the requested order in ko/en.
- [v] Active model changes and recommendations belong to settings; saved A/B pairs and explicit comparison starts belong to comparison, preserving write preconditions, re-observation choice and explicit voice selection.
- [v] History and leaderboard default to observe and retain all stages through validated URL filters; browser history/reload preserves the filter, and existing experiment addresses remain valid.
- [v] History/leaderboard loading, error and empty states remain distinct; navigation alone never mutates selections or starts experiments.
- [v] Relevant behavior tests, frontend checks and browser responsive checks pass.

## impl notes
- Add a pathless model group in app/routes/models and reuse ContentGroupLayout; choose the longest matching group destination so /ai-models does not also select every child.
- Keep /ai-models as the default settings address; add /compare, /experiments and /leaderboard beneath that prefix; keep the experiment detail URL and update its internal typed route id.
- Split the existing AIModelsPage composition into focused page components in pages/ai-models; reuse the existing controls and behavior, separating the active model form from the A/B form.
- Validate optional stage search values observe/analyze/write with observe fallback; preserve matching stage when navigating within the model group and returning from detail to history.
- Test route separation, nested selection, back/forward stage restoration, guarded direct routes and unchanged comparison actions; do not add style-class mirror tests.
- Existing T302 tablet header changes and pending Wanted Sans verification remain intact.
- Long translated menu names and enlarged text must shrink at the trigger, wrap inside the menu and scroll within the remaining viewport; the open group menu clears the fixed phone navigation. The comparison form uses an explicitly shrinkable single grid column below sm.

Settings contains active models/recommendations/costs; comparison retains saved A/B choices and the existing observe/analyze/write start behavior; history and leaderboard have independent read states.
- Existing experiment URLs still resolve under the model group and highlight history; postless experiment details return to their stage's history, while post-backed details retain their existing return-to-post action.
- Browser checks: 64 normal combinations (four pages × four widths × ko/en × day/night), 24 enlarged-text page combinations and 36 enlarged-text open-menu combinations across model/writing/video groups. Verified last menu entries remain clickable, current navigation is unique, stage survives navigation/reload/back, and navigation emits no mutations.
