## acceptance
- [v] no history row renders a 내보내기 link, whatever its status or `exportReady`
- [v] the `내보내기 가능` meta label still shows on an `exportReady` row
- [v] 이어서 작성 / 작업 확인, 이전 AI 결과 확인 and 발행한 글 are unchanged
- [v] `PostEntry.intent`, the stored `intent` filter and the editor's export-intent opening step are gone; opening a post always lands on the step its status gives (POST-44)
- [v] the `list.history.export` i18n key is gone in ko and en
- [v] tests: PostsPage asserts no 내보내기 link on an exportReady review row and keeps the label; the retained-narrowing test opens the row via 이어서 작성 and stores no intent; navigation-context and EditorPage.navigation tests drop the intent cases (the filtered-history return stays covered)
