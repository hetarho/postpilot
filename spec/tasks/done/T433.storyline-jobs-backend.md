# T433 스토리라인 먼저, 다시 만들기 and the storyline request run as storyline jobs (backend)
> st:done@260928 | ssot:GEN-30 GEN-68 GEN-69 GEN-71 GUIDE-7 GUIDE-15 GUIDE-17 QUOTA-13 POST-74 | base:GEN@17 GUIDE@9 QUOTA@23 POST@21 | dep:T429

## goal
Two durable jobs write a post's storyline and no content: `storyline` (스토리라인 먼저 in ①, 다시 만들기 in ②) observes like a generation and makes one call; `revise_storyline` (the space's AI request) rewrites the stored storyline from the owner's request.

## impl notes
- Payloads: `storylinePayload{target_language, template, guidelines, default_guidelines, memories, observe_files (presence as in generate), observations}` and `storylineRevisionPayload{target_language, request, storyline, template, guidelines, default_guidelines, memories}`; a missing language decodes as Korean like the others (GEN-30).
- Prompt wording (Korean shown; English twins in the same style):
  - task `아래 재료로 블로그 글의 스토리라인을 짜세요. 본문은 아직 쓰지 않습니다.`
  - paragraph rule: T429's storyline rule without its last sentence, then `각 문단은 계획을 말하는 문장(…를 보여줍니다, …를 이야기합니다)으로 쓰세요.`
  - output shape `{"storyline":[{"text":"...","files":[]}]}` plus the output-language sentence for the storyline text
  - storyline precedence (no voice here): `지침은 이 스토리라인을 어떻게 짤지 정합니다. 지침이 템플릿과 충돌하면 지침을 우선하세요. 사용자 지침이 기본 지침과 충돌하면 사용자 지침을 따르고, 같은 묶음 안에서 충돌하면 먼저 적힌 지침을 따르세요.`
  - request rule `[현재 스토리라인]을 [수정 요청]대로 고치세요. 요청이 다루지 않는 문단과 사진 배치는 그대로 두고, 첨부 사진과 영상은 모두 정확히 한 문단에 한 번씩 두세요.`
- `StorylineCompletionBudget` is a typed constant in `internal/generation` at the write floor (8192): the storyline is short, but reasoning shares the budget (GEN-22).
- Factor the observe step out of `Generate` into a helper both handlers call, so reuse, provenance and the non-shrinking snapshot stay one implementation (GEN-10 GEN-11).
- The job stage label copy (스토리라인 작성 중) is T435's.
- No comparison runs from a storyline (GEN-72).
- Checking a real model is a paid call: ask the owner first.

- Both start requests carry the picker's models (`observe_model`, `write_model`; the revision `write_model`), as `StartGeneration` does: the server holds no per-post model, so the precondition checks need them.

- The storyline request shows the attachments still attached that the frozen observations cover; one attached later without an observation is not shown.
- The storyline prompt's template section keeps the heading, legend and body form but drops the title form and the template/voice precedence line (there is no title and no voice here).
