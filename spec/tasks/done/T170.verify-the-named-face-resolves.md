# T170 Fail when a text renders in a face it did not ask for
> st:done@260915 | ssot:CDS-52 CDS-17 | base:CDS@16 ARCH@2 | dep:T166

## goal
A font family the renderer cannot resolve stops the render instead of silently substituting another face.

## acceptance
- [v] the renderer validates at construction that every `faces` value in `design.json` matches a family the bundled font file actually declares, reading the TTF `name` table (IDs 1 and 16)
- [v] a value that does not match, or that is not a parsable CSS font-family (any component beginning with a digit), fails `NewRenderer` with a named error rather than starting
- [v] V19 is recorded in the verifier's check list so the contract is visible beside the others
- [v] test: `"Paperlogy 8 ExtraBold"` is rejected and `"Paperlogy"` accepted against the bundled file
- [v] test: `NewRenderer` fails with the unparsable value and succeeds with the corrected one
- [v] `cd backend && test -z "$(gofmt -l .)" && go vet ./... && go build ./... && go test ./...`

## impl notes
- the defect this closes: `faces.paperlogy` was `"Paperlogy 8 ExtraBold"`, which resvg cannot parse as a CSS font-family, so it fell back to Pretendard and every hook, title and 크게 강조 has rendered in the wrong face since the face was bundled — silently, because resvg only warns on stderr
- validate at construction, not per render: the set of faces is fixed at boot, and a startup failure is the cheapest place to catch a constant that is wrong
- do not parse resvg's stderr for the warning — it is not a contract, and a warning that changes wording between versions would make the check unreliable
- T166 fixes the value itself; this task makes the class of mistake impossible to ship again

## result
- Added startup V19 validation in media/font_family.go and NewRenderer: every configured face must match TTF name ID 1 or 16 and consist of parsable unquoted CSS family components.
- ErrFontFamily names the failing faces key and requested family. Missing bundled mappings, numeric name components and family mismatches fail before overlay loading; no stderr matching or fallback.
- Bundled-font and constructor regressions pass for both incorrect and corrected Paperlogy names. Full backend gofmt/vet/build/test gate passes; unrelated FE/agent/generated gates retain T166's verified result.
- No SSOT deviations.
