# T410 The 분야 phrase batch, its Naver search client and its table are removed
> st:done@260926 | ssot:QUAL-1 QUAL-23 QUAL-25 QUAL-26 QUAL-47 | base:QUAL@5 | dep:T409

## goal
The API no longer starts a phrase batch, reads Naver search credentials or holds `field_phrase_lists`. The `naversearch` package is gone, and the 분야 catalogue keeps its ids and names, with no query strings.

- [v] `backend/internal/naversearch/` no longer exists and nothing imports it; `quality.Service` has no phrase collaborator; `quality.Field` has no `Query`; M1–M4 measurement and `quality.Known`/`FieldByID` behave exactly as before
- [v] new goose migration (next free number, after T409's) drops `field_phrase_lists`; Down recreates it empty with 0077's DDL; migration test in the `migration_0083_test.go` pattern; `TestMigration0077IsIdempotent` no longer expects the table

- [v] verify BE (ARCH-26) · `pnpm gen:sql && git diff --exit-code -- backend` · `pnpm lint:retirement`
