# T212 Writing call 2 writes the narration
> st:todo | ssot:CLIP-135 CLIP-134 CLIP-137 CLIP-138 CLIP-63 CLIP-64 CLIP-122 CLIP-118 CLIP-116 | base:CLIP@31 CDS@20 ARCH@3 | dep:T211

## goal
Write the captions and the AI intro/outro slot rows over a resolved flow, with absolute output intervals, grounded on facts, observations and the instruction, and admitted without overlap.

## acceptance
- [ ] `ai.Service.Narrate(ctx, model, clip.NarrationInput{PlanningInput, Flow clip.EditPlan}) (clip.EditPlan, llm.Usage, error)` builds `narrationPrompt` and `schemas/narration.schema.json`: `captions[]{id, text, short_text, keyword, start_ms, end_ms, observation_refs, fact_refs}` and `slots[]{element_id, rows, short_rows, observation_refs, fact_refs}`
- [ ] the request carries the flow as `cuts[]{id, source_id, start_ms, end_ms, rate_permille, output_start_ms, output_end_ms, observation_ids}` with `output_duration_ms`, plus `project_instruction`, `template_guide`, `global_values`, `item_groups`, `item_hints`, `analyses`, `generated_region_slots`
- [ ] the contract states: captions are one narration spoken over the finished flow; intervals are absolute output times that may cross cuts and need not describe the frame beneath; captions never overlap; at most `Cuts` (100) captions; text within CDS-25 (2 lines × 11 characters by CDS-20) and a rapid phrase within 14; every number needs a `fact_ref`, a description cites `observation_refs`, an experiential claim is written only when `project_instruction` is present; the response may not change cuts
- [ ] admission per caption: interval inside the output and disjoint from every earlier-starting caption (else `caption_overlap`); CDS-41 floor 900 + 90 × chars ms met by the text, else `short_text`, else extending the end into free room, else `caption_floor`; `GroundNarration` (T210); character bounds → `composition_generated_bounds`; repeated sentence → `repeated_copy`
- [ ] AI slot rows are repaired through the existing `attachRegionRows` ladder; a `cuts` key or an unknown cut id in the response is ignored with `composition_generated_identity`
- [ ] no notice is recorded for a moment without a caption, a fact not stated or a source not used; `copy_not_generated` is never recorded (CLIP-138)
- [ ] tests: payload shape; the overlap and floor ladder; grounding with and without an instruction; slot rows still repaired; verify BE (ARCH-26)

## impl notes
- attach through a new `attachNarration` beside `attachCompositionCopy`; the latter survives only for the slot rows (`attachRegionRows`) and frozen legacy snapshots
- evidence for a caption is `selectedReferences(ids, union of every cut's evidence, false)` — a caption may cite any selected footage, not only the cut beneath it
- `NarrationCompletionTokens` 32768 (owner's choice, generous first); phrases per caption stay bounded by `design.Rapid.MaxPerCut`
- caption ids from the model are provisional; the server assigns `narration-N` in start order (T210 minting rule) and records the model id nowhere
- CLIP-118 declared maxima apply to slots only; captions take CDS-25's own bound
