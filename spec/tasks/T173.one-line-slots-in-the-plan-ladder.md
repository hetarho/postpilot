# T173 Keep generated slot text to one line through the plan ladder
> st:todo | ssot:CDS-77 CDS-55 CLIP-106 CLIP-107 CLIP-108 CLIP-112 | base:CDS@16 CLIP@23 ARCH@2 | dep:T167 T169

## goal
A generated intro or outro slot that overflows its one line is shortened or omitted with a notice before the plan freezes, so the renderer's slot limit never fails a paid generation.

## acceptance
- [ ] the writer prompt names, for each `kind="ai"` hook/ending row, its slot's one-line limit (`chars` of the preset slot's type) and says the slot is a single line; the legacy "hook is the opening card's title" instruction and the plan-level `hook` request are gone
- [ ] `ai/plan_ladder.go` treats a generated slot text with a newline or more than its limit as a repairable rule: it tries the grounded shorter text first, then omits that slot with a CLIP-108 notice naming what the intro or outro no longer shows; the notice sits beside the element in step ②
- [ ] fixed and answer-bound slots never enter the ladder; their overflow stays the parser's and renderer's authored error
- [ ] test: a 12-character generated `t.hook` slot is shortened when a grounded alternative fits and omitted with one notice when none does; the remaining slots keep their positions
- [ ] test: a fixed slot over its limit is untouched by the ladder and refused by the renderer
- [ ] `cd backend && test -z "$(gofmt -l .)" && go vet ./... && go build ./... && go test ./...`

## impl notes
- CDS-77 splits by authorship: generated text is repairable under CDS-55 and CLIP-106, authored text is identified under CDS-64 — the ladder must read the row's effective `kind` (T169's per-row override) before touching anything
- the "grounded shorter sentence" step already exists for captions in `removeInvalidGeneratedCopies`; reuse its grounding check so a shortened slot still passes CLIP-63
- notices use the owner-language text convention T164 set (what the clip does not show, never the check name), e.g. 아웃트로의 마무리 문장을 한 줄에 담을 수 없어 뺐어요
