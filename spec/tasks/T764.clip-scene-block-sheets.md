## goal
Each scene block opens its own sheet for trimming, splitting at the playhead, rate and source sound; captions and spoken segments open theirs; blocks reorder by drag, touch and keyboard; new cuts start from an observed scene.

## acceptance
- [ ] a block's sheet (shared `Sheet`, bottom sheet below `sm:`) trims the cut's source range with precise source-time entry (`ClipTimeField`), splits at the preview's playhead, sets the fixed rate among the values the source admits and the source sound; each change shows in the preview without closing the sheet (CLIP-55)
- [ ] `장면 추가` opens the observed-scene chooser and inserts the cut after the selected block (CLIP-67)
- [ ] blocks reorder by a drag handle, a phone move control (위로/아래로) and keyboard (`Alt+ArrowUp`/`Alt+ArrowDown` on the focused block), each announced and undoable (THEME-32/33)
- [ ] a caption opens its sheet over a representative frame from the cut where it starts, editing interval, phrases, position, size and style sample (CLIP-143, CLIP-191); a spoken segment opens its sheet for its script and marks changed speech stale (DUB-20/21)
- [ ] the persistent `ClipItemProperties` panel and T763's temporary `세부` entry are removed; no operation the timeline offered is lost (trim, split, reorder, add, rate, sound, caption timing/appearance, segment script)
- [ ] undo/redo spans block, caption and segment edits; no undo or redo synthesizes speech
- [ ] tests: `features/correct-clip/ui/ClipSceneBlockSheet.test.tsx` (trim with time entry, split at playhead, rate choices limited by source, sound toggle), `ClipSceneBlocks.test.tsx` reorder cases (drag handler, move control, keyboard, undo), updated `ClipCaptionStage.test.tsx` and `ClipCutAssemblyControls.test.tsx`, a segment-script sheet test; `pnpm --filter ./frontend exec vitest run src/features/correct-clip src/widgets/clip-workspace src/pages/clip` plus tsc, eslint, prettier, steiger and `pnpm lint:style` pass

## impl notes
- Reuse the controls inside `ClipItemProperties.tsx`, `ClipCutAssemblyControls.tsx`, `ClipTextControls.tsx`, `ClipCaptionStage.tsx` and `ClipCaptionStylePicker.tsx` as sheet bodies; split `ClipItemProperties` into `ClipSceneBlockSheet` (cut), `ClipCaptionSheet` and `ClipSegmentSheet` rather than keeping one switchboard.
- Operations stay in `useClipCorrection` (`splitCut`, `addCut`, `setSourceSound`, `dispatch` reorder/trim/rate); add a `moveCut(id, delta)` command there if reorder has none, recorded in correction history.
- Rate options keep the existing source-admitted list (CDS-68 via the current rate helper); no new constants.
- Sheet open never pauses or hides the preview beyond what `Sheet` overlays on a phone; closing retains selection and playhead (CLIP-53).
