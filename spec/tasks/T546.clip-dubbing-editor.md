## goal
Make dubbing usable before generation and through the contextual editor without implicit synthesis.

## acceptance
- [ ] ① and the empty/existing dubbing track expose narration enablement, account-confirmed voices/sample playback and a path to create a voice; ordinary editing requires none.
- [ ] Script edits show exactly which segments need regeneration and the quote for remaining work; caption/volume changes invoke no synthesis and voice change stales all speech.
- [ ] Too-long regenerated audio offers explicit retiming or script revision; nothing changes owner cuts/caption wording/timing before the selected action is reviewed and committed.
- [ ] Tests cover same-voice reuse, removal/unavailable profile, quote expiry, partial failure, explicit AI script revisions, disabling/re-enabling narration and unchanged captions; review phone/desktop and both themes.

## impl notes
- Use entities/spoken-voice and the clip speech projection through feature/entity APIs; widgets compose voice creation navigation and query invalidation through entity @x boundaries. Do not put supplier model controls in the clip editor.
- The script editor keeps stable segment ids across text edits, explicit add/remove/split operations and undo/redo. Selected segment context exposes playback, wording and readiness; existing stale audio/result is revision-labelled. Quotes occur only on the generate/regenerate action after save flush.
- For a duration conflict, preview an explicit proposed speech placement and footage retiming using existing eligible source/rate bounds; applying requires a whole validated plan patch under expected_revision and one undo entry. Protected caption intervals are changed only if the reviewed proposal explicitly includes them; their owner wording is always preserved.
- If no valid footage proposal fits within chosen/max duration or protected caption rules, retiming is unavailable with its reason and script revision remains offered. Merely choosing script revision opens editing; it never automatically calls the writer or TTS.
- Independent source-track master volume and narration master volume are linear gain 0..1, default 1, with source retention still off by default and existing per-cut source volume preserved. Zero gain is intentional mute, not a missing-asset excuse. Keep these values in the plan and render fingerprint.
- AI edit requests are explicit selection/target actions in the new composer; on narrated clips a narration target changes spoken text and offers separate speech approval. Caption update is T543 wording-only and remains an independent action.
