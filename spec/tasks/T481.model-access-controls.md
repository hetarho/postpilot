## goal
Make the catalog and every model chooser explain free availability, plan locks and balance separately, without silently replacing saved choices.

## acceptance
- [ ] Admin model management has an explicit free classification/group filter across the existing purpose tabs; individual and bulk free classification show server validation failures and retain preview/apply atomicity.
- [ ] Ordinary selectors/pair forms order free then value/balanced/premium/top, hide unclassified registrations and show locked higher grades with the required plan. Missing compatibility, provider, plan and balance are distinguishable; the current saved locked model remains visible.
- [ ] A downgrade/preset refusal never mutates selection in a mount effect; the owner explicitly selects an eligible model. Recommendation errors show all offending refs and applying a partially invalid set changes none of the seven slots.
- [ ] Free models explain possible provider daily/rate/capacity limits without an individual daily-job guarantee, forced payment at zero balance or automatic paid fallback. A feature without a compatible free model explains its unavailable state.
- [ ] Voice check/reflection comparison and clip selectors use the same entitlement projection; winner adoption handles a newly locked winning model without losing the completed comparison. ko/en, keyboard/touch and narrow-layout tests cover each refusal and recovery.
- [ ] Run ARCH-25; mapper/component tests cover Light, all four grade ceilings, retained locked selections, zero-balance free use and bulk free-group round trips.

## impl notes
- Keep Connect access in entities/model-catalog and reuse shared selection components; do not build separate tier-specific catalogs in each page. Extend existing model view types from T480’s machine fields.
- Use the existing normalized reason catalogs and slice-local ko/en resources, never raw server message strings. All primary actions recompute disabled/reason state after plan queries invalidate.
- Admin group controls are a view of per-purpose classification, not a new provider or sixth purpose tab. Keep virtualization and search capable of reaching unmounted catalog entries.
- Respect the voice comparison work produced by T474; its model pair uses this shared selector. No changes to voice generation prompts, badges, fingerprints or experimental verdict logic belong here.
