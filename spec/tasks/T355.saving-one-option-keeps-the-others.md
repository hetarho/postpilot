# T355 Saving one generation option never touches another
> st:todo | ssot:- | base:POST@13 ARCH@9 | dep:-

## goal
Every member of `SavePostGenerationOptions` keeps its stored value when absent, natural length is an explicit clear, and no save rewrites a member it does not name, so a tick or a 기억 toggle can never put back a stale 목표 글자 수.
