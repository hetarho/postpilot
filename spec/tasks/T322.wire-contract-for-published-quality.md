## impl notes
- This is the delta's only proto change (ARCH-41: one file and one service per rpc family). Later tasks consume these names verbatim. T335 may amend `quality.proto` alone, and only if an amendment proves unavoidable.
- A message-typed field already carries presence, so `QualityRuleTicks` and `GuidelinePresetFields` are plain message fields with no `optional`. That follows the `ReobserveSelection` and `GuidelineScopePatch` precedent.
- `post.proto` adds `import "postpilot/v1/quality.proto";`.
- `enum BlogField` in QUAL-23 order (R1): `BLOG_FIELD_UNSPECIFIED = 0` (없음, a real answer), `BLOG_FIELD_RESTAURANT = 1`, `BLOG_FIELD_CAFE = 2`, `BLOG_FIELD_DOMESTIC_TRAVEL = 3`, `BLOG_FIELD_FASHION_BEAUTY = 4`, `BLOG_FIELD_PRODUCT_REVIEW = 5`, `BLOG_FIELD_PARENTING_MARRIAGE = 6`, `BLOG_FIELD_PETS = 7`, `BLOG_FIELD_INTERIOR_DIY = 8`, `BLOG_FIELD_DAILY_LIFE = 9`.
- The `BlogField` comment says SQL stores the ASCII id, never the number.
- `enum ReplacementSurface { REPLACEMENT_SURFACE_UNSPECIFIED = 0; REPLACEMENT_SURFACE_TITLE = 1; REPLACEMENT_SURFACE_TAG = 2; REPLACEMENT_SURFACE_BODY = 3; }` (R29).
- `message ReplacementCandidate { ReplacementSurface surface = 1; int32 index = 2; string source = 3; repeated string phrases = 4; }`.
- The `ReplacementCandidate` comment states GEN-53 and R28: `index` is the tag index for TAG, the block index for BODY and 0 for TITLE; the candidate holds only while `source` still stands there; `phrases` holds at most 3.
- `message QualityRuleTicks { repeated QualityMetric metrics = 1; }` goes beside `ReobserveSelection`.
- `Post` gains fields from 27, HEAD's next free number: `string published_url = 27` ('' = none, stored normalized, POST-77) · `string published_at = 28` (RFC3339 or '', restamped on replace, POST-75) · `BlogField field = 29` · `repeated ReplacementCandidate replacement_candidates = 30` · `repeated QualityMetric quality_rules = 31` (the saved ticks).
- The `Post.status` comment becomes `draft | review | finalized | published` and names SavePostPublishedUrl as the only way in and out of published.

- `SavePostGenerationOptionsRequest` gains `QualityRuleTicks quality_rules = 5`; fields 1–4 are taken. Absent keeps the ticks, present replaces them, and present-and-empty clears them (R23).

- `service QualityService` declares `rpc GetPostMeasurement(GetPostMeasurementRequest) returns (GetPostMeasurementResponse) {}` and `rpc GetAccountQuality(GetAccountQualityRequest) returns (GetAccountQualityResponse) {}`.
- Both quality requests are `{ string slug = 1; }`. GetAccountQuality takes the slug because rule texts render in that post's target language (R22).
- `enum QualityMetric { QUALITY_METRIC_UNSPECIFIED = 0; QUALITY_METRIC_TITLE_SATURATION = 1; QUALITY_METRIC_CROSS_POST_PHRASES = 2; QUALITY_METRIC_IN_POST_REPETITION = 3; QUALITY_METRIC_COMPOSITION = 4; }` covers M1–M4 (R3).
- `enum QualityVerdict { QUALITY_VERDICT_UNSPECIFIED = 0; QUALITY_VERDICT_OVER_BAND = 1; QUALITY_VERDICT_WITHIN_BAND = 2; QUALITY_VERDICT_BELOW_MINIMUM = 3; QUALITY_VERDICT_ABSENT = 4; }` (R3, QUAL-12).
- Every measured value is `optional double`, so an absent value means it cannot be computed and never reads as zero (QUAL-40).
- Shares are fractions in [0,1]. M4 counts are doubles because the account value is a median.
- Band edges ride as plain doubles, so the FE mirrors no band (R21) yet can still say where the band sits (QUAL-6).
- `QualityTitleSaturation { optional double share = 1; double share_warn_above = 2; }` is M1, account only.
- `QualityCrossPostPhrases { optional double share = 1; double share_warn_above = 2; }` is M2.
- `QualityInPostRepetition { optional double repetition_share = 1; optional double title_relevance = 2; double repetition_share_warn_above = 3; double title_relevance_warn_below = 4; }` is M3.
- `QualityComposition { optional double char_count = 1; optional double photo_count = 2; optional double distinct_block_types = 3; optional double average_sentence_length = 4; double distinct_block_types_warn_at_or_below = 5; }` is M4. Only `distinct_block_types` is banded (QUAL-10).
- `QualityReading` fields: `QualityMetric metric = 1; QualityVerdict verdict = 2; int32 minimum = 3; int32 published_count = 4; string rule_text = 5;`.
- `QualityReading` ends with `oneof values { QualityTitleSaturation title_saturation = 6; QualityCrossPostPhrases cross_post_phrases = 7; QualityInPostRepetition in_post_repetition = 8; QualityComposition composition = 9; }`. The set member matches `metric`.
- `rule_text` is set only by GetAccountQuality, and only on OVER_BAND (R22).
- `GetPostMeasurementResponse { int64 content_revision = 1; repeated QualityReading readings = 2; }` carries M2, M3 and M4 in that order, never M1 (QUAL-36). There, `minimum` and `published_count` mean something on M2 only.
- `GetAccountQualityResponse { repeated QualityReading readings = 1; }` always carries all four metrics, in enum order (POST-81).
