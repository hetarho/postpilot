# T405 ① picks intro and outro presets from the renderer's numbered slot drawings
> st:todo | ssot:CLIP-165 CLIP-111 CDS-88 CDS-22 | base:CLIP@45 CDS@26 | dep:T404

## goal
① offers all eight intro and seven outro presets as a selectable grid, each tile the renderer's own drawing of that preset's slots labelled 슬롯 1, 슬롯 2 … at their size and place.

## acceptance
- [ ] proto: `ClipPlanService.GetClipRegionPresetSamples(GetClipRegionPresetSamplesRequest{project_id, slot_label})` returns `{ratio, canvas, intro[], outro[]}` of `ClipRegionPresetSample{preset, svg, box}`; `slot_label` must contain `{n}` and is at most 16 characters, otherwise `INVALID_ARGUMENT`; `pnpm gen:proto` diff-clean (ARCH-28)
- [ ] the API draws each preset through the real layout and region overlay (`layoutComposition` + `declaredSVG` on a synthetic plan in the project's ratio, every slot filled with `slot_label` numbered in slot order, no footage ground so no scrim), prefixes ids per preset like caption fragments, and answers with `Cache-Control: private, no-store`; a service test covers both regions and every preset id in design.json
- [ ] FE `useClipRegionPresetSamples(projectId, slotLabel)` in `entities/clip-plan/api` (sibling of the caption samples hook, `staleTime: Infinity`, key per project and label)
- [ ] `ClipDesignSelection` replaces both SegmentedControls with a `role="radiogroup"` grid per region (2 columns under `sm`, 4 at `sm` and up) of `role="radio"` tiles — the drawing on a dark 9:16 (or project-ratio) ground above the preset's name, `aria-checked` on the chosen one, arrow keys move focus and choice as in `SentenceFeedback`; while samples load or when they fail the tiles show names only and stay selectable
- [ ] i18n (ko/en) names for all 15 presets under `composition.design.intro_<id>` / `outro_<id>` (ko: A 크기만, B 위아래 가로선, 매거진 커버, 명조 매거진, 프레임 박스, 큰 외곽선 글자, 로어서드, 주아 스티커 · B 가로선 구분, E 점수 강조, 엔딩 크레딧, 세로 막대 로어서드, 칩 줄, 세 줄 목록, 원형 도장) and the slot label (`슬롯 {n}` / `Slot {n}`); `CompositionDesignThumbnail` and its now-unused imports are removed
- [ ] the fake server (`test/clips.ts`) answers the new RPC; `pages/clip/ui/ClipDesignSelection.test.tsx` is rewritten for radios: the stored preset is checked, choosing another sends it, a template never overrides it, a failed sample request still lets the owner choose
- [ ] BE gate (ARCH-26), FE gate (ARCH-25) green; FE self-audit (ARCH-17: proto symbols only in `shared/api` and entity `api/`)

## impl notes
- the language of the slot label comes from the browser (the FE sends its own `t('composition.design.slotLabel')`), so the server stays language-free and the drawing still is the renderer's (CLIP-159's rule that the browser invents no drawing)
- samples depend only on the ratio and the label, but the key stays per project like the caption samples hook, since the ratio is read from the project
- ground for the tiles: a flat `#1B1D21` rect in the FE `<svg>` behind the fragment — a UI surface, not footage — with the fragment scaled into a 9:16 box; the tile shows the whole canvas so edge-anchored presets read at their true place
- reuse `previewOwners` locking and the 5 s preview timeout from `app/caption_style_sample.go`
