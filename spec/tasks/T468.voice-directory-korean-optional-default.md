## goal
No account gets a voice it did not make: sign-up and `adduser` create none, a voice is created by name alone as a Korean voice not yet made, the 기본 is optional and any voice deletes, and `/voices` lists voices as 내 글's whole-row links with 기본 and 삭제 on the voice's own title row.

- [ ] the description seed is gone: the `seed_voice` kind and handler, the seed prompts, `CreateVoice.description` / `analyze_model` and `CreateVoiceResponse.job_id` (reserved), `VoiceProfile.seed_failure` (11, reserved), `VoiceDescriptionMaxChars` and `VOICE_DESCRIPTION_TOO_LONG` (retired); a migration fails queued or running `seed_voice` rows and recreates the voice-kind index and duplicate-work trigger with `analyze_voice` alone; the queued-personalization boot sweep (and its call in `contexts.go` 96-100) is deleted
