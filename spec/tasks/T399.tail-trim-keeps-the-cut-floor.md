# T399 the tail trim never leaves a sliver cut
> st:todo | ssot:- | base:ARCH@11 | dep:-

## goal
Trimming a generated flow to its target duration stops each cut at CDS's 1.2 s cut floor and takes the rest from the cut before it. The old overlap floor is used only for an overrun the 1.2 s floors cannot absorb, so no cut becomes a sliver when the flow could avoid it.

## acceptance
- [ ] Failing-first regression test (F3 bug): a flow whose tail cut must give up more than its length minus 1.2 s ends with that cut at exactly 1200 ms of output and the cut before it shortened by the remainder. The total equals the target, and each trimmed cut carries its `plan_target_duration` notice
- [ ] a cut already shorter than 1.2 s is neither trimmed nor lengthened by the floor pass
- [ ] an overrun larger than every cut's room above 1.2 s still reaches the target through the old floor (`transition + 1`, plus the next cut's transition), so `validatePlan` does not refuse it
- [ ] Behavior otherwise unchanged: `TestPresetTargetYieldsToTheApprovedDuration`, the multi-source tests and existing tests pass as written
- [ ] verify BE: `cd backend && test -z "$(gofmt -l .)" && go vet ./... && go build ./... && go test -timeout 30m ./...`
