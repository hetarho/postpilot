## goal
Move the use-case layer of the flat `internal/clip` root (`service.go`, `sources.go`, `quotes.go`, `finalization.go`, `correction*.go`) into `clip/app`, leaving the root as pure domain, and inject the clock where the moved code calls `time.Now()`.

- [ ] `internal/clip` root imports no store, rpc, `database/sql`, or `context`-carrying service types: it holds `types.go`, `render.go`, `composition_verify.go`, `pace.go`, `caption_*.go` and the other pure files (≈3.5k lines)
- [ ] `clip/app` holds `Service`, sources, quotes, finalization, correction (with T270's sagas) and depends on root + the ports; `clip/rpc` calls `clip/app`; `clip/store`, `clip/ai`, `clip/media` import root only
- [ ] the 7 bare `time.Now()` in the old `service.go` use the injected `now func() time.Time`; a test pins one time-dependent path with a fixed clock
- [ ] `applyNativeCorrection` (208 lines) and `VerifyCompositionManifest` (203) are split into named steps ≤80 lines each without behaviour change (existing tests pass)
- [ ] types a subpackage needs stay in root; nothing in `clip/store`/`ai`/`media` imports `clip/app` (checked by a `go list -deps` test)
- [ ] behaviour unchanged: ARCH-26 passes; the release smoke stage runs once locally (ARCH-37)
