## goal
Move every placement and style decision out of the model and into the CDS rule tables: the model reports scenes and writes grounded copy, the compiler classifies, selects, times, falls back and verifies.

## impl notes
- the model stops choosing style and position because CDS-7 needs the same input to give the same output and a model choice cannot be replayed; the model is still the only writer of copy, `short_text`, `hook` and `scene`, which are judgments a table cannot make
- `short_text` in the same call replaces CDS-41's "regenerated at most twice": the credit ceiling approved before the run counts every planned call (CLIP-19, QUOTA-45) and T075 rules out repair calls; asking for the alternative up front costs a few tokens and keeps the fallback deterministic. This is a deliberate reading of CDS-41 to record in the result and, if the owner disagrees, to return through update-ssot CDS
- `subject` replaces `avoid` because CDS-38 needs the subject's area for the 15 % rule, not a keep-out box; the observe prompt names the detection order so the same footage yields the same box
- the compiler extends a cut only inside the segment the cut already came from (CDS-41 "within the source"), which is the same guard `composeTimeline` uses today
- proper-noun detection is intentionally narrow (answers' 상호 and 메뉴 values plus capitalised Latin tokens): a general Korean NER is out of scope, and every number is checked exactly, which is where the advertiser risk sits (CDS-42)
- `design.json` carries the CDS-40 table as data so a table change is a JSON edit plus a pinned test, never a code path
