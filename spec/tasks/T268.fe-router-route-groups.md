# T268 the route tree is assembled from route groups
> st:todo | ssot:ARCH-16 ARCH-24 | base:ARCH@5 | dep:-

## goal
Split the 621-line `app/routes/router.tsx` into one file per route group and let pages export their own search schemas, so a new screen edits its group file and its page only.

## acceptance
- [ ] `app/routes/` holds `router.tsx` (root route, tree assembly, ≤120 lines) plus group files (`auth.ts`, `posts.ts`, `voices.ts`, `clips.ts`, `templates.ts`, `models.ts`, `billing.ts`, `publishing.ts`, `account.ts`, `admin.ts`, `marketing.ts`) each exporting its `createRoute` list
- [ ] every `validateSearch` schema that belongs to a page is exported from that page's `index.ts` (`searchSchema`) and imported by the group; `beforeLoad` guards that are shared (session required) live once in `app/routes/guards.ts`
- [ ] the legacy voice-tab redirect (`:459-505`) lives in `voices.ts` with a unit test for each legacy path
- [ ] a route-tree test pins the full set of paths before and after (snapshot of `routeTree` paths), so the split changes no URL
- [ ] behaviour unchanged: page tests pass; ARCH-25 passes
