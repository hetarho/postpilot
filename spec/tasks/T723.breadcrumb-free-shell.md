## goal
The shell drops the breadcrumb at every width, places the three channel links in the phone's main header row with an underline current mark and no background, and gives every child route one back link at the top of its content.

## acceptance
- [ ] below `lg` the header is one row — brand, the three channel links, account menu — with no second shell row; at 320 px everything fits with no horizontal page scroll and every link keeps the 44 px pointer floor
- [ ] the current channel link has `aria-current="page"`, the current-link colour and a 2 px underline indicator, and no background fill in any state; other channel links show neither underline nor fill
- [ ] no breadcrumb at any width: the desktop breadcrumb row and the phone header location are gone; `Breadcrumb` and its tests are deleted from `shared/ui/navigation`, `ContextualReturn` stays
- [ ] a child route (one with a structural ancestor or a validated contextual return) shows exactly one `ContextualReturn` back link at the top of its content at every width; none on /, the channels, /settings, /setup, /posts/$slug, /clips/$id, /tests, /tests/records/* or /tests/* other than /tests/history
- [ ] `--spacing-chrome` measures the single header row; sticky children (editor progress bar, docks) still sit below it
- [ ] tests pass and cover the change: `app/routes/navigation.test.tsx` (one header row, no breadcrumb landmark, current link underline without fill), `app/routes/navigation-hierarchy.test.tsx` and `source-return.test.tsx` (the back link names the structural parent or the contextual return), `app/routes/router.test.tsx` updated, `shared/ui/navigation/Navigation.test.tsx` keeps only ContextualReturn cases

## impl notes
- `AuthenticatedLayout`: the channel `nav` loses `order-last w-full pb-2` and sits in the row between brand and account (`flex-1 justify-center` below `lg`, beside the brand from `lg`); delete both `Breadcrumb` renders and the desktop breadcrumb row. The back link renders as the first child of the content column above `<Outlet />`, in normal flow (not sticky), padded like the page gutter.
- Back-link visibility reuses the current exclusion test (`/^\/(posts|clips)\/[^/]+$/`, `/tests/records/`, `/tests`, `/tests/*` except `/tests/history`) and adds top-level destinations and /setup; `ContextualReturn` already prefers `returnTo` over the last ancestor.
- Channel link style: no `buttonStyles` ghost (its hover/active fills are a background); a link with `min-h-11 px-2 lg:px-3`, current = `text-link-fg-current underline decoration-2 underline-offset-8`, others `text-content-secondary hover:text-content-primary`. Focus ring from the shared focus utility.
- 320 px fit: brand link keeps its 44 px target; shrink the `Logo` height below `sm` (e.g. `h-5 sm:h-6`) only if the row overflows in the browser check.
- Remove the `nav` i18n keys only the breadcrumb used (`locationLabel` etc.) once nothing references them; `location.*` keys stay for the back link and document titles.
