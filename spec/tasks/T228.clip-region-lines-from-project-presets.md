# T228 The project's presets decide how many intro and outro lines are drawn
> st:todo | ssot:CLIP-111 CLIP-147 CLIP-108 | base:CLIP@33 CDS@22 ARCH@3 | dep:T227

## goal
Fill the intro and outro from the outline's entries in order, as many lines as the project's chosen preset has slots, and record a CLIP-108 notice for each surplus line instead of refusing anything.

## acceptance
- [ ] every reader that used to take the region preset from the template body takes it from the project's `ProjectDesign` instead — `ai/composition_copy.go:regionSelection`, `ai/composition_prompt.go`, `ai/narration_prompt.go:generatedRegionSlots`, `media/regions.go`
- [ ] a region's lines are the rows of every outline entry in that role, concatenated in outline order, so two hook entries of one row each fill the same two slots as one hook entry of two rows
- [ ] a template with more lines than the project's preset has slots renders the first N and records one `region_line_surplus` notice naming the entry, and the generation completes
- [ ] `media/regions.go` no longer fails a surplus with `copy_limit`; the plan it receives can no longer carry one
- [ ] the notice is recorded where plan notices are recorded (composition admission / repair), never inside the media executor (`RecomputePlanNotices` contract)
- [ ] a notice clears when the owner's own edit removes its cause (CLIP-109) and shows in ② beside the element
- [ ] CDS-52 V20 verifies the rendered region against the PROJECT's selected preset
- [ ] tests: 3 intro lines against preset A (2 slots) renders 2 + 1 notice; the same body against preset B renders 2 with no notice; a zero-entry region renders no block (CDS-73)
- [ ] ARCH-26 verify clean, and the media smoke stage for the changed render path per ARCH-37

## impl notes
- the notice check name is `region_line_surplus` with action `removal`, added through `clip.AddPlanNotice`; CLIP-138 admits it because the SERVER dropped the line, unlike a writer's own choice.
- the surplus is knowable without footage — template lines against the project's preset — so compute it at composition admission where the other declared-input checks already run, not at render.
- `PlanningInput` already carries `Design` (`media/composition_admission.go:70`, `media/composition_layout.go:273` use `RegionPresets()`); the AI-side readers are the ones still reading the frozen body's attributes.
- do not reintroduce a default preset inside the composition package: `composition.DefaultDesign` went away with T227, and `clip.ProjectDesign.RegionPresets()` is the single resolution point (it already falls back to the shared defaults).
- ② shows the notice through the existing notice projection; no new owner-facing surface.
