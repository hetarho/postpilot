## goal
The model lab's third tab, 말투 반영, compares how the saved write pair reflects one made voice: both candidates write 검증's piece for one answered prompt from one frozen snapshot, the blind review shows both pieces beside the owner's answer with each piece's fingerprint comparison, and the owner's pick counts toward the write stage's leaderboard with adoption as its only follow-up.

## acceptance
- [ ] a migration adds `model_experiments.source` (`post` | `voice`, default `post`), `voice_prompt_key` and `voice_material_id`
- [ ] `StartVoiceReflectionExperiment(voice_id, prompt_key, candidate_a, candidate_b)` refuses a missing voice (`VOICE_REQUIRED`), an unknown or foreign one (`NotFound`), a tombstone, a voice not made, an unanswered prompt, the same model twice or a model not registered to the write stage, and a photo prompt unless both candidates declare `vision`; it freezes the voice's projection with that answer withheld, the prompt, the answer's text and a photo prompt's photo key into the snapshot, hashes it, records origin `lab`, and creates the experiment and its one job before any provider call
- [ ] each candidate makes one write call through the same prompt and call 검증 uses (T473); a candidate failure is retried alone against the original snapshot (MODEL-35)

- [ ] the 30-day content purge (MODEL-42) removes the snapshot's answer text and both pieces; deleting the voice is never blocked by one of these experiments
- [ ] FE: the stage switch reads 사진 관찰 · 글쓰기 · 말투 반영 on the compare and history pages (the leaderboard keeps 사진 관찰 · 글쓰기); the 말투 반영 tab carries the voice picker (made voices, the 기본 first and preselected), the answered-prompt picker of that voice, the saved write pair and `비교 시작`; its history lists voice-sourced experiments naming the voice and the prompt; the 글쓰기 history lists post-sourced ones
- [ ] the write pair uses the shared ListModels selection component and the start/adoption paths preserve shared model refusals; no local list/order or permission cache overrides MODEL-44 (free/locked projection is integrated by T480/T481)
- [ ] tests: experiment service, store and runner tests (preconditions, snapshot, candidates, verdict counted on the write board, adoption only), the migration test, FE `ModelComparisonPage` (말투 반영 tab), `ModelHistoryPage`, `ExperimentReview` / `CandidateComparison` (answer, pieces, comparisons), `ExperimentActions` (no apply), leaderboard unchanged

## impl notes
- Pricing integration: use the shared model validator and enqueue admission rather than a voice-owned authorization/credit path; propagate a refusal without creating work. T480/T481 implement the new free/paid classification and lock presentation over these completed endpoints; this task must not hardcode all-tier access or suppress those shared refusal states.
- Stage stays `write`; `source = 'voice'` tells the variant apart; `voice_id` (existing column) holds the frozen voice; `post_slug` is NULL; `target_language` is `ko`
- The voice context exposes `SnapshotReflectionInput(ctx, userID, voiceID, promptKey) (snapshot, error)` and `RunReflectionCandidate(ctx, snapshot, model) (piece, error)`, sharing T473's prompt builder and call, plus `CompareText(ctx, userID, voiceID, text) ([]ItemComparison, error)`; the experiment context declares them as ports (`experiment/ports.go`) adapted in `cmd/api/adapters_experiment.go` like the retired analyze hooks were; the snapshot prompt version is its own constant
- Proto: `rpc StartVoiceReflectionExperiment`; `ModelExperiment` gains `source` and `voice_prompt_key` (and the prompt text for display); `ExperimentCandidate`'s output `oneof` gains `voice_piece { text, repeated FingerprintItemComparison comparison }` on a new field number (6 stays reserved for the retired styleguide); `FingerprintItemComparison` is imported from `voice.proto`
- The history RPC filters `stage = 'write' AND source = 'post'` for 글쓰기 and `source = 'voice'` for 말투 반영; the leaderboard reads every write verdict regardless of source (MODEL-67)
- Snapshot answer text and pieces are private content and fall under `ExperimentContentPurger` and the 30-day sweep with the rest of the snapshot
- Reasons: reuse `VOICE_REQUIRED`, `VOICE_NOT_MADE`, `VOICE_CHECK_PROMPT_UNANSWERED`, `VOICE_CHECK_PHOTO_UNSUPPORTED` and the existing pair and experiment reasons, mapped at the experiment rpc edge
- FE: `ModelStageTabs` gets a third value `voice` for the compare and history pages only; `ModelComparisonPage` renders the voice and prompt `Listbox`es (prompt labels are the prompt texts, a photo prompt disabled with the reason unless both candidates declare `vision`) above the write pair form it shares with 글쓰기; `CandidateComparison` renders `voice_piece` with the owner's answer on top and `FingerprintComparison` (label `이 후보`) under each piece; `ExperimentActions` offers `선택` and adoption, no apply
- Do not run concurrently with another task in this tree that regenerates proto or adds a migration
