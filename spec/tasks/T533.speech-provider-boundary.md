## goal

## acceptance
- [ ] The unchanged completion connection boots and works with speech omitted or credentials absent; invalid speech configuration fails boot, and disabled speech returns normalized product reasons before network calls.

## impl notes
- Keep Complete intact and add behavior-shaped VoiceDesigner/VoiceConfirmer/SpeechSynthesizer ports and typed audio/unit evidence in internal/llm. Adapter constructors remain in cmd/api. Read current official docs under ARCH-33 before implementation.
- Initial adapter: internal/llm/elevenlabs, using net/http, xi-api-key and https://api.elevenlabs.io. Add optional top-level speech_provider beside the exactly-one providers list; shipped connection id elevenlabs, adapter elevenlabs, api_key_env ELEVENLABS_API_KEY. No models/prices in yaml.
- Use POST /v1/text-to-voice/design, POST /v1/text-to-voice and POST /v1/text-to-speech/{voice_id}/with-timestamps. Official contracts: https://elevenlabs.io/docs/api-reference/text-to-voice/design ; https://elevenlabs.io/docs/api-reference/text-to-voice/create ; https://elevenlabs.io/docs/api-reference/text-to-speech/convert-with-timestamps . Design-model examples are documented capability candidates, not an automatically selected production model.
- Request mp3_44100_128 initially; keep original audio bytes immutable and report sample format. Provider duration/alignment is evidence to validate, not the clock authority. Decode bounded MP3 frame/sample counts in provider-neutral audio helpers, using a maintained pure-Go decoder selected from current official docs; reject corrupt audio and nonfinite/nonmonotone/out-of-duration timing. No subprocess media work in the API.
- Define named owning-context limits: provider deadline 5m, decoded audio at most 300s, individual encoded audio 8MiB, response body 40MiB and at most 3 candidates. Enforce response caps while reading, plus PCM allocation bounds before decode. Design description 20..1000 Unicode code points and preview text 100..1000 follow the documented initial adapter; disable automatic preview-text generation/enhancement and optional billable features.
- Return request ids and documented reported usage headers without assuming absent usage is zero. Preserve provider-neutral opaque voice handles internally; never expose supplier ids, credentials, raw base64 or diagnostic cost through customer DTOs. One issued audio call has no automatic retry.
