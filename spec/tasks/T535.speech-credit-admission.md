## goal
Reserve and settle audio work using its actual documented units without altering existing token-based job accounting.

## acceptance
- [ ] Server quotes bind exact profile/voice/input/call scope and expiry; forged, stale, changed-input, unknown-price and unbounded requests execute zero provider calls.
- [ ] Audio usage preserves request identity and typed reported units with token columns untouched; three returned design samples do not become three charges when one documented operation is billed.
- [ ] Real-SQLite tests verify ceiling enforcement, confirmed failure usage, unknown usage, cancellation/completion races, enqueue failure, duplicate settlement, grant expiry/reset crossings and master reference usage.
- [ ] Stored playback/metadata changes create no admission/event; existing completion admission and settlement suites remain green.

## impl notes
- Extend product-neutral usage.PlannedCall/Reservation/Event with a discriminated bounded unit budget and evidence, not voice/project nouns. Add append-only audio evidence storage and decimal arithmetic; preserve existing completion rows/mappings and migrate forward.
- An audio operation budget names design/confirm/speech, explicit ref, count, total input-character bound, optional supplier-credit/request/output bound and frozen price fingerprint. Character or supplier-credit pricing is eligible only with documented request limits and verified unit conversion; seconds-based output pricing also requires an enforceable duration ceiling.
- At llm wiring, meter every audio operation using usage.Work and deduplicate supplier request evidence without replaying the call. Resolve reported USD cost first, otherwise sufficiently reported applicable units at the frozen schedule. Never charge requested characters or the reservation as evidence of actual consumption.
- Use server-owned quote ids, canonical input SHA-256, 10-minute expiry, mandatory approved_max_credits and cancellation-policy version, following the existing clip quote shape while keeping audio product fields owned by its caller. One admission per explicit job; confirmation is separate quoted work only when its qualified path is billable.
- Official design billing describes one preview-text charge despite three candidates; saving occupies a supplier voice slot: https://elevenlabs.io/docs/eleven-creative/voices/voice-design . Validate the installation pricing evidence rather than copying retail subscription credits into product credits. Headers/units must be checked against current https://elevenlabs.io/docs/api-reference/introduction .
- Reusable voices need no creation admission; each later synthesis job requires current model entitlement. Once admitted, keep admission-period rights and frozen FX through settlement. Unused holds return to original lots and service-fault compensation remains separate.
