# T287 the write prompt stops describing the photographs
> st:todo | ssot:GEN-47 GEN-16 GEN-44 GEN-14 GUIDE-16 ARCH-24 | base:GEN@7 GUIDE@3 | dep:-

## goal
Add the altitude rule to the write prompt and stop the two constants that made describing the photographs the only safe thing to write.

## acceptance
- [ ] a new altitude constant pair (Korean + English) sits beside the grounding constants in `generation/prompts.go`, states that the observations are grounding and placement material rather than a list to describe, that no paragraph must point at a photo, and that inert visual detail (lighting, walls, ceilings, fixtures, room arrangement) is not written
- [ ] the altitude rule reaches the WRITE prompt only: a test asserts it is absent from the revise prompt and from both observe prompts
- [ ] `koreanGroundingWriteScope` / `englishGroundingWriteScope` state that the rule binds factual claims alone and leave the author's impressions, opinions and changes of subject writable
- [ ] `koreanNaming` / `englishNaming` no longer forbid a subject the memo alone carries; they forbid only writing something into the frame that the observations do not show
- [ ] every `write_prompt_*.golden` is regenerated and its diff is exactly these lines
- [ ] the `revise_prompt_*.golden` files do NOT change, and a test asserts the shared grounding core is still byte-identical in the write and revise prompts
- [ ] `NaturalnessBaseline` is untouched: `TestNaturalnessBaselineContract` passes unchanged
- [ ] ARCH-26 passes

## impl notes
- GUIDE-16 now counts four grounding constants; the altitude rule is the fourth and it is code, not config and not a row, exactly like its three siblings
- word it as subtraction, the way `NaturalnessBaseline` is worded: it forbids describing, it never licenses inventing. The grounding constraint keeps its full force — this task widens nothing about what may be stated
- place the altitude text in the static task rules after the grounding line and before the naming line, in both languages, so the golden stays readable top to bottom
- do not touch `NaturalnessBaseline`: GEN-17 pins its markers, its rejected folk rules and its 700-rune cap, and `naturalness_baseline_test.go` asserts all three
- the write prompt's byte identity is broken here on purpose. It invalidates the provider's prefix cache once, at the deploy, and nothing else — no payload, no job and no stored post changes
- `koreanNaming`'s replacement sentence must stay about the FRAME, not about sources: the memo is one of GEN-16's three legitimate sources and this line must never read as a ban on it again
