## goal
Admit private browser-prepared copies as untrusted artifacts and verify finite safe coverage before any provider call.

## acceptance
- [ ] A versioned preparation session binds owner/project/revision, source identities, profile/version and exact expected interval coverage; upload reservations permit only owned finite artifact slots.
- [ ] The server checks immutable object identity/bytes/hash, supported streams/geometry, decoded duration/cadence/audio and declared coverage through bounded copy verification, not client metadata alone.
- [ ] Forged duration/source/owner/profile, long hidden timelines, malformed copies, missing intervals, overwrite/replay and stale/deleted/finalized attempts authorize no provider call or credit reservation.
- [ ] Browser original measurements retain explicit client provenance; native Max rendering independently verifies its originals and cannot reuse those claims as native proof.
- [ ] Existing quote/checkpoint/reuse and source-retention rules remain bound to compatible accepted work; verification failure preserves originals/previous results and offers explicit continuation.
- [ ] Cancellation, restart, orphan/expired uploads and late reports clean private copies recoverably and settle once; validation capacity is bounded independently from the Max render queue.
- [ ] RPC/store/protocol and malicious-artifact tests plus matching real-binary verification smoke and full local checks pass; completed verified browser profiles remain gated on T603.

## impl notes
- Extend ClipSourceService additively with BeginClipAnalysisPreparation, ReserveClipAnalysisCopy, CompleteClipAnalysisPreparation and CancelClipAnalysisPreparation; return only bounded domain metadata, progress identities and short-lived private upload access.
- Persist preparation sessions/artifact manifests in clip-owned append-only-compatible tables with source fingerprint, object identity, profile version, interval offset/duration, expected/verified bytes and verification status.
- Use a bounded native verification media operation behind the existing lease protocol. Decode only the submitted <=60-second, <=720-long-edge, <=8-MiB copies with explicit frame/audio/geometry/time bounds; never transcode a full original on the qualified browser route.
- Reserve separate bounded verification capacity/worker role on the existing host where needed so a long native render cannot monopolize validation. Advertise accepted operations in a compatible worker profile and reject unqualified roles.
- Finalize handoff only after every required interval is verified; then existing generation quote/admission freezes remaining paid work. Neither session admission nor verification sends a provider request.
- Keep source content-equivalence/semantic claims separate from artifact safety: client source measurements and copy fingerprints are not a proof that a model will interpret the footage correctly.
- Regenerate proto/sql through normal tools; retain existing native stage compatibility, paid-call no-replay guarantees and private cleanup semantics. No database-engine migration is part of this task.
