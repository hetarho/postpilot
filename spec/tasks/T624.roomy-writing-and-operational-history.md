## goal
Make writing spacious and replace archive browsing with operational history.

## acceptance
- [v] New/saved writing preserves creation/history entry context, removes the unconditional post-list button, and returns safely after deletion while preserving autosave, mint/replace, caret, lifecycle and published locks.
- [v] Desktop editor uses the shell-aligned workspace frame with bounded prose inside; empty/short memo gets useful available height that grows with a taller viewport, rather than a fixed136px box and large auto-margin void.
- [v] Writing/clip history is compact chronological information with readable name/time, actual job/failure/unfinished state and relevant continuation/export actions; no article-reading preview or docked primary create CTA remains.
- [v] PostSummary projects actual content/export readiness, owner-entered published URL and latest relevant ordinary failure through post-owned queries/public job ports; history uses no per-row GetPost or cross-context table read.
- [v] Regression tests pin newest material flush, safe creation-origin mint/delete, published state, terminal polling and history empty/error/search/paging recovery. Browser measurements at1440x900/1920x1080 verify wider workspace and increasing authoring height; phones/200% zoom preserve input/caret and one scroller.

- [v] A post-owned test-result publication atomically checks owner, input/content revisions, frozen assignments, draft/review and active ordinary-job guard, then writes content/storyline/baseline/provenance with an idempotent receipt. Lost response, concurrent ordinary writing/manual edit and later changes never permit a stale overwrite.
