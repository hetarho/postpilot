## impl notes
- Parts: `type PreviewPart = 'intro' | 'caption' | 'outro'`, mapped to element roles `hook` · `caption` · `ending`. A part's start is the smallest `startMs` of the timeline elements with its role (the timeline from `sampleClipComposition` already times intro at 0, captions from the intro's end, the outro at `durationMs - CLIP_COMPOSITION_PREVIEW.outroMs`). Offered parts are those with a start, in intro → caption → outro order.
- Current part: the last offered part whose start is ≤ the drawn instant (`Math.min(time, duration - 1)`), else the first offered part.
- Switch: `SegmentedControl` from `@/shared/ui` (no native select, THEME-10), `ariaLabel` a new `composition.parts` string (ko `미리볼 부분`, en `Part to preview`); option labels reuse `composition.role.hook` / `composition.role.caption` / `composition.role.ending`. Choosing sets `time` to the part's start.
- Preset choice: in the intro/outro select `onChange`, after `setPresets`, set `time` to the intro/outro start when that part is offered.
- Caption styles arrive as a prop from the parent's checkboxes, so detect the change during render with React's "store information from previous renders" pattern: keep the last seen `captionStyles.join('|')` in state; when it differs, update it and, from the timeline computed in the same render, set `time` to the first caption whose `element.style` is the first added style, or to the caption start when a style was only removed. Compare the joined key, not array identity (parents pass a fresh array per render).
- Keep the frame's own markup, `data-*` attributes and the error branch unchanged; only the order of the section's children and the new switch change. The frame stays `CompositionDesignFrame` with `max-h-80`.
- Labels: `frontend/src/entities/clip-template/config/i18n.ts` `composition.design.intro_a/intro_b/outro_b/outro_e` in ko and en. `docs/design/clip-release-qa-260916.md` is a dated QA record and keeps its names.
- Integration/e2e: none; the full FE suite runs at the coordinator's push gate.
