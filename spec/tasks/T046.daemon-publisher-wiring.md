# T046 Wiring the real publisher into the daemon
> st:todo | ssot:PUB-16 PUB-18 PUB-23 PUB-29 | base:PUB@4 ARCH@2 | dep:T045

## goal
Give `runAgents` a real publisher factory so an armed Mac claims a queued job and drives it to a terminal result instead of refusing to start.

## acceptance
- [ ] `newPublisher` builds `naver.Publisher{Port: …}` from a `config.Connection`: it launches or reuses that connection's dedicated browser through `browser.OpenEditor`, binds T018's single-page session, and returns a publisher whose port is the `CommitPort` T045 completed
- [ ] the factory stays behind the existing `publisherFactory` type in `cmd/postpilot-agent/main.go`, so `runAgents` remains testable with a fake; the placeholder error and the test asserting it are deleted and replaced by coverage of the real path
- [ ] `postpilot-agent run` on an armed connection claims a queued job, drives it and reaches a terminal result; the per-account isolation T007 pinned still holds, and the owner-only file lock still permits exactly one daemon
- [ ] a browser that cannot be launched, a profile whose Naver login has expired, and a signature mismatch each produce the typed terminal result their decision requires rather than a panic or a silent retry
- [ ] tests: the factory builds a publisher from a connection with a fake browser and a fake port; `runAgents` drives one fake job end to end through the real factory shape; the two-account isolation test from T007 still passes; the launch, login-expiry and signature-mismatch failures map to their typed results
- [ ] ARCH-27 passes on macOS and CI's agent job is green

## impl notes
- `main.go` already carries the `diagnostics`/`diagnosticsWith` and `buildSupervisor`/`daemonDeps` seams T007 extracted; follow those rather than adding a new injection style
- `install` currently crash-loops because the daemon refuses to start without a publisher; this task is what makes `install` usable, so re-run the packaging install/uninstall check by hand once it lands
- this is the last task before T008's end-to-end verification, so leave the live smoke alone: no publication happens here
