# T188 An instruction lets the writer speak from experience
> st:todo | ssot:CLIP-122 CLIP-64 | base:CLIP@27 CDS@19 ARCH@2 | dep:T186

## goal
Where a project carries an instruction, stop refusing experiential and descriptive copy for lack of an owner phrase repeating it, while every figure still needs a field.

## acceptance
- [ ] with an instruction present, a generated sentence is no longer refused by the experiential-marker check in `GroundScopedText` (`evidence.go:362`)
- [ ] with no instruction, that check behaves exactly as it does today, asserted by the existing cases (→CLIP-64)
- [ ] the numeric half is untouched in both cases: a number, unit, currency or price basis still requires a referenced information field or item fact, and a global figure still cannot be presented as the depicted item's price (→CLIP-63)
- [ ] the scoped-fact rules, the item binding and the repeated-caption rule are untouched
- [ ] tests: the same generated sentence admitted with an instruction and refused without one, a figure refused in both cases, and the existing grounding cases still passing
- [ ] verify BE (ARCH-26) passes

## impl notes
- `GroundScopedText` takes the presence of an instruction as an argument; it does not read the instruction's text, so no phrase matching, similarity or classification enters the check
- presence, not content, is the switch: CLIP-122 puts the authority on the owner having asked and reviewing before publishing, and a rule that scanned the text would refuse exactly the paraphrases the owner asked for
- the omission notices this stops raising are the CLIP-108 ones for copy the owner wanted; nothing about notice rendering changes
