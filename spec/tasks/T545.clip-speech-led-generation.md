## goal
Add script → speech → footage-flow initial assembly within one approved bounded generation.

## acceptance
- [ ] Ordinary generation retains flow → caption writing; narrated generation performs script writing → approved synthesis → measured-timing flow writing → deterministic initial captions, with two writing calls plus the quoted speech scope.
- [ ] Fresh captions and scenes follow measured audio within 15–60 seconds and the chosen duration bound; generated caption shortening/readability repair never rewrites the spoken input.
- [ ] Overlong speech, missing alignment or insufficient footage preserves reusable completed checkpoints and presents an explicit conflict, with no hidden extra writing/synthesis or changed source rate/meaning.
- [ ] Generation/quote/recovery tests cover storyline and direct paths, regions, missing analysis, fixed-rate/transition timelines, price/correction ceilings and reuse; plan-estimate UI states separately quoted voice/dubbing work.

## impl notes
- Under DUB-27, implement and automatically verify this task with deterministic fixtures before live supplier qualification; do not promote production readiness from fixtures.
- Add a versioned narrated generation variant to existing clip generation manifests, prompts and checkpoints. Initial quote includes worst-case enforced script total (2000 characters/32 segments), at most one synthesis per segment and bounded script/flow writing with existing approved correction allowances. Total-character and request bounds must be enforced together before each call.
- For unknown initial text, reserve the enforceable maximum speech budget; actual planned text may be smaller but cannot create more calls or exceed total characters. A script exceeding the frozen policy stops before synthesis and preserves it for explicit revision; failed output validation is not permission to regenerate speech.
- Generate narration body separately from region display slots; place its first segment after the enabled intro interval and reserve enabled outro time. Resolve the full duration from measured speech plus region spans and any explicit silent padding needed for the 15-second minimum. Target overrun or unusable source capacity is a conflict, never audio time-stretch.
- When alignment is usable, derive initial caption windows from it inside CLIP-196 body intervals. Otherwise derive bounded readable phrase windows within each measured spoken segment and expose timing precision honestly; if the text cannot fit, repair/omit generated visible text with notices without altering speech.
- Give the second writer measured segment spans and bounded observations; keep its source/scene/rate eligibility. Storyline-first still stops after one storyline writing call; build-from-storyline follows the narrated variant. AI revision remains its separately priced two/one writing calls and marks affected speech stale.
- Preserve prompt versions and frozen model/voice/call fingerprints across recovery. Show speech as a real running stage in THEME-40 without pretending a render happened; no MP4 is emitted by generation.
