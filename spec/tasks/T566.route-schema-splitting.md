# T566 Keep lazily routed pages out of the entry chunk
> st:todo | ssot:ARCH-13 ARCH-16 ARCH-24 | base:ARCH@15 | dep:- | touches:frontend/package.json frontend/vite.config.ts frontend/src/app/routes/

## goal
Importing a page's search schema into `app/routes` (ARCH-16) no longer drags the page itself into the entry chunk, so TemplatePage, GuidelinesPage, the model leaderboard and the model-experiment pages load only when their route does.

## acceptance
- [ ] the page barrels' unused re-exports are tree-shaken: `frontend/package.json` declares `sideEffects` listing only the files that really have side effects (stylesheets, `src/app/main.tsx` and anything else the build proves must stay), or the equivalent `build.rollupOptions.treeshake.moduleSideEffects` rule in `vite.config.ts` if the package field is not honoured for app sources
- [ ] after `pnpm build:web`, the entry chunk contains none of TemplatePage, TemplateRequestBox, GuidelinesPage, ModelLeaderboardPage or the model-experiment page (check with a grep for a unique string from each), and those pages appear in their own lazy chunks
- [ ] `vite.config.ts`'s comment states the measured entry size; the 500 kB warning limit stays and the build prints no chunk-size warning for the entry, or the result records the remaining size and what holds it
- [ ] the app still boots: FE suite green, and the built app served by `pnpm --filter ./frontend preview` renders `/`, `/posts` and `/templates` with no console error (Playwright + the dev account recipe, or a manual check recorded in the result)
- [ ] behaviour unchanged otherwise: `pnpm lint`, `pnpm lint:fsd`, `pnpm lint:style:probe && pnpm lint:style` green

## impl notes
- from review/perf-cost-261004 F32
- ARCH-16 keeps the search schema exported by its page and ARCH-13 forbids reaching inside a slice, so the fix is tree-shaking, not moving the schemas or deep imports
- i18n namespaces are assembled by explicit imports in `app/providers/i18n`, not by side-effect imports — confirm before declaring a module side-effect free; anything that registers itself on import must stay in the list
- measured at review time: entry 975 kB raw / 288 kB gzip, 1.89 MB / 587 kB with 48 preloads
