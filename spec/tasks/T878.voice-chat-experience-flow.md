## goal
The chat opens by asking for one recent experience (kind + optional name), asks that experience's thread question by question, and falls back to imagined situations only when the owner has nothing in mind.

## acceptance
- [ ] First turn: the partner asks `최근에 다녀왔거나 써 본 것 하나만 떠올려 볼까요?` with the six kinds as choices and an optional name field (≤40 chars, `n / 40자`); choosing a kind and sending starts the experience (`useStartVoiceExperience`) and shows the owner's line as the name or the kind label.
- [ ] An experience asks one opening, three description and one closing question in thread order, with `promptText` naming it and T872's examples under the current question; `다른 얘기 할래요` swaps in the next unused question of the same part without counting; five saved replies close the experience.
- [ ] After the first experience the chat offers `경험 하나 더 이야기하기` (default) and `다른 장면으로 답하기`; after ten valid replies covering every part it offers the explicit analysis action as today. `생각나는 게 없어요` on the first turn moves to the starter situations (existing mode) with their examples.
- [ ] Later chats (`mode: 'more'`) open with `경험 하나 더 이야기하기` first and unanswered situations second, situations in catalog order (review moments first, T873).
- [ ] Resume: reopening the chat with an unfinished experience continues that experience at its next unanswered question; Back reopens the previous reply for editing as today; a failed save keeps the reply and the question.
- [ ] Machine tests in `questionnaire-machine.test.ts` cover: pick → five replies → offer; same-part swap; fallback to starters; resume mid-experience; two experiences of the same kind keep separate answers. A `VoiceLearningChat.test.tsx` case drives pick → first thread question with the name in the text.
- [ ] Task check passes: related vitest, ESLint and Prettier on changed files, `pnpm --filter ./frontend exec tsc -b`, `pnpm lint:fsd`, `pnpm lint:style`. Integration handoff: a browser walk of the chat (pick 맛집, five replies, second experience, analysis offer) belongs to the batch's integration owner (ARCH-31).

## impl notes
- Machine: add an `experience` phase before the situation phases; context gains `experienceId` and the thread cursor per part. Saved answers plus `ListVoiceExperiences` are the resume authority (VOICE-65); identify a thread answer by `(experienceId, promptKey)`.
- Kind choices use `shared/ui/choice` or `chip-toggle` (ARCH-20); the name field is the shared `field`. Kinds are plain labels without emoji.
- Keep the partner's lines code-owned (i18n) — no model call anywhere in the chat.
