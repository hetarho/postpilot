## goal
Prove that complete observations, authoritative assembly, owner correction, preview and export produce the same stable review clip across every supported rate and audio state.

## acceptance
- [ ] One deterministic source-owned corpus runs observation → writer → saved assembly → correction preview → export with same-source adjacent splits, reordered cuts, all six rates, certain/uncertain/unusable scenes and item-bound copy without unsupported claims or silent plan changes.
- [ ] The matrix covers source audio off, on, mixed, enabled-but-silent and per-cut zero volume; enabled speech retains pitch, disabled originals do not enter the mix, and the all-off result has no audio stream or in-product BGM.
- [ ] All three ratios and sentence/rapid paces compare source range, cut id/order/rate, transformed duration, transition, crop, caption/element interval, source-audio state and representative frames between the browser manifest and final export within the declared frame-timing limits.
- [ ] Unsupported rate, insufficient cadence, overlap, observation gap, unusable span and invalid authored interval preserve the exact draft and previous result with typed diagnostics; no case silently substitutes 1x, drops a cut/text or starts an unapproved provider call.
- [ ] A render failure after valid assembly followed by continuation makes zero repeated observation/writer calls and uses the latest owner sound setting; a changed sound toggle stales only the render, while changed observation/assembly inputs invalidate only the incompatible recovery stage.
- [ ] Migration fixtures cover v0-v4 correction, portable v5, v1 observations and legacy audio inference; existing result bytes and behavior remain unchanged until an explicit v6 save/rerender, and v1 observations are never promoted to v2 reuse.
- [ ] Production media verification covers 30/40/60 fps originals, CFR slow-rate admission, VFR/unknown refusal, fixed-rate duration and pitch, optional audio output and same-source splits under the existing nonroot resource limits.
- [ ] Full local ARCH gates, deterministic proto/SQL regeneration and spec lint pass; fixture/model responses are recorded and synthetic, no paid AI call, private footage, deployment or Naver publication is part of this task.
- [ ] Archive a concise hashed evidence index outside the repository and record remaining browser-decoder, final loudness and physical-device limits without treating T110 as completed.

## impl notes
- Extend the existing clip quality-release, composition-quality, media smoke/stress and frontend preview corpora rather than creating a second pipeline. Assertions compare semantic manifests and frame/sample boundaries, not only JSON validity or a playable MP4.
- Use generated tone and speech-like fixtures with known cadence to measure output duration and dominant frequency at every rate. Keep personal/customer footage and provider payloads outside the repository.
- Exercise response correction with recorded malformed rate/overlap outputs and explicit exhaustion/cancellation; no live model quality claim is made from fixtures.
- Run T110 only under its separate owner/device conditions after refreshing its CLIP/CDS base; this task does not edit, unblock or claim that immutable task.
