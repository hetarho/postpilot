## goal
Render blur-in, ambient, neon, iridescent and glitch with bounded qualified GPU effects.

## acceptance
- [ ] Every style reproduces its existing colour, motion, mask, pulse/flicker and band behavior from output frame/time, including deterministic glitch state.
- [ ] Filters operate on the required text/effect region with adequate glow/shadow bleed, preserve sRGB/premultiplied-alpha handling and clip no visible letters.
- [ ] Static ink/shadows/gradient resources are reused; animated uniforms/geometry update without a per-frame SVG/PNG text regeneration or server request.
- [ ] Blur/glow extrema, bright/dark backgrounds, rare glyphs, two-line copy and all ratios/paces are compared with native reference frames.
- [ ] Context loss, unsupported filter execution, cancellation and eviction clean resources and refuse the actual style when equivalent output cannot be produced.
- [ ] Real-browser stress/resource/frame tests and required local checks pass; newly bundled filter/shader dependencies have exact-version license evidence.

## impl notes
- Use PixiJS core BlurFilter and selected PixiJS Filters 6 primitives where they match the existing painter; authored shaders remain product code.
- Existing neon uses changing Gaussian radii and intentional repeated glow composition; a generic GlowFilter preset is not automatically appearance-equivalent.
- Glitch's RGB offsets and six horizontal bands and iridescent's moving stops come from the existing deterministic functions, not a random filter default.
- Measure cropped filter passes against the Canvas 2D control; record peak GPU/resource use and no zero-copy or faster-by-default assumption.
- Keep the runtime version and effect implementation in the frozen component catalog so qualified caches cannot cross incompatible builds.
