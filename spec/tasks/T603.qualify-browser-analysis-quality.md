## acceptance
- [ ] A versioned authorized corpus includes small Korean labels/prices/numbers, brief actions/fast cuts, ordinary scenes, speech and focus/shake cases with human-grounded facts and source-time boundaries.
- [ ] The comparison records original/high-quality reference, current native proxy and browser proxy, fixing model/endpoint/prompt/settings and isolating encoder changes from resolution/FPS changes.

- [ ] Actual provider sampling/internal resolution and unsupported controls are recorded; no unsupported option or claim that file FPS equals model sampling is introduced.

## impl notes
- Parallel group execution uses isolated worktrees; exact final cross-slice edits remain uncertain (touches:-). Coordinate shared public exports and adapter seams explicitly; review and integration are serial and resolve overlap without shared-checkout writes.
- Build a reusable diagnostic runner, distinct from ordinary production generation and CI. Offline fixtures prove score/report structure only, not AI quality.
- Use private operator-owned or explicitly licensed fixtures and record their provenance; no arbitrary user's originals or retained speech enter a public benchmark artifact.
- Reference inputs may use a separately bounded diagnostic profile when higher resolution is needed; this does not widen CLIP-29's production limits or bypass endpoint/pricing qualification.
- Record browser/native dimensions, codec/bitrate, decoded frame/audio coverage and preparation version. Same size and codec are not equivalence proof.
- Gemini static sampling and media resolution are independent of upload file FPS/resolution; OpenRouter support must be verified for the actual endpoint. Do not add agentic processing or automatic high-detail reanalysis.
- Live execution has no inferred spending allowance. Obtain/record the required explicit cumulative cap before billable calls; without it complete only harness/offline work and retain the real-qualification gate.
- Qualification requires no additional critical factual invention or loss of required grounded content relative to the native/reference comparison; unexplained event, speech or timing regression blocks activation rather than being averaged away.
- A successful profile is version-bound; later encoder/profile/model-route changes invalidate only incompatible qualification/reuse under CLIP-93. Existing voice/narration readiness is not opened.
