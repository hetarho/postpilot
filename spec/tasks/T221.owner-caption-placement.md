# T221 The owner places, sizes and restyles a caption
> st:todo | ssot:CLIP-143 CDS-82 CDS-38 CDS-52 CDS-74 CLIP-15 | base:CLIP@32 CDS@21 | dep:T219

## goal
Let a caption carry its own absolute position, size and style, clamped to the safe area, and make automatic placement a starting point the owner's value replaces.

## acceptance
- [ ] a plan caption may carry an absolute position, a size and a style id; absent values mean automatic placement and the project's default style, exactly as today
- [ ] an owner-placed caption's measured bounds are clamped inside the ratio's safe area at store time and again at layout, and a size below CDS-3's floor for its role is refused where it is written
- [ ] automatic placement never re-runs over a caption that carries its own position
- [ ] V1 counts an owner placement, V3 records an owner-placed contrast shortfall as a notice instead of a failure, V13 skips an owner-placed caption, and V19 accepts the face the caption's style names
- [ ] `SaveEditPlan` accepts and round-trips the three fields, and a plan saved before them decodes with all three absent
- [ ] layout and verifier tests cover clamping at every ratio, the contrast notice, the skipped anchor-step check and a style outside the allowed set
- [ ] ARCH-26 passes

## impl notes
- position is stored as the caption's own top-left on the 1080-wide canvas of its ratio, in integers ← the layout already resolves everything to canvas pixels and a fraction would not survive the round trip identically
- clamping moves the caption rather than shrinking it ← shrinking would silently change a size the owner set, and CDS-82 clamps position only
- size is stored as the role's font size in px, not a scale factor, so the CDS-3 floor is checked against the same number the renderer uses
- the contrast notice reuses CLIP-108's notice record with the caption named; no new notice kind is introduced
