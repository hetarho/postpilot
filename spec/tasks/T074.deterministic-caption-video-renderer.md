# T074 Deterministic caption and video renderer

## goal
Render an approved edit plan into one stable MP4 with subject-aware crops, exact Pretendard copy, three visual styles, per-cut audio and restrained fades.

## acceptance
- [ ] the repository carries a pinned official Pretendard Variable font file and its OFL license; rendering loads that file explicitly and disables system-font discovery
- [ ] a pinned static `resvg` CLI is built from its official source into the production image and converts generated SVG copy plates to transparent PNG with `--skip-system-fonts` and the bundled font only
- [ ] the renderer maps ratios to exact canvases: vertical 1080×1920, horizontal 1920×1080, square 1080×1080; video is cover-cropped around the plan's normalized focal point and never stretched
- [ ] copy positions are `top|center|bottom` inside ratio-specific safe regions; the placement validator rejects a caption outside them and the planner's avoid region can move a caption only among those approved positions
- [ ] styles are exact code-owned recipes: `clean` = lower translucent dark rounded card with white semibold copy, `diary` = cream rounded label with dark semibold copy, `emphasis` = large bold white copy with a dark outline; the optional accent is restricted to the T069 palette
- [ ] text is XML-escaped, fit by measured glyph bounds, wrapped at grapheme boundaries to at most two lines and never replaced by generated pixels; text that cannot fit at the style's minimum size returns `CLIP_COPY_TOO_LONG`
- [ ] each cut trims only inside its source, keeps original audio by default, applies volume from 0.0–1.0, synthesizes silence for a source without audio, and overlaps adjacent video/audio by a 200 ms fade without changing the requested final timeline length
- [ ] output is MP4 with H.264, AAC when any source has audio, yuv420p, constant 30 fps, square pixels and fast-start metadata; duration is 15–90 seconds and differs from the validated plan by at most one frame
- [ ] the render contract contains no background-music, arbitrary font, decoration, animation or generated-media field, and no direct-publish behavior
- [ ] generated SVG and FFmpeg filter graphs have golden tests; a Docker integration test renders all three ratios and styles from rotated/audio/silent fixtures, extracts frames for PNG assertions and probes the final codec, dimensions, duration and audio volume
- [ ] the current official Naver Clip help is rechecked at implementation; the fixture output is manually accepted by Naver's upload picker or any changed acceptance constraint is returned to `update-ssot CLIP` before code is marked done
- [ ] ARCH-26 passes and the production Docker image completes the renderer smoke test as nonroot

## impl notes
- generate SVG in Go and rasterize it with `resvg`; it is static, dependency-free at runtime and accepts explicit font files, while FFmpeg `drawtext` makes the rounded-card and Korean layout recipes harder to hold pixel-stable
- use stable accent ids with a fixed initial palette: `coral #ff6b5f`, `amber #ffb23f`, `lime #b8d94a`, `teal #43c5b5`, `blue #5b8def`, `violet #8b6fe8`, `pink #e96aae`; `none` uses each style's neutral recipe
- represent time in integer milliseconds in the domain and convert to FFmpeg seconds only at the adapter boundary; floats must never become persisted edit-plan authority
- use filter-complex with explicit stream labels and one concat/xfade plan assembled from validated domain values; user strings never enter command arguments as filter syntax because captions are already PNG paths
- keep Naver validation read-only: T074 may test the file picker with owner help but never clicks a publish/submit control
