## goal
Let owners paste an AI-authored video template or edit its composition and grouped project inputs without category presets.

## acceptance
- [ ] 원문, the composition editor and one save action share one draft; switching without edits is byte-exact, malformed pasted text stays recoverable and errors identify line/element.
- [ ] The copyable format guide describes the implemented grammar, bounds and a valid several-menu example; original body copy and external-AI paste require no provider call or credits.
- [ ] Controls cover required/optional fields, repeated item definitions, scene/context guidance, fixed/generated text, card rows, approved positions/styles and start/end/cut/whole timing.
- [ ] Project setup renders only template-defined fields, supports adding/removing several independently identified items, and shows no preset/campaign selector or universal price requirement.
- [ ] Existing templates/projects show their converted editable content and disclosure choices, with no automatic save on opening; an invalid edit never overwrites a saved template.
- [ ] Interaction tests cover source/builder round trips, optional blank fields, stable item IDs, renaming labels, invalid intervals, copy actions, migration, ko/en and 320–430 px keyboard layouts.
- [ ] Run the applicable local ARCH-25 through ARCH-29 checks, deterministic proto/SQL regeneration when changed, and spec lint; use a before/after generation snapshot when unrelated generated changes already exist.

## impl notes
- Extend entities/clip-template with the composition editor and guide backed by T125 grammar/corpus. features/edit-clip-template owns the shared draft/save; pages/video-template composes it. Use post-template source/builder interaction patterns without importing a sibling feature.
- Use shared Textarea, TextField, Listbox, Checkbox, SortableList, disclosure and ActionBar primitives. Keep source syntax inside 원문, plain labels elsewhere and one expanded element editor at a time. Role/timing controls are authored content decisions, not implementation jargon.
- Project input groups belong in entities/clip-project reusable UI and features/edit-clip-project draft saving. Serialize item IDs and field IDs, never array offsets or labels as identity. Switching a template must not silently remap similarly named fields; retain old facts in the prior generation snapshot.
- Preview a template with clearly illustrative input values and a duration/ratio control, using the same pure timing/validation model. It validates composition structure without pretending sample footage is the owner's generated clip; real draft playback is T130/T131.
- Keep one committing save and standard list/editor chrome; show backend capability refusal if the generation version is not yet available. Do not expose retired SeedPresetFields, campaign or CTA enums as authoring options.
