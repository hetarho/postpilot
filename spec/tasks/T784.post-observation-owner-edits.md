## goal
The owner's corrections to an observation are saved with the draft, kept as the owner's material by every later run, and attributed as the owner's own meaning.

## acceptance
- [ ] SavePostDraft accepts observation edits per attachment filename for `scene`, `mood`, `visible_text`, `objects` and, for a video, `events`; a save replaces those fields, changes no status, revision or baseline, and refuses an unknown filename (InvalidArgument), a published post (existing lock) and a post whose observation-writing job (observe, generate, storyline) is active (`POST_BUSY`, as a storyline edit is refused).
- [ ] An edited entry is stored with `OwnerEdited` and the cumulative set of fields the owner changed; GetPost projects `owner_edited` on each Observation; deleting the attachment still deletes its entry (POST-18).
- [ ] Every run reuses an owner-edited entry unchanged whatever observe model is selected, even when the owner emptied every field (never forced into re-observation); only an observation job that selected that file replaces it, and the fresh entry carries no owner mark.
- [ ] Writing origin material offers each owner-changed field as owner-supplied material compatible with the `owner_input` category, and the unchanged fields stay visual observation (GEN-80).
- [ ] Tests: `backend/internal/post/observation_edit_test.go` (save, field replacement, refusals, flag and field set), `backend/internal/post/rpc` handler test for the request and projection, `backend/internal/generation/reobserve_test.go` (owner-edited reusable, empty owner entry not forced, replaced only when selected), `backend/internal/generation/origin_material_test.go` or the existing origin test (owner fields as owner-input sources, validation accepts them).
- [ ] `pnpm gen:proto` leaves no diff after commit; gofmt, `go vet ./...`, `go build ./...` and the selected `go test` packages pass.

- Save path: mirror the storyline precedent — `DraftSave.Observations []ObservationEdit` in `backend/internal/post/service.go` (`SaveDraft` :154), a guard beside `checkStorylineEdit` (`storyline.go:70`), and persistence through the same draft transaction. `ObservationEdit{File string; Scene, Mood, VisibleText *string; Objects, Events *[]string}` — nil means untouched; a field whose saved value differs from the stored one joins `OwnerFields`.
- Proto: `message ObservationEdit { string file = 1; optional string scene = 2; optional string mood = 3; optional string visible_text = 4; repeated string objects = 5; bool objects_set = 6; repeated string events = 7; bool events_set = 8; }` and `repeated ObservationEdit observation_edits = <next free>` on `SavePostDraftRequest`; `bool owner_edited = <next free>` on `message Observation` (:135). - Reuse: in `backend/internal/generation/observe.go`, `reusableObservations` and the forced check treat `OwnerEdited` as reusable before `observationEmpty`; `mergeObservations` already lets a fresh entry replace the old one.
