## goal
Compute the existing scrim, accent and contrast decisions locally without a server sampling job.

## acceptance
- [ ] First/middle/last sampling uses the frozen layout and the actual original-footage rate/crop/transition composition at the same output frame indexes as the native reference.
- [ ] Rec.709/WCAG region measurements, thresholds, scrim choice, accent-to-white and contrast notices match the current rules across ratios and text roles.
- [ ] Analysis copies, thumbnails, another plan's samples and stale callbacks cannot supply a render's background evidence.
- [ ] A browser render needs no sample media job, server footage intermediate or frame-sheet request; missing originals/measurement capability refuses without unsampled output.
- [ ] Measurements/notices remain bound to the render revision and producing-side verdict, including upload promotion and cancellation races.
- [ ] Bright/dark/noisy sources, threshold boundaries, fades/fade-through-black, cross-cut captions and resource-release tests plus actual browser/native comparisons pass with required checks.

## impl notes
- Use backend/internal/clip/media/ground_sampler.go and existing luminance fixtures as the semantic reference, including mean-of-blends and fade-black clipping.
- Begin with bounded sampled-region pixel reads where necessary to preserve thresholds. Do not read an entire canvas back on every exported frame; a GPU reduction is an optimization only after equivalent decisions are established.
- Layout is resolved before sampling; only paint/scrim decisions change afterward. Deduplicate compatible source frame reads and bound the cache by pixels/bytes.
- Extend the browser verdict/admission contract additively if measurements need durable identity; server-side plan checks remain authoritative without rerendering captions.
- Keep native sampling for Max execution and regression reference; remove only the new browser path's dependence on it.
