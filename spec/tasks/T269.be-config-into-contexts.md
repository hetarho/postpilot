# T269 platform/config holds env only; limits live in their context
> st:todo | ssot:ARCH-21 ARCH-7 ARCH-6 | base:ARCH@5 | dep:-

## goal
Move every product constant out of `backend/internal/platform/config` into the owning context and make platform import no domain package.

## acceptance
- [ ] `internal/platform/config` imports nothing under `internal/` except `platform/*`; `config.go`'s `internal/llm` import and the `clip*.go` imports of `clip`, `clip/ai`, `clip/composition`, `clip/design` are gone
- [ ] clip limits (`ClipMinDurationMS`, `ClipSourceCount`, `MaxSegments`, `PlanCompletionTokens`, FPS/CRF, retention windows) are `clip.DefaultLimits()` (or `clip.Limits` fields with defaults) in the clip context; `clip/store/*` and the clip services read them from the `clip` package, never from `config`
- [ ] post tag range and voice personalization thresholds live in `post` and `voice` (`post.TagCountRange`, `voice.PersonalizationThresholds`); `generation/config.go` and `generation/revise.go` read them from `post`/`voice`, not from `config`
- [ ] `platform/config` keeps parsing env into the typed struct; where an env var overrides a domain default, `cmd/api` merges it into the domain config at construction (`clip.Limits{...}.WithEnv(cfg)` or a plain struct literal) — the domain never reads env
- [ ] a test in `platform/config` pins the import surface (`go list -deps` or a `depguard`-style check) so a domain import fails CI; existing context tests pass
- [ ] behaviour unchanged: ARCH-26 passes; the clip release smoke (`CLIP_RELEASE_SMOKE`) is run once locally because it exercises the limits (ARCH-37)

## impl notes
- from review/arch-260919 F14
- ARCH-21 r4: platform/config = env + cross-context only; limits are named constants in the owning context that the ctor merges env into
- the near-cycle today is `clip/store → platform/config → clip`; after the move `platform/config` has no domain edge and `clip/store → clip` is the normal inward edge
- keep the env names in `.env.example` unchanged; only the Go home of the default value moves
