# T163 Replace the information pill with a product-drawn frame family
> st:todo | ssot:CDS-69 CDS-30 CDS-16 CDS-44 | base:CDS@14 ARCH@2 | dep:-

## goal
Information-role elements render in our own drawn SVG frames instead of one uniform ink.900 pill.

## acceptance
- [ ] the frame family is defined in `backend/internal/clip/design/design.json` with two variants: an emphasis variant (one short name at `t.title`, `stroke.text` and `shadow.text`, no plate) and a compact plated variant (label/value pair)
- [ ] the drawn SVG geometry lives beside the existing overlay assets and is versioned; it is authored art, not AI-generated lettering, and all text is still typeset from bundled fonts (CDS-17)
- [ ] `layoutDeclaredInfo` in `backend/internal/clip/media/composition_roles.go` selects the variant and measures against the drawn frame's real padding
- [ ] the compact variant needs no brightness sampling (CDS-16); the unplated emphasis variant takes the CDS-44 treatment — sampled L and σ, scrim when L ≥ 0.6 or σ ≥ 0.25
- [ ] the disclosure badge is untouched and never uses the family (CDS-69, CDS-15)
- [ ] V1 safe area, V2 size floors and V3 contrast still pass for both variants in all three ratios
- [ ] worked SVG plates and the measurement method are added to `docs/design/clip-output-design-spec-v1.md`
- [ ] test: both variants in 9:16, 16:9 and 1:1 stay inside the safe area and meet the size and contrast floors
- [ ] test: the emphasis variant over a bright frame gains the scrim; over a dark frame it does not
- [ ] test: a disclosure badge in the same header interval keeps its own contract and does not adopt a frame
- [ ] `cd backend && test -z "$(gofmt -l .)" && go vet ./... && go build ./... && go test ./...`

## impl notes
- what this replaces: the shipped `된장찌개 · 3000` and `해미연풍우가` pills the owner rejected; the emphasis variant is for a single short name (상호), the compact one for label/value pairs (가격, 점수)
- `role="info"` accepts only `style="auto"` (CDS-66), so variant choice is the renderer's, driven by the element's resolved content shape — one short value → emphasis, a label/value pair → compact — never by a template style attribute
- CDS-30 keeps the existing header defaults (TOP/LEFT at 96, 80), gap.stack, at most two per row and width ≤ 600 px; only the drawing changes
- `arrangeDeclaredHeader` resizes header rows to a shared height — the emphasis variant's larger type must flow through `resizeHeader` without breaking the badge's own row
