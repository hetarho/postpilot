# T282 Stop and uninstall existing Mac publishing companions
> st:todo | ssot:PUB-39 PUB-41 PUB-44 PUB-48 ARCH-27 ARCH-43 | base:PUB@6 ARCH@7 | dep:T311

## goal
Provide a one-use local retirement command that stops installed publishing execution and removes its app-owned credentials/files without touching Naver.

## acceptance
- [ ] The retirement utility stops and verifies removal of com.postpilot.publishing-agent from the current user LaunchAgent domain before deleting files; inability to stop a still-running daemon is an error and does not claim success.
- [ ] Known active and pending connection credentials are deleted by the stored KeychainAccount under service com.postpilot.publishing-agent; absent entries are idempotent, unrelated Keychain entries are untouched, and no token is retrieved merely to remove it.
- [ ] Remove the companion binary/plist, enumerated job files, config and logs only after their required credential/path inventory is retained for retry; partial failures leave a minimal local recovery record. Browser profile directories, browser binaries, unrelated files and unknown legacy directories survive by default.
- [ ] A separate explicit local profile-deletion option shows the exact owned paths and refuses symlink/path escape or uncertain ownership; no profile is erased by ordinary uninstall, revocation, inspection or server cleanup.
- [ ] The transitional agent binary and install/setup/run/diagnostic entry points cannot arm a connection, bootstrap a daemon, open the Naver editor or execute a publication; install directs to retirement instead of launching KeepAlive work.
- [ ] Tests with fake launchctl/Keychain/filesystem seams cover active/pending/multiple connections, repeated runs, missing config, malformed/unowned paths, partial failures and preserved profiles. Normal tests never call the real developer Keychain or stop a real daemon.
- [ ] ARCH-27 passes while agent/ still exists; document local invocation and a per-device shutdown receipt without uploading local browser paths. No live publish is used as validation.

## impl notes
- Replaces this todo task's prior adapter/preflight refactor under PUB r6; retain the old scope only in Git/review history. T008 is not a dependency and must not be resumed.
- Add a local retire command to the existing Go binary with an inspection-first default and explicit apply mode; it performs no network request. Treat uninstall as retirement-safe; reject obsolete publishing entry points with actionable local text. Do not run packaging/install.sh as a validation shortcut.
- Read config.Connection.KeychainAccount and pending enrollments, not guessed account names; include unfinished connection drafts in the path inventory. Never remove the entire Application Support root when it still contains preserved profiles or unknown files.
- Keep a mode-0600 local receipt outside directories being deleted so interrupted cleanup can finish. It may name local paths for the owner; the server retirement report excludes those paths. Missing config cannot prove that no credential exists, so report unresolved ownership instead of deleting by a global service wildcard.
- Stop only verified companion processes, including any identified manual run instance; do not kill every Go/Chrome process. Old stored jobs can never be restarted to inspect their state. A failed process-ownership check blocks a shutdown-complete receipt.
- T312's deployed cleanup requires receipts for every installed companion from T310's inventory, or an explicit operator inventory reconciliation showing a device was never installed/already destroyed. An offline or unknown device is unresolved, not automatically stopped.
- Keep agent source and its Mac verification job until T284. DEPLOY.md names the reviewed retirement build to use later without bootstrapping the former installer; compilation can be validated with fakes, but actual Mac shutdown is a separately recorded rollout checkpoint.
