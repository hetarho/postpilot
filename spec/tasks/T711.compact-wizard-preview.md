## goal
The template preview reads as a compact post (line bars, a small photo strip, no full-width squares), and the wizard shows it beside every step from sections on: right column at lg, a glowing 미리보기 button → bottom sheet below lg, the current section marked.

## acceptance
- [ ] shared stand-ins in `entities/template/ui/PreviewStandIns.tsx` (post card, AI line bars with topic, photo strip of `count` small tiles + count, answer chip, fixed text, repeat drawn twice) are used by `TemplatePreview`
- [ ] `WizardPreview` draws checked sections in order with each heading as a 소제목, the AI-written title as a stand-in, and the section-step's section marked (`aria-current`)
- [ ] from sections to finish: at `lg` the preview stands right and sticky beside a readable-measure step; below `lg` a sticky `미리보기` button opens it in a `Sheet`; the target questions show no preview; FinishStep no longer embeds a preview
- [ ] the button glows once per preview change (not on first paint) via a new keyframe the global reduced-motion rule stills
- [ ] tests: `TemplatePreview.test.tsx` updated; new `WizardPreview.test.tsx` (order, headings, current mark, photo count, repeat twice); a wizard test that the sheet opens from 미리보기 below lg markup

## impl notes
- `WizardFrame` gains optional `beforeActions?: ReactNode`, rendered between the body and the action row so a `sticky bottom-4` child floats at the viewport bottom and settles above 이전/다음
- layout in `TemplateWizard`: non-target steps wrap `lg:grid lg:grid-cols-[minmax(0,1fr)_minmax(0,22rem)] lg:gap-10`, the frame column `max-w-2xl`; the aside `hidden lg:block sticky top-6 self-start` with its own scroll; the current section scrolls into view inside the preview with `block: 'nearest'`
- glow: `--animate-preview-glow` keyframe (opacity+scale halo, once) in `app/styles/index.css`; retrigger by keying the halo span on a change counter derived from `toWizardBody(sections)`; no travelling border
- the Sheet uses `size="wide"` and its label 미리보기; tokens: `bg-surface-recessed` bars/tiles, `bg-badge-accent-bg`/`text-badge-accent-fg` for the answer chip and the current-section mark, lucide `Image` and `Sparkles`
- stand-ins carry no sample prose (TMPL-66) and no grammar syntax (TMPL-26)
