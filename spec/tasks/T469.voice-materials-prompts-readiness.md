## goal
A voice gathers 학습 글 — pasted posts and answers to 20 shared prompts, a photo prompt answered on the owner's own photo — with no model call; a readiness meter counts prose sentences and parts; and the analysis runs only when the owner presses 말투 만들기 or 다시 분석 (the analysis itself stays the current one until T471).

## acceptance
- [ ] `voice_samples` holds both kinds: a migration rebuilds it with `kind` (`post` | `answer`), `prompt_key`, `photo_key`, `photo_width` and `photo_height` under a table CHECK (a post has no prompt and no photo, an answer has a prompt), one answer per `(voice_id, prompt_key)`, and existing rows become posts; it also creates `voice_photo_uploads`
- [ ] the 20 prompts of impl notes are a code constant served by `ListVoicePrompts`; `AnswerVoicePrompt` stores a trimmed non-empty answer, refuses an unknown prompt (`VOICE_PROMPT_NOT_FOUND`), a second answer (`VOICE_PROMPT_ANSWERED`), an empty one (`VOICE_ANSWER_REQUIRED`) and a photo prompt without an uploaded photo (`VOICE_PHOTO_REQUIRED`)
- [ ] a photo prompt's photo goes through `CreateVoicePhotoUpload` (presigned `image/jpeg` PUT to `voices/{voice_id}/{random id}.jpg`) and is confirmed by a HEAD inside `AnswerVoicePrompt` with POST-36's size and dimension limits; `GetVoiceSample` returns the full body and a 10-minute presigned view URL; deleting a 학습 글 removes the row, then the object
- [ ] a voice-owned orphan sweep reclaims expired pending uploads and `voices/` objects no row names, on the post sweep's interval and rules (never at boot, a failed listing deletes nothing)
- [ ] `AddVoiceSample` and `DeleteVoiceSample` enqueue nothing (`AddVoiceSampleRequest.model` and both `job_id` fields reserved); `AnalyzeVoice(voice_id, model)` enqueues `analyze_voice` only at 100% (`VOICE_NOT_READY` otherwise) with a model registered to the analyze stage; the analysis publishes the snapshot it read and never repeats itself
- [ ] non-prose lines (VOICE-61) are left out of the sentence count and the analysis corpus, pinned by table tests over a pasted Naver post (place card, 영업시간, hashtags, `[출처]`, an address, a URL-only line)
- [ ] readiness is 60 prose sentences plus at least one opening, one description and one closing (a post counts as all three, an answer as its prompt's part), `N` held at 99 while a part is missing; `GetVoiceProfile` returns it with `made`, and `ListVoices` returns `made`, the readiness percent, the 학습 글 count and the analysis date
- [ ] FE: the voice's second tab is 학습 글 at `/voices/$voiceId/materials` (가져오기 and `/import` are gone): the meter, `글 붙여넣기`, `문항 풀기` grouped 글머리 · 본문 · 마무리 with answered prompts marked, the 학습 글 list opening each entry to its full text and photo with `삭제`, and `말투 만들기` / `다시 분석` disabled below 100% or without an active analyze selection, each saying why; a new voice lands here
- [ ] the directory row's meta line and ①'s picker show `만드는 중 N%` for a voice not yet made
- [ ] tests: voice service, store, prose and readiness table tests, the migration test, rpc tests for the new RPCs and reasons, the sweep test; FE tests for the 학습 글 tab (paste, answer with and without a photo, open, delete, meter states, 말투 만들기 gating), `VoicesPage`, `PostVoiceSelect`, routes

- Schema: rebuild `voice_samples` the 0009 way (`_new` table, copy with `kind = 'post'`, drop, rename, recreate `voice_samples_voice_created_idx`) with `CHECK ((kind = 'post' AND prompt_key IS NULL AND photo_key IS NULL) OR (kind = 'answer' AND prompt_key IS NOT NULL))` and `CREATE UNIQUE INDEX voice_samples_voice_prompt ON voice_samples(voice_id, prompt_key) WHERE prompt_key IS NOT NULL`; `voice_photo_uploads(id PK, user_id FK cascade, voice_id, prompt_key, object_key, expires_at, created_at, FOREIGN KEY (voice_id, user_id) REFERENCES voices(id, user_id))`
- Storage: the voice context declares its own `ObjectStore` port (PresignPut, PresignGet, Head, Delete, List — the post port's shape) adapted over `internal/storage` in `cmd/api`; the object id is 16 random bytes hex; the pending upload expires with `PRESIGN_PUT_TTL`; `AnswerVoicePrompt` HEADs the object, refuses a missing one `VOICE_PHOTO_REQUIRED`, deletes an oversized one (reuse the post upload's size and dimension reasons), and writes the answer and drops the pending row in one transaction
- Sweep: `voice.SweepPhotos` mirrors `post/sweep.go` for the `voices/` prefix (`ORPHAN_MIN_AGE`, referenced keys read in one transaction), scheduled beside the post sweep in `cmd/api`
- Prose (`voice/prose.go`, standard library only): a line is not prose when, trimmed, it is empty; every whitespace token starts with `#`; it starts with `[출처]`; it matches `^(주소|영업시간|운영시간|전화|휴무|주차|가격|위치)(\s*[:：]|\s)` or starts with 📍, ⏰ or ☎ (with or without U+FE0F); it starts with a 시·도 name (서울 부산 대구 인천 광주 대전 울산 세종 경기 강원 충북 충남 전북 전남 경북 경남 제주, full or short form) and holds a token ending in 시 · 군 · 구 and a digit; or it holds no Hangul (U+AC00–U+D7A3, U+3131–U+318E); sentences are `SegmentSentences` over the prose lines
- Readiness: `percent = floor(min(sentences, 60) / 60 × 100)`, capped at 99 while a part is missing; the response names the missing parts; FE copy `말투 학습에 필요한 정보 N% 확보`, `아직 없는 부분: 글머리 · 마무리`, and at 100% `이제 말투를 만들 수 있어요`
