# T226 The approval surface quotes sequence-rendered captions separately
> st:todo | ssot:CDS-81 CLIP-19 | base:CDS@21 CLIP@32 | dep:T220

## goal
Count and show the sequence-rendered captions and their added render time before the owner approves a generation or a rerender.

## acceptance
- [ ] the quote carries the number of sequence-rendered captions the current plan or selection implies and the render time they add, measured from the style registry rather than guessed
- [ ] ① and ② show both numbers on the approval surface beside the existing credit ceiling
- [ ] no ceiling is enforced and nothing is refused for the count alone (→CLIP-145)
- [ ] a project using only static styles shows the count as zero and the added time as none
- [ ] backend tests pin the count for a mixed plan and the frontend renders both numbers
- [ ] ARCH-25 and ARCH-26 pass

## impl notes
- the added time is stated as a measured per-frame cost from the style registry times the frames each caption covers ← CLIP-145 is open precisely because a ceiling needs real numbers first, and this surface is where they accumulate
- the count is not a credit line: sequence rendering consumes no AI call and CLIP-20 keeps rendering credit-free
