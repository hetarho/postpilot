# T554 Send a template-request correction with only the answer it corrects
> st:todo | ssot:ARCH-24 | base:ARCH@15 | dep:T553 | touches:backend/internal/template/request.go

## goal
Each correction call carries the request, the last wrong answer and what it broke — not every earlier wrong answer — so a three-correction request no longer pays for the history twice over.

## acceptance
- [ ] `RunRequest` builds each correction's messages as `[request, last answer (assistant), correction (user)]`; earlier wrong answers are dropped
- [ ] test: a fake model that fails the rules twice sees exactly three messages on the second and third calls, and the third call's assistant message is the second answer
- [ ] behaviour unchanged otherwise (same correction count, same refusal on `length`/`content_filter`, same ctx check before a paid correction): ARCH-26 green
